# 业务理解

- 软件名称：广告视频内容检索分析系统
- 产品定位：面向广告视频素材审核、投放复盘和内容分析场景的本地 Web 检索分析工具，围绕广告视频的语音文本、画面文字、视觉标签和素材说明建立证据包，并支持基于证据的语义检索和问答分析。
- 面向领域 / 行业：广告营销与视频内容分析
- 核心价值：把分散的广告视频线索整理成可查看、可检索、可追溯的证据记录，帮助用户围绕促销、背书、行动号召等广告要素快速查找素材并形成问答分析结果。
- 证据文件：`业务理解证据.md`

## 目标用户

- 广告投放运营人员
- 品牌内容分析人员
- 视频素材审核人员
- 广告营销研究或测试人员

## 主要业务功能

- 系统总览与运行状态查看
- 广告视频素材登记
- 识别结果批量导入
- 内容预处理与证据包生成
- 广告语义检索
- 广告视频问答分析
- 分析历史记录管理

## 功能说明

- 系统总览与运行状态查看：系统首页展示视频素材数量、已预处理数量、知识条目数量、证据包数量，并显示分析流程、运行环境、大模型状态、最近素材和最近问答记录，方便用户确认本地服务和数据状态。
- 广告视频素材登记：用户可登记素材名称、视频引用、封面引用、视频时长、归属人、所属行业、来源平台、识别来源、ASR 语音文本、OCR 画面文字、视觉标签和素材元信息。保存后素材进入素材库，并可在列表和详情区查看。
- 识别结果批量导入：系统提供 JSON 导入区域，用户可一次导入来自 ASR、OCR 或离线识别流程的多条素材识别结果。系统校验 JSON 结构，拆分视觉标签，补齐素材编号和识别来源，然后写入本地数据库。
- 内容预处理与证据包生成：用户选择素材后生成证据包。系统根据语音文本、画面文字、视觉标签和元信息识别价格优惠、时间紧迫、品牌标识、权威背书、社会认同、行动号召等语义要素，并保存最近证据包记录。
- 广告语义检索：用户输入检索问题后，系统对素材证据文本和广告知识库进行匹配，返回素材匹配、知识匹配、综合分、证据分和匹配词，帮助用户定位与问题相关的广告片段和营销知识。
- 广告视频问答分析：用户选择素材并输入问题后，系统基于素材证据、检索知识和声明校验计划生成分析结果。未配置大模型时使用本地检索式回答；配置 OpenAI-compatible 接口后可调用第三方模型，调用失败时自动回退。
- 分析历史记录管理：系统保存每次问答分析记录，展示素材名称、问题、时间和答案内容。用户可以删除单条记录，也可以清空全部历史，便于整理测试过程和复查分析结果。

## 典型操作流程

1. 用户启动本地 Flask 服务并在浏览器进入系统首页，先查看素材、证据包、知识库和模型状态。
2. 用户在视频素材管理页登记广告视频信息，或粘贴 JSON 批量导入识别结果。
3. 用户在素材列表中查看素材状态和详情，确认 ASR、OCR、视觉标签和元信息是否完整。
4. 用户进入内容预处理页选择素材，生成证据包并查看语义要素和证据类型。
5. 用户进入语义检索页输入分析问题，查看素材匹配和广告知识匹配结果。
6. 用户进入问答分析页选择素材、输入问题并生成分析答案，检查检索知识和声明校验计划。
7. 用户在历史记录页复查或删除问答结果，保留需要归档的分析过程。

## 操作手册页面/流程模块

1. 系统总览：浏览器访问系统首页后默认进入“总览”，也可点击左侧导航“01 总览”。
   - 使用场景：用户刚打开系统或完成一轮素材处理后，需要了解当前素材库、证据包、知识库和问答历史是否已更新。
   - 操作要点：打开系统首页，查看顶部状态和指标卡。；检查分析流程图和运行卡，确认 Web 服务、SQLite 数据存储和分析引擎状态。；查看最近素材和最近问答，确认最近操作结果。；需要同步最新数据时点击“刷新数据”。
2. 视频素材管理：点击左侧导航“02 视频素材管理”。
   - 使用场景：用户拿到一条广告视频或识别结果后，需要把视频引用、画面文字、语音文本和标签整理进素材库。
   - 操作要点：在登记区域填写素材名称、视频引用、封面引用和视频时长。；填写归属人、行业、来源平台，并选择识别来源。；录入 ASR 语音文本、OCR 画面文字、视觉标签和素材元信息。；点击“保存素材”。
3. 批量导入识别结果：进入“视频素材管理”页面后，在页面下方找到“批量导入识别结果”。
   - 使用场景：用户已有一批结构化识别结果，不希望逐条手工登记时使用该功能。
   - 操作要点：将素材识别结果按页面示例格式粘贴到 JSON 文本框。；确认每条记录包含素材名称、视频引用、ASR 文本、OCR 文本、视觉标签等需要入库的信息。；点击“导入识别结果”。；导入完成后回到素材列表查看新素材。
4. 内容预处理：点击左侧导航“03 内容预处理”。
   - 使用场景：用户准备分析某条广告素材前，需要先把该素材的语音、文字、标签和说明汇总成可追溯证据。
   - 操作要点：在下拉框中选择需要处理的广告素材。；点击“生成证据包”。；查看页面上方卡片中的素材名称、语义要素和证据类型。；需要核对详细内容时查看下方 JSON 输出。
5. 语义检索：点击左侧导航“04 语义检索”。
   - 使用场景：用户想知道哪些素材与某类广告手法、促销线索或信任背书相关时使用该功能。
   - 操作要点：在输入框中输入检索问题，例如询问广告如何制造紧迫感。；点击“检索”。；查看素材匹配区，确认相关素材和语义要素。；查看知识匹配区，参考对应广告知识条目和匹配词。
6. 问答分析：点击左侧导航“05 问答分析”。
   - 使用场景：用户需要解释某条广告如何表达优惠、塑造信任或触发行动时，通过该页面提问并查看回答依据。
   - 操作要点：在素材下拉框选择需要分析的广告素材。；在问题输入区填写要分析的问题。；根据当前环境选择是否勾选接入大模型回答。；点击“生成分析结果”。
7. 历史记录管理：点击左侧导航“06 历史记录”。
   - 使用场景：用户完成多次问答后，需要回看历史答案，或删除不需要保留的测试记录。
   - 操作要点：进入历史记录页面查看已有问答记录。；阅读记录中的素材名称、创建时间、问题和答案。；对不需要的单条记录点击“删除”。；需要清理全部记录时点击“清空历史”。

## 申请表建议口径

- 开发目的：用于广告视频素材的本地化登记、证据整理、语义检索和问答分析。
- 软件的主要功能：广告视频内容检索分析系统围绕广告视频素材的证据化整理和分析使用展开。系统提供本地 Web 操作界面，用户可以先在总览页查看素材库、知识库、证据包和问答历史的数量，确认服务处于可用状态。素材管理功能支持录入广告视频引用、封面、时长、归属人、行业、来源平台、识别来源、ASR 语音文本、OCR 画面文字、视觉标签和素材元信息，也支持通过 JSON 批量导入识别结果。内容预处理功能会对已登记素材生成证据包，结合语音、画面文字、视觉标签和元信息识别价格优惠、时间紧迫、品牌标识、权威背书、社会认同、行动号召等广告语义要素。语义检索功能允许用户输入自然语言问题，系统返回相关素材、广告知识、匹配分和匹配词。问答分析功能基于素材证据和检索知识生成结构化回答，并附带声明校验计划，便于用户复核答案依据。历史记录功能保存问答分析过程，支持查看、单条删除和清空，便于整理广告素材测试和复盘记录。
- 技术特点：采用 Flask、SQLite 与原生前端构建本地 B/S 系统，支持证据包构建、检索打分、可选大模型问答和失败回退。
