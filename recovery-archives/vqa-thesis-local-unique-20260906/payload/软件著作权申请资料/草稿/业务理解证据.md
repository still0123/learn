广告视频内容检索分析系统V1.0 本目录是面向软著材料整理补齐的本地 Web 系统代码。系统围绕广告视频素材的内容解析、语义检索与问答分析，提供视频素材管理、内容预处理、语义检索、问答分析、结果展示和历史记录管理等功能。当前技术方案采用 Python + Flask + SQLite + 原生 HTML/CSS/JavaScript，属于轻量 B/S 架构，便于本地运行、截图和提交材料核对。 技术方案 - 后端框架：Python Flask，负责 API 路由、静态页面服务和请求异常处理。 - 数据库：SQLite，保存视频素材、广告知识库、问答历史和系统配置。 - 前端界面：原生 HTML、CSS 和 JavaScript，提供左侧导航、表单录入、检索结果、问答结果和历史记录展示。 - 大模型接入：支持 OpenAI-compatible Chat Completions 接口；未配置或调用失败时自动回退到本地检索式问答。 - 核心算法：Python 模块实现证据包构建、语义要素识别、广告知识检索、提示构建、问答结果组织和声明校验计划。 - 运行方式：本地浏览器访问 Flask 服务，无需单独部署前端工程。 功能范围 - 视频素材管理：登记广告视频引用、ASR 文本、OCR 文本、视觉标签和素材元信息。 - 内容预处理：根据画面文字、语音、视觉标签和元信息生成证据包，识别价格优惠、时间紧迫、品牌标识、权威背书、社会认同等语义要素。 - 语义检索：对用户检索问题、素材证据和广告营销知识进行匹配，输出素材匹配和知识匹配结果。 - 问答分析：基于素材证据和检索知识生成广告理解问答结果，并输出声明校验计划。 - 结果展示：在页面展示证据、知识、答案和校验项。 - 历史记录管理：保存每次问答分析结果，支持查看和清空历史。 运行方式 打开浏览器访问： 系统默认使用 app/seed.py 内置样例初始化 data/ad video analysis.db 。如果旧目录中存在 data/state.json ，首次创建 SQLite 数据库时会自动导入旧数据。 大模型配置 系统默认
