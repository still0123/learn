## 二、说明

广告视频内容检索分析系统 V1.0 适用于广告营销与视频内容分析场景。用户启动本地服务后，通过浏览器进入系统页面，可以完成广告素材登记、识别结果导入、证据包生成、语义检索、问答分析和历史记录整理等操作。

日常使用时，广告投放运营人员、品牌内容分析人员、视频素材审核人员、广告营销研究或测试人员可以先把广告视频的语音文本、画面文字、视觉标签和素材说明登记到系统中，再通过预处理和检索页面查看素材中是否包含促销、背书、行动号召等广告表达线索。系统把这些分散信息整理成可查看、可检索、可追溯的记录，便于后续复查。

本软件以本地 Web 服务方式运行，用户通过浏览器访问操作页面。系统默认支持本地检索式问答；在用户配置第三方问答服务后，也可以在问答分析页面选择接入该服务。无论采用哪种方式，页面都会保留素材证据、检索知识和声明校验计划，方便用户核对分析依据。

本手册说明软件的用途、功能特点、运行要求和页面操作流程。各功能章节按左侧导航中的页面顺序展开，重点描述用户能够看到的输入项、按钮、列表、提示信息和处理结果。

## 三、功能特点

系统总览页集中显示视频素材、已预处理素材、知识条目和证据包数量。用户在这里可以先判断数据是否已经加载，查看分析流程图、系统运行卡片、最近素材和最近问答记录，并通过刷新按钮同步最新状态。

视频素材管理页用于登记和维护广告视频素材。用户可以填写素材名称、视频引用、封面引用、视频时长、归属人、行业、来源平台、识别来源、ASR 语音文本、OCR 画面文字、视觉标签和素材元信息。保存后，素材会进入列表；点击查看后，右侧详情区域会展示该素材的完整信息。

批量导入识别结果区域用于处理外部 ASR、OCR 或离线识别脚本得到的结构化结果。用户把 JSON 内容粘贴到文本框后，点击导入即可把多条素材写入素材库。导入成功时，页面会显示导入数量和素材名称，用户可以继续查看详情、生成证据包或进行问答分析。

内容预处理页用于把已登记素材整理成证据包。用户选择素材后点击生成，系统会根据语音文本、画面文字、视觉标签和元信息识别价格优惠、时间紧迫、品牌标识、权威背书、社会认同和行动号召等语义要素，并把结果显示在卡片和 JSON 输出区中。

语义检索页用于根据用户输入的问题查找相关素材和广告知识。页面会分区展示素材匹配结果和知识匹配结果，并显示匹配分、综合分、证据分和匹配词，帮助用户判断哪些素材或知识条目与当前问题有关。

问答分析页用于围绕选定素材生成有证据来源的分析结果。用户选择素材、填写问题后，可以使用本地检索式回答，也可以在已配置第三方问答服务时勾选相应选项。结果区域会展示答案、检索知识和声明校验计划，方便用户回到 ASR、OCR 或视觉标签中复核依据。

历史记录管理页保存问答分析结果。用户可以按素材名称、问题和生成时间回看答案内容，也可以删除单条记录或清空全部历史。删除操作会先弹出确认提示，确认后页面立即更新记录列表。

## 五、系统总览

系统总览页面让用户进入系统后先确认本地服务、数据数量、分析流程和最近操作记录。用户可以通过浏览器访问系统首页后默认进入“总览”，也可点击左侧导航“01 总览”。

用户刚打开系统或完成一轮素材处理后，需要了解当前素材库、证据包、知识库和问答历史是否已更新。

用户在系统总览页面会看到视频素材、已预处理、知识条目、证据包四个指标卡、分析流程图、系统状态运行卡、最近素材列表、最近问答列表、第三方问答服务或本地检索问答状态和刷新数据按钮等信息，并可依据页面显示继续处理。

使用该功能时，用户先打开系统首页，查看顶部状态和指标卡，随后检查分析流程图和运行卡，确认 Web 服务、SQLite 数据存储和分析引擎状态，接着查看最近素材和最近问答，确认最近操作结果，最后需要同步最新数据时点击“刷新数据”。

页面会按照数据为空时最近素材或最近问答区域显示暂无记录和未配置第三方问答服务时顶部状态显示本地检索问答等规则限制或提示用户。处理结束后，用户可以看到页面刷新后指标数量、最近素材和最近问答记录同步更新和运行卡展示当前分析引擎和证据链路状态。

## 六、视频素材管理

用户可在视频素材管理页面登记和维护广告视频素材的基础信息及识别文本，为后续预处理、检索和问答提供数据来源。用户点击左侧导航“02 视频素材管理”。

用户拿到一条广告视频或识别结果后，需要把视频引用、画面文字、语音文本和标签整理进素材库。

该部分提供素材名称输入框、视频引用输入框、封面引用输入框、视频时长输入框、归属人和所属行业输入框、来源平台输入框、识别来源下拉框和ASR 语音文本输入区等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先在登记区域填写素材名称、视频引用、封面引用和视频时长，随后填写归属人、行业、来源平台，并选择识别来源，接着录入 ASR 语音文本、OCR 画面文字、视觉标签和素材元信息，之后点击“保存素材”，再在素材列表中点击“查看”，核对该素材详情，最后如果素材不再需要，可点击对应行的“删除”。

素材名称需要填写后才能保存。视觉标签可以用逗号、空格或顿号分隔，系统保存时会整理成标签列表。用户删除素材时，页面会先弹出确认提示；确认后，该素材会从列表中移除，相关证据包和问答历史也不再显示。

## 七、批量导入识别结果

用户可在批量导入识别结果页面把外部 ASR、OCR 或离线识别脚本得到的多条广告素材结果一次导入素材库。用户进入“视频素材管理”页面后，在页面下方找到“批量导入识别结果”。

用户已有一批结构化识别结果，不希望逐条手工登记时使用该功能。

页面上主要呈现识别结果 JSON 文本框、导入识别结果按钮和导入结果提示区域等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先将素材识别结果按页面示例格式粘贴到 JSON 文本框，随后确认每条记录包含素材名称、视频引用、ASR 文本、OCR 文本、视觉标签等需要入库的信息，接着点击“导入识别结果”，最后导入完成后回到素材列表查看新素材。

导入内容必须是 JSON 数组，或包含 materials 数组字段。JSON 解析失败时，页面会在导入结果区域提示格式错误；未填写素材编号时，系统会自动生成编号；未填写识别来源时，系统默认标记为批量导入。导入成功后，页面显示已导入条数和素材名称，新素材进入素材列表，可继续查看、预处理和问答分析。

## 八、内容预处理

用户可在内容预处理页面把已登记素材整理成证据包，提取广告语义要素和证据类型，为检索和问答提供依据。用户点击左侧导航“03 内容预处理”。

用户准备分析某条广告素材前，需要先把该素材的语音、文字、标签和说明汇总成可追溯证据。

用户在内容预处理页面会看到素材选择下拉框、生成证据包按钮、素材、语义要素、证据类型卡片、证据包 JSON 输出区和最近证据包列表等信息，并可依据页面显示继续处理。

使用该功能时，用户先在下拉框中选择需要处理的广告素材，随后点击“生成证据包”，接着查看页面上方卡片中的素材名称、语义要素和证据类型，之后需要核对详细内容时查看下方 JSON 输出，最后在最近证据包列表中确认该素材的证据包记录。

生成证据包前，素材必须已经存在于素材库。素材缺少 ASR、OCR 或视觉标签时，证据包仍可生成，但对应证据内容会较少。处理完成后，素材状态更新为已预处理，页面展示价格优惠、时间紧迫、行动号召等语义要素，并在最近证据包列表中出现新记录。

## 九、语义检索

用户可在语义检索页面根据用户输入的问题查找相关广告素材和广告知识，帮助用户定位分析依据。用户点击左侧导航“04 语义检索”。

用户想知道哪些素材与某类广告手法、促销线索或信任背书相关时使用该功能。

该部分提供检索问题输入框、检索按钮、素材匹配结果区、知识匹配结果区和匹配分、综合分、证据分和匹配词等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先在输入框中输入检索问题，例如询问广告如何制造紧迫感，随后点击“检索”，接着查看素材匹配区，确认相关素材和语义要素，最后查看知识匹配区，参考对应广告知识条目和匹配词。

检索问题为空或与素材内容差异较大时，页面可能显示未找到匹配素材或知识。匹配分用于辅助排序，不等同于最终人工结论。检索完成后，页面会分区展示素材匹配和知识匹配，每条结果包含分值、说明文本和匹配标签，用户可据此继续进入问答分析。

## 十、问答分析

用户可在问答分析页面围绕选定广告素材生成有证据来源的问答分析结果，并列出需要复核的声明校验项。用户点击左侧导航“05 问答分析”。

用户需要解释某条广告如何表达优惠、塑造信任或触发行动时，通过该页面提问并查看回答依据。

页面上主要呈现素材选择下拉框、分析问题输入区、接入第三方问答服务复选框、生成分析结果按钮、分析引擎状态、答案展示区、检索知识区和声明校验计划区等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先在素材下拉框选择需要分析的广告素材，随后在问题输入区填写要分析的问题，接着根据当前环境选择是否勾选接入第三方问答服务，之后点击“生成分析结果”，最后阅读答案、检索知识和声明校验计划，必要时回到素材详情核对 ASR、OCR 和视觉标签。

问答分析前必须选择素材并输入问题。未配置第三方问答服务或服务调用失败时，系统自动回退为本地检索式回答。回答内容依据素材证据和检索知识组织，不替代人工最终审核。生成完成后，页面显示当前回答方式，答案区展示观察证据、知识匹配、分析过程和最终答案，声明校验计划列出需要核查的 ASR、OCR、视觉或营销声明依据，问答结果同时写入历史记录。

## 十一、历史记录管理

历史记录管理页面保存和整理问答分析结果，帮助用户按素材、问题和生成时间复查分析过程，也用于清理调试过程中产生的临时问答记录。用户点击左侧导航“06 历史记录”。

用户完成多次问答后，需要查看某次分析的素材名称、提问内容、生成时间和答案正文；当测试记录较多或素材已经删除时，也需要通过本页删除单条记录或一次性清空历史。

用户在历史记录管理页面会看到历史记录管理标题、清空历史按钮、历史记录列表、单条删除按钮、答案内容框、素材名称、问答创建时间和用户问题文本等信息，并可依据页面显示继续处理。

使用该功能时，用户先进入历史记录页面查看已有问答记录，随后从列表中找到需要复查的记录，先查看记录顶部的素材名称、创建时间和用户问题，接着展开阅读答案内容框，核对其中的观察证据、知识匹配、分析过程或最终答案，之后对不需要保留的单条记录点击“删除”，在浏览器确认提示中确认后完成删除，最后需要清理全部测试记录时点击“清空历史”，确认后让页面恢复为空记录状态。

删除单条记录或清空全部历史前，系统都会弹出确认提示；用户取消确认时不会删除记录。没有历史记录时，页面显示暂无历史记录。删除成功后，对应记录从列表中消失；清空成功后，历史记录列表恢复为空状态。未删除的记录仍保留素材名称、问题和答案内容，用户可以继续逐条查看。

## 十二、典型使用流程

用户完成一次完整分析时，通常先进入广告视频内容检索分析系统，登记或导入广告素材，再按照页面提示生成证据包、检索问题、查看问答结果并整理历史记录。

用户启动本地 Flask 服务并在浏览器进入系统首页，先查看素材、证据包、知识库和问答引擎状态；用户在视频素材管理页登记广告视频信息，或粘贴 JSON 批量导入识别结果；用户在素材列表中查看素材状态和详情，确认 ASR、OCR、视觉标签和元信息是否完整；用户进入内容预处理页选择素材，生成证据包并查看语义要素和证据类型。

## 十三、常见问题解答

问题：为什么问答页面显示本地检索问答？
解决方法：系统未配置第三方问答服务数据通道，或数据通道配置不完整时会使用本地检索式回答。此时仍可根据素材证据和广告知识生成分析结果。

问题：批量导入提示 JSON 格式错误怎么办？
解决方法：请检查文本框内容是否为合法 JSON。可以直接使用数组格式，也可以使用包含 materials 数组的对象格式；视觉标签可以写为数组或分隔字符串。

问题：生成证据包后没有出现某类语义要素怎么办？
解决方法：请回到素材管理页检查 ASR、OCR、视觉标签和素材元信息是否包含相关线索，补充后重新生成证据包。

问题：删除素材会影响哪些数据？
解决方法：删除素材时会同步删除该素材关联的证据包和问答历史，删除前页面会显示确认提示。

## 十四、术语表

| 术语 | 解释 |
| --- | --- |
| ASR 语音文本 | 由语音识别得到的广告视频旁白、口播或声音内容文本。 |
| OCR 画面文字 | 从广告视频画面中识别出的字幕、价格、按钮文案、品牌文字等文本。 |
| 视觉标签 | 用于概括视频画面元素的标签，例如倒计时、商品展示、认证徽章、购买按钮。 |
