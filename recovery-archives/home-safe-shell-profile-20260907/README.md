# Safe home shell-profile archive

This archive preserves two small login-profile files from the home directory:

- `.zprofile`
- `.profile`

Both files were scanned for company, internal-platform, private-key, Token, recovery-code, password, and machine-credential markers before upload; no such marker was found. Other shell, Git, npm, and network configuration files remain local because they contain company settings or high-sensitive credentials.

The originals remain in place to avoid changing active shell behavior.
