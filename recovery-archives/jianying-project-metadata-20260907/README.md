# Jianying project metadata archive

This archive contains only 26 JSON engineering-metadata files selected from the local Jianying `Projects` directory on 2026-09-07.

Excluded before upload:

- all images, audio, video, and extensionless Cloud files;
- three JSON files that matched a company marker and were therefore left local;
- any JSON matching internal-platform or high-sensitivity patterns.

The archive is intentionally metadata-only. The local JSON originals remain in place because the Jianying runtime-status query did not complete reliably; they are not moved until safe to do so.
