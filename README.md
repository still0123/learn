## 归档原则

- 同一主题只保留当前权威版本，历史草稿和可再生成产物不重复上传。
- 数据集、模型权重、密钥、私有答案与运行缓存不进入仓库。
- 论文实验数字保留原始评测边界；机器裁判不等同于人工金标准。
- 专利与软件著作权材料不构成法律意见，提交前仍需代理人或登记机构复核。
