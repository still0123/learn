# 说明书摘要

本发明涉及视频理解与多模态信息处理技术，公开一种基于可追溯多模态证据包与证据缺口主动获取的广告视频问答方法、系统、设备及存储介质。该方法将视频帧、带时间戳语音段和带区域坐标文字构造成具有统一证据标识的候选单元，依据问题相关度和时间冗余获得初始证据集并生成初始答案；将答案拆分为声明，建立声明与证据标识的支持、冲突和缺失关系；当存在时间证据缺口或区域证据缺口时，分别在关联语音时间窗或关联图像区域主动获取补充视图，并更新证据包；依据补充证据生成候选答案，经声明级充分性校验后选择保留、替换或拒答。由此使证据选择、补充获取和答案校验共用同一证据链，提高广告视频问答的可追溯性与回答准确性。

# 说明书

## 一、技术领域

本发明涉及计算机视觉、语音处理、自然语言处理和多模态信息检索技术领域，尤其涉及一种基于可追溯多模态证据包与证据缺口主动获取的广告视频问答方法、系统、设备及存储介质。

## 二、背景技术

广告视频通常在较短时间内集中呈现产品画面、字幕、Logo、价格、行动号召、人物行为、背景音乐和旁白。上述线索在时间上可能只出现数帧，在空间上可能只占据较小区域，并且旁白与对应画面可能存在提前或滞后。若仅对视频进行均匀采样，容易遗漏短时出现的决定性证据；若只按照全局图文相似度选取若干帧，容易得到视觉内容相似而时间上重复的帧；若仅将语音文本拼接到问题中，则无法说明语音内容与具体画面或区域之间的对应关系。

现有技术还可采用全局图像与局部裁剪图像联合输入、基于外部知识的检索增强生成或对初始答案进行再次反思。然而，单纯增加局部视图不能保证所裁区域与问题所需证据一致；通用知识可能替代而非辅助视频事实；再次调用模型也可能在缺少新证据时重复或放大原错误。更重要的是，若选帧、补看、推理和校验分别使用相互独立的数据表示，系统难以回答“该答案由视频中的哪一帧、哪一段语音和哪一块文字区域支持”，也难以在发现证据不足时精确决定应补看时间还是补看区域。

因此，需要一种不是简单叠加选帧、裁剪和反思模块，而是以统一证据对象贯穿多模态信息定位、按需补充和答案核验的技术方案。

## 三、发明所要解决的技术问题

本发明至少解决以下技术问题：

1. 在广告视频存在短时关键线索、画面冗余和声画异步的情况下，如何从候选帧、语音和文字中形成与问题相关且时间上不过度重复的初始证据集合；
2. 如何将视觉帧、文字区域和语音片段组织为可被后续生成和校验共同引用的数据结构，避免推理阶段与证据阶段脱节；
3. 如何区分时间证据缺口和区域证据缺口，并仅在存在明确缺口时获取对应补充证据；
4. 如何在补充证据后控制答案替换风险，降低原本正确的答案被无依据改错的概率；
5. 如何记录最终答案与原始视频证据之间的映射关系，以支持审计、错误诊断和拒答。

## 四、术语与符号定义

1. “证据单元”是指与一个可定位原始来源关联的多模态记录，其可以包含视频帧、帧内区域、语音片段、OCR文字、Logo文字或视觉标签。
2. “统一证据标识”是指在证据选择、主动获取、回答生成和声明校验各阶段均可引用的证据编号。
3. “证据包”是指若干证据单元及其时间、空间、模态和评分信息构成的结构化集合。
4. “证据锚点”是指用于触发补看操作的时间位置、帧位置或空间区域；其不是预先固定的业务标签，而是由问题相关响应和已有证据状态确定。
5. “证据缺口”是指回答声明所需的关键模态、时间关系或局部属性未被现有证据包覆盖的状态。
6. “支持度”是指证据包对待验证声明成立的支持程度；“冲突度”是指证据包中存在与待验证声明矛盾证据的程度。
7. “主动获取”是指由证据缺口触发，对原视频执行限定时间窗采样或限定区域查看，而非无条件增加帧数。

## 五、技术方案

### 5.1 总体架构

本发明的总体数据流为：

```text
广告视频与问题
→ 视听文字候选证据单元
→ 问题条件响应与冗余约束选择
→ 初始证据包与初始答案
→ 声明级支持/冲突/缺失诊断
→ 时间补看或区域补看
→ 更新后的证据包与候选答案
→ 证据充分性校验
→ 保留、替换或拒答并输出证据链
```

上述各阶段共用统一证据标识。主动获取所得证据还记录其触发来源和获取动作，使最终答案能够逐级回溯到原视频。

### 5.2 多模态候选证据构建

对输入广告视频以预设候选数量进行时间采样，得到候选帧集合`F={f_i}`。对音轨执行自动语音识别，得到语音片段集合`A={(a_j,t_j^s,t_j^e)}`。对候选帧或高频采样帧执行文字检测与识别，得到文字集合`O={(o_k,b_k,c_k,f_k)}`，其中`b_k`为区域框，`c_k`为识别置信度。

将落入帧时间邻域的语音片段与候选帧关联，将同帧文字区域与候选帧关联，得到候选证据单元：

```text
U_i = <evidence_id, frame_index, timestamp, time_window,
       modality_source, bbox, content, confidence>
```

当音轨不存在、未检测到语音、识别失败或画面中不存在文字时，分别记录相应状态，而不是统一写为空字符串，以避免把“证据不存在”和“证据处理失败”混为同一状态。

### 5.3 问题条件跨模态响应

分别计算问题与候选帧、关联语音片段和关联文字片段之间的相关度。一个实施例中，第`i`个候选单元的响应分数为：

```text
R_i = alpha_i * S_v(i,q)
    + beta_i  * S_a(i,q)
    + gamma_i * S_o(i,q)
```

当某一模态不可用时，其对应权重置零并重新归一化其余权重；当某一模态识别置信度较低时，降低该模态权重。对于语音相关度，在候选帧时间点前后预设窗口内聚合语音片段，以覆盖声画提前或滞后。

### 5.4 冗余约束的初始证据选择

为避免高相关帧集中在同一短时间段，采用相关度与冗余联合准则。设已选集合为`S`，候选单元`i`的选择目标为：

```text
Score(i) = lambda * R_i
         - (1-lambda) * max Sim(i,j), j in S
         - eta * TemporalPenalty(i,S)
```

其中，`Sim(i,j)`表示视觉语义相似度，`TemporalPenalty(i,S)`表示时间邻近惩罚。依次选择若干证据单元，形成初始证据包。该步骤在限定视觉视图数或视觉输入预算内执行。

### 5.5 空间证据锚定与上下文保留

对于文字、Logo、价格、按钮、包装细节或局部动作相关问题，根据问题响应、语音响应和文字响应构成空间响应图`H(x,y)`。根据响应图重心或高响应区域确定空间中心。根据归一化响应熵确定视野尺度：响应越集中，局部视野可以越小；响应越分散，保留的上下文范围越大。

本发明不把任意紧裁剪视图直接视为有效证据。每个局部视图均与同一时刻的全局上下文视图绑定，且记录裁剪框、原始帧索引、触发证据槽和预期观察内容。若区域定位置信不足，则返回同一时刻的高清全局视图或较大范围上下文视图。

### 5.6 证据包结构

一个证据包可以表示为：

```text
EvidencePackage = {
  evidence_id,
  sample_id,
  video_id,
  frame_index,
  timestamp,
  time_window,
  global_view,
  local_evidence_view,
  bbox,
  asr_text,
  asr_state,
  ocr_text,
  ocr_state,
  visual_tags,
  modality_source,
  response_scores,
  trigger_slot,
  expected_observation,
  source_evidence_id,
  traceable_to_raw
}
```

其中，`source_evidence_id`用于表明补充证据由哪个初始证据或声明缺口触发；`trigger_slot`表示缺失的是文字、语音、视觉对象、局部属性或时间关系；`expected_observation`表示补看预期确认的内容。具体实现中可以根据数据源缺失部分字段。

### 5.7 初始回答和声明分解

多模态问答模型基于初始证据包生成初始答案`A0`。随后将`A0`分解为声明集合`C={c_m}`。声明可分为：

1. 视觉对象或动作声明；
2. OCR、Logo、价格或文字声明；
3. 语音或旁白声明；
4. 时间先后或跨时刻关系声明；
5. 需要多个模态共同支持的联合推断声明。

针对每个声明，记录所需证据类型、已引用证据标识和证据状态。形成声明-证据矩阵`M`，矩阵元素至少包括支持、冲突和缺失三种状态。

### 5.8 证据缺口诊断与动作路由

根据声明-证据矩阵执行动作路由：

1. `DIRECT`：所有关键声明均已获得足够证据，直接进入答案校验；
2. `LOOK_TIME`：缺少事件发生时刻、动作顺序或语音对应画面，从相关语音段、已有锚点或其邻域建立时间窗，补充边界帧、邻近帧或窗口内高相关帧；
3. `LOOK_REGION`：缺少局部文字、Logo、价格、按钮、包装属性或人物局部动作，从相关帧的文字框、问题响应区域或多尺度上下文区域获取补充视图。

在多个可用动作之间，可按照单位视觉输入成本的预期缺口减少量选择动作：

```text
action* = argmax_a ExpectedGapReduction(a) / Cost(a)
```

当剩余预算不足或补看后支持度不再提高时停止继续获取。

### 5.9 反事实证据充分性校验

为了判断答案是否真正依赖决定性证据，可构造与正证据状态`E+`对应的反事实证据状态`E-`。反事实状态可以通过删除决定性时间段、替换为同视频相似但不含决定性线索的帧、遮挡关键文字区域或移除相应模态获得。

若一个声明在`E+`下获得高支持，而在`E-`下支持度显著下降，则该声明被认为对相应证据具有依赖性。若删除或替换证据后支持度未变化，则该声明可能依赖视频整体语义、模型先验或无关线索，应降低其可信度。

### 5.10 候选答案生成和风险控制

使用更新后的证据包生成候选答案`A2`，并分别计算`A0`和`A2`的声明支持度、冲突度及覆盖率。一个实施例采用以下替换条件：

```text
support(A2) >= tau
and support(A2) - support(A0) >= margin
and conflict(A2) <= conflict_limit
```

满足条件时输出`A2`；不满足时保留`A0`。若`A0`和`A2`均存在关键证据缺口或可靠冲突，则输出证据不足标识。阈值`tau`和增量`margin`仅利用与测试视频隔离的校准数据确定。

### 5.11 可选的证据约束知识检索

对于广告策略、情感诉求或目标受众等需要领域知识解释的问题，可以在证据包已触发对应广告语义槽时检索广告知识条目。检索结果必须记录支持该知识匹配的证据标识，且外部知识只能解释已在视频中出现的事实，不能单独支持视频中不存在的品牌、价格、功效或行为声明。该可选步骤不改变视频事实声明仍需由原始视频证据支持的约束。

## 六、有益效果

与缺少统一证据对象的视频问答方法相比，本发明至少具有以下技术效果：

1. 通过将视频帧、语音段和文字区域写入具有统一证据标识的证据包，使选帧、补看、回答和核验共享同一数据链路，能够定位最终答案所依赖的原始时间和空间证据；
2. 通过问题相关度和时间冗余联合选择，减少初始证据集中在相似画面或相邻时刻的情况，提高有限输入预算下的时间覆盖；
3. 通过将证据不足区分为时间证据缺口和区域证据缺口，能够执行与缺口匹配的补充获取操作，避免无条件增加视觉输入；
4. 通过保留全局上下文并按问题响应确定局部视图，降低紧裁剪丢失语境的风险；
5. 通过声明级支持、冲突和反事实充分性校验，使答案替换以新增证据为条件，降低无证据自由反思导致的错误改答；
6. 通过校准阈值形成准确率优先和成本优先工作点，使系统能够在回答精度与视觉输入成本之间进行可解释配置。

## 九、具体实施方式

### 实施例一：基于八视图初始证据和选择性补看的广告视频问答

接收一段广告视频和用户问题。首先从视频中获得64个候选时间位置，并提取相应视觉特征。对音轨进行分段语音识别，对候选帧执行OCR。将问题分别与候选帧、关联语音片段和OCR文字编码后计算相关度。

从候选集中依次选择8个证据时刻。选择第一帧时取跨模态响应最高的候选；之后每次同时考虑问题相关度、与已选帧的视觉相似度和时间间隔，直至得到8个时间分散的初始证据帧。将8个帧及其关联ASR、OCR组成初始证据包，生成初始答案。

将初始答案拆分为声明。例如，对问题“广告通过什么方式制造紧迫感”的回答可以拆分为“画面出现倒计时”“旁白提示活动即将结束”“上述信息构成稀缺或紧迫诉求”三个声明。系统分别检查OCR证据、ASR证据和联合推断证据。

若倒计时文字区域未被现有视图清楚覆盖，则触发区域补看；若旁白片段存在但对应画面缺失，则触发时间补看。区域补看返回同一证据时刻的一张全局帧和一张上下文裁剪图，时间补看返回语音段边界及邻近时间的候选帧。新增视图均绑定原证据标识和触发声明。

更新证据包后生成候选答案，并重新计算各声明支持度。只有候选答案的支持度达到校准阈值，且相对初始答案提高并未引入可靠冲突时，才输出候选答案；否则保持初始答案。

### 实施例二：时间证据缺口处理

对于问题“人物在听到旁白后做了什么”，系统将“听到旁白”定位到ASR片段`[t_s,t_e]`。若初始证据包中没有覆盖`t_e`之后的画面，则形成时间顺序声明的证据缺口。系统以`t_e`为中心构造前后时间窗，采样边界帧、紧邻帧以及窗口内与动作词相关度最高的帧。新增证据记录其来源语音证据标识，使“旁白”和“后续动作”的时间关系可被追溯。

### 实施例三：区域证据缺口处理

对于问题“屏幕上显示的价格是多少”，系统先检查已选帧中的OCR区域。若存在低置信文字框或回答声明未被OCR支持，则在相关帧中融合问题响应和OCR响应，确定文字响应中心。系统保留该时刻全局帧，同时获取覆盖文字区域及周边产品上下文的区域视图。若区域框过小或响应分散，则扩大区域范围；若未获得可靠区域，则回退为同一时刻高清全帧。

### 实施例四：反事实证据依赖验证

对候选答案中的价格声明，将包含价格文字的证据包记为`E+`，将相同帧中价格区域遮挡后的证据包记为`E-`。若模型在`E+`中支持该价格、在`E-`中转为不确定或不支持，则说明答案依赖该区域证据。若两种状态输出完全相同且支持度不变，则降低该声明的充分性评分。

### 实施例五：成本优先工作点

在与正式测试视频隔离的校准集合上，枚举支持度阈值。对每个阈值计算问答准确率、错误替换率、触发率和平均视觉输入成本。在准确率距离最优值不超过预设容差的候选阈值中选择触发率最低者，作为成本优先阈值。部署时可以根据算力条件在准确率优先阈值和成本优先阈值之间切换，但不能使用测试答案重新选择阈值。

### 实施例六：系统与电子设备

本发明系统可部署在具备图形处理器的服务器、工作站或云端推理节点上。处理器执行存储器中的程序后，完成视频解码、语音识别、文字识别、证据选择、多模态回答、声明校验和结果存储。证据包可以保存为JSON、数据库记录或其他结构化格式；视觉视图可以保存为原视频帧引用和区域坐标，而无需重复保存整幅图像。

## 十、技术效果验证实施例

以下数据用于说明所述技术方案的可行性和技术效果。评测采用AdsQA公开广告视频问答数据，回答器为未使用AdsQA微调权重的Qwen3-VL-8B。机器裁判采用统一answer-only口径，结果标记为`not_human_gold=true`。实验数值仅对应所述实施条件，不构成对所有模型和数据的效果保证。

### 10.1 完整数据集结果

原始有效题为7,846题，其中2题的候选答案连续两次无法由裁判解析，因此严格配对统计使用7,844题。

| 方法 | 输入设置 | Strict | Relaxed |
|---|---|---:|---:|
| Uniform8 | 64候选中均匀取8帧，1,024视觉Token | 29.70% | 45.86% |
| MMR8 | 问题相关度与时间冗余联合选8帧，1,024视觉Token | 33.31% | 49.75% |
| 本发明完整策略 | MMR8初答；低支持时补充视听证据并执行充分性门控 | **40.31%** | **59.87%** |

本发明完整策略相对MMR8提高Strict 7.00个百分点、Relaxed 10.12个百分点。按视频聚类进行10,000次Bootstrap，Strict差95%置信区间为[+5.96,+8.09]个百分点，Relaxed差为[+9.28,+10.98]个百分点。

### 10.2 外部数据验证

在E-VAds External-1000B的1,000题、200视频上，MMR8的R5/R3/R2分别为51.925%、35.25%和11.30%；完整证据补看与门控策略分别为53.625%、37.35%和12.90%，对应提高1.70、2.10和1.60个百分点。

### 10.3 证据定位验证

在人工审查的23条样本、30个必需证据单元中，加入查询条件OCR响应的证据组织方式命中29/30个证据单元，并在10个具有区域框的证据中达到10/10的区域召回。该结果用于说明证据包能够记录和回溯时间及区域证据，不用于证明任意局部裁剪均提高最终问答准确率。

## 十一、其他说明

本发明不限定具体多模态模型、视觉编码模型、语音识别模型或文字识别模型。相关模型可以替换，只要能够生成本发明要求的证据单元、执行证据缺口对应的补充获取，并根据统一证据标识完成声明级核验。

本领域技术人员在不脱离本发明核心构思的情况下，可以调整候选帧数量、初始证据数量、响应融合方式、时间窗口、区域尺度、阈值校准方法和数据存储形式。凡以统一证据标识贯穿问题条件证据选择、证据缺口主动获取和答案充分性校验的等同方案，均应落入相应权利要求的保护范围。
