## 渲染要求

- 输出采用黑白线条、白色填充、无渐变、无阴影；不得使用彩色状态区分。
- 当前 SVG 已由 `render_figures.cjs` 在本地生成并完成 XML 与肉眼检查；正式递交前仍应根据代理人版式要求置入黑白附图页。
- 图3中的实线有向箭头表示声明依赖方向；虚线箭头表示增量证据对声明的支持或冲突关系；虚线边框仅表示逻辑集合边界。
- 图4的状态名称与编号应保持不变，以便与实施例状态机对应。

## 本地重新生成

使用工作区随附 Node 运行：

```sh
node render_figures.cjs
```

重新生成后应检查中文字体、箭头方向、编号完整性和黑白打印效果。
