# 基于视频证据双差分许可的视频问答答案更新控制权利要求书 V4.5.1

> 日期：2026-08-24  
> 定位：针对 CN121388101A、CN117744802A 和 CN103870528B 逐句对照后的第二轮收紧稿。  
> 说明：本文件只重写权利要求书；说明书支撑沿用 V4.5 全文初稿，不覆盖历史文件。正式递交前由代理人复核用语和保护层级。

## 一、方法权利要求

**1.** 一种基于视频证据差分许可的视频问答答案更新控制方法，其特征在于，包括：

获取视频、针对所述视频的问题、初始视频证据快照 E0 以及基于 E0 生成的初始答案 A0，并根据所述问题和预设任务规则确定至少一个规范化事实槽；

从所述视频中取得源证据单元不属于 E0 已使用证据单元的增量视频证据 ΔE，并冻结由 E0 和 ΔE 构成的扩展视频证据快照 E+；

通过证据许可服务，按照相同的事实槽模式和规范化配置确定所述规范化事实槽在 E0 和 E+ 下的规范化观测状态，并在 E0 下的规范化观测状态与 E+ 下由 ΔE 形成的规范化观测状态之间存在实质事实差分时，生成证据差分许可记录，所述证据差分许可记录至少关联事实槽、经消歧实体或事件、谓词、限定上下文、规范化事实值或状态目标、E0/E+ 快照标识以及属于 ΔE 的时空模态见证；其中，在与答案事实状态有关的数据访问范围内，所述证据许可服务的可读数据域包括所述问题、预设任务规则、E0、ΔE 和 E+，且不包括 A0、候选答案及由 A0 或候选答案导出的事实值，并且不以 A0 或候选答案的事实值作为证据检索、事实抽取、事实归一化或证据选择目标；

将所述证据差分许可记录写入控制存储区，冻结许可记录摘要并记录许可冻结时点 `t_p`；

在 `t_p` 之后通过候选生成服务开始生成候选答案并记录生成开始时点 `t_s`；其中，在与答案事实状态有关的数据访问范围内，所述候选生成服务的可读数据域包括所述问题和 E+ 的原始视频证据表示，且不包括 A0 的语义内容、由 A0 导出的改写指令以及所述证据差分许可记录，所述候选生成服务无所述控制存储区的读取权限；

冻结由所述候选生成服务生成的候选答案 A2 的内容摘要和版本并记录候选冻结时点 `t_a`，在 `t_a` 之后才允许控制服务联合读取 A0、A2 和所述证据差分许可记录，并记录首次联合读取时点 `t_j`，其中 `t_p<t_s<t_a<t_j`；

由所述控制服务按照相同的 E+、相同的事实槽模式和相同的核验配置，将 A0 和 A2 分别转换为规范化答案事实，核验各规范化答案事实在 E+ 下的支持状态，并形成 A0 至 A2 的实质答案事实迁移；

将每一实质答案事实迁移与证据差分许可记录按事实槽、经消歧实体或事件、谓词、限定上下文、规范化事实值、E0/E+ 快照以及 ΔE 时空模态见证进行配准；其中，对于每一实质答案事实迁移，存在唯一一条上下文相容且快照有效的许可记录，且同一许可记录不授权两个相互不相容的目标事实；新增迁移或替换迁移的目标事实在 E+ 下处于支持状态，撤回迁移的旧事实在 E+ 下处于冲突状态；

根据预定义的有向事实依赖关系，从所述实质答案事实迁移对应的事实槽沿表示受影响方向的依赖边构造语义依赖闭包；以及

仅在所述语义依赖闭包中的全部实质答案事实迁移均完成所述配准、所引用的 E+ 快照和许可记录均有效、且同一事实槽和限定上下文中不存在达到竞争条件的非等价目标事实时，将所述语义依赖闭包的目标事实状态作为一个事务原子写入可输出状态集合；否则禁止写入所述语义依赖闭包中的全部候选目标事实状态，并基于 E+ 下仍处于支持状态的旧事实状态或者不确定状态生成输出。

**2.** 根据权利要求1所述的方法，其特征在于，每个视频证据单元包括视频标识、源片段标识、帧号或时间区间、证据模态和内容摘要；对于图像区域、画面文字或标识类证据，还包括区域坐标；所述增量视频证据 ΔE 的源片段标识、原始时间覆盖范围或区域视图标识不属于 E0 的已使用证据单元集合。

**3.** 根据权利要求1所述的方法，其特征在于，事实槽模式至少包括主体类型、谓词类型、值类型、单位类型、限定字段、槽基数规则、允许证据模态和归一化规则；规范化观测状态至少包括未解析、唯一解析、竞争歧义、冲突和仅质量提高状态；事实槽模式由问题和任务规则确定，不由 A0 或 A2 的事实值生成。

**4.** 根据权利要求3所述的方法，其特征在于，证据差分许可记录还包括许可类型、增量证据标识集合、竞争组标识、许可生成时间、记录摘要和快照版本；许可类型至少包括事实值写入许可和事实冲突许可，所述事实冲突许可由不读取 A0 事实值的证据许可服务依据 E+ 下的确定事实或显式否定事实形成，并在 A2 冻结后用于判断是否授权对应旧事实的撤回；竞争歧义、仅质量提高或证据不足状态不产生事实值写入许可。

**5.** 根据权利要求1所述的方法，其特征在于，所述证据许可服务、候选生成服务和控制服务采用不同服务账户、不同访问控制列表或不同进程地址空间；候选生成接口采用输入字段白名单并拒绝初始答案、旧事实元组、许可标识、许可规范化值、许可观测状态、竞争组标识和迁移映射键；审计日志保存所述四个时点及各服务的输入摘要。

**6.** 根据权利要求3所述的方法，其特征在于，针对槽基数为一且限定上下文相同的事实槽，将规范化值不同的观测划分至同一竞争组；仅当一个值簇满足预设证据质量和适用条件且不存在达到竞争条件的非等价值簇时，生成事实值写入许可；原价和促销价、不同说话人、不同事件阶段或不同适用时间对应的观测因限定字段不同而划分至不同上下文。

**7.** 根据权利要求1所述的方法，其特征在于，A0 与 A2 的规范化答案事实采用由事件标识、主体角色和谓词构成的主映射键进行映射，事实值和限定字段用于确定迁移类型；迁移类型包括新增、替换、撤回、不确定化、保持和等价压缩，其中新增、替换和撤回属于实质答案事实迁移，保持和等价压缩不消耗事实值写入许可。

**8.** 根据权利要求1所述的方法，其特征在于，A0 与 A2 在 E+ 下的核验结果采用相互排他的支持状态、证据不足状态、冲突状态和异常状态；异常状态不参与闭包提交；A0 与 A2 的核验记录均保存相同的 E+ 快照标识、核验配置标识、事实槽模式标识和状态判定规则标识。

**9.** 根据权利要求1所述的方法，其特征在于，当目标事实由两个以上上游事实确定性计算得到时，建立派生许可记录，所述派生许可记录包括全部上游证据差分许可标识、确定性运算符、输入单位、单位换算规则、舍入规则和 E+ 快照标识；仅在全部上游许可有效且计算结果与目标事实一致时，允许所述派生许可记录授权对应迁移。

**10.** 根据权利要求1所述的方法，其特征在于，若有向依赖边 `X→Y` 表示事实 Y 的成立依赖事实 X，则从实质答案事实迁移沿出边方向确定需要共同写入或共同不写入的下游事实作为状态写入集合，并沿入边方向确定核验所需的上游事实作为只读证明引用集合；所述只读证明引用集合不因被引用而成为回滚对象；依赖边限制为预设的实体、属性、数量、时间或因果关系，并受事件消歧、时间相容条件和节点数量上限约束。

**11.** 根据权利要求10所述的方法，其特征在于，当第一语义依赖闭包的状态写入集合与第二语义依赖闭包的证明引用集合包含同一事实槽，且第一语义依赖闭包对该事实槽执行非等价状态改变时，在第一语义依赖闭包提交或禁止写入后使第二语义依赖闭包的核验结果失效并重新核验；重新核验后仍存在写入—引用冲突时，将两个语义依赖闭包合并为联合闭包。

**12.** 根据权利要求1所述的方法，其特征在于，当语义依赖闭包被禁止写入时：若旧事实在 E+ 下处于支持状态，则保留所述旧事实；若旧事实处于证据不足状态且仍有取证预算，则继续取得增量视频证据；若取证预算耗尽，则将对应事实槽设为不确定状态；若旧事实处于冲突状态且不存在受支持替代事实，则撤回所述旧事实；必填事实槽无法被唯一受支持事实填充时输出证据不足状态或拒绝回答，且不恢复 E+ 下已经处于冲突状态的 A0 事实。

**13.** 根据权利要求1所述的方法，其特征在于，生成最终答案时，重组器的输入仅包括所述可输出状态集合中的事实标识、事实值和对应证据标识；将重组结果再次转换为输出事实集合，当存在不能映射至所述可输出状态集合的新增事实时，删除所述新增事实并重新重组，重新重组后仍存在新增事实时输出结构化事实集合、证据不足状态或拒绝回答。

**14.** 根据权利要求1所述的方法，其特征在于，对用于形成证据差分许可记录的见证证据执行匹配反事实核验：从 E+ 中移除所述见证证据，并分别加入与所述见证证据模态相同、时间位置近似、分辨率和输入预算满足匹配条件且经预核验不支持目标事实的多个非见证证据集合，形成多个反事实证据快照；当目标事实在各反事实证据快照下均不能保持所述证据差分许可记录中的目标观测状态时，确定所述见证证据满足差分必要性条件。

**15.** 根据权利要求1所述的方法，其特征在于，记录问题标识、E0/E+ 快照摘要、增量证据标识、事实槽模式、证据差分许可、候选生成输入摘要、A2 内容摘要、联合读取时间、答案事实迁移、迁移—许可配准关系、依赖闭包、提交或禁止写入动作以及原因代码；当 E+ 内容、规范化规则或许可见证发生变化时，将对应许可及其已暂存迁移标记为失效并触发重新核验。

## 二、装置、设备和存储介质权利要求

**16.** 一种基于视频证据双差分许可的视频问答答案更新控制装置，其特征在于，包括：

- 初始状态生成单元，用于形成 E0 和 A0；
- 增量证据获取单元，用于取得 E0 未使用的 ΔE 并冻结 E+；
- 证据许可单元，用于在第一读取域中形成并冻结证据差分许可记录，所述第一读取域包括问题、任务规则、E0、ΔE 和 E+，且不包括 A0、A2 及其派生事实值；
- 隔离候选生成单元，用于在第二读取域中基于问题和 E+ 原始视频证据表示生成并冻结 A2，所述第二读取域不包括 A0 和证据差分许可记录；
- 联合控制单元，用于仅在 A2 冻结后联合读取 A0、A2 和证据差分许可记录，在同一 E+ 下形成答案事实迁移并执行迁移—许可配准；以及
- 闭包控制单元，用于在闭包内全部迁移均配准成功时原子写入目标事实状态，否则禁止写入全部候选目标事实状态；

所述各单元被配置为执行权利要求1至15任一项所述的方法。

**17.** 一种电子设备，包括处理器和存储器，所述存储器中存储有计算机程序，其特征在于，所述计算机程序被所述处理器执行时，实现权利要求1至15任一项所述的方法。

**18.** 一种计算机可读存储介质，其上存储有计算机程序，其特征在于，所述计算机程序被处理器执行时，实现权利要求1至15任一项所述的方法。

## V4.5→V4.5.1 关键改动说明（正式稿删除）

1. 把抽象的“许可不可见”改成证据许可服务、候选生成服务的事实状态读取域互相隔离；
2. 把许可冻结摘要、候选冻结摘要和 `t_p<t_s<t_a<t_j` 联合读取时序提升至权利要求1；
3. 把“证据通道不使用候选值”写成可读数据域不含 A0/A2 及其派生事实；
4. 保留 A2 不读取 A0、同 E+ 核验、唯一许可配准和闭包全有或全无；
5. 将详细安全状态、反事实、跨闭包传播和无新增终检留在从属权利要求；
6. 本次收紧提高了技术具体性和对三件核心文件的区分，但也缩小保护范围并增加内部流程的侵权取证难度。
