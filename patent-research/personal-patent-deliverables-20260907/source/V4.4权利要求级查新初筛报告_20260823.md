# V4.4 权利要求级查新初筛报告

更新时间：2026-08-23  
检索截止：2026-08-23（北京时间）  
对象：`基于预冻结视频证据观测记录的视频问答答案状态更新控制专利 V4.4`  
性质：申请前技术查新初筛，不替代专利代理机构使用 CNIPA、EPO、WIPO 或商业数据库出具的正式检索及法律意见。

## 一、先给结论

### 1. 新颖性初筛

截至本轮检索，**未发现一篇单独文献完整公开 V4.4 的全部控制链**。尤其未见同一文献同时公开：

1. 仅由本轮新增且此前未使用的视频证据形成具体事实差分；
2. 该差分在 A2 生成前冻结，形成过程不使用 A0/A2 候选值；
3. 冻结记录不传给 A2 生成器，A2 又不接收 A0 语义内容；
4. A0 与 A2 在同一扩展证据快照下形成答案事实差分；
5. 仅允许与前述证据事实差分逐项一致的 A0→A2 迁移写入；
6. 竞争、失配或闭包不完整时禁止写入。

因此，按本轮可得材料，**收紧后的整体方案具有保留新颖性的空间**。

### 2. 创造性初筛

**V4.4 当前写法的创造性风险为“高”，不能按原样视为已经查新通过。** 原因不是某一篇文献完全相同，而是各零件已经高度拥挤：

- 视频问答中的缺口取证、重选区域和迭代输出已有；
- 证据发生变化后重新生成或更新旧答案，2012 年优先权的 IBM 中国授权同族 CN103870528B 已有；
- 旧答案与新答案之间计算变化程度，2014 年优先权的 IBM 专利已有；
- 事实模式、位置标签、规范化字符串匹配及不匹配即丢弃已有；
- 生成答案中的关键实体与证据实体做类型和值匹配，再决定是否下游使用已有；
- 候选输出拆成语义单元，赋支持状态并做无新增词元的保守重组已有；
- 候选输出依据预先构造的确定性证据包逐句仲裁、阻断显示及在证据更正后撤销旧输出已有；
- 预注册证据触发、见证集合和保守回退已有非专利文献；
- 结构化证据状态、依赖、冲突、闭合和确定性提交已有非专利文献。

所以，不能再把“预冻结”“值匹配”“状态机”“见证”“闭包”“无新增声明”分别列成若干创新模块。建议把独权压成一条更难拆开的关系：

> **将 `E0→E+` 产生的候选值盲化视频事实差分，与 `A0→A2` 产生的答案事实差分逐项配准；证据差分在 A2 前冻结且对 A2 生成器不可见，只有配准成功的答案迁移才能按依赖闭包提交。**

下文称为“**双差分、双通道迁移许可**”。

### 3. 递交判断

- V4.4：可保留为技术母稿，**不建议直接按现有独权递交**。
- V4.4.1：应按本报告第八部分收紧后再形成权利要求初稿。
- 收紧后仍需代理人做正式分类号/引文/同族检索；本轮不能承诺授权。

## 二、冻结的查新特征

| 编号 | 特征 | 检索后的地位 |
|---|---|---|
| H1 | 由问题确定事实槽模式、值类型、限定字段、基数和允许模态 | 常见结构化抽取手段，不单独支撑创造性 |
| H2 | 从同一视频取得此前未被 E0 使用的 ΔE，并冻结 E+ | D1 已逼近增量区域/帧取证；只能作为链条前提 |
| H3 | 从 ΔE 抽取带时间、区域、模态来源的规范化事实观测 | 文档实体抽取、OCR 定位和结构化事实均拥挤 |
| H4 | 同上下文竞争值分组及 RESOLVED/AMBIGUOUS 等状态 | 冲突分类属拥挤方向，宜服务于禁写条件 |
| H5 | 观测在 A2 前冻结且构造时不使用 A0/A2 候选值 | 尚有区别，但“先计划/先证据后生成”已有上位公开 |
| H6 | A2 不以 A0 语义内容作为改写输入 | 相对 D2 和旧申请是强方向性区别，但单独看是输入选择 |
| H7 | A0/A2 在同一 E+ 和配置下规范化、映射、复评 | 未见单篇直接覆盖；但多模型同证据验证已有 |
| H8 | 事实迁移必须匹配预冻结观测的槽、上下文、值和 ΔE 见证 | 值匹配与门控已有；必须限定为旧新迁移和增量证据差分 |
| H9 | 失配、竞争或快照失效时禁止候选状态写入 | 输出阻断/丢弃/撤销已有，不能单独主张 |
| H10 | 依赖闭包内全量通过才原子提交 | 证据闭合、确定性提交及语义单元保守重组已有近邻 |

查新后新增三个必须联合使用的收紧特征：

| 编号 | 收紧特征 | 作用 |
|---|---|---|
| S1 | 证据差分许可：只有某事实槽从 `E0` 下未解析/旧值状态变为 `E+` 下由 ΔE 解析的新值，才生成许可 | 排除一般证据包和旧证据重复确认 |
| S2 | 生成器隔离：许可的规范化值、解析状态、许可 ID 和映射键在 A2 冻结前不得进入 A2 的提示、上下文、工具返回或可读缓存 | 同时防止许可驱动照抄和候选反向挑证据 |
| S3 | 双差分配准：`ΔAns(A0,A2)` 的每项实质迁移必须一一映射至 `ΔObs(E0,E+)`，再按闭包提交 | 将取证、生成和更新压为一个状态转换条件 |

1. `E0→E+` 的事实状态变化先形成许可；
2. 许可不向 A2 生成器公开，A2 又不接收 A0；
3. `A0→A2` 的变化只有与许可逐项配准才写入。

但这只是初筛结论，不能替代正式新颖性检索意见。

## 六、最强创造性组合攻击

### 攻击 A：同领域视频补证 + 值级门控

组合：CN121388101A + EP4617945A1 + US12536376B2。

审查员可能认为：D1 教导视频缺口补证和再答；EP 教导关键实体类型/值匹配后才下游使用；US12536376 教导按模式和位置取得规范化值、不匹配即丢弃。因此，把视频 OCR/ASR 值做成门控记录是常规拼接。

V4.4 当前独权对此抗性不足。

### 攻击 B：证据变化 + 旧新答案变化

组合：CN103870528B/US9141660B2（及 US9141662B2）+ US20160034457A1 + EP4617945A1。

审查员可能认为：第一篇教导证据变化后更新原回答，第二篇教导计算旧新答案差异，第三篇教导把关键实体值与证据值匹配后决定使用；因此，比较答案变化是否与证据变化一致是顺理成章。

抗辩不能只说“双差分”四个字，而要靠更具体的执行约束：

- 证据差分必须由此前未用的同视频 ΔE 引起；
- 许可在 A2 前固定；
- 许可对生成器字段级不可见；
- A2 不接收 A0；
- 映射对象是规范化事实迁移而非整体答案变化程度；
- 同一竞争组歧义时不发许可；
- 一个依赖闭包内不能部分提交。

### 攻击 C：预构造证据包 + 隔离验证 + 确定性提交

组合：US20260121859A1 + US20260134218A1 + Omni-Decision/PBRC。

审查员可能认为：预先构造证据包、候选输出后用隔离验证器逐单元核验、依据状态提交或回退都已有；把证据包对生成器隐藏只是已知隔离设计。

可争辩之处是 V4.4.1 不是一般的隐藏答案或安全策略，而是让同一 E+ 经过两个不共享中间事实状态的计算通道：

- 证据通道先计算 `ΔObs(E0,E+)`；
- 生成通道只从 Q 与 E+ 原始证据独立产生 A2；
- 控制通道在两边冻结后才计算 `ΔAns(A0,A2)→ΔObs` 映射。

它同时阻断两类错误：候选值反向影响证据选择，以及结构化许可值直接诱导生成器照抄。该功能关系必须写进独权和实施例，不能只在效果段描述。

## 七、哪些内容不能再宣传为主创新

1. 低置信度触发补证；
2. 问题驱动选帧、OCR、ASR、ROI 或放大；
3. 一般事实槽、三元组或键值结构；
4. 一般声明拆分、支持/矛盾/不确定分类；
5. 一般实体类型和值匹配；
6. 一般证据 ID、时间戳、位置或引用；
7. 一般输出门控、失败重试、拒答或安全回退；
8. 一般依赖图、证据闭合、事务提交；
9. 一般“不得新增声明”的保守重组；
10. 仅比较 A0 与 A2，或仅在证据变化后重新回答。

这些内容可以留作实现手段或从属限定，但不能作为创造性论证的中心。

## 八、查新后的独权收紧建议

建议将方法独权围绕以下连续状态变换组织：

1. 保存初始证据快照 E0 和初始答案 A0；
2. 根据问题定义规范化事实槽，在同一视频中取得 E0 未使用的 ΔE，固定 E+；
3. 分别求得槽在 E0 与 E+ 下的规范化观测状态，只对“E0 未解析/旧值，E+ 由 ΔE 解析为新值”的项目生成 `EvidenceDeltaPermit`；
4. 许可记录包含旧观测状态、新观测事实元组、ΔE 时空见证、竞争状态及 E0/E+ 标识，并在 A2 前冻结；
5. 通过独立存储区、访问控制列表或单向接口，使许可中的规范化值、解析状态、许可 ID 和映射键在 A2 冻结前不能被 A2 生成器读取；
6. A2 仅接收问题与 E+ 原始证据，不接收 A0 语义内容及许可记录；
7. A2 冻结后，用同一 E+ 和同一规则规范化 A0/A2，形成 `AnswerMigration`；
8. 仅当每个实质迁移与唯一有效许可在事实槽、实体、谓词、限定上下文、规范化值和 ΔE 见证上相容时，标记为可提交；
9. 存在同上下文竞争值、许可过期、迁移无许可或一项许可被不相容迁移复用时，禁止写入；
10. 同一语义依赖闭包的全部迁移均可提交时原子写入，否则保持 E+ 下最后受支持状态、降级为不确定或拒答。

建议名称可改为：

> **一种基于视频证据差分与答案事实差分配准的视频问答答案更新控制方法**

名称本身不决定授权，但比“可靠性保障”或“证据闭合”更准确地指向新增技术关系。

## 九、说明书必须补足的可实施定义

1. E0 的“已使用证据单元”如何编号，ΔE 如何保证不重复；
2. 同一事实槽在 E0/E+ 下状态的确定方法；
3. `EvidenceDeltaPermit` 的字段、冻结时点、哈希和失效条件；
4. 生成器不能读取许可字段的具体内存/API/权限隔离方式；
5. A0/A2 的一对一、一对多、多对一和未匹配声明如何规范化；
6. 许可与迁移的一一映射、复用冲突及确定性派生值规则；
7. 同上下文竞争组的形成及 RESOLVED/AMBIGUOUS 判据；
8. 依赖闭包的边类型、遍历方向和原子提交；
9. 保留、不确定、撤回和拒答的可判定边界；
10. 价格 79/59、原价/促销价、跨帧冲突、派生优惠值等完整失败实施例。

## 十、建议的最小验证

不要求递交源代码或大规模实验，但为了验证构思不是纸面规则，建议递交前至少做小样本五臂：

1. A0 基线；
2. 强制采用 A2；
3. 候选生成后再取证/验证；
4. 许可在 A2 前形成但许可值提供给 A2；
5. V4.4.1：许可在 A2 前形成且对生成器不可见，双差分配准后闭包提交。

至少记录：

- 错误事实迁移接受率；
- 正确旧事实误删率；
- 有效更新通过率；
- 同上下文冲突时的错误写入率；
- 许可值可见/不可见对候选照抄与独立一致率的影响；
- 每次许可、迁移、见证和最终状态的可复核日志。

不得把旧 Full-7844 数字写成该新机制的效果证据。

## 十一、查新结论等级

| 维度 | 判断 |
|---|---|
| V4.4 单篇新颖性 | 暂未发现完整单篇覆盖，仍有空间 |
| V4.4 当前创造性 | 高风险，零件可被多文献组合 |
| V4.4.1 双差分+生成器隔离 | 中高风险，但比 V4.4 更集中、可辩护 |
| 是否已经可以正式递交 | 否；应先收紧权项并做正式数据库复核 |
| 是否值得继续 | 值得，但需接受保护范围明显收窄 |

一句话：**查新没有把方案判死，但把真正可争取的发明中心从“预冻结观测值门控”进一步压缩成“对生成器不可见的增量证据事实差分，与独立生成的新旧答案事实差分之间的闭包级配准许可”。**
