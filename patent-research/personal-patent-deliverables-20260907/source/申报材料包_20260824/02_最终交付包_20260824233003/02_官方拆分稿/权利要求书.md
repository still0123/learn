# 权利要求书



**1.** 一种视频证据双差分许可的视频问答答案更新方法，其特征在于，包括：

获取视频、针对所述视频的问题、初始视频证据快照 E0 以及基于 E0 生成的初始答案 A0，并根据所述问题和预设任务规则确定至少一个规范化事实槽及其事实槽模式；

从所述视频中取得相对于 E0 未使用的增量视频证据 ΔE，并冻结由 E0 和 ΔE 构成的扩展视频证据快照 E+；

通过证据许可服务，按照相同的事实槽模式和规范化配置确定所述规范化事实槽在 E0 和 E+ 下的规范化观测状态，所述规范化观测状态为未解析状态、唯一解析状态、竞争歧义状态、冲突状态、仅质量提高状态和观测异常状态中的一个；当所述规范化事实槽在 E0 和 E+ 下的规范化观测状态之间的差异属于由未解析状态变为唯一解析状态、由一个唯一解析值变为与其不相容的另一唯一解析值、或者由非冲突状态变为冲突状态中的一种时，判定存在由 ΔE 导致的实质事实差分，并生成证据差分许可记录，所述证据差分许可记录至少关联事实槽、经消歧实体或事件、谓词、限定上下文、规范化事实值或状态目标、E0/E+ 快照标识以及属于 ΔE 的时空模态见证，所述时空模态见证包括所述 ΔE 的证据模态、源片段标识以及帧号或时间区间，对于图像区域或画面文字类证据还包括区域坐标；其中，在与答案事实状态有关的数据访问范围内，所述证据许可服务的可读数据域包括所述问题、预设任务规则、E0、ΔE 和 E+，且不包括 A0、任一候选答案及由 A0 或所述候选答案导出的事实值，并且不以 A0 或所述候选答案的事实值作为证据检索、事实抽取、事实归一化或证据选择目标；所述证据许可服务无存储 A0 的初始答案存储区和存储候选答案的候选答案存储区的读取权限；

将所述证据差分许可记录写入控制存储区，冻结许可记录摘要并记录许可冻结时点 t_p；

在 t_p 之后通过候选生成服务开始生成候选答案并记录生成开始时点 t_s；其中，在与答案事实状态有关的数据访问范围内，所述候选生成服务的可读数据域包括所述问题和 E+ 的原始视频证据表示，且不包括 A0 的语义内容、由 A0 导出的改写指令以及所述证据差分许可记录，所述候选生成服务无所述初始答案存储区和所述控制存储区的读取权限，并且在候选答案 A2 冻结之前，控制服务不得向所述候选生成服务的输入接口、共享缓存或消息队列写入或转发所述证据差分许可记录中的字段；

冻结由所述候选生成服务生成的候选答案 A2 的内容摘要和版本并记录候选冻结时点 t_a，在 t_a 之后才允许控制服务联合读取 A0、A2 和所述证据差分许可记录，并记录首次联合读取时点 t_j，其中 t_p<t_s<t_a<t_j；

由所述控制服务按照相同的 E+、相同的事实槽模式和相同的核验配置，将 A0 和 A2 分别转换为规范化答案事实，并将各规范化答案事实在 E+ 下的核验结果确定为相互排他的支持状态、证据不足状态、冲突状态和异常状态中的一个，其中在核验器无异常时，若存在与所述规范化答案事实相矛盾的确定证据则判定为冲突状态，若存在满足预设充分性条件的支持证据则判定为支持状态，否则判定为证据不足状态；将 A0 与 A2 的规范化答案事实按由事件标识、主体角色和谓词构成的主映射键进行映射，并根据事实值和限定字段的变化，从中确定属于新增、替换或撤回的实质答案事实迁移；

将每一实质答案事实迁移与证据差分许可记录按事实槽、经消歧实体或事件、谓词、限定上下文、规范化事实值、E0/E+ 快照以及 ΔE 时空模态见证进行配准；其中，对于每一实质答案事实迁移，存在唯一一条许可记录，所述许可记录的事实槽、经消歧实体或事件、谓词和限定上下文与所述实质答案事实迁移一致，所述许可记录关联的 E0/E+ 快照标识与当前 E0/E+ 快照标识一致，且所述许可记录的时空模态见证属于 ΔE，且同一许可记录不授权两个相互不相容的目标事实；新增迁移或替换迁移的目标事实在 E+ 下处于支持状态，撤回迁移的旧事实在 E+ 下处于冲突状态；

根据预定义的有向事实依赖关系，从所述实质答案事实迁移对应的目标事实或目标状态出发，沿表示受影响方向的依赖边取得需要共同写入或共同不写入的下游事实，构成所述语义依赖闭包的状态写入集合，并沿相反方向取得核验所需的上游事实作为只读证明引用集合；以及

仅在所述语义依赖闭包中的全部实质答案事实迁移均完成所述配准、所引用的 E+ 快照和许可记录均有效、且同一事实槽和限定上下文中不存在与目标事实值不等价且满足预设证据质量和适用条件的其他非等价目标事实时，将所述语义依赖闭包的状态写入集合中的全部目标事实状态先暂存，再作为一个事务一次性提交写入可输出状态集合；否则禁止写入所述语义依赖闭包的状态写入集合中的全部候选目标事实状态，并依据 E+ 下旧事实的支持状态、证据不足状态或冲突状态生成保留、不确定、撤回或拒绝回答输出，且任何在 E+ 下处于冲突状态的事实均不得进入所述可输出状态集合。

**2.** 根据权利要求1所述的方法，其特征在于，每个视频证据单元包括视频标识、源片段标识、帧号或时间区间、证据模态和内容摘要；对于图像区域、画面文字或标识类证据，还包括区域坐标；所述增量视频证据 ΔE 至少满足下列一项：其源片段标识不属于 E0 已使用源片段标识集合；其原始时间覆盖范围与 E0 已使用的各原始时间区间均不重叠；或者其区域视图包含不属于 E0 实际输入像素集合的原始像素区域，或以 E0 未达到而所述区域视图达到的预设有效空间分辨率呈现所述区域；仅改变裁剪参数、编码格式或预处理而未增加原始区域覆盖或有效空间分辨率，不视为增量视频证据。

**3.** 根据权利要求1所述的方法，其特征在于，事实槽模式至少包括主体类型、谓词类型、值类型、单位类型、限定字段、槽基数规则、允许证据模态和归一化规则；规范化观测状态至少包括未解析状态、唯一解析状态、竞争歧义状态、冲突状态、仅质量提高状态和观测异常状态；事实槽模式由问题和任务规则确定，不由 A0 或 A2 的事实值生成；证据差分许可记录还包括许可类型、增量证据标识集合、竞争组标识、许可生成时间、记录摘要和快照版本，许可类型至少包括事实值写入许可和事实冲突许可，所述事实冲突许可由不读取 A0 事实值的证据许可服务依据 E+ 下的确定事实或显式否定事实形成，并在 A2 冻结后用于判断是否授权对应旧事实的撤回；竞争歧义状态、仅质量提高状态、未解析状态或观测异常状态不产生事实值写入许可。

**4.** 根据权利要求1所述的方法，其特征在于，所述证据许可服务、候选生成服务和控制服务采用不同服务账户、不同访问控制列表或不同进程地址空间；候选生成接口采用输入字段白名单并拒绝初始答案、旧事实元组、许可标识、许可规范化值、许可观测状态、竞争组标识和迁移映射键；审计日志保存所述四个时点及各服务的输入摘要。

**5.** 根据权利要求3所述的方法，其特征在于，针对槽基数为一且限定上下文相同的事实槽，将规范化值不同的观测划分至同一竞争组；仅当一个值簇满足预设证据质量和适用条件且不存在达到竞争条件的非等价值簇时，生成事实值写入许可；原价和促销价、不同说话人、不同事件阶段或不同适用时间对应的观测因限定字段不同而划分至不同上下文。

**6.** 根据权利要求1所述的方法，其特征在于，A0 与 A2 的规范化答案事实采用由事件标识、主体角色和谓词构成的主映射键进行映射，事实值和限定字段用于确定迁移类型；迁移类型包括新增、替换、撤回、不确定化、保持和等价压缩，其中新增、替换和撤回属于实质答案事实迁移，保持和等价压缩不消耗事实值写入许可；A0 与 A2 在 E+ 下的核验结果采用相互排他的支持状态、证据不足状态、冲突状态和异常状态，异常状态不参与闭包提交，A0 与 A2 的核验记录均保存相同的 E+ 快照标识、核验配置标识、事实槽模式标识和状态判定规则标识。

**7.** 根据权利要求1所述的方法，其特征在于，当目标事实由两个以上上游事实确定性计算得到时，建立派生许可记录，所述派生许可记录包括全部上游证据差分许可标识、确定性运算符、输入单位、单位换算规则、舍入规则和 E+ 快照标识；仅在全部上游许可有效且计算结果与目标事实一致时，允许所述派生许可记录授权对应迁移。

**8.** 根据权利要求1所述的方法，其特征在于，若有向依赖边 X→Y 表示事实 Y 的成立依赖事实 X，则从实质答案事实迁移沿出边方向确定需要共同写入或共同不写入的下游事实作为状态写入集合，并沿入边方向确定核验所需的上游事实作为只读证明引用集合；所述只读证明引用集合不因被引用而成为回滚对象；依赖边限制为预设的实体、属性、数量、时间或因果关系，并受事件消歧、时间相容条件和节点数量上限约束；当第一语义依赖闭包的状态写入集合与第二语义依赖闭包的证明引用集合包含同一规范化事实映射键，所述规范化事实映射键至少包括事实槽、经消歧实体或事件、谓词和限定上下文，且第一语义依赖闭包针对所述规范化事实映射键存在拟写入的非等价目标事实状态时，在第一语义依赖闭包完成提交或其拟写入被禁止后，将第二语义依赖闭包的核验结果及其暂存目标事实状态标记为失效并重新核验；重新核验后仍存在写入—引用冲突时，将两个语义依赖闭包合并为联合闭包。

**9.** 根据权利要求1所述的方法，其特征在于，当语义依赖闭包被禁止写入时：若旧事实在 E+ 下处于支持状态，则保留所述旧事实；若旧事实处于证据不足状态且仍有取证预算，则继续取得增量视频证据，建立新的 ΔE 和 E+ 版本，将基于旧 E+ 的许可记录、A2 版本、核验结果、迁移配准关系和暂存闭包标记为失效，并依次重新执行许可生成、候选生成、联合核验和闭包门禁；若取证预算耗尽，则将对应事实槽设为不确定状态；若旧事实处于冲突状态且不存在受支持替代事实，则撤回所述旧事实；必填事实槽无法被唯一受支持事实填充时输出证据不足状态或拒绝回答，且不恢复 E+ 下已经处于冲突状态的 A0 事实；生成最终答案时，重组器的输入仅包括所述可输出状态集合中的事实标识、事实值和对应证据标识，将重组结果再次转换为输出事实集合，当存在不能映射至所述可输出状态集合的新增事实时，删除所述新增事实并重新重组，重新重组后仍存在新增事实时输出结构化事实集合、证据不足状态或拒绝回答。

**10.** 根据权利要求1所述的方法，其特征在于，记录问题标识、E0/E+ 快照摘要、增量证据标识、事实槽模式、证据差分许可、候选生成输入摘要、A2 内容摘要、联合读取时间、答案事实迁移、迁移—许可配准关系、依赖闭包、提交或禁止写入动作以及原因代码；当 E+ 内容、规范化规则或许可见证发生变化时，将对应许可及其已暂存迁移标记为失效并触发重新核验。
