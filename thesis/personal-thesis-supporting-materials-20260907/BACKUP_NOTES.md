# Personal thesis supporting materials backup — 2026-09-07

## Scope

This snapshot contains 19 owner-authorized personal thesis support files:

- 11 thesis construction, figure-generation, progress, and probe scripts
- 6 text extracts from thesis and patent source materials
- 1 software-copyright code-material PDF
- 1 reference PDF

Files are organized by content under `source/`, while `MANIFEST.tsv` preserves
the original relative source path and the corresponding backup path.

## Safety and verification

Before copying, all files were checked against the current private repository
for Git blob and Git LFS content matches; none had a current remote duplicate.
Common credential, identity-document, recovery-code, and company-marker scans
found no matches. PDF scans used embedded-text inspection because a dedicated
PDF text extractor was not available on this computer.

`SHA256SUMS` covers every backed-up source file. Original local files remain
in place until a fresh-clone checksum and byte-for-byte verification passes.
