# 敌对审查记录

## 首轮 P0/P1

1. 独权中的“可提交等级/迁移关系/未解决冲突”过于结果化。
2. 闭包部分成功与失败后的旧状态保留可能生成混合矛盾答案。
3. 声明值进入映射键会把替换误判为新增加撤回。
4. 跨闭包的“合并或禁止”属于任意二选一。
5. 事件消歧、必填槽、边生成和输出等价映射披露不足。

## 已执行修正

- 权1直接限定支持/不足/冲突、逐槽见证、事实槽冲突和全闭包原子提交。
- 任一必要迁移失败时，同闭包候选实质变化全部不写入。
- 回退采用固定优先级，且只保留 E+ 下仍受支持且无冲突的旧状态。
- 映射主键固定为 `(event_id, subject_role, predicate)`，值只判定迁移。
- 跨闭包先重核验，仍冲突则联合闭包；联合闭包整体通过才提交。
- 增加事件消歧、边规则、疑问词槽规则和输出等价映射。

## 仍需代理人判断

- 独权1是否需要进一步缩短；
- 跨闭包和匹配反事实是否保留在本申请；
- 验证器训练方法是否并案、分案或另案。
