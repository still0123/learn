# P0 最终建议

## 直白结论

V3不是“一查重就必然没有创新”，但当前独立权利要求的创造性组合风险为高。

最危险的是权1：审查员容易用“低分再看视频”的迭代方案结合“验证后修正答案”的方案，再把同一评分、双阈值和回退解释成常规工程选择。权7同样偏弱，因为正反声明、视频证据、冻结视觉编码器和语言侧LoRA都容易被视为常规训练手段；较有差异的最小破坏证据对目前仅在权8。

最值得保留的答辩支点，是同一经训练的声明—视频证据支持度量同时控制补证与换答，A2不以A0为改写输入，且候选不满足绝对和相对条件即回退。但现有实验只证明完整闭环有效，尚未单独隔离这一联动关系的额外效果。

## 建议顺序

1. 先做正式特征级查新；
2. 补共享支持度双用途门控消融；
3. 收紧权1的实现一致性；
4. 完成最小破坏证据对联合训练后，评估拆分第二申请；
5. 由代理人重写独权与创造性论证。
