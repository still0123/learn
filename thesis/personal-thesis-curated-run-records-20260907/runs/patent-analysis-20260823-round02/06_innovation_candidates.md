# P6 候选创新点再评级

## I1 同一支持度量驱动补证与换答

- 机制：同一经训练的视频声明支持度量先评价A0并触发新证据，再评价不输入A0生成的A2，只有绝对和相对条件同时满足才替换。
- 建议：保留为推理主线。
- 风险：高组合风险；需要专门消融证明不是D1+D2的可预期拼接。

## I2 真实视频最小破坏证据对训练

- 机制：只删除/遮蔽/错移原子声明的决定性视频、OCR或ASR证据，保持背景不变，用排序约束训练验证器。
- 建议：保留为窄从属或考虑独立拆案。
- 风险：端到端效果未确认；现有多模态反事实核查可用于组合攻击。
