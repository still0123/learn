# P7 强化策略

1. 正式查新必须按权1和权7逐项特征检索，而不是只搜标题或关键词。
2. 在权1中继续保持不可拆关系：A0与A2对应不同证据集合、A2不输入A0、同一经训练验证器采用相同聚合尺度、绝对阈值与相对裕量、失败回退。
3. 将“自动拆解原子声明”改为与实现一致的“获得原子声明，原子声明由独立拆解模块形成”，除非补足在线实现。
4. 考虑把真实视频最小破坏证据对训练上提到训练独权，并与推理申请拆分；前提是完成联合训练实现和效果验证。
5. 补一个固定A0、A2、证据和token的门控消融：共享支持度双用途门控 vs 随机触发/独立触发分数/仅绝对阈值/始终采纳A2，报告right-to-wrong与视频级Bootstrap。
6. 核实论文、代码、答辩材料和旧申请的公开时间，避免自有公开成为在先技术。
