# 09｜检索材料报告

## 检索问题

1. 是否已有“从视频先抽取事实元组，再约束问答输出”的专利；
2. 是否已有“候选答案生成前冻结证据事实”的预提交机制；
3. 多候选值、冲突证据和上下文消歧是否已知；
4. 事实—证据映射、版本、证明树和结构化更新是否可作为创新支柱；
5. 视频 OCR 跨帧观测是否会覆盖观测记录的具体实现。

## 关键命中

1. US9613317B2 / US10769552B2：候选答案与支持、反对或证明性证据的关联和评分；
2. US10068175B2：关键数据元素的可能值、证据关系和替代值并行处理；
3. US20230205824A1 / US9342608B2：冲突候选值和区分因素；
4. US20250005298A1：大模型生成输出的证据映射；
5. CN121660075A：最终答案事实抽取、证据 ID、来源、版本和审计；
6. WO2024073087A1：首份文本、逐声明证据、第二文本及输出门控；
7. US20250390544A1：模式约束下的结构化增量更新提案；
8. US20180121816A1 / US20210398000A1：观测/推导事实认证、版本和证明血缘；
9. US9064174B2：视频 OCR 的共同坐标、跨帧跟踪及识别结果合并；
10. WO2022271266A1：视频问答的语义范围和候选特征筛选。

## 检索后的设计变化

- 不把“有事实—证据映射”作为主创新；
- 不把“处理多个冲突值”作为主创新；
- 不把“结构化更新/JSON”作为主创新；
- 不把“证据版本、证明树或认证”作为主创新；
- 将核心缩为：由本轮 ΔE 形成的具体视频事实观测，先于 A2、候选值盲化地冻结，并在后续成为事实状态写入许可。

## 本轮未命中的完整关系

本轮没有发现单篇同时明确公开：

```text
本轮新增视频证据中的具体事实观测
→ 候选值盲化且先于替代答案冻结
→ 替代答案事实迁移做槽、上下文和值匹配
→ 匹配结果作为答案状态硬写入许可
→ 同上下文竞争观测直接禁写
```

## 检索限制

- 使用的是定向网页检索，不是 CNIPA、Derwent 或商业数据库的完整分类号检索；
- 部分 2026 年资料的公开日、申请日前可用性仍需代理人核验；
- “未命中”仅表示本轮结果，不表示不存在；
- 原申请的官方著录、公开范围、申请人关系和优先权问题仍须调档。
