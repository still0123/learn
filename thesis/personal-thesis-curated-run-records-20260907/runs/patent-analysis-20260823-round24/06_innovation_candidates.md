# 06｜创新候选筛选

## C1：预冻结类型化视频观测许可（主选）

从 ΔE 抽取具体事实元组和上下文，在 A2 前以候选值盲化方式冻结；后续事实迁移必须值匹配才能写入。

- 相对 V4.3：修复“覆盖清楚但候选值错误”漏洞；
- 单一性：高，同一记录贯穿取证和写入；
- 定向检索残余：中高；
- 实施成熟度：中低，底层字段已有、主逻辑未实现。

## C2：同上下文竞争值禁写（强从属/可并入独权）

按实体、谓词、限定字段、时间上下文和槽基数建立竞争组；存在两个达到条件的非等价值时，不对任一值发放许可。

- 直接解决多价格、多人物、多时间段中的错误择值；
- 冲突候选和消歧已有近邻，不能独立主张；
- 与 C1 结合可增强观测许可的确定性。

## C3：依赖闭包原子提交（强从属）

获许可的迁移先暂存，闭包中一项失败则候选闭包不提交。

- 防止价格更新而优惠差值未更新等部分写入；
- 通用事务和前序闭包思路近邻较多；
- 作为 C1 的强从属，不宜和 C1 并列宣传。

## C4：匹配反事实（从属/训练）

用同模态、近时间、同分辨率和同预算的非见证证据替换原见证，检查目标状态支持变化。

- 可强化证据必要性；
- 推理成本高、其他领域已有反事实近邻；
- 不作为主创新。
