# 08｜修订策略

## 建议独权保留

1. 问题事实槽模式及最少上下文字段；
2. 本轮 ΔE 和 E+ 快照；
3. 从 ΔE 抽取带具体值、限定字段和视频时空来源的规范化观测；
4. A2 前冻结且不使用 A0/A2 候选值作为检索、抽取或选证目标；
5. A2 不接收 A0 语义内容；
6. A0/A2 在同 E+ 下形成事实迁移；
7. 迁移必须与 RESOLVED 观测在槽、上下文和值上匹配才可写入；
8. 失败时禁止候选状态并输出 E+ 下安全状态。

## 默认下放从属

- 依赖闭包原子暂存/提交；
- 写入集合与证明引用集合冲突后的重核验；
- 具体竞争阈值、值簇算法和多模态质量规则；
- 匹配反事实；
- 确定性派生事实血缘；
- 快照 CAS、失效标记和恢复证明；
- 预算调度、审计摘要和最终无新事实终检。

## 可合并回独权的收紧特征

若正式检索发现一般预冻结事实表示近邻较强，优先把“同上下文竞争值时禁写”并入独权；仍不足时，再把“依赖闭包全量获许可才提交”并入。不要先把 OCR/ASR、知识库或模型名称堆进去。

## 删除或降级的表述

- 不把一般证据映射、事实认证、冲突检测、JSON 更新或事务称为独立创新；
- 不重复主张原申请的声画滑窗、三流响应图和自适应锚定；
- 不写“消除幻觉”“保证正确”或未记录的准确率提升；
- 不以 Full‑7844 证明 V4.4；
- 不宣称定向检索已确认新颖性或创造性。
