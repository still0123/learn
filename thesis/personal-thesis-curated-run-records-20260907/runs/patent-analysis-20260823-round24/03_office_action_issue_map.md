## 新的审查重点

1. “在 A2 前冻结”是否只是一般流水线顺序；
2. “答案值盲化”是否可被认为显而易见的防泄漏做法；
3. 规范化观测匹配是否只是把证据评分改成结构化等值比较；
4. 候选证据、事实映射和结构化更新能否被组合得到 H3—H9；
5. 槽模式、上下文、竞争条件及安全状态是否公开充分。
