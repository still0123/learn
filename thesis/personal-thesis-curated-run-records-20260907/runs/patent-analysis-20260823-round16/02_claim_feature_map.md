# V4 核心特征与本轮风险

| V4 特征 | 近邻风险 | 当前判断 |
|---|---|---|
| 缺口驱动增量取证 | Omni-Decision、Q-Guide | 不能单独作为创新主支点 |
| 证据见证与失败回退 | PBRC | 必须结合视频声明槽、同 E+ 复核和局部闭包限定 |
| 确定性状态提交 | Omni-Decision | 不能泛称“事务提交”即主张创新 |
| A0/A2 在同一 E+ 下对称复评 | 三篇当前核对未见直接披露 | 正式全文查新前仅为候选区别点 |
| A2 不接收 A0 作为改写草稿 | 旧案现有文本明确把 A0 作为待核查草稿 | 是与旧案的重要区分候选 |
| 有向声明依赖闭包、局部失效传播和无新增声明重组 | 三篇及旧案现有材料未见完整组合 | 是当前主张重点，但仍需全文和组合检索 |
