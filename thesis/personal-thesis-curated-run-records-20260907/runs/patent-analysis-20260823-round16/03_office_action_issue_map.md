# 法律与审查问题图

| 问题 | 法律性质 | 本案处理 |
|---|---|---|
| 未完成申请人自行全文查新 | 不是 CNIPA 不予受理的形式原因 | 设为内部实质风险 P0 |
| 未完成自身在先申请评估 | 不是 CNIPA 不予受理的形式原因 | 设为更高优先级的内部实质风险 P0 |
| 新颖性、创造性 | 授权实质条件 | 依据专利法第二十二条做特征比对 |
| 同样发明、抵触申请 | 可能影响授权 | 核对专利法第九条、第二十二条及旧案时间线 |
| 国内优先权 | 可能改变申请路径和时间 | 需确认旧案申请日、原始公开支持和十二个月期限 |
| 后补新内容 | 原则上不得超出原始记载 | 递交前必须把拟保护的闭包机制充分写入 |
