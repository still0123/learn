# 强耦合创新候选

## C1 首选：增量证据闭合的声明迁移提交机制

- 技术机制：将 A0、A2 分解并匹配为保留、新增、修改、删除声明；要求每个新增/修改声明由本轮 ΔE 中的具体帧、OCR 区域或 ASR 时间段支持，删除声明由 E+ 中的冲突或失去支持证明；保留的关键声明不得发生超过容差的支持退化。全部迁移满足后才提交 A2，否则回退 A0。
- 非堆叠理由：补证的输出不只是交给后续模块，而是成为每条答案变化的法定输入和提交条件；生成、验证和回退共享同一迁移对象。
- 效果目标：避免答案级均值掩盖单条新增幻觉或删除正确事实，减少无新增证据依据的错误替换。
- 本地支持：`claim_checker.py`、`evidence_package.py` 提供脚手架；完整迁移证书未实现。
- 权项：推理独权核心。
- 风险：中高候选；需对 CN122264085A、Omni-Decision、PBRC 继续逐权查新。

## C2：增量证据反事实必要性证书

- 技术机制：对 C1 中每个新增/修改声明，分别在 E+ 与移除其关联 ΔE 的反事实证据状态下评分；只有支持差达到冻结阈值，才认定本轮新证据对答案变化具有必要贡献。
- 非堆叠理由：反事实不是独立解释模块，而是 C1 提交谓词的一部分。
- 效果目标：拒绝与新答案变化无关的“伪补证”。
- 本地支持：已有 E+/E− 构造与排序脚本，但没有该推理时证书实现和端到端确认。
- 权项：窄独权备选或强从属。
- 风险：反事实证据归因已有近邻，必须绑定 C1。

## C3：声明缺口—模态—时序残差驱动的补证

- 技术机制：由低支持声明产生缺口向量 `(claim_id, missing_modality, time_uncertainty)`；OCR声明触发高分辨率文字区域，ASR声明根据声画偏移窗口获取视觉邻域，视觉声明从 E0 排除集合外取峰值帧。
- 非堆叠理由：取证参数直接由将要闭合的声明迁移生成，输出必须回填 C1 的证书。
- 效果目标：固定 Token 预算下减少重复或错误模态补证。
- 本地支持：声明类型映射和声画异步方案存在；当前 Full 锚点仍是问题驱动，不是声明缺口驱动。
- 权项：从属；也可形成另一申请。
- 风险：Q-Guide/Omni-Decision 已覆盖泛化缺口取证，必须保留视频时序与闭合关系。

## C4：声明安全约束下的序贯视觉预算

- 技术机制：按证据批次执行 `8→10→12` 视图；每批更新未闭合声明集合，达到 C1 的迁移提交条件即停止，预算耗尽仍未闭合则回退 A0 或输出证据不足。
- 非堆叠理由：停止条件不是通用置信度，而是迁移证书是否完整。
- 效果目标：在最大视觉预算固定时减少无效补看，同时保持错误替换约束。
- 本地支持：仅有固定 8→12 与 Token 上限；无序贯实现。
- 权项：从属/工程优化。
- 风险：主动感知和预算停止均拥挤，不能承担主创造性。

## C5：迁移感知的验证器训练

- 技术机制：训练样本不仅含声明支持/冲突，还包含旧声明、新声明、ΔE 及迁移类型；联合优化声明状态分类、同 E+ 下 A2>A0 的配对排序、移除 ΔE 后改变声明支持下降、保留声明稳定四类约束。
- 非堆叠理由：训练目标直接对应 C1 的提交谓词，而非通用事实核查。
- 效果目标：提高迁移证书的可校准性和关键声明退化识别。
- 本地支持：现有分类/排序/一致性损失可复用；迁移训练集不存在。
- 权项：训练独权或分案候选。
- 风险：实现和数据成本最高，当前只能标候选。
