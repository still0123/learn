# 模拟审查员批判

## 对旧 V4 的攻击

- D1 给出低置信补证再答，D2 给出验证初答并修正；同证据候选评分、阈值、margin 和回退是常规选择策略。
- 不输入 A0 只是提示词删除，不能产生足够技术贡献。
- “同一分数贯穿全流程”只是模型复用，不是功能上的相互作用。

## 对 C1 的继续攻击

- 将答案差异拆成声明并绑定证据 ID 可能只是解释/审计信息。
- PBRC 已要求任何变更引用外部验证见证集，Omni-Decision 已有显式证据状态和修复。

## 必须写入以提高抗辩性的限定

1. 声明迁移类型直接改变最终答案的 commit/rollback，而不是仅输出解释。
2. A0/A2 在同一 E+、同一验证器和同一聚合规则下评分。
3. 新增/修改/删除/保留四类迁移采用不同的机器判定条件。
4. 关联证据必须是 E0 未覆盖的具体视频位置/区域/语音时间段，并参与反事实必要性或支持增量计算。
5. 技术效果以错误替换、关键声明退化和固定视觉预算为指标，而不是泛称“更可信”。
