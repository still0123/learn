# 最终建议

不要通过继续增加模块来解决“堆叠”问题。应把专利重构成一个单一发明概念：

> 对旧答案与候选答案执行声明级差异分析，将每一项答案变化绑定到本轮新增视频证据；只有所有声明迁移完成证据闭合并通过同扩展证据配对评分时才提交新答案，否则回退旧答案。

建议将其命名为“增量证据闭合的声明迁移门控”或“证据约束的答案变更事务”。它比“补证+独立生成+评分+双阈值”更抗堆叠，因为补证结果、答案差异、验证结果和最终选择围绕同一声明迁移对象发生不可拆的数据依赖。

优先级：

1. C1 声明迁移证书：主独权候选。
2. C2 反事实必要性：强从属，绑定 C1。
3. C3 声画异步的声明缺口补证：从属或另一申请。
4. C4 序贯预算：工程从属。
5. C5 迁移感知训练：补齐数据后再考虑训练独权/分案。

当前门禁：C1-C5 均未形成完整代码和冻结实验，只能作为 V4/V5 候选方向；不能将 Full-7844 的既有数字作为这些机制的效果证据。
