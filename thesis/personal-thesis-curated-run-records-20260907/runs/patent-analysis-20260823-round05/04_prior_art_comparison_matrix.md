# 新增现有技术矩阵

| 近邻 | 已公开核心 | 对新候选的压力 | 尚可争取的差异 |
|---|---|---|---|
| CN121388101A | 低置信迭代补充视觉信息并再答 | 补证主框架高风险 | 无旧/新答案声明迁移和增量证据闭合 |
| CN117744802A | 初答进入验证链并修正 | 初答核验高风险 | A2隔离、视频新证据、配对状态提交 |
| CN122264085A（待官方核验） | 同图像证据下生成多候选并由选择模型裁决 | 同证据候选比较被压缩 | 不是基于新证据解释旧→新声明迁移 |
| Q-Guide | 识别缺失证据并调用定向视觉工具 | 泛化“缺口→定向补证”被压缩 | 视频时序、旧/新答案迁移和提交证书 |
| Omni-Decision | 显式证据状态控制规划、取证、验证、修复、停止 | 泛化证据状态机被压缩 | 对 A0/A2 差异逐声明证明本轮新增证据的贡献 |
| PBRC | 证据触发、见证集和保守回退 | “变更需新证据”概念被压缩 | 视频帧/OCR/ASR证据、同证据配对评分、声明迁移规则 |
| SciClaimEval/CMA | 修改证据构造反例、反事实模态贡献 | 反事实本身不是新点 | 将反事实必要性作为答案变更证书的一项提交条件 |
