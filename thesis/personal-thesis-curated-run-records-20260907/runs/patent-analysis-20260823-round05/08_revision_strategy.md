# 权利要求收敛策略

## 建议题名

`一种基于增量视频证据闭合的答案变更控制方法及装置`

## 推理独权骨架

1. 由初始视频证据 E0 生成 A0，并得到声明级支持状态。
2. 存在未闭合声明时，从 E0 未覆盖位置取得 ΔE，形成 E+。
3. 在不输入 A0 的隔离上下文中由 E+ 生成 A2。
4. 对 A0/A2 的原子声明进行匹配，形成保留、新增、修改、删除的声明迁移集合。
5. 在同一 E+ 上评分 A0/A2；为发生变化的声明建立到 ΔE 的证据映射。
6. 仅在新增/修改声明被 ΔE 闭合、删除声明被冲突/失去支持证明、保留关键声明不退化且答案级双门槛满足时提交 A2，否则回退 A0。

## 从属布局

- 反事实移除 ΔE 的必要性检查。
- 声画异步窗口及声明缺口到模态取证动作的映射。
- 证据排除集合、时间秩间隔、证据 ID 结构。
- 序贯视觉预算和证据不足输出。
- 异常回退、视频级隔离阈值校准和审计。

## 不再承担创造性的特征

MMR、固定帧数、OCR/ASR本身、裁剪、LoRA、Token上限、日志、单个阈值和广告场景。
