## 已合并的部分 deep-research 外部线索

> 以下内容来自正在运行中的 deep-research 已返回的**部分可靠来源**，目前用于增强组合风险判断；最终仍以 workflow 完成后的完整核验版为准。

### 外部线索 A：TVQA（EMNLP 2018）

- 来源：`https://arxiv.org/abs/1809.01696`
- 已提取到的核心点：
  - TVQA 明确要求**局部时间证据定位**；
  - 联合使用字幕/对话与视觉线索进行视频问答；
  - 已有 multi-stream end-to-end model baseline。
- 对本案的影响：
  - 会削弱对“视频问答 + 局部时序证据定位 + 字幕/视觉联合推理”的宽泛主张；
  - 但 TVQA 仍不足以直接公开“问题 + ASR + OCR/Logo 三源协同响应图”以及广告视频场景下的声画异步处理链条。

### 外部线索 B：TextVQA / LoRRA（Towards VQA Models That Can Read）

- 来源：`https://arxiv.org/abs/1904.08920`
- 已返回摘要结论：场景文本保留与读取已经是视觉问答中的成熟路线。
- 对本案的影响：
  - 会削弱对“加入 OCR / 保留文字细节”本身的主张；
  - 反过来要求我们把重点放在**广告视频里的 OCR/Logo 与 ASR/问题语义如何共同参与证据定位**，而不是只强调“能读文字”。

### 外部线索 C：FEVER

- 来源：`https://arxiv.org/abs/1803.05355`
- 已返回摘要结论：claim-level evidence verification 在事实核验领域已有强先例。
- 对本案的影响：
  - 会削弱对“声明级证据回溯/核验”这一宽泛层面的主张；
  - 因此本案如果继续保留链式校验，必须突出其**多模态证据回溯、广告视频高风险声明类型触发、以及与上游证据流闭环的耦合**。

### 外部线索 D：KSR v. Teleflex + MPEP 2143

- 来源：
  - `https://www.law.cornell.edu/supct/html/04-1350.ZS.html`
  - `https://www.bitlaw.com/source/mpep/2143.html`
- 对本案的影响：
  - 从专利审查/显而易见性角度，**把已知部件按已知方式组合并得到可预期结果**，非常容易被认定 obvious；
  - 因此“过采样 + global/local + OCR + RAG + verification”如果只是并列堆叠，组合风险极高；
  - 只有当我们能证明若干步骤之间存在**特定技术动机、连续耦合关系、以及非可预期的联合效果**时，才更有机会抗辩。

## 小结

### 当前更适合保住的方向

1. **F-02 视听-文字协同响应图 + 声画异步滑动窗口**
2. **F-03 响应密度驱动自适应锚定 + 双流视觉表征**
3. **F-04 证据约束的广告知识检索**（作为依附特征）

### 当前高风险方向

1. **F-06 链式校验**：容易被 D2 吸收为自验证框架。
2. **F-05 结构化链式推理**：容易被解释为普通 CoT / prompt 协议。
3. **F-07 evidence package / evidence ID**：更像后续系统化布局点，当前原始公开支持不足。
