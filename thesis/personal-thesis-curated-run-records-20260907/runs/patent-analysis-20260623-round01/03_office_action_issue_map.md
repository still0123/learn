# P3 审查意见问题图谱

## O-01 D1 作为通用视频问答主框架基底

- 被驳回权利要求：1-6。
- 审查员使用的对比文件：D1（CN121388101A）。
- 审查员映射逻辑：D1 已公开视频文件 + 自然语言查询、采样关键帧、初始字幕、多模态生成答案、置信度迭代优化。
- 显而易见组合路径：把本申请的一般框架先压缩为“通用视频问答主流程”。
- 当前答复弱点：现有意见陈述仍花大量篇幅证明“不相当于”，但没有把主线重新组织成“证据流闭环”，容易看起来仍在解释模块。
- 可反制点：强调广告视频场景中的声画异步、短时文字/Logo、营销隐喻与目标受众推理，并把这些问题与后续证据定位/证据解释/证据校验耦合起来，而非仅强调“视频问答用于广告”。
- 需要补充的证据：对广告视频特有失败模式的本地实例或后续实验支撑。

## O-02 D2 吸收“链式校验/自我验证”

- 被驳回权利要求：1 及其依附特征。
- 审查员使用的对比文件：D2（CN117744802A）。
- 审查员映射逻辑：D2 的自我验证生成验证问题、比较答案、修正答案，足以启发链式校验；高风险触发、确认/修正令牌被视为本领域常规设计选择。
- 显而易见组合路径：把本申请的校验机制压缩为“文本自验证框架 + 常规触发条件 + 常规反馈格式”。
- 当前答复弱点：现有意见陈述强调了参数冻结、多模态证据回溯和高风险触发，但仍缺少“为什么这三者必须一起出现才能解决广告视频问答的特定幻觉类型”的更强证据。
- 可反制点：把校验对象从“答案整体”改写为“多模态证据约束下的高风险声明核查”；强调文本细节/逻辑因果/语音内容三类风险并不是任意配置，而是广告视频问答中的高风险失真位点。
- 需要补充的证据：后续最好给出声明类型、证据类型和纠错类型之间的结构映射表。

## O-03 D3 吸收全局/局部特征与外部知识检索

- 被驳回权利要求：1、3、4 等围绕双流视觉表征与广告知识检索的内容。
- 审查员使用的对比文件：D3（CN121765049A）。
- 审查员映射逻辑：D3 已公开全局图像 + ROI 局部图像、外部知识库 Top-K 检索、把上下文送入 LLM 生成答案，因此本申请的双流视觉表征和知识检索显而易见。
- 显而易见组合路径：把本申请压缩为“global/local + RAG + LLM”。
- 当前答复弱点：现有意见陈述已经指出 D3 是静态图文场景，但尚未把“证据约束检索”与“广告专业知识维度”进一步形式化。
- 可反制点：强调本申请不是普通外部知识检索，而是“问题 + 双流视觉证据 + 广告领域维度”的联合检索；知识条目必须与视频证据对齐，而不是只与问题对齐。
- 需要补充的证据：本地代码中 evidence-conditioned retrieval 的实现片段可作为工程支撑，但还需外部检索补强公开差异。

## O-04 D4/D5 吸收跨模态对齐、约束解码、热力图与局部定位

- 被驳回权利要求：2-5 中与跨模态对齐、结构化约束、热力图和局部精细视角有关的内容。
- 审查员使用的对比文件：D4（CN121031606A）、D5（CN121350217A）及公知常识。
- 审查员映射逻辑：D4 可启发 CLIP 对齐、音视频对齐和约束解码；D5 可启发 Grad-CAM/热力图定位；多模态热力图融合被视为惯用手段。
- 显而易见组合路径：把本申请压缩为“跨模态对齐 + 热力图 + 局部区域裁剪 + 约束解码”的常规工程组合。
- 当前答复弱点：虽然意见陈述强调了“三模态热力图 + 时序滑动窗口 + 语义重心 + 响应密度”的整套链条，但缺少更明确的层级表达：哪些是单个工具，哪些是必须协同出现的技术路径。
- 可反制点：把重点从“用了热力图”改成“多模态响应图协同生成 + 声画异步矫正 + 语义重心定位 + 多尺度响应密度筛选”的连续过程。
- 需要补充的证据：后续需要更明确地区分“单一热力图”与“多模态协同响应图”的技术效果差异。

## O-05 当前答复策略本身的风险

- 被驳回权利要求：整体答复逻辑。
- 审查员使用的对比文件：D1-D5 的组合。
- 审查员映射逻辑：把申请分解为若干常规模块，并按功能对位找到启示。
- 当前答复弱点：
  1. 权利要求1未进一步限缩；
  2. 论证较长，但关键耦合机制仍容易被读成“把几个常见模块组合起来”；
  3. 缺少代码/工程支撑去证明某些中间层设计并非口头抽象；
  4. 对“哪些点适合当前答复、哪些更适合继续申请”尚未分层。
- 可反制点：
  1. 统一主线为“证据定位 → 证据压缩 → 证据解释 → 证据校验”；
  2. 明确当前最值得保的核心特征是三模态协同响应与自适应锚定；
  3. 把“证据约束检索”和“触发式校验”作为依附于证据流闭环的耦合点，而非孤立模块；
  4. 对原始公开较弱的新点直接转入继续申请/新申请策略。
