## 推荐权利要求策略

### 独立权利要求可考虑限定

- 把真正的核心从“链式反思”切换到“视听-文字三模态协同响应 + 声画异步处理 + 自适应锚定 + 双流视觉表征”。
- 强调：
  1. 问题语义、ASR 语义、OCR/Logo 语义共同参与响应图生成；
  2. 通过时间窗口与加权融合处理声画异步；
  3. 基于语义重心、多尺度候选框和归一化响应密度提取局部精细视角。

### 从属权利要求可新增/强化

- 广告知识库维度及其检索方式；
- 结构化语义约束协议；
- 高风险触发关键词类型；
- 确认令牌/修正令牌的反馈机制。

### 不建议加入当前权利要求的内容

- evidence package / evidence id 全链路追踪；
- 没有明确原始公开支撑的软件架构层细节；
- 任何未经实验支撑的性能收益表述。

## 3. 推荐意见陈述策略

- 审查员拆解路径：通用视频问答 + 过采样 + 全局/局部 + RAG + CoT + 自我验证 + 热力图 + 广告场景。
- 我方反制主线：上述拆解忽略了本申请围绕广告视频高信息密度与声画异步问题构造的**连续证据流闭环**，其关键不在于单个模块，而在于“证据定位—证据压缩—证据解释—证据校验”的有机耦合。
- 推荐论证顺序：
  1. 先打三模态协同响应图与声画异步；
  2. 再打响应密度驱动的自适应锚定与双流视觉表征；
  3. 再说明广告知识检索是证据解释层；
  4. 最后谨慎使用链式校验作为高风险声明核查机制。
- 不应使用的论证：
  - “我们用了 RAG 所以更强”；
  - “我们用了链式思维/自反思所以更创新”；
  - “这是普通视频问答迁移到广告领域”；
  - “一定具备创造性/一定可以授权”。

## 5. 风险清单

- 新增内容风险：evidence ID 全链路追踪和更细的软件架构层设计原始公开不足。
- 创造性风险：链式校验、普通 RAG、普通 CoT 最容易被现有技术吸收。
- 技术效果证据风险：目前只能做定性效果主张，不能做量化性能主张。
- 代码实现风险：最强视觉特征（协同响应图、自适应锚定）当前缺少直接实现。
- 法律表述风险：若继续坚持“当前权利要求1无需限缩”，可能会削弱答复说服力。
- 已并入的部分外部 research 风险提示：
  - `TVQA` 已经显著覆盖“局部时序证据定位 + 字幕/视觉联合推理”的宽泛表述；
  - `TextVQA/LoRRA` 会削弱“保留 OCR/文字细节”本身的宽泛主张；
  - `FEVER` 会削弱“声明级证据回溯/验证”这种宽泛层面的新颖感；
  - `KSR` 与 `MPEP 2143` 提醒：如果你的方案只是把过采样、global/local、OCR、RAG、verification 这些已知部件拼在一起并产生可预期结果，组合风险会非常高。
