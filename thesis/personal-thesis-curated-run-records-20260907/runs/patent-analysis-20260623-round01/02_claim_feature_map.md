# P2 权利要求-技术特征映射

## F-01 过采样与语义关键帧优选

- 权利要求文本：对视频进行过采样与基于语义的关键帧优选，得到关键帧序列及对齐后的语音文本。
- 归一化技术含义：先高频保留广告视频中的短时关键信息，再用问题/语音语义筛选相关关键帧。
- 所属步骤/模块：预处理与证据定位入口。
- 原始公开支持：`source_texts/patent_docx.txt` 中 S1、步骤一部分。
- 代码/论文支撑：当前代码中未见真实视频过采样实现；更像待实现或实验层内容。
- 被审查员攻击风险：中。
- 修改潜力：可保留为上游预处理，但单独主张容易被审查员视为常规优化。

## F-02 视听-文字协同响应图与声画异步处理

- 权利要求文本：构建视听和文字协同感知机制；引入 OCR 语义向量；通过时序滑动窗口与加权融合机制解决声画异步问题。
- 归一化技术含义：问题、ASR、OCR/Logo 三类文本信号共同指导视觉证据定位，并显式处理广告视频的声画异步。
- 所属步骤/模块：证据定位核心。
- 原始公开支持：`source_texts/patent_docx.txt` 中摘要、S2、发明内容第一点。
- 代码/论文支撑：当前代码暂无真实响应图计算；仅有文字级 evidence container 支撑后续流程。
- 被审查员攻击风险：中。
- 修改潜力：这是当前最值得保留和强化的核心特征之一。

## F-03 响应密度驱动的自适应锚定与双流视觉表征

- 权利要求文本：基于响应密度指标与多尺度策略自适应生成锚框，提取局部视觉特征，并保留全局语义特征，构建双流视觉表征。
- 归一化技术含义：先找语义重心，再以多尺度候选框和归一化响应密度选出最优局部区域，与全局图共同送入下游推理。
- 所属步骤/模块：证据压缩。
- 原始公开支持：`source_texts/patent_docx.txt` 中 S2、公式说明、发明内容第一点。
- 代码/论文支撑：现有代码没有真实 anchor/crop 流程；目前仅存在 text-level evidence package。
- 被审查员攻击风险：中。
- 修改潜力：可作为当前答复和后续继续申请的共同重点。

## F-04 证据约束的广告知识检索

- 权利要求文本：根据用户问题与双流视觉表征提取语义关键词，在多维广告宣传专业知识库中检索，以获取匹配的专家上下文信息。
- 归一化技术含义：不是单纯问句检索，而是结合视频证据和问题，共同驱动广告知识检索。
- 所属步骤/模块：证据解释。
- 原始公开支持：`source_texts/patent_docx.txt` 中 S3、发明内容第二点。
- 代码/论文支撑：`code_refactor/rag/retriever.py` 已有 `evidence_score` 和 `supporting_evidence_ids`；说明代码层面已有方向性实现。
- 被审查员攻击风险：中高。
- 修改潜力：适合作为依附于“证据流”的中游特征，而不宜单独包装为“用了 RAG”。

## F-05 结构化语义约束下的链式推理

- 权利要求文本：驱动大语言模型在结构化语义约束下进行链式推理与答案生成，遵循“观察—分析—推理—答案”。
- 归一化技术含义：把视频证据、知识和问题组织进固定的推理协议，限制生成过程。
- 所属步骤/模块：证据推理。
- 原始公开支持：`source_texts/patent_docx.txt` 中 S4、发明内容第三点。
- 代码/论文支撑：`code_refactor/reasoning/prompt_builder.py` 已体现 Observation / Knowledge Matching / Analysis / Answer 的结构化协议。
- 被审查员攻击风险：中高。
- 修改潜力：必须绑定到证据流闭环，单独主张“CoT/结构化提示”说服力弱。

## F-06 触发式链式校验与多模态证据回溯

- 权利要求文本：检测高风险触发关键词；保持模型参数冻结；将问题、初始答案和双流视觉表征再次输入；回溯关键帧序列与对齐后的语音文本；输出确认令牌或修正令牌。
- 归一化技术含义：只在高风险问题上启动事实核查，并用冻结模型回查多模态证据，对答案做保留或修正。
- 所属步骤/模块：证据校验。
- 原始公开支持：`source_texts/patent_docx.txt` 中 S5；`source_texts/patent_opinion_statement.txt` 中现有答复也把它列为区别特征 C。
- 代码/论文支撑：`code_refactor/reflection/claim_checker.py` 已有按声明类型路由证据的雏形，但没有真正的 frozen-LLM + tokenized correction loop。
- 被审查员攻击风险：高。
- 修改潜力：适合作为当前答复的重要特征，但必须强调“触发式 + 多模态证据回溯 + 证据可追溯”，否则容易被压到 D2 的自验证框架里。
