# 05｜代码实现映射

| 机制 | 现有基础 | 新增工作 | 难度 |
|---|---|---|---|
| 帧/OCR/ASR 证据 ID 与时空位置 | 现有 EvidencePackage 和实验记录可复用 | 统一快照摘要 | 低—中 |
| SlotSchema 和规范化事实 | 有声明检查计划基础 | 增加值类型、限定字段、基数规则 | 中 |
| E0/E+ 观测差分许可 | 无完整实现 | 新增许可对象、竞争组、失效逻辑 | 中—高 |
| 候选生成 ACL/API 隔离 | 无完整实现 | 拆服务账户或输入字段白名单 | 中 |
| A0/A2 同 E+ 事实迁移 | 有验证器和声明拆分基础 | 新增统一映射键和迁移记录 | 中 |
| 迁移—许可唯一配准 | 无完整实现 | 新增匹配谓词和失败码 | 中 |
| 闭包原子提交 | 无完整实现 | 新增暂存、提交和回滚状态 | 中—高 |
| 审计时序 | 有日志基础 | 记录四个时间点和联合读取 | 低—中 |

结论：V4.5 可实施，但不能表述为已经完整实现。
