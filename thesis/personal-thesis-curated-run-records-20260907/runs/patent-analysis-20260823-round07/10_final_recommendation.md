# 最终建议

最新建议方向约八成五可采纳，明显优于上一版，但不能原样定稿。

必须修正四点：

1. “连通分量间有边则合并”在数学上自相矛盾，应改成从变化节点沿带类型、带方向的依赖边迭代求可达闭包。
2. 五类迁移可作为完整实施方案，但不宜全部穷举进独权；保留和等价压缩并非实质事实变化，撤回与不确定化也应分别定义状态后果。
3. 可把具体绝对阈值、相对裕量放入从属，但独权必须保留同 E+ 的可比较核验、预设接受谓词及失败回退，否则容易退化为抽象事务规则。
4. 闭包局部提交必须配套结构化答案重组和“不得新增声明”终检，否则重组阶段会破坏闭合结果。

另一个不能遗漏的既有分界是：若 V4 继续依靠“A2 不接收 A0 文本作为生成输入”区别初答自修订方案，该限定必须与代码和实验保持一致；否则不应仅为规避文献而写入。

建议独权主线：

> 对初始答案和候选答案的声明建立带类型的有向依赖关系，从实质变化声明迭代确定依赖闭包；在同一扩展视频证据集上核验闭包内旧、新声明，使实质变化绑定本轮增量视频证据的时空模态见证并满足其迁移类型对应的预设闭合条件；闭包满足接受条件时提交相应声明状态，否则恢复该闭包的初始声明状态。

该主线的单一发明构思比“补证+验证器+门控”的并列组合更清楚，但仍需最小实现、失败分支和冻结记录后才能成为稳健的申请稿。
