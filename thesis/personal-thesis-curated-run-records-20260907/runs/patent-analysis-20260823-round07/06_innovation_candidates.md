# 创新候选

## C1：有向声明依赖闭包事务

从 A0→A2 的实质变化声明出发，沿实体约束、属性归属、数量归属、时间约束、因果或指代等有向依赖边迭代求可达闭包；闭包内变化通过预设证据判据时提交，否则整体回退。

## C2：迁移类型的不对称闭合

- 新增：新声明得到 ΔE 见证支持。
- 替换：新声明获支持，且旧声明与新增证据冲突或新旧二者满足预设优势关系。
- 撤回/不确定化：在达到预设取证覆盖后旧声明仍不足，不得据此断言相反事实。
- 保留：同 E+ 下不得发生关键支持退化。
- 等价压缩：语义等价且不减少证据覆盖；不作为实质事实迁移强制绑定 ΔE。

## C3：匹配控制的见证必要性

将目标见证的移除效应与同模态、近似时间位置、相同分辨率和预算且经核验为非见证的控制证据移除效应比较，降低输入布局和长度扰动造成的伪贡献。
