# 权利要求特征映射

| 层级 | 建议保留的限定 | 不宜全部塞入独权的内容 |
|---|---|---|
| 独权 | A0/A2 声明结构；有向依赖关系；从实质变化节点求依赖闭包；同一 E+ 下比较；ΔE 见证；预设闭合判据；闭包提交/回退 | 五类完整枚举、具体阈值数值、所有证据字段、反事实公式 |
| 强从属 | 不同迁移类型的不对称判据；匹配控制反事实；同 E+ 的绝对支持与相对优势 | 固定模型和数据集参数 |
| 实施例 | 时间窗、分辨率、Token 预算、阈值、最大闭包规模、重组器实现 | 不必要的结果性表述 |

五类迁移适合作为说明书中的完整状态设计，但独权宜用“实质变化/非实质等价变化”及“至少包括”表达，避免穷举性自限。
