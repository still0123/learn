## 1. 当前正式稿保持不改

### 1.1 推理侧方法独权核心

当前权利要求 1 的核心关系保持不变：

1. 从视频帧和带时间段语音文本形成初始证据，并生成初始答案。
2. 声明－证据支持度验证器按照预设协议，将答案拆解为原子声明、估计声明支持状态并聚合为答案级支持度。
3. 初始答案支持度低于触发阈值时，获取与初始证据不同的补充视频证据。
4. 基于增强证据独立生成候选答案，不以初始答案为改写对象。
5. 由同一验证器按照同一评分协议评价初始答案与候选答案。
6. 候选答案同时满足绝对替换阈值和相对提升裕量时才替换。
7. 条件不满足或生成、拆解、评分失败时回退初始答案。

上述必要关系构成“同一支持度量控制补看触发和候选采纳”的闭环。现稿不加入 P01-P08 的任何新术语、状态结构或计划实验。

### 1.2 验证器训练独权核心

当前权利要求 7 的核心关系保持不变：

1. 获取样本回答、参考答案、用户问题及包含视频帧和带时间段语音文本的视频证据。
2. 将样本回答拆解为原子声明，并依据其与参考答案的关系标注正标签声明或反标签声明。
3. 以证据视图、用户问题、原子声明和支持状态监督训练多模态基座模型的至少部分参数。
4. 得到能够输出声明级支持度并聚合为答案级支持度的声明－证据支持度验证器。

### 3.1 P02：互斥带符号声画时延假设格

**未来独权必须保留的必要关系：**

```text
视觉事件和带时间范围的音频/ASR事件
-> 在有界正负时延范围内提取多个局部关联峰
-> 形成记录方向、时延区间、峰宽、来源及互斥组的时延假设格
-> 由问题中的实体、动作或属性槽位选择相容时延边
-> 按所选边联合回取两端视听证据并生成答案
-> 无有效边时输出单模态降级状态和边级证据回执
```

非平凡关系必须是：带符号时延同时控制事件配对、回取范围和冲突方向；互斥组禁止相反方向假设被平均成伪同步；问题槽位实际决定采用哪条边。仅扩大滑动窗口、修改距离衰减、执行普通互相关、动态时间规整或多模态拼接均不能作为核心。

**实验门槛：**

1. 建立旁白领先、视觉领先、近同步、无关四类双审数据，预注册边界、冲突处理和一致性统计。
2. 证明联合模态路径真实激活，不能复用旧 AV 退化为 CLIP 的结果。
3. 固定事件候选、ASR 文本量、视图数、视觉/文本 Token 和回答器，对照零时延、固定滑窗、Scene-RAG 式场景对齐。
4. 独立删除互斥组、时延符号和问题槽位；完整方法的收益不得来自更多上下文。
5. 预注册至少一个配对机制主指标和一个 QA 主指标；相对最强对照的差异置信区间方向为正，且三个核心删除项均出现可归因退化，否则停止独权方向。
6. 新冻结版本重新通过 I3：总分 `>=80`、全部七项分项达线、无硬失败，并获得非空 `PASS_TO_I4`，之后才能启动 I4。

### 3.2 P03：镜头曝光欠账守恒

**未来独权必须保留的必要关系：**

```text
镜头切分
-> 为各镜头记录时长、切换强度、语义变化、实体连续性和已分配视图
-> 先满足每镜头最低覆盖
-> 由冻结状态转移计算镜头曝光欠账
-> 同一欠账状态触发高欠账镜头的边界后/中部/边界前突发增配
-> 从低欠账且超过最低覆盖的长静态镜头回收等量预算
-> 在固定总视图和视觉 Token 下输出实际帧、分配及预算回执
```

非平凡关系必须是：同一欠账状态共同控制最低覆盖、突发增配和等量回收，并满足预算守恒。仅使用镜头检测、短镜头多采样、覆盖约束、相关性排序、熵/注意力调度或生成前预算审计不能作为核心。

**实验门槛：**

1. 冻结欠账状态变量、状态转移、清偿条件、预算冲突优先级和守恒公式。
2. 建立快切镜头及决定性事件双标注集，记录压缩前后实际保留帧。
3. 在等解码帧、等视图、等视觉 Token、同回答器条件下执行 Uniform、MMR、EcoFrame、CREST、Exposure 五臂实验。
4. 对照等价标量排序、每镜头单帧，并分别删除最低覆盖、等量回收、三时刻突发和实体连续性。
5. 预注册快切子集的机制主指标和 QA/Token 主指标；完整方法须正面超过 EcoFrame 与 CREST，优势不能来自更多解码帧，任一核心关系无独立效应即停止独权方向。
6. 新冻结版本重新通过 I3 的全部门槛并获得非空 `PASS_TO_I4` 后，方可进入 I4。
