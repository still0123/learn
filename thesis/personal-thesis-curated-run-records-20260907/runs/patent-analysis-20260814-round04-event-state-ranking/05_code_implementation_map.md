# P8 代码实现映射

| 方向 | 代码状态 | 可复用基础 | 需要新增 | 难度 |
|---|---|---|---|---|
| 广告事件状态链 | scaffold | 逻辑树 `SEQ/RIGHT_AFTER`、有序帧选择、时间戳 | 实体关联、状态节点、转移边、路径匹配和状态差分标注 | 高 |
| 声明条件化证据行为 | 部分实现 | 原子声明、声明类型、所需模态、支持评分 | 行为契约、时间接受谓词、轨迹聚合和路径许可 | 中 |
| 短时文字生命周期 | 部分实现 | OCR 时间戳、框、置信度、跨帧重复统计 | 文字轨迹关联和 `APPEAR/STABLE/CHANGE/DISAPPEAR` 状态 | 中 |
| 事实与营销意图分层 | 部分实现 | 观察/知识/声明状态文档、声明类型、结构化提示 | 事实—意图依赖边和 fail-closed 许可执行器 | 低至中 |
| 失败与不存在分离 | 部分实现 | ASR 的无音频/无语音/转写失败状态、候选 C 小试 | OCR/视觉统一状态、覆盖证明、否定许可门禁 | 中至高 |

## 实现优先级

1. 先实现不依赖模型训练的 `BehaviorContract`、`EventStateNode`、`TransitionEdge` 数据结构和确定性校验器。
2. 用现有时间戳与 OCR/ASR 缓存构造人工可审计的小样本事件链。
3. 再训练状态、边和路径排序头；不得直接把生成答案准确率作为唯一训练信号。
4. 短时文字生命周期作为第一种可落地的状态节点类型。
5. 失败/不存在分离另建实验，不从空 OCR 或空 ASR 自动生成“真实不存在”标签。

## 边界

当前仓库没有完整事件状态链、声明行为契约或缺席覆盖证明实现；不能把设计稿表述为已实现。
