# P5 模拟审查员批判

## C-01 对纯“广告事件状态链”的攻击

- **结论**：原表述不通过。
- **理由**：事件图、状态机、动作前后状态和时间关系均是视频理解常规手段；把节点替换成产品、价格和 Logo 只是场景字段变化。
- **补强**：必须加入“声明行为契约限定状态节点、允许边和完整路径，完整路径再直接控制声明许可”的双向约束。
- **幸存性**：修改后进入查新候选。

## C-02 对“声明条件化证据行为”的攻击

- **结论**：原表述不通过。
- **理由**：Logo 重复、价格短闪、动作连续和情绪持续可被解释为四类人工规则或问题类型路由。
- **补强**：将每类行为转成机器执行的时间接受谓词，并要求同一检测结果在不同契约下形成不同轨迹聚合和支持状态。
- **幸存性**：与事件状态图耦合后为本轮最强。

## C-03 对“短时文字生命周期”的攻击

- **结论**：不宜独立。
- **理由**：视频文字检测、跨帧跟踪、出现/消失和文本变化检测现有技术拥挤。
- **补强**：限定生命周期状态控制问题时点有效价格/CTA 版本，并禁止前后文字值拼接。
- **幸存性**：作为从属特征。

## C-04 对“事实与营销意图分层”的攻击

- **结论**：不通过。
- **理由**：事实/推断分层、知识图谱和证据许可容易被视为认知规则、业务规则或结构化提示；旧案的广告知识与结构化推理已受到直接攻击。
- **补强**：事实节点状态变化必须自动撤销依赖意图节点的机器许可。
- **幸存性**：仍为高风险实施例，不进入主权。

## C-05 对“检测失败与真实不存在分离”的攻击

- **结论**：有条件通过。
- **理由**：`FAILED/UNKNOWN/ABSENT` 可被视为普通错误码；覆盖阈值和重试也可能属于常规工程选择。
- **补强**：将检测有效性、时空覆盖、替代观察和否定输出许可形成不可拆分的状态升级条件。
- **幸存性**：适合作为第二申请候选；本地证据不足以主张跨模态准确率提升。

## 敌对排序

1. 方向 1 与方向 2 融合后的“声明条件化事件状态路径”；
2. 方向 5 的“覆盖证明约束否定许可”；
3. 方向 3 作为第一项的文字生命周期从属；
4. 方向 4，仅作实施例。
