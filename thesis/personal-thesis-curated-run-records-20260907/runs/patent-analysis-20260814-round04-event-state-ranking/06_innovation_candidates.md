# P6 创新候选

## I-01 声明条件化的广告事件状态路径

### 技术机制

将问题或候选声明转换为证据行为契约。契约限定所需状态角色、允许的状态转移边、时间连续性、可重复性和路径完整条件；随后从同一广告对象的多模态观测构造状态转移图，仅允许满足契约的完整路径支持相应声明。

### 关键结构

```text
BehaviorContract = {
  claim_type,
  required_roles,
  allowed_edges,
  continuity,
  repeatability,
  completion_rule
}

EventStateNode = {
  entity_id,
  state_value,
  time_interval,
  modality,
  source_id,
  observation_status
}
```

### 为什么不是模块拼接

声明契约直接决定图中哪些节点和边可被接受；图路径完整性又直接决定声明许可。缺少任一对象，另一对象无法独立完成回答。

### 训练

- 顺序交换；
- 动作结果删除；
- 价格或状态值替换；
- 相同 Logo/背景但无目标事件的同视频困难负样本；
- 连续情绪段截断或短时文字区间错位。

损失至少覆盖状态分类、转移边分类、契约满足和正负路径排序；答案损失仅为下游项。

### 推理硬约束

- 动作结果声明必须匹配同一实体的前态—动作—后态路径；
- 价格/CTA 声明必须匹配短时文字有效区间；
- Logo 声明可接受跨镜头重复，但不得替代价格或动作路径；
- 不完整路径只能输出证据不足，不得由相似画面补齐。

### 建议

**主申请候选，需定向查新后再定稿。** 方向 1 提供结构骨架，方向 2 提供真正的差异化约束。

## I-02 广告短时文字生命周期

将同一文字实例编码为 `APPEAR/STABLE/VALUE_CHANGE/DISAPPEAR` 状态轨迹，并使问题时点和声明契约决定可引用的文字版本。适合作为 I-01 的从属方案，不建议单独主张。

## I-03 观察失败与验证缺席分离

将检测执行状态、时空覆盖和有效观察结果共同映射到存在性状态；仅完整覆盖且无处理失败时允许生成验证缺席。技术关系清楚，但与拒答、开放集识别和可靠性门控现有技术接近，且本地跨模态效果尚未成立。

**建议：独立备选申请或有限从属，不与 I-01 主权利要求堆叠。**

## I-04 事实—营销意图依赖许可

事实状态失效时自动撤销依赖它的营销意图节点。当前最容易被解释为业务规则、知识图谱分层或结构化推理，建议仅作为实施例或后续独立研究。
