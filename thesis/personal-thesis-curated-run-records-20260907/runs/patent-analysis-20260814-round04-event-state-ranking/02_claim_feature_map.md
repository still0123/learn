# P2 候选特征与对象关系映射

## 单项判断

| 方向 | 新中间结构 | 训练干预 | 推理硬约束 | 单独主张风险 |
|---|---|---|---|---|
| 1. 广告事件状态链 | 同一对象的状态节点、时间区间和转移边 | 顺序交换、结果删除、状态值替换、相似无关片段 | 回答必须匹配完整状态路径 | 容易被普通事件图、时序图和动作识别覆盖 |
| 2. 声明条件化证据行为 | 声明行为契约：所需状态角色、允许边、持续/重复模式 | 同对象但缺目标动作、同 Logo 但无价格、连续场景截断 | 不同声明只能接受满足其行为契约的路径 | 单独写容易退化为问题类型路由或人工规则 |
| 3. 短时文字生命周期 | 文字轨迹及 `APPEAR/STABLE/CHANGE/DISAPPEAR` 状态 | 文字插入、擦除、错位、值替换 | 价格/CTA 声明必须引用对应生命周期区间 | 普通视频文字检测与跟踪现有技术拥挤 |
| 4. 事实与营销意图分层 | 事实节点、意图节点及许可边 | 删除倒计时、折扣、CTA 等事实线索 | 无已验证事实路径时意图节点不得输出 | 容易被视为业务规则、知识图谱或结构化推理 |
| 5. 检测失败与真实不存在分离 | 观察状态及缺席覆盖证明 | OCR/ASR 故障、模糊、丢帧、遮挡 | 处理失败或未检测不得许可否定结论 | 可靠性门控、拒答和开放集识别现有技术接近 |

## 推荐合并后的主对象关系

主案不采用“方向 1 + 方向 2”并列模块，而采用单一数据依赖：

```text
问题/候选声明
→ 生成证据行为契约
→ 契约限定状态节点、转移边和路径完整条件
→ 从视频构造同一广告对象的状态转移图
→ 只检索满足契约的完整路径
→ 完整路径许可相应声明进入答案
```

其中：

- 状态节点记录 `entity_id、state_value、time_interval、modality、source_id`；
- 转移边至少区分 `APPEAR、PERSIST、VALUE_CHANGE、ACTION、RESULT_OF、DISAPPEAR`；
- 行为契约记录 `required_roles、allowed_edges、continuity、repeatability、completion_rule`；
- Logo 声明允许非连续重复出现，价格声明要求短时文字值及其有效区间，动作结果声明要求前态—动作—后态，情绪声明要求连续状态段；
- 相似画面或相同 Logo 只有在满足声明行为契约时才可进入支持路径。

## 推荐定位

- 独立权利要求核心：方向 1 与方向 2 的耦合关系。
- 第一组从属：方向 3 的文字状态节点和生命周期边。
- 第二组从属：方向 5 的失败状态不得完成缺席路径。
- 说明书实施例或后续申请：方向 4；不放入本案主权利要求。
