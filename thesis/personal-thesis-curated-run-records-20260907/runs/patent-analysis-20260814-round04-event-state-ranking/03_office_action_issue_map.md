# P3 旧审查路径对本轮候选的影响

## 旧案被拆解的方式

1. 以通用视频问答作为最接近现有技术。
2. 把幻觉校验、信息保留、广告场景适配和准确率分别定义成独立技术问题。
3. 分别引入自我验证、全局/局部 RAG、跨模态对齐和热力图 ROI 对比文件。
4. 把触发词、窗口、确认令牌、锚框和结构化提示归为常规选择。
5. 不接受“广告场景不同”或“模块有机协同”作为不可拆分技术关系。

## 对五方向的敌对判断

| 方向 | 主要组合攻击 | 最小救活限定 |
|---|---|---|
| 1. 事件状态链 | 通用事件图/动作前后状态识别 + VideoQA | 状态链必须约束同一实体、连续证据边界和声明许可，后继状态不得由不同实体或相似无关片段补齐 |
| 2. 声明条件化证据行为 | 问题类型路由 + 时序跟踪/分类 | 声明类型实例化机器可执行的时间接受谓词，并实际改变轨迹聚合、允许边和支持判定 |
| 3. 文字生命周期 | OCR tracking + 变化检测 | 生命周期状态必须控制问题时点有效文字版本，禁止前后价格或 CTA 拼接 |
| 4. 事实与营销意图 | 知识图谱分层 + RAG/结构化推理 | 事实节点失效时，依赖它的意图节点自动撤销许可；仍有业务规则风险 |
| 5. 失败与不存在 | 开放集检测 + 错误码 + 拒答 | 检测有效性、时空覆盖和替代观察共同形成缺席证明，失败或覆盖不足不得许可否定 |

## 结论

- 方向 1 单独写成“构建状态链并回答”仍会重蹈旧案。
- 方向 2 的差异性更强，但必须落入方向 1 的图构建和路径判定，避免退化为人工规则。
- 方向 5 具有独立的“观察状态→否定许可”关系，可作为另一主案候选；本地跨模态效果尚未成立。
- 方向 3、4 不宜承担独立权利要求的创造性主线。
