# P7 新申请策略

## 推荐名称

**一种声明行为契约约束的广告事件状态路径编码与视频问答方法**

不建议使用过宽的“一种基于广告事件状态转移编码的视频问答方法”，因为该名称对应的核心机制容易被普通事件图覆盖。

## 主权利要求骨架

1. 获取广告视频和待回答问题，并将问题转换为至少一个待核查声明。
2. 根据声明类型生成证据行为契约，契约至少包含所需状态角色、允许状态转移边、时间连续条件和路径完整条件。
3. 从视频的视觉、OCR、Logo 和 ASR 观测中关联同一广告实体，形成带时间区间和来源标识的状态节点。
4. 根据节点间的实体同一性、时间顺序和状态值变化建立事件状态转移边。
5. 按证据行为契约从状态图中检索候选路径，并拒绝不满足实体同一性、允许边或路径完整条件的路径。
6. 将满足契约的路径标记为声明支持，将状态冲突路径标记为声明冲突，将缺少必要角色的路径标记为证据不足。
7. 仅允许被完整路径支持的声明进入答案；冲突或证据不足声明不得由相似画面、相同 Logo 或无关时间段补齐。
8. 使用至少包含顺序交换、结果状态删除、状态值替换和同视频相似无关片段替换的配对样本训练状态、转移边和契约满足判定。

## 从属布局

1. Logo/品牌声明采用可跨镜头重复的身份保持契约。
2. 价格/CTA 声明采用短时文字生命周期契约。
3. 动作结果声明采用前态—动作—后态完整路径契约。
4. 情绪声明采用连续状态段契约。
5. 文字节点具有 `APPEAR/STABLE/VALUE_CHANGE/DISAPPEAR` 状态。
6. 检测失败节点和未检测节点不得满足缺席路径。
7. 相同 Logo 和背景但缺目标价格或动作的片段作为困难负样本。
8. 状态节点和路径保留原始帧、时间戳、OCR/ASR 片段的来源标识。

## 第二申请候选

将方向 5 独立为“观察覆盖证明约束的否定答案许可方法”，主线为：

```text
检测执行状态 + 时空/模态覆盖
→ NOT_DETECTED / PROCESS_FAILED / VERIFIED_ABSENT
→ 仅 VERIFIED_ABSENT 许可否定答案
```

不建议把完整七状态机与主案堆叠，以免再次形成大而全的模块组合。

## 暂不加入

- 补看、裁剪、放大；
- RAG、多 Agent、自由反思；
- 事实—营销意图分层主权利要求；
- 固定阈值、固定权重和未经验证的效果数值。
