# 模拟审查员攻击

## 最可能的新驳回链

1. 以对比文件1作为视频问答、证据补充和迭代回答的基础框架。
2. 以对比文件4补足多模态时间对齐和统一表示。
3. 以对比文件3、5补足OCR、ROI、全局/局部视图和问题响应区域。
4. 以对比文件2补足答案拆分、核验和修正思想。
5. 以公知常识补足去冗余选择、条件路由、数据ID、阈值门控和日志追溯。

## 对新稿S1-S7的攻击

- **S1**：已知视频、ASR、OCR预处理结果的汇总。
- **S2**：统一ID和字段表是普通数据结构及审计记录。
- **S3**：问题相关选帧与时间去重属于常规检索优化。
- **S4**：声明拆分是验证问题的粒度细化，三态是常规标签。
- **S5**：缺时间补帧、缺区域裁剪是符合问题类型的常规路由；父ID是来源记录。
- **S6**：支持/冲突阈值是置信度门控的等价表达。
- **S7**：保存ID、时间和坐标属于常规索引与追溯输出。

## 新稿的真实进步

新稿已经实质放弃“全局/局部双流 + RAG + CoT + 关键词反思”作为独权主线，转向声明状态驱动的主动证据获取。S4-S5形成了旧稿没有的控制关系。

## 仍未过关的原因

- 独权没有写清声明缺口如何计算。
- 缺口结果没有直接转换成时间窗、帧ID、区域坐标或尺度参数。
- 父子证据关系没有明确字段和状态更新规则。
- 支持/冲突值没有计算和聚合定义。
- 实验没有证明主动路由优于随机或整帧补看。

## 敌对结论

新稿属于“部分实质绕开”，但尚未稳定绕开模块拼接。若按当前独权提交，仍有较高概率被拆成数据结构、分类器、两个已知执行器和答案门控后组合评价。
