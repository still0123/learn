# 修改与申请策略

## 旧申请处理决定

用户已决定放弃复审。本轮不再设计意见陈述、复审理由或旧权利要求修改方案。

为避免重复和自有在先申请风险，新申请按最保守口径处理：

- 把旧申请全文视为必须绕开的现有技术边界。
- 不再以过采样、三流热力图、自适应锚定、全局/局部双流、广告知识RAG、结构化CoT、关键词触发、参数冻结或确认/修正令牌作为独权创新点。
- 旧申请是否公开、何时公开及其对新申请的影响，交由代理人核验。

## 新申请

1. 删除RAG、CoT、关键词触发、参数冻结和确认令牌等旧弱点。
2. 独权只围绕“声明状态图 → 参数化补证 → 父子谱系回写 → 同状态门控”。
3. 明确以下必需字段：
   - `evidence_id`
   - `source_evidence_id`
   - `claim_id`
   - `modality`
   - `timestamp/time_window`
   - `frame_id/bbox`
   - `acquisition_action`
4. 明确缺口到动作参数的映射，不只写 `LOOK_TIME/LOOK_REGION` 标签。
5. 增加一条端到端数值实施例和状态变化表。
6. 用同预算随机补看、整帧补看作为直接对照，验证路由效果或成本效果。
7. 反事实、自适应裁剪和RAG仅放从权或实施例。

## 新申请与旧案的隔离边界

新申请解决的问题改为：

> 在有限证据预算下，如何从答案声明的结构化证据状态中计算时间或空间证据缺口，生成对应获取参数，并将补充证据按父子谱系回写，以控制答案更新和形成可重放证据链。

旧案中的采样、ASR、OCR、视觉模型等只作为可替换的前端证据来源，不构成新独权的创造性中心。
