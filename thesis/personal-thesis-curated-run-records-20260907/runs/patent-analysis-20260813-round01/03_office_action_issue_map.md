# 驳回逻辑问题图

## 权利要求1的三段式驳回

### 基础框架

对比文件1公开视频与问题输入、采样、字幕、问题导向检索、关键帧、答案生成及低置信度迭代，被选为最接近现有技术。

### 区别特征拆分

1. 链式校验、条件触发、参数冻结、证据回溯和确认/修正令牌。
2. 过采样和广告视频场景。
3. 三模态感知、全局/局部视觉、广告知识RAG及结构化生成。

### 组合路径

- 区别1：对比文件2 + 常规条件执行、冻结推理和反馈格式。
- 区别2：对比文件1 + 惯用采样优化和场景迁移。
- 区别3：对比文件3 + 常见语音对齐。

结论为对比文件1、2、3及惯用手段组合显而易见。

## 从属权利要求

- 权利要求2：对比文件4补足多模态预处理和时间对齐。
- 权利要求3：对比文件3、5及公知常识补足OCR、ROI、热力图、滑窗和锚框。
- 权利要求4：广告知识库被视为通用RAG的知识内容替换。
- 权利要求5：对比文件3的输入拼接与对比文件4的约束解码组合。
- 权利要求6：系统权利要求直接随方法权利要求否定。

## 旧答复失败原因

1. 重点证明单篇文献未公开全部特征，但审查员采用的是多文献组合。
2. 用从属权利要求的具体算法为上位、宽泛的独立权利要求抗辩。
3. 主要强调广告、法律、静态图像等场景差异，未形成不可拆分的数据或控制耦合。
4. “整体协同”停留在定性描述，缺少与各区别特征对应的消融或直接技术效果。
5. 第二次审查意见后没有继续限缩，审查对象没有实质变化。

## 可争议点

- 多篇文献和公知常识的组合存在事后拼接风险。
- 对比文件2未直接公开多模态原始证据回溯。
- 对比文件5的单热力图到三流响应图存在跨越。
- 权利要求4、5、6的三步法论证较简略。

上述争议可用于复审，但不足以自动推翻实体创造性结论。
