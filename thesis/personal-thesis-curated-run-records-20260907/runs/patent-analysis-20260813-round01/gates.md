# 风险门禁

| 门禁 | 状态 | 说明 |
|---|---|---|
| 原始公开支持 | 未通过 | 新稿多个核心字段和动作不在旧申请原始公开中，不得直接用于旧申请修改 |
| 现有技术差异 | 部分通过 | 声明状态驱动补证是文字区别，但尚未完成专项检索 |
| 非模块拼接 | 未通过 | 独权仍可拆成数据结构、分类、两个执行器和门控 |
| 技术效果 | 部分通过 | 完整补看+门控有正向结果；主动路由和父子谱系无独立效果 |
| 代码实现 | 部分通过 | ID与门控有基础；三态矩阵、父子谱系和反事实不足 |
| 无虚构数据 | 通过 | 使用的实验数值均来自本地记录，并保留失败结果 |
| 可直接提交 | 未通过 | 需要实现、检索、实验及代理人复核 |

## 允许输出标签

- 候选方向
- 修订建议
- 需代理人复核

## 禁止输出标签

- 保证授权
- 一定具备创造性
- 可直接提交
