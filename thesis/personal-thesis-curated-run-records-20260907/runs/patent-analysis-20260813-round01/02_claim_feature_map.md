# 权利要求与技术特征映射

## 原申请主线

| 环节 | 原申请特征 | 驳回中的定性 |
|---|---|---|
| 证据获取 | 过采样、ASR、语义关键帧 | 通用采样与惯用优化 |
| 证据定位 | 问题/语音/OCR三流响应图 | 对比文件3、5与公知常识组合 |
| 局部锚定 | 语义重心、多尺度锚框、响应密度 | ROI、自适应锚框惯用手段 |
| 知识增强 | 广告知识库、Top-K、重排序 | 通用RAG的内容适配 |
| 结构化生成 | 观察—分析—推理—答案 | 约束解码与规则按需设置 |
| 链式校验 | 关键词触发、冻结模型、确认/修正令牌 | 自验证、条件执行及反馈格式常规化 |

## 新候选稿独立权利要求

| 步骤 | 新特征 | 原驳回材料中的覆盖程度 |
|---|---|---|
| S1 | 帧、带时间戳语音、带坐标文字 | 基本覆盖 |
| S2 | 统一证据ID和字段化证据单元 | 文字区别，但可能被认定为常规数据结构 |
| S3 | 跨模态相关度与时间冗余联合选证据 | 主体覆盖；MMR细节未进入独权 |
| S4 | 声明拆解及支持/冲突/缺失关系 | 核心新区别之一 |
| S5 | 缺口驱动时间/区域补看及父子回溯 | 最强新区别 |
| S6 | 支持提升、冲突约束下替换/拒答 | 多数可由置信度迭代和自验证覆盖 |
| S7 | 输出ID、时间或坐标证据链 | 有形式区别，但追溯日志本身较弱 |

## 关键判断

新稿已移除RAG、CoT和关键词触发作为独立权利要求核心，确实改变了旧稿主线；但S4-S6仍偏功能结果描述，尚未限定缺口如何计算、如何生成具体补看参数、补证后如何更新声明状态。
