# 检索与法律核验

## 必须在锁定正式独权前完成

1. 核验原申请和 D1-D5 的官方著录、公开日、优先权和法律状态；
2. 确认旧案申请人、新案申请人及发明人/权属；
3. 确定是否要求本国优先权，以及旧案能够支持的相同主题范围；
4. 对申请日前公开专利和非专利文献补做关键词、分类号和引用链检索；
5. 形成 D1+D2、D1+D2+D5、D1/D2+Omni/PBRC 的组合创造性意见。

## 依据

专利法要求说明书清楚完整、权利要求以说明书为依据；本国优先权仅针对在先申请的相同主题并有期限与手续要求。AI 审查指引及 2026 年施行的审查指南进一步强调具体场景中模型/算法输入、输出及其内在关联的可实施公开。
