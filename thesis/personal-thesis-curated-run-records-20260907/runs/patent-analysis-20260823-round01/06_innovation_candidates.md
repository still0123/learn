# P6 创新候选

## 候选A：同一经训练支持度验证器驱动的补证—采纳回退闭环

- 机制：A0低支持触发同视频增量证据；A2不以A0为改写对象；同一验证器对A0/A2评分；绝对阈值与相对提升决定采纳，否则回退。
- 非简单拼接论点：触发、证据获取和采纳通过同一支持度量形成依赖关系。
- 效果：Full-7844完整闭环相对MMR8提高+7.00/+10.12pp，但仍有604次正确到错误。
- 风险：D1+D2组合非常接近，需靠训练验证器、增量证据和独立候选关系抗辩。
- 建议：保留为推理独权候选，需正式查新。

## 候选B：真实正反原子声明训练的多模态支持度验证器

- 机制：真实模型回答拆成声明，与参考答案关系生成正反标签；冻结视觉编码器，语言侧LoRA训练支持状态。
- 效果：Calibration-240 AUROC 0.5409→0.6599，ECE 0.3780→0.2120。
- 建议：保留为训练独权候选。

## 候选C：声明定向的真实视频最小破坏证据对

- 机制：只删除关键帧、遮蔽OCR、错移ASR或替换同视频邻近非证据，保留背景；加入E+>E-排序约束。
- 风险：反事实多模态事实核查已有近邻；未单独证明最终QA提升。
- 建议：仅作窄从属/备选分案方向。
