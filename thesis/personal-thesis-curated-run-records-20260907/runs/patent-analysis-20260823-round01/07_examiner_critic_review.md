# P5 模拟审查员批判

1. MMR是成熟检索方法，把Top-K换成MMR可能只是排序函数替换；实验有效不等于非显而易见。
2. D1已公开低置信度迭代获取，D2已公开自验证修正；“低支持→补看→比较→回退”仍可能被组合得到。
3. OCR/ASR是常见视频多模态输入，现有消融只证明联合系统中的贡献，未证明某种融合公式具有意外效果。
4. A0/A2比较、绝对阈值、相对裕量和失败回退可能被认为常规风险门控。
5. 证据ID、时间戳和日志具有审计价值，但本地完整闭环尚未实现，且容易被认定为数据记录。
6. 最小破坏反事实训练需面对CN118627623B等因果/反事实多模态事实核查近邻；区别必须落在真实视频、声明定向、局部物理扰动、背景保持和独立支持度验证器。

结论：本稿只能标为“候选方向 / 需代理人复核”，不得称可直接提交或保证授权。
