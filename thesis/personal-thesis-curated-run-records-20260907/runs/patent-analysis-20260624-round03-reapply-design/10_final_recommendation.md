# 最终专利创新推荐报告

## 执行结论

- 本轮目标：面向另案重申请，重新设计一条区别于原案“视听协同感知 + 链式校验”的新技术主线。
- 最终建议：新申请不再主打响应图、双流视觉表征、RAG 或自我反思，而应主打 **多模态证据一致性图谱 + 问题驱动证据路由 + 冲突仲裁 + 可信证据包约束生成**。
- 推荐新专利名称：**一种基于多模态证据一致性图谱的广告视频问答可信生成方法及系统**。
- 可直接用于新申请交底书的内容：`06_innovation_candidates.md`、`08_revision_strategy.md`、`05_code_implementation_map.md`。
- 不建议直接塞回原案复审：证据一致性图谱、可信证据包、证据缺失降级等内容在原申请中公开支撑不足，更适合另案。
- 必须由专利代理人复核的内容：本国优先权策略、新申请相对原案的新增内容边界、权利要求中“图谱/路由/仲裁”的清楚性和创造性表达。

## 推荐权利要求策略

### 独立权利要求建议主线

独立权利要求应保持连续链条：

1. 获取广告视频、用户问题和多模态基础证据；
2. 对问题进行意图解析，生成问题约束项；
3. 基于问题约束项执行证据路由，形成证据单元集合；
4. 基于证据单元构建一致性图谱，图谱边至少包括支持、补充、矛盾、时序邻接和知识映射关系；
5. 对图谱进行一致性评分和冲突仲裁，生成可信证据包；
6. 用可信证据包约束大模型生成，要求答案声明引用证据标识；
7. 对无证据映射或与冲突边矛盾的声明进行删除、降级或重写。

### 从属权利要求建议

- 证据单元数据结构：`evidence_id`、模态类型、时间位置、空间位置、语义标签、置信度、来源路径。
- 问题路由规则：文字/价格/logo 优先 OCR/Logo，旁白/声音优先 ASR，为什么/策略/受众优先视觉证据 + 广告知识。
- 图谱边类型：支持边、矛盾边、补充边、时序邻接边、知识映射边。
- 一致性评分：问题相关度、跨模态支持度、矛盾强度、时序一致性、知识适配度。
- 冲突仲裁：原始视频证据优先于知识条目；问题槽位指定的证据类型优先；低置信或缺失证据触发降级。
- 可信证据包格式：采纳证据、排除证据、冲突说明、声明许可状态、最终置信度。

### 不建议作为新案核心

- 普通 RAG；
- 普通 CoT/结构化提示词；
- 大模型自我反思；
- 热力图/响应图/双流视觉表征；
- 单纯广告知识库；
- 单纯“广告场景特殊”。

## 风险清单

- 新增内容风险：本轮核心适合另案申请，不宜作为原案复审修改内容。
- 创造性风险：如果只写“图谱、路由、仲裁、可信”，会被认为抽象功能；必须写清数据结构、边类型、评分和状态转移。
- 技术效果风险：当前不能主张准确率、幻觉率等量化效果，只能主张可追溯、冲突识别、证据约束生成等机制性效果。
- 代码实现风险：MVP 可以 3-5 天跑通文本级原型，真实 OCR/Logo/视觉检测和端到端实验需要 2-4 周。
- 检索风险：当前外部检索不足，正式提交前仍需代理人检索“multimodal evidence graph / evidence-aware VQA / multimodal fact verification”等方向。
