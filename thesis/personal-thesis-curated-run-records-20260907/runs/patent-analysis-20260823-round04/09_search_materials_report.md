- CN121235759B：Google Patents 全文显示《一种对APP广告内容合规性的检测方法及系统》；不是 V3 原表中的简称。
- CN117744802A：Google Patents 全文显示初始问题和初始答案共同进入提示，随后验证并修正初答。

## 法律时间点

- 中国专利法第二十九条规定，同一主题的中国在先申请通常须在十二个月内提出后一申请并主张国内优先权。
- 第二十二条以申请日/优先权日前为公众所知的技术界定现有技术。
- 第三十三条禁止申请后修改超出原说明书和权利要求记载范围。

因此，应先取得旧案的 CNIPA 受理通知书、著录项目数据和公开文本，再判断国内优先权及自身在先公开风险。
