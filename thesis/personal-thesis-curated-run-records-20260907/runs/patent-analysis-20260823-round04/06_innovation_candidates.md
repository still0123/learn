# V4 候选方向

## C1：证据状态分离的两阶段评分门控

- 机制：以初始证据上的 φ_init(A0) 仅负责触发；补证后在同一扩展证据集上分别计算 φ_ext(A0)、φ_ext(A2)，再执行绝对阈值和相对裕量。
- 非简单拼接理由：明确分离“是否需要补证”和“补证后哪个答案更可靠”两个决策状态，避免证据变化污染答案差值。
- 当前支持：V3 有概念描述，但未见对应 Full 实现或冻结实验。
- 建议：候选方向；实现并冻结实验后再进入独权。

## C2：去初答锚定的独立候选生成

- 机制：A2 只接收问题与扩展视频证据，不接收 A0 文本；A0/A2 的选择交给外部验证器。
- 非简单拼接理由：把答案生成与答案采纳解耦，针对初答锚定这一具体错误传播路径。
- 当前支持：V3 文本有，Full 代码相反；发明人称曾实验但结果未保存。
- 建议：候选方向；必须补代码、配置、输出、裁判和哈希后才能作为已验证主线。

## C3：证据语义一致的验证器训练

- 机制：参考答案仅作候选标签初筛；最终标签由对应视频证据下的支持/冲突/不足标注或复核决定，并可加入最小破坏证据对。
- 非简单拼接理由：监督目标直接对应部署时的证据支持决策。
- 当前支持：真实正反声明训练已存在；证据支持标签闭环与未保存的新实验仍需复核。
- 建议：修改权7；未保存结果不写数值。
