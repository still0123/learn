# 近邻边界

| 近邻 | 已覆盖 | 本机制仍需限定的差异 |
|---|---|---|
| Q-Guide | 缺口驱动OCR/缩放/定位 | 视频内 E0/ΔE 来源与答案迁移提交关系 |
| Omni-Decision | 显式证据状态、取证、验证、修复、停止 | A0/A2声明差异、同E+配对评分、迁移类型判定 |
| PBRC | 变更需外部证据见证及保守回退 | 视频帧/OCR/ASR时空见证和声明依赖闭包 |
| SciClaimEval/CMA | 证据修改及反事实模态归因 | 反事实结果直接作为答案迁移提交条件 |

结论：外部 AI 对三篇近邻的总体定位基本正确，但“闭合、见证、回退”本身不能承担创造性。
