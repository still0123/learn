# 修订后的候选

## C1：语义依赖闭包的证据约束答案事务

- 将 A0/A2 原子声明形成依赖图，依据共同实体、属性、数量、时序、因果或指代关系计算受答案变化影响的连通闭包。
- 在同一 E+ 上核验闭包内所有旧/新声明；每个实质变更必须绑定本轮 ΔE 的时空模态证据。
- 闭包内任一关键条件失败则回滚该闭包，而不是逐句混拼，也不必无条件回滚整份答案。
- 当前仅为候选，依赖图及闭包事务尚未实现。

## C2：三态删除/降级规则

- 冲突：允许替换或删除旧事实。
- 持续不足：不得断言相反事实，可删除无证据细节、降级为不确定或整体保留 A0。
- 冗余：只有在语义等价且不降低关键声明覆盖时允许压缩。

## C3：匹配控制的反事实见证

- 用时间/模态/Token匹配的非见证证据替代 W，而不是简单删掉 W。
- 以见证替换造成的支持下降超过匹配控制下降的预设裕量，作为 ΔE 的必要贡献条件。
