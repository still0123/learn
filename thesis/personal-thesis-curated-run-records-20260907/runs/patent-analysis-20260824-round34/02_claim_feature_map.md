# 终稿权利要求特征图

| 权项 | 核心限定 |
|---|---|
| 1 | 双读取域隔离、四时点、同 E+ 双差分、唯一许可配准、依赖闭包原子写入和冲突事实禁入 |
| 2 | ΔE 的源片段、时间、原始像素覆盖或有效空间分辨率集合口径 |
| 3—6 | 事实槽模式、观测状态、许可类型、物理隔离和竞争组 |
| 7—9 | 迁移分类、同 E+ 核验状态和派生许可 |
| 10—11 | 下游写入/上游证明双域及共享映射键失效传播 |
| 12—15 | 安全状态机、受限重组、匹配反事实和审计失效 |
| 16—18 | 装置、电子设备和存储介质 |

从属链：4/6→3→1，11→10→1，其余2—15→1；16—18为并列独立权利要求。
