# 原审查风险与终稿处理

| 风险 | 终稿处理 |
|---|---|
| 低置信补证迭代已知 | 不把触发补证单独作为创造性核心 |
| 把 A0 喂回模型改写已知 | 候选服务不能读取 A0，且 A2 在许可不可见时冻结 |
| 一般事实—证据映射已知 | 要求 E0→E+ 许可与 A0→A2 迁移按同槽、同上下文、同快照和 ΔE 见证唯一配准 |
| 一般闭包/回退已知 | 把配准结果直接作为有界依赖闭包全写或全禁写的门禁 |
| 回退可能复活错误旧事实 | 权1和权12明确 E+ 下冲突事实不得进入可输出状态集合 |
| 新取证可能混用旧记录 | 权12和§7.15明确旧许可、A2、核验、配准和暂存闭包失效并重跑 |
