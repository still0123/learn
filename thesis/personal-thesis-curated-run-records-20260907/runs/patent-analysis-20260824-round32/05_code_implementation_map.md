## 仍建议递交前做的最小验证

测试代码不是递交的法定附件，但一个最小可运行验证会明显改善代理人对 26.3/26.4 支持关系和创造性技术效果的把握。至少保留三条可复核记录：许可在 A0/A2 不可见时生成；A2 冻结前无许可字段流入；闭包失败时没有部分目标事实写入。不得把未冻结的准确率、时延或拦截率写入说明书。
