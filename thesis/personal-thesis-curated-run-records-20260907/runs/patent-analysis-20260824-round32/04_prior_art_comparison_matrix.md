## 单篇新颖性初筛

当前仍未发现单篇同时公开以下连续关系：

1. 许可服务无法读取 A0/A2 事实值并先形成、冻结 E0→E+ 许可；
2. 候选服务无法读取 A0 和许可，且在许可冻结后独立生成 A2；
3. A0/A2 在同一 E+ 下配对复核；
4. 每项 A0→A2 事实迁移按 ΔE 见证与唯一许可配准；
5. 配准结果直接控制有界依赖闭包全写或全禁写，并禁止复活冲突旧事实。

因此，V4.6 的窄主链仍有单篇新颖性抗辩基础。

## 最强组合攻击

审查员可组合：

`CN121388101A（视频补证迭代） + ADER（同视频当前/候选配对核验） + CN121901431A 或 CN122346550A（原子声明—证据映射） + CN122570719A（独立控制栈） + PBRC/Omni-Decision（见证、依赖闭合、提交/回退）`。

该组合已覆盖大多数上位模块，因此创造性风险为 **高**。抗辩重点不能是“模块分别不存在”，而必须是：R2/R4/R5 的不可读权限和冻结时序先保证两个差分独立形成，R6/R8 再证明两个差分在同一视频快照上同事实配准，R9/R10 最后把该配准结果转成不可分割的状态写入条件。
