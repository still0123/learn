# 旧案与 V4 关键区别

| 控制环节 | 旧案 | V4 新申请必须保留 |
|---|---|---|
| 触发 | 问题中高风险关键词 | 声明必要槽在视频证据下不足/冲突 |
| 证据 | 回溯已有关键帧和语音 | 从 E0 未覆盖位置获取 ΔE，形成 E+ |
| 候选生成 | 把 A0 作为待核查草稿再次输入并修正 | A2 生成不以 A0 为待改写输入 |
| 比较口径 | 整体确认/修正 | A0/A2 在同一 E+、同一核验定义下声明级配对复评 |
| 变化控制 | 整答确认令牌/修正令牌 | 声明映射、逐变化 ΔE 见证、有向依赖闭包原子提交 |
| 失败结果 | 保留 A0 或直接输出修正文本 | 不复活 E+ 下失效旧声明；受限重组并终检无新增声明 |

上述整条控制链是新申请的最小区别组合，不能把关键环节全部下放从属权利要求。
