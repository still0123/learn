# 06｜创新候选筛选

## C1：覆盖增量授权（主选）

问题槽覆盖前后变化生成 `delta_id`，具体声明迁移必须绑定相同槽的正覆盖增量及造成增量的 ΔE，方可进入闭包提交。

- 单一性：高；
- 视频技术具体性：高；
- 相对近邻残余：中高；
- 实施基础：中，核心尚待编码。

## C2：快照版本 CAS + 失效标记（强从属）

核验和暂存均带证据快照版本；提交前版本不一致则重核验；冲突旧状态只有获得后续恢复证明才可再次输出。

- 技术性：高；
- 通用数据库/答案更新近邻较多；
- 适合作为 C1 的从属增强，不宜单独作为主发明。

## C3：匹配反事实见证必要性（强从属）

用模态、时间、分辨率和预算匹配的非见证证据替换 W，验证目标声明支持下降。

- 证据因果性强；
- 推理成本高，且反事实必要性在其他领域已有；
- 宜作从属或验证器训练方案。

## C4：覆盖收益/预算调度（普通从属）

按单位 Token 或帧预算的预计覆盖增益选择证据。

- 有效率技术效果；
- 主动检索和预算调度近邻密集；
- 不作为创新中心。

## C5：派生覆盖增量血缘（实施从属）

对不能由视频直接感知、但可由已覆盖输入槽确定性计算的声明，记录上游 `delta_id`、运算符、输入快照和输出槽；只有可复算得到唯一输出才允许写入。

- 补齐数量、差值、时间先后等派生声明的可实施边界；
- 与 C1 使用同一覆盖增量数据链，不形成独立模块；
- 不作为创造性支柱：US20210398000A1 已公开基于版本证明树派生隐含事实，故本项仅用于补齐可实施边界。

## 选择

以 C1 为 V4.3 单一发明构思；C2、C3 作强从属；C4、C5 作实施从属，不单独宣传创新性。
