# 03｜旧案审查问题与 V4.3 响应

| 旧案问题 | 旧案组合路径 | V4.3 的处理 |
|---|---|---|
| 低置信触发重选帧和迭代回答被认为已有 | CN121388101A | 不以“触发补证”作为主创新；限定覆盖前后变化直接控制具体声明是否允许写入 |
| 初答验证、增删或重述被认为已有 | CN117744802A | A2 不接收 A0 语义内容作为改写输入；在同一 E+ 复评新旧答案 |
| 关键帧、ROI、OCR/ASR、跨模态对齐属于常规拼接 | D3—D5 | 这些只作为覆盖单元的证据模态或质量条件，不作为独立发明点 |
| 模块间缺少非显而易见功能联系 | 旧案整体 | 用 `delta_id` 和机器授权谓词建立覆盖变化、声明变化与写入动作之间的连续数据依赖 |

## 新增风险

REVEAL 已公开“充分性失败—缺失线索—定向重检索”，因此 V4.3 不能再把问题槽缺口和定向补证本身作为残余创造性。CN121901431A 已公开原子陈述及三态核验，因此声明拆分与证据标注也不是独立区别点。
