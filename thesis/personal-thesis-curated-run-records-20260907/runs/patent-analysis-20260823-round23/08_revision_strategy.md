# 08｜修订策略

## 独权必须保留

1. 问题所需槽对应的视频时空—区域—模态覆盖单元；
2. E0 与 E+ 的覆盖前后状态，以及在 A2 前以答案候选值盲化方式冻结的正覆盖增量记录；
3. A2 非 A0 改写和 A0/A2 同 E+ 复评；
4. 声明迁移的必要差异槽绑定 `delta_id`；
5. 正覆盖增量 + 本轮 ΔE 见证 + 状态条件组成授权谓词；
6. 闭包暂存且全部获授权才提交。

## 下放从属

- 具体覆盖公式、阈值和质量项；
- 预算约束覆盖增益；
- 声明映射基数和迁移分类；
- 下游写入/上游证明双域；
- 跨闭包重核验；
- 匹配反事实；
- 派生声明的上游 `delta_id`、确定性运算符和快照血缘；
- 快照 CAS 和失效/恢复证明；
- 无新增声明终检及审计字段。

## 删除或弱化宣传

- 不再把“缺口驱动补证”“原子声明”“三态核验”“时空证据”“原子提交”单独称为创新；
- 不写尚无记录的准确率或性能提升；
- 不用 Full‑7844 证明 V4.3；
- 不宣称已绕开所有近邻或必然授权。
