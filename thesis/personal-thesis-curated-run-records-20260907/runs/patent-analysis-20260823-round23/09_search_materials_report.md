# 09｜检索材料报告

## 本轮检索主题

- video QA evidence coverage / semantic slot / spatiotemporal modality；
- evidence sufficiency、missing clue、targeted retrieval；
- answer change、evidence provenance、snapshot/version；
- counterfactual evidence necessity；
- 原子陈述核验、候选答案证据关联和状态更新。

## 关键新增发现

1. REVEAL 已公开长视频问答的证据充分性失败、缺失线索定位和定向重检索，显著削弱 V4.2 中泛化的“证据缺口→增量取证”。
2. E‑VQA 已公开答案与精确时空视频证据联合输出，削弱“答案绑定时空证据”单点。
3. US20170004204A1 已公开动态信息变化下旧答案映射更新和变化传播，说明答案状态更新/溯源并非空白。
4. CN121901431A 已公开候选回答拆原子陈述、支持/矛盾/不确定核验和二次生成。
5. WO2024073087A1 已公开针对首份生成文本的声明级证据比较、第二文本生成以及按证据一致度/内容保留度决定输出。
6. CN121660075A 已公开最终答案事实抽取、证据映射、证据 ID/来源/版本和可审计证据链。
7. US20210398000A1 已公开利用知识库不同版本和证明树解释新旧查询结果差异，并由显式事实/规则派生隐含事实。
8. US20160110357A1 已公开低置信候选答案触发不同模态证据检索，进一步削弱“按所需模态补证”的单点价值。
9. US20260121859A1 已公开经规范化、血缘跟踪的确定性证据包及可复现排序/裁剪，进一步说明“确定性证据血缘”不能单独作为创新。
10. US12380343B2 已公开为复杂问题寻找能够覆盖完整证据的互补段落，US20140072948A1 已公开识别缺失信息并生成次级问题；因此“完整覆盖/缺失链路”仍属已知方向。

围绕“在候选答案生成前，以不使用候选槽值的方式冻结视频覆盖增量，并将其作为之后对应声明迁移的写入许可”进行的本轮定向检索，未命中单篇直接公开该完整关系的文献。这只是本轮检索结果，不代表不存在其他专利或非专利文献。

## 本轮未见的完整关系

未在本轮单篇命中中看到：先计算同一问题事实槽在 E0 与 E+ 下的覆盖状态变化，再把该正覆盖增量记录及其 ΔE 证据设为对应旧/新声明迁移进入依赖闭包写入的必要许可。

## 限制

- 搜索引擎命中不等于专利分类全库查新；
- 部分比较基于公开摘要或网页文本，不替代全文法律比对；
- 2026 年接近申请日的文献需由代理人核实准确公开日和可用现有技术地位；
- 旧案自身公开、优先权和抵触判断必须基于官方档案。
