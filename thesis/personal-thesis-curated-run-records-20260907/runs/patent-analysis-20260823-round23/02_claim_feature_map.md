# 02｜V4.3 特征图

| 编号 | 候选独权特征 | 在连续链中的作用 |
|---|---|---|
| G1 | 从问题生成所需事实槽及带模态、时间、区域和质量条件的覆盖单元 | 把抽象“证据不足”变为机器可判定的取证状态 |
| G2 | 基于 E0 计算补证前覆盖状态并确定覆盖缺口 | 形成补证输入 |
| G3 | ΔE 后重算覆盖状态，在 A2 前生成并冻结含前后状态、证据 ID 和快照 ID 的覆盖增量记录；计算不使用新旧答案候选槽值 | 固定本轮补证实际改变了什么，并防止事后按候选答案挑证据 |
| G4 | A2 不以 A0 语义内容作为改写输入 | 避开 D2 式初答改写路径 |
| G5 | A0/A2 在同一 E+ 与同一配置下复评 | 保证新旧状态可比较 |
| G6 | 声明迁移记录绑定必要差异槽和所需覆盖增量记录 | 把补证结果传到状态更新 |
| G7 | 只有预先冻结记录与 E+ 身份一致、必要差异槽对应正覆盖增量且见证来自该记录所列 ΔE 时，迁移才获授权 | 核心写入许可谓词 |
| G8 | 获授权迁移按声明依赖组成暂存闭包，全通过且快照有效才原子提交 | 防止相关状态部分更新 |
| G9 | 失败时仅输出 E+ 下安全状态，最终文本不超出已提交或受支持状态 | 防止复活旧失效声明和重组幻觉 |

## 必须整体理解的中心

V4.3 不把 G1、G3 或 G8 单独视为创新。保护中心是 `G1→G3→G6→G7→G8`：同一覆盖变化记录从取证阶段流入声明迁移并成为闭包提交的必要输入。
