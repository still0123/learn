# 原申请驳回问题图

## 事实纠正

- 2026-05-30 的第二次审查意见是驳回前的审查意见，不是最终“判死”时点。
- 本地驳回决定显示，最终驳回决定日期为 2026-06-18，核心法律依据是专利法第二十二条第三款，即权利要求缺乏创造性。
- “说明书没有可授予专利权的实质性内容”属于审查过程中的严厉评价，不能替代最终驳回决定的法律理由。

## 原申请的实质失败点

1. D1 已给出低置信触发、更新候选区域、重新选帧和迭代输出的总体骨架。
2. D2 已给出初始答案自验证并据此修正的链式校验思路。
3. 原申请的区别主要落在模型、场景和常规模块组合，没有形成不可拆分的数据状态与控制关系。
4. 答复未能证明区别特征之间产生超出各模块预期效果的协同技术效果。

## 对 V4 的启示

V4 不能再以“低置信触发补帧”或“自验证修正”为发明核心，而应以同 E+ 可比较核验、增量证据见证、声明依赖闭包和安全状态更新的连续控制链与原申请区分。
