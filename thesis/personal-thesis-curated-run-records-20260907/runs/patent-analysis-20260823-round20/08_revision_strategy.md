# 修订策略

## 独立权利要求

保留但压缩 F1/F2：

> 基于初始视频证据集 E0 生成初始答案 A0；根据 A0 中原子声明的证据支持缺口，从 E0 未覆盖的视频位置获取增量证据 ΔE，并形成扩展证据集 E+。

把创造性重心放在：

> 非改写 A2 + 同 E+ 同口径复评 + 声明迁移 + ΔE 见证 + 有界依赖闭包 + 原子提交/非陈旧回退 + 无新增声明重组。

## 从属权利要求

下放以下细节：

- 具体支持阈值和相对裕量；
- OCR、ASR、ROI、时间窗和帧选择算法；
- 声明映射基数、事实槽主键；
- 依赖边类型、最大跳数、稀疏约束；
- 跨闭包写集/引用集冲突重核验；
- 匹配反事实、Token 预算和审计字段。

## 背景与创造性论证

- 背景技术优先针对 D1 和 D2；
- D5 需补入候选答案评分风险；
- Omni/PBRC/Q-Guide 不能删除，因为它们可能在 V4 的有效申请日前构成相关非专利文献；
- 不再表述“前十五轮全部建立在错误基础上”，应改为“已覆盖 D1/D2，但 D3-D5 的全文纳入不足”。
