# 创新候选

## 主候选：同证据基准下的声明闭包安全更新

不是把 F3-F9 各自宣称为创新，而是保护以下协同关系：

1. 从未覆盖视频位置取得 ΔE，并形成共同证据基准 E+；
2. 不以 A0 为改写输入生成 A2，降低旧答案锚定；
3. 在同一 E+ 下复评 A0/A2，使支持状态可比较；
4. 将二者映射为声明迁移，并要求变化由本轮 ΔE 的时空模态证据见证；
5. 沿语义依赖确定受影响闭包，闭包内全量满足接受条件才原子提交，否则回到最后一个在 E+ 下仍受支持的状态；
6. 输出只能由已接受声明重组，终检不得引入新声明。

## 可论证的技术效果

- 减少因把旧答案作为改写输入造成的错误继承和锚定；
- 避免用不同证据集评分造成的候选比较偏差；
- 防止答案平均得分掩盖单条声明的新增幻觉或错误删除；
- 限制失败影响范围，并避免回退时复活已被新证据否定的旧事实；
- 防止最终语言重组绕过已完成的证据闭合。

## 不应单独主张的点

- 低置信触发；
- 补帧或 ROI 取证；
- 生成多个候选并评分；
- 抽象的“证据闭合”“见证”或“回退”。
