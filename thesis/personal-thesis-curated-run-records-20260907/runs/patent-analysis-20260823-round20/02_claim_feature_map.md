# V4 权利要求特征图

| 编号 | 当前 V4 技术特征 | 在独权中的建议位置 |
|---|---|---|
| F1 | 基于初始证据集 E0 生成 A0，并按声明证据支持缺口触发 | 保留为压缩的前置条件，不作为单独创造性支点 |
| F2 | 从 E0 未覆盖的视频位置取得增量证据 ΔE，形成 E+ | 保留形成 E+ 的最小限定；具体取证算法下放 |
| F3 | A2 不以 A0 文本作为改写输入而独立生成 | 保留在特征部分，但不能单独主张创造性 |
| F4 | 在同一 E+、同一核验口径下复评 A0 与 A2 | 保留，构成可比较性的核心 |
| F5 | A0/A2 原子声明映射并识别实质变化 | 保留必要功能关系；映射基数和槽位细节下放 |
| F6 | 每项变化绑定本轮 ΔE 的时空、模态见证 | 保留，限定变化由新增视频证据引起 |
| F7 | 按有向语义依赖形成受影响闭包与证明上下文 | 保留最小闭包规则；边类型、跳数和稀疏约束下放 |
| F8 | 闭包级原子提交/回退，并禁止复活已失效声明 | 保留，明确状态更新后果 |
| F9 | 仅由已接受声明受限重组，并终检无新增声明 | 保留，防止输出阶段绕过门控 |

## 因果链

`E0/A0 → 支持缺口 → ΔE/E+ → 非改写 A2 → 同 E+ 配对核验 → 声明迁移与 ΔE 见证 → 依赖闭包 → 原子提交或安全回退 → 无新增声明输出`

F1/F2 虽然本身较弱，却定义了 E+ 和后续见证的来源；若整体移出独权，F4-F8 会失去技术前提并趋于抽象。
