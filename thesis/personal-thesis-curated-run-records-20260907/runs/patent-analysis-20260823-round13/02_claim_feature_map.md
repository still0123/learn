# 最终权项结构

| 权项 | 核心内容 |
|---|---|
| 推理方法独权 | 支持缺口触发ΔE；A2非A0改写；声明映射；受影响闭包；同E+有序状态核验；ΔE见证；一致性提交/安全回退；无新增重组 |
| 从属2 | 一对一、一对多、多对一及未匹配声明映射 |
| 从属3 | 上游证明上下文和下游事务闭包、边类型/方向/稀疏约束 |
| 从属4 | 新增、替换、撤回、不确定、保留及等价压缩状态转移 |
| 从属5 | 绝对支持阈值与同E+相对裕量 |
| 从属6 | 证明引用集/状态写入集的事实槽交叉失效与联合复核 |
| 从属7 | 问题必填语义槽、局部撤回和整体拒答 |
| 从属8 | 匹配反事实见证与必要性分数 |
| 训练方法独权 | 真实E+、最小破坏E−、支持三分类及排序联合训练 |
