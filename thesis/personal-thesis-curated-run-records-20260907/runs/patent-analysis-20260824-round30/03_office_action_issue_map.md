# 原驳回问题与 V4.6 对应关系

| 原申请被攻击的骨架 | 既有对比文件 | V4.6 的实质改向 |
|---|---|---|
| 低置信后补帧并迭代 | CN121388101A | 不把补证当创新；增加答案值盲化的许可通道和逐迁移许可 |
| 把 A0 喂回模型验证、增删、重述 | CN117744802A | A2 服务无 A0 存储区读取权限，且无许可读取权 |
| 新旧答案或多答案比较 | CN120561217A 等 | 要求同 E+ 复评后形成规范化事实迁移，不直接按整体答案选择 |
| 直接输出迭代/改写结果 | 原申请及近案 | 仅在迁移与 ΔE 许可唯一配准且闭包全通过时原子写入 |
| 失败保留或恢复旧答案 | 一般迭代方法 | 不恢复 E+ 下已经冲突的旧事实，进入确定安全状态 |

重要：V4.6 不是把原申请换标题重报，而是采用与“喂回 A0 改写”相反的数据访问约束，并新增双差分唯一配准和闭包状态写入。正式递交仍需官方调档核对新增内容和权属。
