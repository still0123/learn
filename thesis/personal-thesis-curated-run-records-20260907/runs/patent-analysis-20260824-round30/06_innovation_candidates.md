# 创新候选排序

## 主创新（必须整体出现）

**答案值盲化的视频观测差分许可 + 许可值盲化的候选答案生成 + 双方冻结后在同 E+ 下形成答案事实迁移 + 迁移与 ΔE 见证许可唯一配准 + 依赖闭包全成或全败。**

## 强从属

1. 出边写入闭包与入边只读证明上下文双域；
2. 跨闭包写入—引用相交后的失效传播与重核验；
3. 派生事实的全部上游许可和确定性运算血缘；
4. 受限重组和无新增事实终检；
5. 匹配反事实必要性；
6. 竞争事实、冲突许可和安全状态机。

## 不应单独作为创新点

- 低分补证、OCR/ASR、重新选帧；
- 多模型独立回答或答案一致性；
- 哈希、冻结、ACL、服务账户、审计日志；
- 原子事实拆分、来源 ID、知识图谱；
- 通用 permit-before-commit、事务、回滚。
