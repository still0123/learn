# V4.6 权利要求特征图

| 特征 | 权利要求1中的作用 | 不可单独宣传的原因 |
|---|---|---|
| R1 E0/ΔE/E+ | 建立两个可比较视频证据快照 | 补证和冻结快照已知 |
| R2 许可通道答案值盲化 | 防止待验证结论反向选证 | 一般信息流隔离已知，必须绑定本场景数据对象 |
| R3 E0→E+ 观测差分许可 | 形成“证据允许发生什么变化” | 外部 witness/证据状态已有上位公开 |
| R4 四时点及反向写入禁令 | 保证两个中间结果先后冻结且无旁路污染 | 冻结/commit-before-decision 已知 |
| R5 A2 不读 A0/许可 | 形成“候选实际发生什么变化”的独立通道 | 独立多模型/多路径生成已有公开 |
| R6 同 E+ 配对复评 | 消除 A0、A2 证据口径不一致 | 同上下文进一步答案比较已有公开 |
| R7 规范化事实迁移 | 把全文变化转成可控状态变化 | 原子事实拆分和支持/冲突状态已知 |
| R8 ΔE 见证唯一配准 | 把 R3 与 R7 在同槽/事件/值/快照上逐项耦合 | 事实—来源映射已有公开；“双差分唯一配准”才是关键 |
| R9 有向语义依赖闭包 | 定义需共同写入的影响边界 | 事实图、依赖图已知 |
| R10 全成或全败 + 不复活失效旧事实 | 将配准结果变成安全的输出状态控制 | 通用事务/回滚已知；特定闭包和安全回退才有意义 |

单一发明构思：`R2/R3 → R4 → R5 → R6/R7 → R8 → R9/R10`。独权不能被压缩成“补证 + 独立回答 + 验证 + 回滚”。
