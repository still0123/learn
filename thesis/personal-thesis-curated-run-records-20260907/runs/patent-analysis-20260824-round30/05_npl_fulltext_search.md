## 5. 可核验全文位置和关键事实

- Omni-Decision §3.1（HTML 约100--105行）定义带证据、冲突、事实/计算依赖和未满足需要的查询状态；§3.2（约107--117行）让 planner、critic、finalizer 共享 state digest，仅 reducer 写入。该共享读取恰好不满足 V4.6 的 R2/R4。
- PBRC §4.2--4.4（约379--420行）规定触发器、非空证据 witness、router 执行或回退；§8.5（约906--912行）规定证书无 witness 则 fallback。Definition 18（约734--751行）说明 witness 不保证唯一。
- Q-Guide §3.1（约77--91行）定义文档证据状态及带区域坐标的 observation，主动选择恢复动作和 sufficiency predicate。
- SAFEFLOW §1（约20--23行）明示按信任级别调节读/写/传播、事务执行、日志、回滚、并发与依赖故障隔离。
- PlanGuard §I（约17--22行）将仅读用户指令的 isolated planner 与处理外部数据的 agent 分离，再通过 verifier 比对执行行为。
- CLR §2（约66--92行）生成多个解和关键 claims，再按原问题及 claims 搜索反证、给候选重加权；并非回答更新写入协议。
- RAGChecker §3.2（PDF 第3页）拆分 claim 并检查对参考文本的 entailment；ClaimVer §3.3（约85--142行）给 support/insufficient/contradiction 三状态及逐 claim 证据归因。

## 6. 组合显而易见性风险

### 最危险组合：SAFEFLOW + Omni-Decision + PBRC（高）

审查员可能提出：Omni-Decision 给出多模态证据状态、事实依赖与确定性 reducer；PBRC 给出“无外部见证不更新、失败回退”的许可/证书逻辑；SAFEFLOW 给出信息流控制、事务、回滚、依赖故障隔离。再结合视频问答现有技术，可能认为隔离、见证与原子写入是并列常规手段。

可用的技术性反驳点不能只是“用了三个模块”，而应落在以下因果约束：

1. **互斥读取域和时序的用途**不是安全泛化，而是消除“候选事实被许可值污染”导致的虚假独立一致；R2/R4/R3 精确规定谁不能读什么、何时才能联合读。
2. **双差分的配准对象不同**：许可来自 `E0→E+` 的观测状态，候选变化来自 `A0→A2`、且二者在同一 `E+` 下核验；必须用槽/实体/谓词/限定上下文/值/快照/视频时空见证唯一配准。PBRC 的 witness 可不唯一，Omni/SAFEFLOW 未给出此约束。
3. **闭包的语义不是通用数据库事务**：向下游状态写入、向上游仅做证明引用，禁止把证明节点一并回滚；该定向规则服务于视频事实一致性。
4. 候选生成后才执行联合读取并不等同于 PlanGuard 的安全规划隔离；其输入固定为视频 `E+` 原始表示，控制对象为答案事实状态而非工具执行。

### 次危险组合：PlanGuard/DACS + CLR/RAGChecker + PBRC（中高）

这一路可拼出“隔离生成/核验 + claim 级验证 + witness 门控”，但仍缺视频增量观测差分许可、A0/A2 同 E+ 配对复评、唯一匹配和闭包写入。应避免将独权压缩成“隔离 + claim verify + rollback”，否则很容易被此组合覆盖推理。

### Q-Guide 相关组合（中）

Q-Guide 可说明“发现证据缺口后定向取证、证据不足输出 Unknown”已知；因此不要把主动取证、OCR/缩放或 Unknown 当主创新。独权中保留 ΔE 的“非 E0 已使用来源”仅作为双差分输入的必要限定，而非孤立卖点。

## 7. 结论和行动建议

1. **不存在本轮找到的单篇 NPL 同时公开 R1--R10**；V4.6 的新颖性残余主要是 R2--R6 的组合，尤其互斥读取域 + 四时点 + 同 E+ 双答案复评 + 许可唯一配准。
2. **创造性并非稳妥**：SAFEFLOW、Omni-Decision、PBRC 的三篇组合已把“信息隔离/证据状态/外部 witness/事务回退”的上位概念覆盖得很广，应评为中高组合风险。
3. 若拟申请日在 2026-08-20 之后，Q-Guide 和 2026-08-12 的 CLR 属申请日前文献；若申请日早于这些日期，需按实际申请日重新裁剪本表。
4. 递交前仍必须做：中文/英文专利全库的分类号、申请人和引证扩展检索；逐篇专利全文权项比对；并由代理人核实旧申请 `CN121962369A` 的抵触/自身在先公开风险。本报告仅覆盖 NPL。
