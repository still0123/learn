## 1. 检索口径：把权利要求1冻结为 R1—R10

| 编号 | 必须按整体理解的技术特征 |
|---|---|
| R1 | 从同一视频中取得排除 E0 已用来源的 ΔE，并冻结 E+=E0∪ΔE |
| R2 | 证据许可服务在不能读取 A0/A2 存储区、且不以答案值选证的读取域中工作 |
| R3 | 以同一事实槽下 E0→E+ 的规范化观测实质差分及 ΔE 时空模态见证生成许可 |
| R4 | 许可冻结、候选启动、A2 冻结、首次联合读取满足 `t_p<t_s<t_a<t_j`，且 t_a 前禁止许可字段流入候选服务 |
| R5 | 候选服务仅读 Q 与 E+ 原始视频表示，不能读取 A0 或许可，独立形成 A2 |
| R6 | 联合阶段仍直接读取 A0、A2 与 E+，在同一 E+、槽模式和配置下形成 A0→A2 事实迁移 |
| R7 | 将答案拆成规范化事实并区分新增、替换、撤回等实质迁移及支持/冲突状态 |
| R8 | 每一实质迁移按槽、消歧事件、谓词、限定、值/状态、快照及 ΔE 见证与唯一许可配准，禁止一许可授权不相容目标 |
| R9 | 沿预定义有向语义依赖边形成下游写入闭包，并区分上游只读证明引用 |
| R10 | 仅在闭包内全部迁移通过时原子写入；失败则全部禁写并且不复活 E+ 下已冲突旧事实 |

R1、R7、事务日志等子步骤本身并不新。创造性必须评价 R2—R10 在上述顺序和数据依赖下形成的整体控制链。

## 4. 最危险的组合创造性攻击

### 攻击 A：同领域主案 + 同上下文多答案 + 事实证据链

`CN121388101A + CN120561217A + CN121660075A/Atomic Fact Decomposition`

审查员可拼出：视频补证迭代、再生成/比较答案、把答案拆成事实并关联证据。该组合能逼近 R1、R6、R7、R8 的上位概念，但仍缺：

1. 许可通道在物理权限上不能读取 A0/A2，且不以答案值选证；
2. 候选通道不能读取 A0 和许可；
3. `t_p<t_s<t_a<t_j` 与 t_a 前的反向写入禁令；
4. E0→E+ 许可和 A0→A2 迁移之间按 ΔE 见证做唯一配准；
5. 配准结果驱动有向语义闭包的全成或全败。

### 攻击 B：视频更新 + 信息流隔离 + 见证事务

`CN121388101A + Cordon-MAS + PBRC/SAFEFLOW`

该攻击会说：为了避免污染而隔离服务、用 witness 门控、失败回滚都是常规安全措施。反驳重点不是“这些模块首次出现”，而是：两个隔离域承担不同计算任务，分别形成 `ΔObs` 和 `ΔAns`；只有二者按同一视频快照和时空见证唯一配准后，闭包才可写入。删除其中任一步，系统就无法区分独立一致与共享中间值造成的虚假一致。

### 攻击 C：独立/冻结裁决 + 通用许可先提交

`Evidence Lock/TRUST + ORPRG/US20260236570 + ProvenanceGuard`

该组合能拼出独立处理、哈希冻结、来源 ID、allow/block 和提交门，但领域和数据对象不同。V4.6 必须避免把创新概括为“两个智能体互盲、冻结后比较、许可后提交”；应始终写成“视频观测差分许可与答案事实差分在双读取域中分别形成，并在同 E+ 下按 ΔE 见证唯一配准后驱动语义闭包写入”。

### 风险等级

- 单篇新颖性风险：**中低（初步通过）**
- 两至三篇组合创造性风险：**中高**
- 旧申请自身公开/权属/重复申请风险：**高，属于独立法律门禁**
- 2026-08-20 前后临近公开遗漏风险：**高，需要递交当日增量检索**

## 5. 本轮对 V4.6 已完成的查新收口修改

1. 权利要求1明确：许可服务无 A0/A2 存储区读取权限；候选服务无 A0/许可存储区读取权限；t_a 前控制服务不得把许可字段写入候选输入、共享缓存或消息队列。
2. 背景技术加入“同上下文进一步答案比较”和“多路径候选—证据融合”，避免把这些已知手段误写成创新。
3. 说明书明确：冻结许可不是后续裁决的排他输入；联合阶段仍直接读取 A0、A2 和 E+，与 Evidence Lock 的 exclusive interface 区分。
4. 新增 ASR 时间事件和前置条件闭包示例，证明方案不只适用于价格 OCR。
5. 未加入签名、nonce、epoch、一次性 token 等 ORPRG/Mirror 式通用授权模块，避免偏离单一发明构思并撞入更密集的现有技术。
