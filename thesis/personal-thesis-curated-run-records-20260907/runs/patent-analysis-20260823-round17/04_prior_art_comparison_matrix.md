# 当前近邻结论的可用程度

| 材料 | 可用结论 | 不可据此断言 |
|---|---|---|
| Omni-Decision | 强威胁证据状态、缺口取证、依赖、验证/修复和确定性提交 | 未覆盖所有 V4 特征不等于 V4 已具创造性 |
| PBRC | 强威胁“变化需外部见证，否则保守回退”原则 | 没有页码/章节和稳定全文证据前，不能称正式全文对比完成 |
| Q-Guide | 强威胁缺口驱动 OCR/缩放/区域取证 | 文档域差异本身不当然产生创造性 |
| 疑似旧案文本 | 已见广告视频 QA、A0 作为草稿、回溯证据与迭代修正 | 未核官方著录前不能确定公开号、公开日和法律时点 |

三篇矩阵是有价值的技术预检，但不是正式查新闭环。
