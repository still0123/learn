# 07｜模拟审查员批判

## 攻击 1：所谓双差分只是把两个已知比较串起来

证据：CN103870528B 权利要求33及其优先权同族 US9141660B2 已知证据变化后自动更新回答，US9141662B2 覆盖带批准的平行分支；US20160034457A1 已知比较第一/第二回答；EP4617945A1 已知把回答实体值与证据实体值匹配后决定使用。

评价：这是最强攻击，成立概率不低。

应对：不能只写 `ΔObs`、`ΔAns` 数学符号。独权必须限定：ΔE 是 E0 未用的同视频证据；许可在 A2 前形成；许可构造候选值盲化；许可字段对 A2 不可读；A2 不读 A0；映射粒度是槽—上下文—规范化值—见证；闭包不允许部分提交。

## 攻击 2：生成器隔离是常规防泄漏设计

证据：US20260134218A1 使用架构隔离模型；公开的 Adaptive Query 材料还描述单向接口不向外部模型传递验证状态。

评价：隔离本身不新。

应对：隔离不是目的，而是保证许可与候选由同一 E+ 的两条非共享中间事实状态通道产生；最终只有两通道独立收敛到同一事实迁移才授权。这一功能关系和时序必须进入独权。

## 攻击 3：预先证据包与后验仲裁已有

证据：US20260121859A1 在生成前构造确定性证据包，生成后逐句核验和显示门控。

评价：V4.4 原“预冻结记录→候选→核验”的上位结构已被覆盖。

应对：该文献把证据包送入生成提示；V4.4.1 的控制许可不进入生成器，且其唯一用途是授权 A0→A2 相对 E0→E+ 的事实迁移。不要主张一般证据包。

## 攻击 4：逐声明状态、见证和无新增重组已有

证据：US20260134218A1 的语义单元状态及候选词元子序列；PBRC 的预注册见证；Omni-Decision 的证据闭合和提交。

评价：成立。

应对：“无新增声明”和一般闭包下放；独权中的闭包只限定双差分迁移的提交粒度。

## 攻击 5：视频只是应用场景

证据：旧案审查员曾否定仅凭广告场景和模块差异取得创造性。

评价：若仅写“应用于视频”，攻击成立。

应对：写清 ΔE 的机器证据单元、帧号/时间段/ROI/ASR 见证、E0 已用单元排除以及快照血缘；这些字段直接参与许可有效性和状态写入，不只是数据内容标签。

## 攻击 6：许可不可见与 A2 可看 E+ 自相矛盾

评价：若说明不清，易出现清楚性问题。

应对：区分“原始证据表示”和“控制许可”。A2 可看 E+ 原始帧、OCR/ASR 原始结果，但不能读取证据通道形成的规范化值、解析状态、许可 ID、竞争组和映射键。给出 ACL、API 模式和时序日志实现。

## 攻击 7：E0 未解析、E+ 已解析的判定仍靠模型分数

评价：可实施性风险。

应对：按槽类型分别公开确定性/半确定性规则：数值 OCR 的字符串、单位和区域一致；ASR 的时间段与说话者；对象属性的检测类别和置信区间；关系事实的实体 ID 与时间窗。模型支持度只作为补充，不作为唯一判据。

## 攻击 8：无实验，所谓减少相关错误只是推测

评价：说明书不必提交大实验，但不得虚构效果。

应对：公开三种可运行失败分支，尤其“许可 OCR 错、A2 独立正确时因不一致阻断”；递交前做许可可见/不可见小对照，冻结原始日志。

## 总评

V4.4.1 的单一构思明显强于 V4.4，但创造性仍不是稳授权级。它的可辩护性依赖 S1—S8 全部联合；任何把独权放宽成“一般预证据+一般输出核验”的版本都会落入本轮近邻组合。
