## 必须联合的 S 特征

| 编号 | 内容 |
|---|---|
| S1 | `E0→E+` 的槽状态确因 ΔE 从未解析/旧值变成解析新值，才生成许可 |
| S2 | 许可构造不使用 A0/A2 候选值 |
| S3 | 许可先于 A2 冻结 |
| S4 | 许可值、状态、ID 和映射键在 A2 冻结前对生成器不可读 |
| S5 | A2 仅从 Q+E+ 原始证据独立生成，不读 A0/P |
| S6 | A0/A2 在同一 E+ 形成事实迁移 |
| S7 | 每项答案迁移一一匹配许可的槽、上下文、值和 ΔE 见证 |
| S8 | 竞争、失效、复用冲突或闭包不完整时禁止写入 |

单一发明构思为：**用先冻结、生成器不可见的证据事实差分，授权后形成的旧新答案事实差分。**
