# 06｜可保留的创新候选与取舍

## 核心候选（独权）

以同一冻结 E+ 为比较基准，令不含 A0 的 A2 与 A0 进行原子声明映射；仅当每项实质变化由本轮 ΔE 覆盖必要差异证据槽、且相关下游写入闭包和上游证明上下文满足一致性条件时，原子写入变化；否则按 E+ 下安全状态输出并禁止重组新增事实。

## 从属候选

1. 事件标识—主体角色—谓词槽的规范化事实槽和一对多/多对一映射；
2. 出边写入、入边只读的双域依赖构造和跨闭包失效传播；
3. OCR/标识区域、ASR 时间段和匹配反事实必要性核验；
4. 取证预算耗尽后的结构化不充分输出/拒答协议；
5. 审计字段和验证器训练方式。

## 明确放弃作为单独创新点

低置信补帧、候选答案评分、逐声明证据、一般性见证、一般性回退、OCR/ASR 和广告视频场景。它们可支撑实施例或从属项，但不应单独承担创造性。
