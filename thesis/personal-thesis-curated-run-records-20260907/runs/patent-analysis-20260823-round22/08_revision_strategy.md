# 08｜收口与代理人改写策略

1. 独权始终保持“E0 缺口→ΔE→冻结 E+→非 A0 payload 的 A2→同 E+ 配对→迁移见证→双域闭包→非陈旧安全状态→无新增重组”的顺序；不要拆成并列模块。
2. 将整体候选分数、绝对/相对阈值、OCR、ASR、反事实、边大小等保留为从属或实施例。
3. 明确新增/撤回等未匹配声明也在同一 E+ 和同一核验定义下核验；明确支持、不足、冲突、异常的互斥关系与异常分支。
4. 使用“必要差异证据槽由 ΔE 覆盖”，不要误写为所有身份基础事实均必须来自 ΔE。
5. 解释技术效果时使用“使新旧状态可比、限制未获新增视频证据授权的事实写入、避免陈旧回退”，避免承诺准确率或泛化收益。
6. 正式申请文件由代理人根据官方检索结果重写背景、权利要求层级和附图标记；本稿不替代法律意见。
