# 02｜V4.2 独权特征图

| 编号 | 控制特征 | 在独权中的作用 | 不能单独主张的原因 |
|---|---|---|---|
| F1 | A0 必填槽缺口/未支持触发 | 将取证起点限定为可核验事实缺口 | 低置信触发迭代已常见 |
| F2 | 同视频、E0 覆盖外的 ΔE | 使新增证据可追溯且与初始快照区分 | 视频重选帧/区域补证已公开 |
| F3 | 仅以 Q+E+ 正面载荷生成 A2，不接收 A0 或 A0 衍生改写指令 | 切断初答改写锚定 | 单独“不输入 A0”不足以创造性 |
| F4 | A0/A2 在同一 E+、同一核验定义下配对复评 | 消除新旧答案证据口径不可比 | 是全链的比较基准 |
| F5 | 原子声明映射与迁移记录 | 将答案变化落到规范化事实槽和状态对象 | 片段核验本身已有近邻 |
| F6 | 每项实质变化的必要差异槽由本轮 ΔE 时空模态见证授权 | 区别于整体评分和泛化证据链 | 见证原则本身已有近邻 |
| F7 | 出边下游写入闭包、入边只读证明上下文 | 限定局部更新范围且避免上下文被误回滚 | 依赖/闭合概念本身已有近邻 |
| F8 | 闭包原子提交；失败转入 E+ 下非陈旧安全状态 | 避免整体改写或恢复失效 A0 | 事务/回退抽象规则不能单独主张 |
| F9 | 仅已提交或保留声明重组并终检无新增声明 | 防止语言重组重新制造幻觉 | 受限输出本身已有近邻 |

主张单元必须是 `F1→F2→F3→F4→F5→F6→F7/F8→F9` 的连续数据流；其中 F3、F4、F6、F7/F8 是相对旧案和 D1/D2/D5 的关键收束点。
