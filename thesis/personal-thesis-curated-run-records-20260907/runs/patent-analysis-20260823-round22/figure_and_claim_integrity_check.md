### P1-1：Mermaid 源文件与 SVG 正图不同步

Markdown 实际引用的是五张 `.svg`，其内容与 V4.2 基本一致；但配套 `.mmd` 源文件仍保留较早表述，不能可靠再生成同一套正图。例如：

- `fig1_overall_method.mmd` 的“无补证”分支为“输出 A0”，且未接入受约束重组和无新增声明终检；实际 SVG 已改成进入状态控制与终检链。
- `fig3_dependency_closure.mmd` 仍以“ΔE见证”单独画点，没有实际 SVG 中的完整迁移记录字段。
- `fig4_state_transition.mmd` 的编号/状态名称为401—412，与实际 SVG 的401—410不同。

**建议：** 以现有 SVG 为基准同步修改 `.mmd`，或在 README 中明确 `.mmd` 仅为历史草图、正式附图以 SVG 为准。递交前推荐前者，避免后续版式转换时意外回退图义。

### P1-2：图3的“授权”箭头文字不够准确

实际 SVG 图3把从“306 迁移记录”指向声明节点的两条虚线标为“授权”。权利要求1与说明书中，迁移记录的功能是绑定必要差异证据槽和 ΔE 见证，并供提交条件核验；“原子提交”由闭包满足全部条件后发生。仅凭迁移记录本身并不“授权”。

**建议：** 将两处“授权”替换为“见证约束”或“核验依据”，并在 README 的图例中同步说明虚线含义。
