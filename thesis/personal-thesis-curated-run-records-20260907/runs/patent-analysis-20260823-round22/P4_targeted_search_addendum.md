# P4｜V4.2 定向补检增补记录

日期：2026-08-23  
范围：围绕“同证据快照、候选答案关系、原子陈述核验、证据见证、闭包提交与回退”进行公开网页定向补检。本记录不是 CNIPA 全库检索报告。

## 新增重要命中

| 文献 | 已公开内容 | 对 V4.2 的影响 |
|---|---|---|
| CN121901431A | 权利要求7公开：候选回答拆分为原子陈述，逐条召回证据，标注支持/矛盾/不确定，删除或降权矛盾项，不确定项触发二次生成，保留项附证据引用 | 显著削弱“原子声明拆分、三态核验、删除/再生成、证据约束输出”单点；未公开视频 E0/ΔE、A0/A2 同 E+ 配对、必要差异见证和依赖闭包事务 |
| CN103229168A | 权利要求1公开多个候选答案之间的关系、候选答案支持证据、证据传递与置信度更新 | 削弱“候选答案关系+支持证据+评分”单点；未公开旧/新答案状态迁移及视频增量证据 |
| US10769552B2 | 对每个候选答案匹配支持/反驳证据片段并评分、排序，还可追加证据检索 | 削弱候选答案逐证据评估和补充检索的宽泛表述 |
| US20250259044A1 | 说明书公开跨状态一致性核验、原子提交或整体回滚 | 说明“原子提交/回滚”作为通用计算机状态控制本身不宜单独主张；其权利要求和应用对象与 V4.2 距离较远 |

## 更新后的创新边界

不能再单独依赖：补证、候选答案、原子陈述、支持/冲突/不确定三态、证据引用、受限重写、原子提交或回退。

本轮仍未在单篇命中文献中见到以下连续链：

`E0 缺口 → E0 未覆盖位置的 ΔE → 冻结 E+ → 不接收 A0 语义内容的 A2 → A0/A2 在同一 snapshot_id 与 verifier_config_id 下配对复评 → 变化的必要差异槽仅由本轮 ΔE 见证 → 下游写入闭包/上游证明引用集合 → 闭包整体提交或 E+ 下非陈旧安全状态 → 无新增声明终检`。

## 风险判断

- 单篇新颖性：本轮定向检索下仍有残余区别，但不能视为无遗漏结论。
- 组合创造性：中高风险。D1 视频补证 + D2 初答修正 + CN121901431A 原子陈述核验/重写，已能构成较强组合攻击。
- 建议：独权必须保留“同 E+ 配对复评—本轮 ΔE 必要差异授权—双域闭包非陈旧更新”的因果关系；不要把通用模块并列宣传为创新。
