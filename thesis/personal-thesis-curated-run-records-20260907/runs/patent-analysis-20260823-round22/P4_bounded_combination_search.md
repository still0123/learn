# P4｜V4 递交前有边界组合检索报告

日期：2026-08-23  
范围：D1–D5 本地全文、旧案第二次审查意见/驳回决定文本、以及三篇 arXiv 原文。仅分析指定组合；不作全库穷尽检索，亦不修改 V4。

## 1. 结论摘要

1. **D1 是视频问答“补证—再答”骨架，D2 是“初答—核验—修改”骨架，D5 还公开多候选生成和评分。** 因而“低置信补证”“再生成候选”“评分选优”均不能作为 V4 独立创造性支点。
2. **D1+D2 或 D1+D2+D5 能给出组合动机**：均旨在提高视频/视觉问答的回答可靠性。但它们没有提出、也不必然导向：在同一扩展证据集 E+ 下配对重评 A0/A2、将变化限定为声明映射后的槽级迁移、逐项绑定本轮 ΔE 见证，并按有界依赖闭包进行原子提交或非陈旧回退。
3. **Omni-Decision 与 PBRC 显著提高 F6–F8 的风险，不能再把“状态、闭合、见证、确定提交、回退”单独表述为创新。** 它们仍未公开 V4 的双答案同 E+ 配对比较以及视频增量证据对每项声明迁移的绑定。
4. **建议锁定的抗组合核心不是 F3–F9 的并列罗列，而是一条因果控制链：**

   `E0 → A0 声明支持缺口 → 未覆盖位置获取 ΔE → E+ → 不接收 A0 的 A2 → A0/A2 在同一 E+、同一核验器下配对核验 → 声明映射识别变化 → ΔE 见证和依赖闭包限定写入范围 → 原子提交/非陈旧安全状态 → 无新增声明重组`。

5. **已据此形成并收口 V4.2 技术候选稿，但仍不宜给出“创造性已充分/可直接递交”的确定结论。** 提交前由代理人核验旧案的申请/公开/优先权与新案有效日，并补一次 CNIPA 或商业库的分类号、同义词和引用链检索。

## 3. 指定组合的动机与反动机

### 3.1 D1 + D2

**审查员可能的组合路径**：D1 已经因低置信进行视频区域更新、重选帧和迭代回答；D2 为减少 LLM 幻觉，对初始回答提出验证问题、比对并修正。技术目标均为提升问答答案可靠性。旧案第二次审查意见正是按这一方向组合，且认定 D2 对 D1 有应用启示。

**V4 的可辩护反动机/差异**：

- D2 的修正以初始回答为输入；V4 明确禁止把 A0 作为待改写文本输入 A2，目的不是换一个生成提示，而是切断 A0 对后续候选的锚定影响；
- D1/D2 均没有要求 A0 与 A2 必须在同一 E+、同一声明核验定义下同时复评。缺少这一限制时，`A0|E0` 与 `A2|E+` 不可比较；
- D1/D2 按整答预测/验证/改写推进，不会自然得到声明映射、迁移类型、每一变化槽的 ΔE 时空模态见证及局部闭包写入；
- 因此主张的不是“补证后再验证”本身，而是用同证据配对核验把 **变化原因、比较基准和状态写入范围** 绑定为一套控制规则。

**风险结论**：中高。F3 单独不足以抗组合；F3+同 E+ 配对复评+迁移见证/闭包需在独权连续表述。

### 3.2 D1 + D2 + D5

**审查员可能的组合路径**：D1 提供视频补证和迭代，D2 提供初答验证修正，D5 提供多个候选答案和多维评分筛选。审查员可称“补证后产生多个答案并评分选择”为提高可靠性的常规设计。

**V4 的可辩护反动机/差异**：

- D5 的评分面向语义匹配、图像一致性、语言质量等整体候选质量，并不要求同一扩展证据集下对旧/新答案逐项配对核验；
- D5 没有“旧声明在 E+ 下仍应保存”的约束，故不能解决 A2 改坏 A0 中原本正确事实的回归问题；
- D5 没有将新增/替换/撤回等迁移分别要求 ΔE 见证，也没有以有向依赖闭包作为原子写入单元；
- 仅把 D5 评分器插入 D1+D2，得到的是全答候选排名，不会自然导向“闭包内全量通过才提交、失败则按 E+ 下安全状态处理、最终不得新增声明”的事务语义。

**风险结论**：高于 D1+D2。独权不应写成“生成多个候选并按分数选优”；应明确 A0/A2 是同 E+ 下的受控状态迁移比较，并把 D5 可能覆盖的通用评分阈值降至从属。

### 3.3 旧案 + D1/D2

**审查员可能的组合路径**：旧案与 D1/D2 同属视频/多模态问答可靠性，且旧案已采用触发式链式校验与初答改写。若旧案在新案有效日前公开，旧案是最贴近的自身在先公开和创造性起点。

**V4 的可辩护反动机/差异**：旧案的技术路线是“回溯已有关键帧/语音证据 + 将初始答案喂回模型修改”。V4 必须把以下差异写成协同链，而非词语差异：

1. 从初始覆盖之外的视频位置获取 ΔE；
2. A2 独立于 A0 文本生成；
3. 旧/新答案在同一 E+ 下核验；
4. 仅将由 ΔE 逐项见证的声明迁移写入有界依赖闭包；
5. 失败时不复活在 E+ 下已不足或冲突的旧声明，并限制最终重组不得新增声明。

**风险结论**：P0。上述内容若没有在旧案中明确公开，不能当然取得旧案优先权；若新案主体/有效日安排不当，旧案会是最强在先公开。需代理人依据旧案全文和官方著录最终判断。

### 3.4 D1/D2 + Omni-Decision

**审查员可能的组合路径**：D1/D2 的视频取证与修复环可被 Omni 的查询级证据状态、开放证据需求、依赖、确定性更新与 insufficient stopping 加强。该组合在“证据状态管理”层面具有目的相容性。

**V4 的可辩护反动机/差异**：

- Omni 的状态从查询和观测逐步构建，最终只在 ready 时输出单一候选；它没有“旧答案 A0 与独立 A2”的双状态比较；
- Omni 的事实/计算依赖是面向回答闭合的状态字段，并不等于 A0→A2 声明映射后的下游写入闭包/上游只读证明上下文双域；
- Omni 的 reducer 只将观察/判定事件写入状态，未要求每项答案变化必须由 **本轮 ΔE** 中同时绑定视频时间、模态及文字区域的见证授权；
- V4 的相同 E+ 机制不仅管理证据状态，也校正了候选间证据口径不一致。Omni 不给出这一动机。

**风险结论**：高。不得把“状态、依赖、闭合、确定性提交”单独主张为新颖。应主张它们在同 E+ 双答案迁移核验中的具体数据流和技术效果。

### 3.5 D1/D2 + PBRC

**审查员可能的组合路径**：PBRC 已公开“非回退更新需要预设触发和非空外部验证见证；否则回退”，可被用于强化 D1/D2 的验证可靠性。

**V4 的可辩护反动机/差异**：

- PBRC 明确不提出新的底层修正算子或候选选择控制器；其对象是多智能体间信念变化，不是视频问答的答案更新；
- PBRC 的 witness 是验证 token 集合；V4 的见证是仅来自 ΔE 的、对应声明必要证据槽的可定位视频证据（帧/时间、模态，OCR/标识另有区域）；
- PBRC 的 fallback 为保持 argmax/不放大置信度等信念分布操作；V4 的失败状态机需在 E+ 下区分继续取证、保留、证据不足、撤回和必填槽拒答，并禁止复活已失效旧声明；
- PBRC 无旧/新答案声明映射、同 E+ 双答案配对复评和有界依赖闭包的局部事务。

**风险结论**：中高。PBRC 使“见证 + 回退”抽象原理不可独占；V4 的权利要求需锁定“增量视频见证 + 配对核验 + 闭包状态机”的相互作用。

## 4. 反组合论证应避免的写法

不要主张：

- “不把 A0 喂回模型”本身足以创造性；
- “低置信/缺口触发补证”本身新颖；
- “候选答案评分”本身新颖；
- “证据见证、闭合、原子提交、回退”本身新颖；
- 只以广告视频场景、模型名称或阈值参数区别。

应主张：V4 用同一 E+ 对 A0/A2 进行可比的槽级核验；因而能将“由新增视频证据引起的事实变化”与模型改写波动区分开来，随后仅对带 ΔE 见证的受影响闭包作原子更新，失败则输出 E+ 下安全状态且不允许重组阶段重新引入未经提交的事实。该效果是防锚定、避免证据口径偏差、避免局部正确事实被整体改写破坏的联合控制效果，而不是候选得分更高。

## 5. 写入 V4.2 的最小权利要求边界

保留以下最短前置链，以避免权利要求退化为抽象文本事务：

`E0 生成 A0 → A0 声明支持缺口 → E0 未覆盖位置的 ΔE → E+`。

其后紧接特征性控制链：

`A2 不接收 A0 文本 → A0/A2 在同一 E+、同一核验定义下比较 → 声明映射确定变化 → 每项变化由 ΔE 时空模态见证 → 受影响依赖闭包原子提交或 E+ 下安全处理 → 仅由已提交/保留声明受限重组，且终检无新增声明`。

将候选数量、整体分数、绝对阈值/相对裕量、OCR 工具、边界框算法、依赖边类型和闭包大小等作为从属或实施例细化，避免被 D1/D5 的常规迭代/评分直接覆盖。
