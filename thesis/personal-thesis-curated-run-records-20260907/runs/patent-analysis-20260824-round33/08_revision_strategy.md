# Round33 定稿修订策略

## 推荐方案

维持 V4.6 独立权利要求、发明名称、六张附图和单一发明构思不变。算法优化分两类处理：

1. **应做但不称创新**：在实施方式中明确快照哈希、兼容边、唯一配准、SCC、证明版本和条件原子提交；
2. **可选从属增强**：运行时信息流非干扰，一旦发现 A0/许可派生数据进入候选输入，关联许可和迁移立即失效。

## 不建议做

- 不把动态阈值、最大匹配、图算法、哈希、污点跟踪或 CAS 单独写成发明点；
- 不增加第三验证器、多智能体或主动取证模块；
- 不用“变换谱系互斥”作为主创新，因为独立原始输入重算和数据血缘已有直接近案；
- 不扩张权14的反事实保护范围。

## 版本选择

- 若目标是现在冻结：保留 **V4.6** 即可；
- 若代理人希望进一步提高可实施性：只形成 **V4.6.1 算法细化版**，不改独权构思，不新增附图，不把细化内容宣传为查新后的新核心。
