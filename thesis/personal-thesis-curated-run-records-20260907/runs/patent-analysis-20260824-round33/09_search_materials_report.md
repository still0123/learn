# Round33 定向算法近案检索

## 检索主题

- 多模态问答中的数据血缘、非干扰和独立原始输入重算；
- 事实/命题—证据的图匹配和原子见证准入；
- 动态污点传播、版本化依赖和原子提交；
- 匹配反事实证据与候选答案替换。

## 关键命中

| 来源 | 公开内容 | 对候选的影响 |
|---|---|---|
| CN111240991A | 动态污点及隐式污点传播检测 | 证明一般来源标签/污点传播很旧，候选 A 不能单独主张 |
| US20210216229A1 | 数据血缘和影响数据的输入、实体、系统、过程记录 | 一般 lineage/provenance 已成熟 |
| Shadow-Channel Verification（2026-07-07） | 从独立原始输入重算，不复用主通道中间张量，比较结果以检测静默值错误 | 直接逼近“变换谱系互斥/独立重算”，不建议作为新增核心 |
| Quotient Admission Algorithms for Witness-Supported Graph Windows（2026-06-07） | 见证原子、超图守卫、证书/阻断准入和复杂度算法 | 直接提高“见证原子容量超图”风险，淘汰该方向 |
| CN122196109A | 问答数据血缘子图、证据锚点、约束边界和审计快照 | 进一步说明一般 QA 血缘与可复核快照不是空白 |
| ADER / Evidence-RL / PBRC | 当前—候选视频证据替换、匹配反事实、见证与保守回退 | 限制权14和一般候选门控的创造性空间 |

## 结论

定向检索没有找到应当加入独权的新算法空白，反而确认“污点/血缘、独立重算、见证原子超图、匹配反事实、图依赖提交”各自均已有近案。算法优化应仅用于把 V4.6 现有主链做成可执行、可审计的确定性流程。
