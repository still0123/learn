# 03｜原审查问题与 V4.6 应对关系

| 原有风险 | V4.6 的结构性应对 | 仍有风险 |
|---|---|---|
| 低置信触发补证属于既有迭代问答 | 不把触发本身作为创造性中心 | 若独权后续被删弱，仍会退化 |
| 把初始答案喂回模型验证和改写 | 候选服务第二读取域明确排除A0和改写指令 | 需证明不是纯提示词限定 |
| 更新区域、重选帧已被公开 | ΔE仅作为前提，核心转到冻结后的差分许可 | F2单独保护强度有限 |
| 证据变化后更新答案已有上位公开 | 增加两种独立差分、同E+核验和唯一许可配准 | 三文件组合显而易见性仍高 |
| 多步骤易被说成模块堆叠 | 所有步骤围绕同一许可、快照、摘要和事务状态传递 | 说明创造性时必须论证功能耦合 |
| 更新失败固定回到A0 | 以E+下最后仍受支持状态为回退目标 | 状态判据须保持互斥 |

结论：V4.6 已针对原驳回逻辑改变发明中心，但不能把“重写了一篇”本身当作避开原申请和对比文件的法律理由。
