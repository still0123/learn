# 06｜创新候选分层

## 主独权应守住

1. 证据许可服务和候选生成服务针对答案事实状态的读取域相互隔离；
2. 许可先冻结、候选后生成并冻结、候选冻结后才联合读取的四时点约束；
3. 同一E+下形成答案事实差分，并与候选值盲化形成的证据事实差分唯一配准；
4. 配准结果进入有向依赖闭包的全有或全无写入门禁。

## 强从属

- 竞争组；
- 冲突许可和撤回条件；
- 派生许可；
- 状态写入集合/证明引用集合双域；
- 跨闭包失效传播；
- 匹配反事实；
- 无新增事实终检；
- 审计和陈旧快照失效。

## 不宜单独作为创新点

- 低置信触发；
- 重新选帧或裁切；
- OCR/ASR补证；
- 一般意义的答案验证、证据变化后重答或失败回退。
