# 5 小时夜间多 Agent 目标

## 总目标

围绕“图像问答 / 多模态视觉问答”重新寻找新专利创新点。当前阶段不实现代码，优先进行多方向检索、跨领域迁移构思和模拟审查员筛选，避免重复原专利被驳回时的“多模块组合、场景替换、常规技术手段”问题。

## 主研究范围

图像问答领域，包括但不限于：

- 图像 VQA
- 文档图像问答
- 图表问答
- 科学图像问答
- 医学/遥感/工业质检图像问答
- 视觉 grounding 问答
- OCR 视觉问答
- 视觉幻觉检测与抑制
- 视觉 RAG 和证据利用
- 不确定性、拒答、选择性回答
- 小样本、长尾、反事实、因果、主动感知等小众方向

## 检索来源

优先检索 2021-2026 年高质量来源：

- CCF A：CVPR、ICCV、ECCV、NeurIPS、ICLR、AAAI、IJCAI、ACL、EMNLP、SIGIR、KDD
- CCF B：ACMMM、COLING、NAACL、WACV、ECAI 等
- 期刊：TPAMI、IJCV、TIP、TMM、TOIS、TKDE 等
- arXiv 仅作为趋势线索，需标注其正式发表状态

## 每一轮必须完成的闭环

每一轮围绕一个方向完成：

```text
论文/方法检索
-> 提炼技术问题
-> 判断能否迁移到图像问答
-> 构思一个单一创新机制
-> 模拟审查员攻击
-> 淘汰或保留
-> 输出本轮最佳候选创新点
```

## 20 轮执行原则

- Round 05-Round 23 每轮保留 1 个候选创新点。
- Round 24 统一模拟审查员攻击并排名。
- 如果时间不足，优先保证前 8-10 轮质量，而不是机械填满 20 轮。
- 每个候选创新点必须能写成“输入、处理、输出、状态/评分/选择规则”，不能只是功能目标。
- 每轮都要明确“为何不是简单组合”。

## 5 小时内优先级

1. 多方向广泛检索，不急着写代码。
2. 每轮至少覆盖 1 个主方向和 1 个可迁移外领域方法。
3. 每轮必须输出一个“本轮最佳候选创新点”，并说明为什么不是简单组合。
4. 每轮必须包含模拟审查员反驳，专门检查是否会被说成：
   - 场景替换；
   - RAG / CoT / self-check 常规组合；
   - 置信度阈值；
   - 知识图谱或规则路由；
   - 已有视觉 grounding / VQA 方法的直接应用。
5. 最终从多轮候选中筛出 1-2 个最值得新申请的方向。

## 不做事项

- 不继续围绕广告视频做主线。
- 不把 RAG、CoT、自我反思、知识图谱作为主创新。
- 不编造实验指标。
- 不声称授权概率，只输出技术和撰写建议。
- 暂不实现状态机 MVP。
- 暂不写完整专利交底书，除非已有足够检索和审查筛选结论。
