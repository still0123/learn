# Round 12：反事实 / 因果视觉问答

## 1. 本轮方向

- 方向名称：反事实 / 因果视觉问答，重点是区分图像直接证据、语言先验和因果推断越权。
- 检索范围：counterfactual VQA、causal VQA、intervention、spurious correlation、dataset bias、causal VLM；覆盖 CVPR、TMM、MICCAI、NeurIPS、ICLR/OpenReview、arXiv 2021-2026 相关工作。
- 目标问题：寻找一个可写成单一技术机制的创新点，使 VQA 系统在回答前判断“该答案是否由图像可见证据支持，还是由问题语言先验或未经许可的因果外推产生”。

## 3. 热点趋势判断

- 当前领域真正关注的问题：
  - VQA / MLLM 在开放场景下仍会依赖问题模板、答案频率、显眼物体、背景、共现关系、社会/场景常识等捷径。
  - 研究从早期 VQA-CP 语言偏置，转向多模态共同偏置、真实错误驱动的 spurious correlation、反事实样本验证、黑盒大模型审计。
  - 单纯提升准确率不够，越来越强调“答案是否有可见证据”“推理链是否越过图像可支持范围”。

- 已经成熟、不能作为创新点的部分：
  - 仅把问题输入语言分支，估计语言先验，再从答案 logits 中减去，已被 CF-VQA 覆盖。
  - 仅构造反事实样本做数据增强或训练去偏，已被 CF-VQA、DeBCF、SpuriVerse 等覆盖。
  - 仅做 self-check、CoT、置信度阈值或“请模型解释依据”，容易被认为是提示词或后处理。
  - 仅做视觉 grounding，再要求答案引用框，也容易被认为是 VQA + grounding 的常规组合。

- 仍有空白或可迁移空间的部分：
  - 现有方法多在“降低偏置”或“构造评测集”，较少在单个问答推理过程中明确裁决每个中间声明的证据权限。
  - 对“因果推断越权”的处理不足：例如图像能看到“地面湿”，但不能直接回答“刚下过雨”；能看到“人拿伞”，但不能断言“天气正在下雨”。
  - 大模型时代可利用多轮局部视觉查询、问题槽位干预、候选答案反事实替换，形成在线的路径效应比较，而不是离线训练一个去偏模型。

## 4. 候选创新点

```text
候选名称：证据权限分层的反事实裁决 VQA
解决的具体技术问题：
现有 VQA 模型在回答时无法区分答案来自图像直接可见证据、语言先验，还是超出图像支持范围的因果外推，导致在偏置样本和因果型问题上产生看似合理但不可证的答案。
输入：
图像 I、问题 Q、候选答案集合 A 或模型初始答案 a0、可选的候选证据区域 R。
核心处理步骤：
1. 将问题 Q 拆成若干待验证声明槽位，包括对象/属性/关系槽位、答案约束槽位、因果或常识推断槽位。
2. 对每个槽位生成三类最小干预：视觉证据干预（遮蔽或替换相关区域）、语言先验干预（保留问题类型但中和实体/属性）、因果越权干预（把因果词改写成直接可见描述或反事实条件）。
3. 分别计算候选答案在原始输入、视觉干预输入、语言干预输入、因果干预输入下的响应变化，得到视觉必要性分数、语言先验分数、因果越权分数。
4. 建立“证据权限图”：节点为中间声明，边为声明对最终答案的路径效应；节点被标记为直接可见、语言先验、允许因果、越权因果。
5. 最终答案只允许使用直接可见节点和通过权限测试的因果节点；若答案主要依赖语言先验或越权因果节点，则降级为“不足以从图像判断”或输出受限答案。
输出：
答案、证据权限图、每个中间声明的权限标签、拒答或降级原因。
为什么不是简单组合：
核心不是“反事实样本 + VQA”或“解释 + VQA”，而是在单次推理中对中间声明执行成对路径干预，并用路径效应差异决定该声明是否有资格进入答案生成。
可实验数据集：
VQA-CP v2、VQA v2、AOK-VQA、OK-VQA、MM-SpuBench、SpuriVerse、MORE；可额外人工构造小型“因果越权”测试集。
主要风险：
如果干预只靠文本提示生成，审查员会认为是 self-check；必须把视觉区域干预、问题槽位干预和路径效应计算写成明确算法。
```

```text
候选名称：反事实候选答案交换的因果越权检测
解决的具体技术问题：
VQA 模型在多个候选答案之间选择时，会把常识上更常见的答案当成图像事实，尤其在“为什么/会不会/是否导致”类问题中越权推断。
输入：
图像 I、问题 Q、候选答案 A={a1...an}。
核心处理步骤：
1. 为每个候选答案生成最小反事实问题 Q(ai->aj)，保持问题结构不变，只替换答案相关实体或属性。
2. 检查图像中的可见证据是否随候选替换发生对应变化。
3. 若候选答案替换后模型仍给出高一致性解释，说明回答依赖问题模板或常识先验，而非图像证据。
4. 将候选答案按“可见证据敏感度”重排，并拒绝证据敏感度低但先验分高的答案。
输出：
重排后的候选答案、越权风险分数。
为什么不是简单组合：
强调候选答案之间的成对反事实交换和可见证据敏感度，而不是单次置信度。
可实验数据集：
AOK-VQA、OK-VQA、MORE、SpuriVerse。
主要风险：
与知识库反事实问题生成、对抗问题改写较接近，独立性中等。
```

```text
候选名称：虚假相关类型库驱动的在线反事实探针
解决的具体技术问题：
模型面对背景、共现物体、风格、空间关系等虚假相关时，无法知道当前样本触发了哪类捷径。
输入：
图像 I、问题 Q、预置 spurious type library。
核心处理步骤：
1. 根据问题类型和图像标签检索可能的虚假相关类型。
2. 为每类虚假相关生成一个轻量探针，例如背景遮蔽、共现物体去除、显著性反转、空间关系重排。
3. 比较探针前后的答案漂移，识别最可能触发的捷径类型。
4. 对触发捷径的证据路径降权或要求追加直接证据。
输出：
答案、触发的 spurious type、纠偏后的证据权重。
为什么不是简单组合：
将 SpuriVerse/MM-SpuBench 的偏置类型从离线评测迁移到在线推理控制。
可实验数据集：
MM-SpuBench、SpuriVerse、VQA-CP v2。
主要风险：
容易被认为是偏置类型库 + 数据增强/测试时增强，创新强度低于候选 1。
```

## 5. 模拟审查员攻击

- 是否只是应用场景替换？
  - 候选 1：不是单纯把因果推理用于 VQA，而是提出“证据权限图 + 三类路径干预 + 中间声明准入”的推理控制机制；但如果权利要求只写“用反事实减少 VQA 偏置”，会被 CF-VQA 和 Possible Worlds VQA 覆盖。
  - 候选 2：有较高风险，被认为是把反事实问题生成用于答案候选重排。
  - 候选 3：有较高风险，被认为是把 spurious benchmark 的类型库用于在线检测。

- 是否只是 RAG / CoT / self-check / 置信度阈值？
  - 候选 1：需要避免写成“让模型自我判断是否有证据”。技术重点应落在区域遮蔽/替换、问题槽位中和、因果词改写前后的路径效应差值，而不是自然语言自检。
  - 候选 2：如果只是让模型回答“你确定吗”，会被打成 self-check；必须保留候选交换后的响应稳定性度量。
  - 候选 3：如果只检索偏置类型并提示模型注意，会被打成 prompt/RAG；必须有具体视觉探针和答案漂移计算。

- 是否只是现有 grounding / VQA / OCR / 图表解析方法组合？
  - 候选 1：使用 grounding 只作为生成视觉干预区域的手段，创新点在“被干预后的路径效应决定声明权限”，不是引用框本身。
  - 候选 2：不依赖 OCR/图表；与 grounding 关系较弱。
  - 候选 3：可能使用 grounding 找共现物体或背景区域，但仍需证明类型库驱动探针不是常规遮蔽。

- 是否能被一篇或几篇论文自然组合推出？
  - 候选 1：最强攻击是 CF-VQA 的路径效应 + MORE 的 Decompose-Verify-Answer + SpuriVerse 的反事实偏置验证。防守点是这些工作没有把每个中间声明划分为“直接可见/语言先验/允许因果/越权因果”，也没有将权限标签作为最终答案准入门控。
  - 候选 2：可能由知识库反事实问题生成 + CF-VQA 自然推出，防守较弱。
  - 候选 3：可能由 MM-SpuBench/SpuriVerse + test-time augmentation 自然推出，防守较弱。

- 是否缺少可验证技术效果？
  - 候选 1：可验证效果明确：在 VQA-CP / SpuriVerse 上降低语言先验错误，在自建因果越权集上提高“拒绝不可见因果结论”的准确率，同时不显著损伤 VQA v2 常规准确率。
  - 候选 2：可测候选重排准确率和先验型错误率，但需要高质量候选答案。
  - 候选 3：可测 spurious type 识别和纠偏后准确率，但类型库覆盖不足会影响泛化。

## 6. 本轮最佳候选

本轮只保留：**证据权限分层的反事实裁决 VQA**。

- 为什么选它：
  - 它正面回应本轮目标：区分图像直接证据、语言先验和因果推断越权。
  - 它不是单纯训练去偏，也不是只构造反事实数据集，而是在推理过程中生成“证据权限图”，用路径效应裁决哪些中间声明可以进入最终答案。
  - 它适合写成专利方法步骤：槽位分解、三类干预、路径效应计算、权限标注、答案准入控制。

- 为什么淘汰其他候选：
  - 候选 2 更像反事实问题改写和候选答案重排，容易被知识库反事实查询和 CF-VQA 组合推出。
  - 候选 3 依赖已有 spurious type library，容易被认为是 SpuriVerse/MM-SpuBench 的在线应用，独立技术动作不够集中。

- 如果写专利，独立权利要求应该抓住哪个技术动作：
  - 抓住“对问题拆分出的中间声明分别执行视觉证据干预、语言先验干预和因果越权干预，依据干预前后答案路径效应差异为中间声明生成证据权限标签，并根据证据权限标签控制最终答案输出”的动作。
  - 关键限定应包括：
    - 中间声明槽位化；
    - 至少三类干预；
    - 路径效应差异计算；
    - 证据权限图；
    - 对越权因果或语言先验主导答案的拒答/降级。

- 如果做实验，最快怎么证明：
  - 数据：VQA-CP v2 + VQA v2 做语言偏置与常规能力平衡；SpuriVerse/MM-SpuBench 做虚假相关鲁棒性；人工构造 200-500 条因果越权样本，例如“地面湿 -> 是否刚下雨”“人拿伞 -> 是否正在下雨”“烟雾 -> 是否着火”。
  - 基线：原始 VLM、CoT/self-check、CF-VQA 思路的语言先验消除、简单区域遮蔽 grounding。
  - 指标：常规准确率、偏置样本准确率、越权拒答准确率、错误答案中语言先验占比、路径效应解释与人工标注一致率。
  - 最小验证：不训练模型，只用现有 VLM + 区域遮蔽/问题改写做 test-time 裁决，先证明越权型错误显著下降；若效果成立，再考虑轻量学习权限分类器。
