# Round 24 总审查与候选创新点排名

## 1. 汇总范围

本轮汇总 Round 05-Round 23 共 19 个方向的候选创新点，目标是筛出最适合另案申请的图像问答技术方案。

评价标准：

- 是否是单一技术机制，而不是功能模块堆叠；
- 是否能避开原案被驳回时的“现有技术组合”问题；
- 是否能写成明确的输入、处理步骤、状态/评分规则、输出；
- 是否有快速实验路径；
- 是否有足够审查抗辩空间。

## 2. 总体结论

19 个方向最后明显收敛到一个共同母题：

```text
图像问答答案不是整段生成后再检查，而是把答案拆成声明；
每个声明根据风险、证据类型、反证、尺度、数值、常识或扰动结果获得不同许可状态；
最终答案只输出被许可或被降级后的声明。
```

因此，新专利不建议写成“多模态 RAG + grounding + self-check”。更稳的写法是：

> 一种面向图像问答的声明级证据许可与反证裁决方法。

但为了避免太泛，独立权利要求最好选择一个具体切口，而不是把所有方向都塞进去。

## 3. 最推荐的 3 个主申请方向

### 第一名：声明影响切片驱动的三轴变形差分验证器

来源：Round 18 软件测试 / 差分验证迁移。

核心机制：

```text
候选答案声明
-> 以声明为 slicing criterion 确定影响切片
-> 生成图像、问题、答案三轴 follow-up / mutant
-> 根据声明类型配置 metamorphic relation
-> 判断输出应稳定、应翻转或应拒答
-> 根据 violation / mutant survival 控制声明保留、降级、删除或拒答
```

推荐理由：

- 跨领域迁移味道最强，不像常规 VQA/RAG/grounding 直接组合；
- 技术动作明确：切片、变异、差分、期望关系、存活判定；
- 审查抗辩较好：不是普通数据增强，因为扰动由答案声明切片驱动；不是普通一致性检测，因为每类声明有不同 metamorphic relation；
- 实验快：GQA、TextVQA、ChartQA 都能构造 200-500 条验证集。

主要风险：

- 软件测试方法本身是成熟技术，需强调其在图像问答中的“声明级影响切片”和“三轴变形关系表”不是简单套用；
- 不要写成“扰动图像后比较答案一致性”。

建议专利名称：

**一种基于声明影响切片和变形差分验证的图像问答可信生成方法**

### 第二名：鉴别诊断式互斥证据许可状态机

来源：Round 08 医学诊断迁移。

核心机制：

```text
候选答案集合
-> 生成相邻候选之间的互斥证据槽
-> 检查支持证据、排除证据、冲突证据、必要可见证据
-> 构建候选-互斥证据矩阵
-> 对候选答案执行许可、降级、阻断
```

推荐理由：

- 医学鉴别诊断迁移到通用图像问答，有清晰跨领域来源；
- 特别适合细粒度识别、长尾实体、相似物体、遮挡、不确定问题；
- 比“声明级状态机”更具体，避免过泛；
- 实验可用 GQA、A-OKVQA、POPE、VLR-IF、细粒度分类数据构造 hard negative。

主要风险：

- 容易被审查员说成候选答案重排或反证检测；
- 必须写清“互斥证据槽”和“候选-证据矩阵”的生成与状态转移。

建议专利名称：

**一种基于互斥证据槽的图像问答候选答案许可裁决方法**

### 第三名：数值声明证据图谱与量纲一致性校验器

来源：Round 15 图表 / 数值 / 量纲一致性。

核心机制：

```text
图表问答候选答案
-> 拆分 numeric / comparison / trend claim
-> 构建图元、坐标轴、刻度、单位、计算操作证据槽
-> 执行轴标定、单位规范化、量纲一致性、趋势反证
-> 输出精确值、区间值、降级回答或拒答
```

推荐理由：

- 小众、实验快、技术边界清楚；
- 与普通 ChartQA/DePlot/ChartReasoner 的区别相对明确：不是回答模型，而是声明级数值证据校验；
- 可构造 stress set：双 y 轴、断轴、非零基线、百分比点、单位换算、趋势局部反例。

主要风险：

- 范围相对窄，适合作为图表/文档图像问答方向单独申请；
- “证据图谱”表述要谨慎，避免被打成普通知识图谱或图表解析后规则校验。

建议专利名称：

**一种面向图表图像问答的数值声明量纲一致性许可方法**

## 5. 不建议作为独立主案的方向

- 普通“声明级视觉证据许可状态机”：Round 05/06/21 均支持该主线，但作为独立主案仍偏泛，容易被 claim checker、RAG verifier、grounded VQA 组合攻击。
- 普通 Visual RAG / evidence utilization：现有 MRAG、Visual RAG、MM-RAGChecker 已经很密。
- 普通反常识冲突门控：Round 16 有价值，但容易落入 hallucination detection / commonsense verification。
- 普通少样例证据策略自适应：Round 22 可作为从属或实验策略，但主案容易被 few-shot prompt / TTA 覆盖。
- 普通遥感多尺度许可账本：Round 09 可作为多尺度证据实施例，但单独申请容易被认为场景迁移。

## 6. 最终推荐申请策略

### 推荐主案 A

优先申请：

**一种基于声明影响切片和变形差分验证的图像问答可信生成方法**

理由：

- 最不像原案；
- 最不容易被直接拆成 RAG/CoT/grounding 组合；
- 跨领域迁移明确；
- 代码和实验都能快速做 MVP。

独立权利要求抓手：

```text
以候选答案声明为切片准则，
生成图像、问题和答案三轴变形样本，
依据声明类型配置变形关系，
根据变形关系违背和突变体存活结果，
控制声明的保留、降级、删除或拒答。
```

### 推荐主案 B

备选或并行申请：

**一种基于互斥证据槽的图像问答候选答案许可裁决方法**

理由：

- 与医学鉴别诊断迁移相关，技术概念清楚；
- 与长尾/细粒度候选排除方向可合并；
- 适合构造 hard negative 实验。

### 推荐小众专案 C

如果想先做实验快、边界窄的案子：

**一种面向图表图像问答的数值声明量纲一致性许可方法**

理由：

- 图表数据实验快；
- 技术边界较窄，审查时更容易解释；
- 可形成明确的图元、坐标轴、单位、计算证据链。

## 7. 下一步建议

1. 先围绕主案 A 写一版 1-2 页技术交底摘要。
2. 同时实现一个最小实验：GQA/TextVQA/ChartQA 各 50 条，生成声明切片、三轴扰动、metamorphic relation、声明许可结果。
3. 用主案 B 的“互斥证据槽”增强主案 A，而不是把两者并列堆叠。
4. 将主案 C 作为备选专案或从属实施例，不要强行塞进主案 A。

## 8. 总结

本轮 19 个方向的搜索结果显示，“声明级证据许可”仍然是稳定主线，但不能直接泛泛申请。最值得继续推进的是把它具体化为：

```text
声明影响切片 + 三轴变形差分验证 + 许可动作控制
```

这条路线相比原驳回专利更不依赖广告场景，也更不像现有技术的简单组合。
