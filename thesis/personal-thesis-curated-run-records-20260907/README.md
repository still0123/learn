# Curated personal thesis and patent research run records

This is a curated backup of the substantive, personal research records from
`vqa_thesis_continue/runs`, prepared before the local machine is reset.

Included:

- final conclusions, ranking reports, and claim strategies;
- substantive patent/thesis analysis and review records;
- source/provenance and gate records needed to interpret those conclusions;
- the small local scripts and verified research outputs needed to understand
  the patent-innovation run.

Deliberately excluded from this backup:

- files whose identical Git blobs already existed on `learn/main`;
- additional byte-identical local copies;
- generated literature retrieval/screening pools that can be regenerated from
  the preserved workflow; and
- generated run plans, artifact indexes, checksums, and resumability state.

Every copied source file is listed in `SHA256SUMS`. From this directory, verify
the archive with:

```sh
shasum -a 256 -c SHA256SUMS
```
