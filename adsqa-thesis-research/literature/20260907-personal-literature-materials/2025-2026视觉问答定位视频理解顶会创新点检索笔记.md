# 2025-2026 视觉问答/定位/视频理解顶会创新点检索笔记

记录日期：2026-07-07

用途：为广告视频问答毕业论文重新判断创新点强弱，避免把已有热点写成“新方法”。

## 1. 总体趋势

2025-2026 年视觉相关 A 会/顶会工作的共同趋势是：

```text
高分辨率/长视频输入
-> 问题条件化证据选择
-> token/帧/区域压缩
-> grounding / temporal evidence
-> 答案与证据联合评价
```

因此，单独写“关键帧选择”“局部裁剪”“RAG”“CoT”“反思”都不够新。更稳的创新点必须落在更具体的约束上：广告视频的短时字幕、Logo、价格、产品细节、ASR 旁白、声画错位和营销语义。

## 3. 对本文创新点的结论

### 3.1 不能作为强创新的表述

- “我做了关键帧选择”：Frame-Voyager、HiMu、VideoDetective 等已经覆盖问题驱动选帧/片段。
- “我做了视觉 token 压缩”：BIMBA、PruneVid、Dynamic-VLM 等已经覆盖。
- “我做了局部裁剪/高分辨率局部图”：ZoomEye、FOCUS、ViCrop、AdaptVision、DeepEyes 等已经很接近。
- “我做了 RAG”：ViG-RAG、Visual RAG、MM-RAGChecker 等方向已经很密。
- “我做了 CoT/反思”：Grounded CoT、MJ1、VideoSEAL、EV2-Bench 等都在走证据化推理/校验。

### 3.2 本文可以保留的差异化切口

广告视频不是一般长视频，也不是一般图像 VQA。本文更应该强调：

1. **广告证据短时且局部**：字幕、Logo、价格、包装、CTA 可能只出现极少帧。
2. **证据跨模态且错位**：旁白和画面常不同步，不能简单帧级对齐。
3. **问题需要营销语义映射**：情绪、受众、说服策略不是纯视觉对象识别。
4. **知识不能越权替代视频证据**：营销知识只能解释已观察证据，不能凭空补答案。

## 4. 更稳的论文创新点写法

### 创新点 1：广告证据需求驱动的视听-文字证据定位与输入重构

不要写成“token 压缩”或“局部裁剪”。建议写成：

> 面向广告视频中短时字幕、Logo、价格、商品细节和旁白错位等证据特征，提出广告证据需求驱动的视听-文字证据定位方法。该方法以问题语义为中心，融合 ASR 邻域语义、OCR/Logo 显著性和视觉相关性，生成广告证据响应图，并据此构建全局语境视图与局部高分辨率证据视图。

技术动作：

- 高频候选帧过采样；
- 问题-视觉相关性；
- 邻域 ASR-视觉相关性；
- OCR/Logo 弱显著性；
- 时空响应图融合；
- 响应密度局部锚定；
- 全局视图 + 局部高分辨率证据视图；
- evidence package。

### 创新点 2：广告语义证据槽驱动的知识检索与低噪声注入

不要写成普通 RAG。建议写成：

> 基于第一创新点输出的证据包，将问题和视频证据映射为广告语义证据槽，并只在证据槽触发时检索相应营销知识。知识条目必须与 ASR、OCR、视觉标签或局部证据视图形成匹配，才允许进入推理上下文。

技术动作：

- 问题类型路由；
- 证据槽：情绪、主题、受众、策略、行动号召、视觉文字；
- dense + lexical hybrid 检索；
- 证据触发过滤；
- top-1/top-2 低噪声注入；
- knowledge-only claim 降级。

### 创新点 3：广告答案声明的证据许可校验

不要写成“四维链”。建议写成：

> 将广告问答答案拆解为视觉声明、语音声明、文字声明和营销语义声明，并根据声明类型回溯对应 evidence package 与知识条目。只有满足证据许可条件的声明才能进入最终答案，不足声明需要降级或删除。

技术动作：

- claim split；
- claim type classification；
- evidence requirement slot；
- supported / contradicted / insufficient 状态；
- 高风险触发词；
- 答案降级/删除/改写；
- hallucination / unsupported claim 指标。

## 5. 对毕业论文的建议

最稳结构不是两个并列大创新，而是：

```text
主创新：广告证据需求驱动的视听-文字证据定位与输入重构
辅助创新：证据槽驱动的广告语义知识检索与声明许可校验
```

这样可以避开 2025-2026 年已有工作的拥挤点：普通高分辨率 crop、普通视频 token compression、普通 Video RAG、普通 CoT/self-check。
