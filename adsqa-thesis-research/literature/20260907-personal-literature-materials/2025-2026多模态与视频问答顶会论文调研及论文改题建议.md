## 1. 总体结论

### 1.1 对当前论文方向的核心判断

当前 2025-2026 年多模态和视频问答相关工作呈现一个明显趋势：

```text
从“直接生成答案”
转向“选择证据 → 压缩证据 → 基于证据生成 → 基于证据验证 → 答案与证据联合评价”
```

这说明，用户当前论文不宜继续把创新点写成：

```text
热力图 + 思维链 + RAG + 反思
```

这种写法会显得像已有模块堆叠。更稳妥的主线应改为：

```text
问题条件化证据选择 → 证据保留型视觉输入重构 → 证据约束生成 → 答案-证据一致性评价
```

对应到广告视频问答场景，可表述为：

> 面向广告视频问答，本文围绕品牌、商品、字幕、Logo、口播、卖点、行动号召和画面-音频对应关系等广告证据，构建问题条件化的视听文字证据定位与证据保留型输入重构方法，并通过答案与证据的一致性约束提升问答可靠性。

---

### 1.2 “热力图/响应图/证据定位”是否还能作为创新点

可以，但要改写。

不能写成：

```text
本文生成热力图解释模型关注区域。
```

这种说法创新性弱，容易被理解为普通注意力可视化或 saliency map。

应写成：

```text
本文构建问题条件化的视听-文字时空响应图，用于在有限输入预算下选择与问题相关的广告视频证据，生成可追溯证据包，并进一步约束答案生成与证据一致性评价。
```

也就是说，热力图/响应图必须具备三个功能，才足够作为工作点：

1. **参与输入选择**：决定哪些帧、哪些时间段、哪些局部区域进入模型；
2. **参与生成约束**：答案必须回指被选中的证据；
3. **参与评价闭环**：不仅评答案是否正确，还评答案是否由正确证据支持。

如果它只是事后展示图，则创新性不足；如果它是证据选择、证据压缩和证据评价的核心接口，则可以成为论文主要工作点。

---

### 1.3 “思维链”应如何处理

“思维链 / CoT”不建议作为题目或核心创新点。

原因：

- CoT 已是通用 LLM 推理范式；
- 广告视频场景替换不足以构成强创新；
- Prompt 型 CoT 容易被认为是工程技巧；
- “热力图 + CoT”容易被看成模块串联。

建议将“思维链”降级为实现形式，改写为以下更机制化的概念：

| 不建议主打 | 建议替换 |
|---|---|
| 思维链 | 证据约束生成 |
| 链式推理 | 答案-证据一致性验证 |
| 链式反思 | 声明级证据回溯校验 |
| 自我检查 | 受控答案修正 |
| CoT Prompt | 观察—证据—答案的结构化输出协议 |

## 2. 推荐中期改题方向

### 2.1 最推荐题目

> **基于视听证据定位与证据约束生成的广告视频问答方法**

优点：

- 不再把“思维链”作为创新点；
- 保留“证据定位/响应图/热力图”这条主线；
- 能兼容现有第3章“视觉特征压缩”和第4章“声明级回溯”；
- 与 2025-2026 年视频问答、VLM hallucination、grounded VQA 的趋势一致；
- 不把 RAG 作为核心，符合当前实验口径中 no-RAG evidence pipeline 更稳的结果。

---

### 2.2 偏方法机制版题目

> **基于证据保留型视觉输入重构与证据一致性校验的广告视频问答方法**

适合强调“视觉压缩/输入重构”仍是主要方法部分。

---

### 2.3 偏可靠问答版题目

> **面向广告视频问答的证据引导多模态推理与验证方法**

适合如果后续想把第4章“证据验证/回溯校验”写得更重。

---

### 2.4 不建议题目

| 题目 | 问题 |
|---|---|
| 基于热力图与思维链的广告视频问答方法 | 热力图和思维链都像已有模块，创新性弱 |
| 基于视觉特征压缩与链式反思的广告视频问答方法 | “视觉特征压缩”易被误解为 token pruning；“链式反思”易被理解为 Self-Refine |
| 基于 RAG 与思维链的广告视频问答方法 | RAG/CoT 均为通用范式，且当前实验显示 RAG 不宜作为主贡献 |
| 基于多模态大模型的广告视频问答系统 | 太泛，像应用系统，不像方法论文 |

## 3. 建议重构后的三条创新点

### 创新点 1：问题条件化的广告视频证据定位机制

面向广告视频中短时字幕、Logo、价格、商品细节、口播和行动号召等证据，构建由问题、ASR、OCR/Logo 和广告证据类型共同驱动的视听-文字时空响应图，用于选择与问题相关的关键帧、时间片段和局部证据区域。

对应文献支撑：

- QA-TIGER：问题条件化时间证据选择；
- EG-VQA：视频问答需要 grounded temporal evidence；
- VISTAQA：答案应与视觉证据联合评价；
- Frame-Voyager / HiMu / VideoDetective：查询驱动帧/片段选择。

---

### 创新点 2：证据保留型视觉输入重构方法

在有限输入预算下，不是简单均匀采样或随机裁剪，而是通过全局语境视图与局部高分辨率证据视图共同保留关键广告证据，实现“降低冗余输入”和“保留细粒度证据”的平衡。

对应文献支撑：

- BIMBA：长视频 QA 中选择性压缩与长程依赖建模；
- PruneVid：训练自由的视频视觉 token 剪枝；
- Fre-Res：空间细节与时间覆盖之间的预算权衡；
- LLaVA-Scissor：语义连通区域的 token 压缩；
- Q-Fold：focus-context 式长视频输入折叠。

---

### 创新点 3：答案-证据一致性约束与验证

将广告视频问答从“只生成答案”改为“答案必须由选中证据支持”。可在轻量实现中要求模型输出答案、证据时间段/证据区域/证据描述，并通过证据一致性、无依据知识注入率、幻觉率或人工复核验证答案可靠性。

对应文献支撑：

- Visual Description Grounded Decoding：视觉描述约束生成，降低幻觉；
- Commonsense Video QA with Video-Grounded Entailment Tree：把视频 QA 转为可验证命题树；
- MJ1：基于 grounded verification chain 的多模态裁判；
- VideoSEAL：长视频答案与证据错配问题；
- VISTAQA / EG-VQA：答案正确性与证据 grounding 联合评价。

## 4. 论文机制统一表达：避免“模块堆叠”

### 4.1 不建议的堆叠式表达

```text
本文使用热力图定位关键区域，再使用 RAG 检索知识，最后用思维链进行推理和反思。
```

问题：

- 热力图、RAG、CoT、反思是几个并列模块；
- 缺少统一技术假设；
- 评委容易认为只是工程串联。

---

### 4.2 推荐的机制式表达

```text
本文认为广告视频问答的主要困难在于：问题相关证据稀疏分布于视觉、文字和语音线索中，且模型容易在无证据支撑时生成看似合理的广告解释。为此，本文提出问题条件化的证据定位与证据保留型输入重构方法，先在有限预算内筛选与问题相关的关键帧、时间片段和局部证据区域，再以证据包约束答案生成和证据一致性验证，从而降低无关帧/token干扰和无依据推断风险。
```

统一假设：

```text
广告视频 QA 的性能瓶颈 = 问题无关视觉冗余 + 答案与证据不一致
```

统一方法：

```text
问题条件化证据选择 + 证据保留型输入重构 + 答案-证据一致性验证
```

统一指标：

```text
Accuracy + 证据定位质量 + Token/Latency + 幻觉率/证据一致性
```

### 6.3 第3章推荐改写主线


## 8. 中期答辩建议口径

### 8.1 如果老师问：“你的创新点是不是就是热力图 + 思维链？”

建议回答：

> 不是。本文没有把热力图作为事后可视化，也没有把思维链作为主要创新。本文关注的是广告视频问答中的证据稀疏和证据不一致问题：一方面通过问题条件化的视听-文字响应图选择与问题相关的时间片段和局部视觉证据；另一方面让最终答案回溯到这些证据，避免模型生成无依据的广告解释。因此，热力图只是证据定位的表达形式，核心是证据选择、证据保留型输入重构和答案-证据一致性约束。

---

### 8.2 如果老师问：“为什么不是模块堆叠？”

建议回答：

> 简单模块堆叠通常是先采样视频，再检索知识，再让模型用思维链回答；各模块之间没有统一约束。本文的区别在于，问题条件化响应图生成的证据包贯穿后续过程：知识必须由证据触发，答案必须引用证据，校验也基于同一证据进行。因此，本文不是把热力图、RAG 和思维链串联起来，而是围绕同一个证据接口完成证据定位、证据压缩、证据生成和证据验证。

---

### 8.3 如果老师问：“那你的实验怎么证明？”

建议回答：

> 除了常规问答准确率，后续实验会增加三个维度：第一，证据定位质量，例如证据时间段命中率、OCR/Logo区域命中率；第二，效率指标，例如关键帧数、视觉token、推理时延；第三，答案-证据一致性指标，例如无依据回答比例、幻觉率和声明级证据支持率。这样可以证明方法不是单纯提高答案分数，而是提高广告视频问答中的证据利用质量。

---

## 9. 建议最小可落地实验组合

考虑毕业论文时间成本，不建议一开始做像素级 mask 标注。更现实的是：

### 9.1 最小可交付实验

| 实验 | 目的 | 指标 |
|---|---|---|
| Qwen3 raw/uniform vs Qwen3 evidence no-RAG | 验证证据组织有效 | Accuracy / strict / relaxed |
| Uniform sampling vs question-aware frame selection | 验证问题条件化帧选择 | Accuracy、关键证据帧命中率 |
| Global only vs Local only vs Global+Local | 验证局部高分辨率证据视图 | OCR/Logo 子集准确率、Token |
| no-RAG vs evidence-aware RAG | 验证知识是否应由证据触发 | 知识一致性、无关知识注入率 |
| no verification vs evidence consistency check | 验证证据校验作用 | 幻觉率、误修正率 |

---

### 9.2 建议人工标注小集

不需要全量标注。建议抽样 100-300 条，标注：

```json
{
  "sample_id": "...",
  "question": "...",
  "answer": "...",
  "evidence_time": [start, end],
  "evidence_type": ["visual", "ocr", "asr", "logo", "product", "cta"],
  "ocr_or_logo_needed": true,
  "answer_supported_by_evidence": true
}
```

这样即可支持：

- 时间证据命中率；
- OCR/Logo 证据召回；
- 答案-证据一致性；
- 幻觉/无依据推断分析。

## 11. 最终建议

### 11.1 题目建议

最推荐：

> **基于视听证据定位与证据约束生成的广告视频问答方法**

备选：

> **基于证据保留型视觉输入重构与证据一致性校验的广告视频问答方法**

---

### 11.2 论文主线建议

不要写成：

```text
视觉压缩 + RAG + CoT + Reflection
```

要写成：

```text
证据定位 → 证据保留型输入重构 → 证据约束生成 → 答案-证据一致性验证
```

---

### 11.3 “热力图”最终定位

热力图不是创新点本身，而是“证据响应图”的可视化表达。真正的创新点是：

```text
问题条件化证据响应图如何选择广告视频中的时间片段和局部证据区域，
并如何将这些证据用于答案生成与证据一致性评价。
```

---

### 11.4 “思维链”最终定位

思维链不应写成创新点，只能作为结构化输出或解释格式。真正应强调的是：

```text
答案声明必须回溯到视频证据，且无法被证据支持的声明应降置信、修正或删除。
```
