### 新增文献揭示的六条技术脉络

1. **静态筛选正在被主动观察替代。** LensWalk、Act2See、LongVT、VideoThinker、VideoARM 都让模型决定下一次观察的时间范围、采样密度或局部区域。对 AdsQA 的化用不是处理小时级长视频，而是在短广告内寻找持续时间极短、空间极小的 Logo、价格、CTA 和免责声明。
2. **学习对象从“回答器”扩展到“采样器/工具策略”。** MSJoE、Select Less、VideoITG 和 AdaTP 说明轻量选择器可以是独立可训练模块；这支持“冻结 Qwen3-VL + 训练广告证据选择器”的可行路线。
3. **监督从最终答案扩展到时间、区域、步骤和证据引用。** TOGA、Vid-Group、Grounded-VideoLLM、VideoRFT、RLER 共同表明可以通过伪标注、工具轨迹和反事实删除构造过程监督，不必完全依赖昂贵人工标注。
4. **多证据融合已成为独立瓶颈。** HERBench、CaST-Bench、SAMA、DualGround 都表明，即使关键帧已找对，模型也可能无法正确整合多个时间段/区域/模态线索；论文需要单独测量证据召回与融合，不只报 QA accuracy。
5. **Token 压缩研究正在反思“attention = 重要性”。** FrameFusion、AdaTP、DART 及 ACL 分析论文都提示，注意力会带来时间端点偏置、空间位置偏置和重复性误判。因此“按注意力切 Token”无法单独成立；广告方法应显式优化功能证据覆盖、重复度和预算。
6. **纯文本 CoT/RAG 已不足以保证可靠。** When Thinking Drifts、Deeper Thought, Weaker Aim、VGR、RLER 强调推理会削弱视觉感知。广告知识只应解释已经观察到的视频证据，声明缺证据时应触发重看，而非继续文本化思考。

## 技术内容拆解

### 1. 2025：从“看更多帧”转向“证据定位 + 压缩”

2025 年的主线是解决视频输入太长、无关帧太多、模型容易靠语言先验猜答案的问题。

代表技术动作：

- BIMBA：用 selective scan / state-space 思路压缩长视频 token，重点是保留关键时空信息。
- Flexible Frame Selection / M-LLM frame selection：用可学习策略选择更有信息量的帧。
- VideoTree / ReVisionLLM / VideoMiner：用树状、递归、粗到细结构处理长视频。
- Cross-modal Causal Relation Alignment：把回答和时间片段定位做因果一致性约束，避免伪相关。
- Commonsense VideoQA with Entailment Tree：把 commonsense answer 变成 video-grounded entailment tree，减少黑盒猜测。

对本文的直接含义：单独做“关键帧选择”“token 压缩”“粗到细定位”已经不够新。若保留 token 定位切割，必须升级成“广告证据保留型 token/区域/帧联合定位”，并且要证明普通压缩会丢掉广告短时证据。

### 2. 2025：图像侧已经卷到“主动 crop / 内部表征定位”

图像 VQA 的细粒度路线已经不满足于裁剪图像，而是开始利用模型内部表征决定看哪里。

代表技术动作：

- FOCUS：从 MLLM 的 KV cache 生成 object relevance map，再提出并排序 crop 区域。
- VLM-R3：将 region recognition、reasoning、refinement 嵌入推理链，让模型边推理边重看局部区域。
- VTimeCoT：把视频进度条变成视觉工具，用“画出来”的方式做 temporal CoT。

对本文的直接含义：如果你的创新点只是“token 定位后切图给模型看”，会被 FOCUS / VLM-R3 / VTimeCoT 一类工作压住。更好的落点是：token 定位不是通用局部 crop，而是广告证据槽驱动的证据需求定位，并生成可审计的 evidence package。

### 3. 2026：VideoQA 的热点是“证据纯度”和“多证据整合”

2026 的几个 CVPR 工作非常接近你现在想做的方向。

代表技术动作：

- Select Less, Reason More：强调 evidence purity，少选但选准，用 RL 训练主动证据选择。
- HERBench：每个问题至少需要三个不同时间段 cue，评估多证据融合能力。
- CaST-Bench：要求模型回答 causal question，同时定位 causal chain 的时间段和 bbox track。
- GroundVTS：在 LLM 前做 query-guided visual token sampling，保留时间线上的关键信息。
- Divide, then Ground：先判断问题是 global 还是 localized，再决定 uniform sampling 或 query-aware selection。

对本文的直接含义：论文不能只说“我选证据”，而要说“广告问题需要什么最小充分证据集”。这比单纯 token 定位更高级，也能和你的 AdsQA 任务结合。

### 4. 2026：VideoQA 正在走 agentic observation

视频理解从一次性输入，转向模型主动决定下一步看哪里。

代表技术动作：

- LensWalk：reason-plan-observe 循环，模型每一步指定时间范围和采样密度。
- VITAL / Thinking With Videos：使用视觉工具箱按需密集采样，并用多任务 RL 训练 video reasoning。
- SAGE：长短视频都能处理的 any-horizon agent，简单问题一轮答，复杂问题多轮看。
- A.I.R.：adaptive、iterative、reasoning-based frame selection for VideoQA。

对本文的直接含义：如果毕业论文允许改技术路线，最强借鉴不是再堆一个静态 adslot，而是把广告证据定位做成“问题驱动的多轮证据探测”：先粗看广告，再根据缺失证据主动补看 OCR/Logo/产品/CTA 片段。

### 5. OCR / scene text / text-rich video 是广告 VQA 的强切口

广告视频和普通 VideoQA 最大差异之一是文字密集：品牌、包装、价格、卖点、免责声明、CTA 往往是局部短时证据。

代表技术动作：

- EgoTextVQA：指出动态 egocentric 场景中文字问答很难，高分辨率、多帧、temporal grounding、辅助 scene-text 输入都很关键。
- MME-VideoOCR：视频 OCR 不只是识别文字，还包括跨帧文字理解、时空推理和抗语言先验。
- CLIP is Almost All You Need for Scene Text Retrieval：说明 OCR-free scene text retrieval 也在被研究。

对本文的直接含义：广告 VQA 可以把“文字证据”从普通 OCR 提升为广告功能性文字证据，例如 Logo、价格、优惠规则、CTA、卖点词、免责声明。这个比泛泛 adslot 更有技术抓手。

### 6. RAG / 知识注入方向已经变成“可审计”和“视觉空间融合”

2026 的 RAG 不再只是检索文本拼 prompt。

代表技术动作：

- Graph-to-Frame RAG：先构建视频知识图，再检索最小充分子图，并把知识融合到视觉空间，强调 auditable。
- Wiki-R1：面向知识型 VQA，用数据课程和采样课程做 RL。
- CC-VQA / ReAG：处理知识冲突、知识型视觉问答中的推理增强。
- Separation of Powers：强调 observation 和 knowledge 分权，避免知识替代视觉观察。

对本文的直接含义：营销知识库不能作为主创新。更稳的是“证据许可的知识注入”：只有当视频证据触发某个广告语义槽时，知识才能进入答案生成；知识不能替代视频证据。

## 对你现有技术路线的初步判断

### token 定位切割仍然可以成为强点，但必须升级

原始说法：

```text
根据 token 定位关键区域/帧，再切割输入给模型。
```

这个说法已经不够，因为 2025-2026 已有 FOCUS、VLM-R3、GroundVTS、QViC-MF、PruneVid、Dynamic-VLM、VideoTree 等大量相近工作。

建议升级为：

```text
广告功能证据保留的跨模态 token-帧-区域联合定位。
```

它要解决的问题不是“压缩 token”，而是：

- 普通 token pruning 会误删小字、Logo、价格、CTA；
- 普通 frame selection 会错过短时广告证据；
- 普通 crop 会看见局部但不知道广告功能；
- 普通 VideoQA grounding 很少区分广告证据类型。

### 更强的技术主线候选

1. 广告功能证据保留定位：把 OCR、Logo、产品、价格、CTA、免责声明、卖点词作为功能证据，而不是普通视觉 token。
2. 多轮证据探测：借鉴 LensWalk / VITAL / SAGE，让模型先粗看，再根据问题缺失证据主动补看局部帧或高分辨率 crop。
3. 最小充分证据集：借鉴 Select Less / HERBench / CaST-Bench，把每个答案绑定到最少但足够的广告证据集合。
4. 证据许可知识注入：借鉴 Graph-to-Frame RAG / Separation of Powers，让营销知识只能解释已观察证据。
5. 广告证据失败诊断：借鉴 VidHalluc / When Thinking Drifts，对答案错误拆成看漏、看错、推理漂移、知识越权四类。

### 本轮最值得迁移的两个机制

1. **不确定性感知的响应场融合。** 对每个模态通过时间偏移、图像扰动或 OCR 置信度获得响应均值和方差，按局部不确定性而不是固定权重融合。这可以替换第一创新点中较弱的规则门控，并把声画错位、OCR 可靠性和多峰响应统一到一个概率证据场。
2. **反事实证据充分性学习。** 对完整证据执行关键帧删除、OCR 模糊、ASR 置换等最小破坏，训练模型区分“相关证据”和“足以回答的证据”。第二创新点可以只保留这个学习目标，低充分性时的一次补看只是应用，不再强调 Agent 编排。
