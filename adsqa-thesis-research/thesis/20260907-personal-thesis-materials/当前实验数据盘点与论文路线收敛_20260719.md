## 2. 可以进入论文主结果的现有实验

### 2.1 Evidence-300：Qwen3-VL-8B，固定32视图/11,664 Token

| 方法 | Strict | Relaxed | 证据召回代理 | 提交视图证据精度代理 |
|---|---:|---:|---:|---:|
| Raw Uniform32 | 64.00% | 76.17% | 100.00% | 75.05% |
| MMR32 | 63.33% | 75.17% | 100.00% | 78.23% |
| CLIP Single-Peak | 57.00% | 69.50% | 99.17% | 78.46% |
| AdSlot Fixed | 58.00% | 70.83% | 99.72% | 78.25% |
| VideoITG-32 | 65.33% | 76.33% | 100.00% | 78.42% |

结论：所有选择方法都能改变证据分布，但只有 VideoITG 的 QA 点估计略高于 Raw，Relaxed 仅 `+0.17 pp`，95% CI `[-3.33,+3.00]`。AdSlot 相对 Raw 的 Relaxed 低 `5.33 pp`，其证据代理精度却更高。这是“证据定位与生成式 QA 非单调”的最强现有证据。

### 2.2 Evidence-300：干净 Qwen2.5-VL-7B，固定32视图/16,384 Token

| 方法 | Strict | Relaxed | 相对 Raw |
|---|---:|---:|---:|
| Raw Uniform32 | 48.33% | 61.83% | 基线 |
| AdSlot Fixed | 42.67% | 58.67% | `-5.67/-3.17 pp` |

Raw−AdSlot 的配对 Relaxed 差值为 `+3.17 pp`，95% CI `[-0.67,+7.00]`。Qwen2.5 与 Qwen3 上方向一致，因此不能再把负结果解释为“Qwen3 太强”。

### 2.3 Confirm-300C：冻结轻量时间选择器

## 4. 创新点二现有实验

| 路线 | 结果 | 当前判断 |
|---|---|---|
| 普通反思 | Relaxed `56.5→57.0`，CI跨0 | 几乎无效，不作为创新点 |
| 结构化证据精读 | `56.5→56.0` | 没有提高 QA |
| 保守改写 | 100/100 全部保持原答案 | 没有形成纠错能力 |
| 条件似然反事实补看 | Raw `58→55`；MMR `55.5→54` | 反事实敏感不等于答案应被修改 |

| 分数融合内部留出 | AUROC `0.9229` | 仅训练诊断，未在真实分布泛化 |
| LLM-assisted Development | verifier AUROC `0.6404`，视觉基线 `0.6655` | 没有超过冻结视觉 Qwen |
| Stage-2 A/B | 严格方向 `0/20`、`8/20` | 反事实没有真正移除重复广告事实 |
| Stage-2 C/D 正式 | C `14/20`但由ASR主导；D `15/20`，OCR `5/10` | 不能训练稳定跨模态验证器 |

结论：创新点二的失败不是“模型还不够复杂”，而是目标定义和监督不足。证据存在、模型敏感、答案正确是三个不同变量；当前弱监督无法可靠学习何时改答案。

## 5. 当前实验体系的主要问题

1. **评测口径混杂。** `full_response`、`answer_only`、旧自有裁判和论文官方口径并存，跨表绝对数字不能直接比较。
2. **视觉预算混杂。** Qwen3 主表为11,664 Token，Qwen2.5 表为16,384 Token，当前40视图实验为20,480 Token；只能在各自同协议内配对。
3. **证据标签不够强。** Evidence-300 的大规模时间区间是 AI 复核代理，没有 bbox 金标；可靠区域标注只有10个框。
4. **创新点一版本过多。** V1/V2、16+16、24+8、MMR、Coverage、AdSlot、CLIPCrop 等名字分散了论文主线。
5. **创新点二缺少独立监督。** 合成反事实和机器标签可以用于开发，不能证明真实证据充分性或答案纠错。
6. **曾把定位指标和 QA 指标当成同一目标。** 现有结果已反复证明二者不单调，需要在论文中明确分开。

## 6. 建议收敛后的论文主线

建议题目暂定为：

> **固定视觉 Token 预算下的广告视频多模态证据定位与充分性分析**

### 创新点一：固定预算的问题条件化局部视觉证据增强与上下文保持分配

统一技术对象，不再并列多个选择器：

```text
固定全局上下文锚点
→ 问题条件化视觉相关性定位
→ 固定局部证据槽位替换部分全局帧
→ 时间覆盖与冗余保护
→ ASR/OCR作为可审计辅助响应与消融
→ 实际视图、Token、源帧和二次采样审计
```

这个名称比“概率不确定性场”更符合当前实现。当前方法具有可靠性和激活门控，但没有训练出严格的概率不确定性估计，因此暂不在标题中使用“概率不确定性感知”。

创新点一可主张：在固定视觉Token预算下，用问题条件化局部视觉证据替换部分均匀全局视图，同时保留全局上下文，并提供实际视图、Token、源帧和二次采样的完整审计。GroupCV-500上观察到 Strict `+7.2 pp`、Relaxed `+3.8 pp`，但FreshQ-500上转为 Strict `-1.6 pp`、Relaxed `-1.2 pp`，确认门禁失败。因此不能声称稳定泛化的QA精度提升，也不能声称ASR/OCR激活带来额外收益；主贡献应放在证据分配方法、定位改善、预算审计及定位—QA非单调关系。

### 创新点二：答案条件化的模态证据充分性校准

不再做普通反思或自由答案改写。若能获得独立可靠标签，只保留一条路线：

```text
冻结初答
→ 拆分原子命题
→ 标注命题对应的时间段 / OCR框 / ASR span
→ 构造经过外部复验的 E+ / E-
→ 计算答案命题 token 的似然差
→ 按模态校准风险
→ 接受原答案 / 保留原答案 / 拒答
```

它的主要指标应是证据充分性 AUROC、ECE/Brier、risk-coverage 和反事实方向，不强制要求自动改写提高总体 QA。只有校准后的保守决策确实满足 harm 约束，才把 QA 改善写入贡献。

如果无法获得可靠双审标签，创新点二应降级为“答案—证据依赖的反事实评测框架与系统性分析”，不要再训练新验证器。硕士论文采用“一个主算法 + 一个评测/分析方法”比两个弱算法更稳。

## 7. 冻结实验决策结果

GroupCV冻结结果曾命中原决策树第2项：AV与CLIP无可确认差异，但CLIP优于Raw40；FreshQ-500随后未复现该收益并触发确认失败。故执行停止规则：不再扫门控阈值、裁剪数、预算比例或模态权重。创新点一完整算法以问题条件化局部证据分配和可审计预算为主，ASR/OCR响应作为辅助分析，不承担稳定准确率主张。

## 8. 下一步执行顺序

1. 将GroupCV-500正结果、FreshQ-500负确认和Evidence-300旧AdSlot负结果并列整理，明确区分内部信号、独立题目确认和跨设计诊断。
2. 冻结创新点一现有配置，不再进行精度参数搜索；先完成181条gain/harm机制复核，再决定是否提出一个单一修复候选。
3. 创新点二先解决标签：完成Candidate F独立双审，或明确降级为答案—证据依赖评测框架；在此之前不运行GPU训练。
4. 创新点二口径冻结后，再决定是否把完全冻结的创新点一接入一个外部数据集验证泛化。

当前新增执行状态：FreshQ-500 v2的Raw40与CLIPCrop40均完成500/500，正式协议、DeepSeek裁判和10,000次视频聚类Bootstrap全部完成；确认门禁未通过。该集合只能验证题目级复现性；真正视频级泛化仍必须使用外部数据集。

## 9. 当前禁止事项

- 不在 GroupCV-500 的中途输出上调75%分位阈值；
- 不扫描32+8、24+16或其他视觉预算；
- 不叠加普通思维链、RAG、多 Agent 或答案自由改写；
- 不把机器初标写成人工金标准；
- 不把 Evidence-300 的 AI 时间代理写成 bbox 金标；
- 不把 ReAd-R、Qwen3 和 Qwen2.5 的不同协议数字放进同一公平领先表；
- 不因为单个点估计为正就扩大到 balanced-3000。
