# 第5章 实验设计与结果分析

> 论文题目：基于视觉特征压缩与链式反思的广告视频问答方法  
> 本章定位：围绕第 3 章“视觉特征压缩与证据定位”和第 4 章“知识增强链式反思推理”设计实验，证明本文方法不是简单模块拼接，而是围绕广告视频问答证据流形成的闭环框架。

---

## 5.1 本章引言

前两章分别提出了面向广告视频问答的视觉特征压缩方法和知识增强链式反思推理方法。第 3 章重点解决“模型应该看哪里、如何保留关键视觉证据”的问题，通过高频过采样、语义关键帧优选、视听-文字时空响应图、响应密度锚定和全局—局部双流视觉输入构建多模态证据包；第 4 章重点解决“这些证据如何解释、答案是否被证据支撑”的问题，通过证据驱动广告知识检索、结构化推理、声明拆解和证据回溯式链式反思生成可靠答案。

本章实验围绕上述方法主线展开，目标是从有效性、效率、鲁棒性和可靠性四个方面回答以下问题：

1. 本文方法相较于现有多模态视频问答模型是否能够提升广告视频问答整体性能？
2. 视听-文字协同证据定位是否能够提升关键帧、局部文字、Logo 和产品细节等证据的捕获能力？
3. 基于响应密度的全局—局部双流视觉输入是否能够在保留细粒度证据的同时控制视觉冗余？
4. 时序滑动窗口是否能够缓解广告视频中常见的声画异步问题？
5. 证据驱动的广告知识检索是否优于普通 RAG 或随机知识注入？
6. 证据回溯式链式反思是否能够降低事实性幻觉、文字误读和营销策略误归因？
7. 本文方法在视觉 Token、输入 Token、推理时延和显存占用方面是否具备实际效率收益？

## 5.2 数据集与任务划分

### 5.2.1 AdsQA 数据集

本文以 AdsQA 广告视频问答数据集作为主要实验数据集。AdsQA 面向广告视频理解任务，包含不同品类、不同场景和不同营销表达方式的广告视频及其对应问答样本。与通用视频问答数据集相比，AdsQA 的问题不仅关注视觉对象和动作识别，还关注广告主题、情绪表达、营销策略和目标受众等高层语义。

根据任务语义，本文将 AdsQA 测试样本划分为五类：

| 任务类别 | 说明 | 典型问题 |
|---|---|---|
| 视觉感知 | 识别画面中的对象、人物、场景、Logo 或文字 | “画面中出现了什么产品？” |
| 情感分析 | 判断广告的情绪氛围、情感诉求和受众感受 | “广告传达了怎样的情绪？” |
| 主题提取 | 概括广告主题、核心信息或产品卖点 | “该广告主要表达什么主题？” |
| 营销策略 | 分析广告使用的说服策略、创意手法或转化机制 | “这个广告如何制造紧迫感？” |
| 受众分析 | 判断广告可能面向的人群或使用场景 | “该广告主要面向哪类用户？” |

### 5.2.2 专项子集构建

为了验证本文方法对广告视频关键难点的针对性，除整体测试集外，本文进一步构建以下专项子集：

| 子集名称 | 构建依据 | 用途 |
|---|---|---|
| 声画对齐子集 | 旁白和画面语义基本同步 | 作为声画异步实验对照 |
| 语音领先子集 | 旁白先出现，相关画面后出现 | 验证时序窗口能否捕获后续画面 |
| 语音滞后子集 | 画面先出现，旁白后解释 | 验证时序窗口能否捕获延后语音 |
| 语音无关子集 | 背景音乐或旁白与画面关系弱 | 验证语音噪声抑制能力 |
| OCR/Logo 子集 | 问题依赖字幕、Logo、价格或品牌标识 | 验证局部高分辨率证据价值 |
| 营销策略子集 | 问题涉及稀缺效应、社会认同、情绪共鸣等概念 | 验证广告知识检索效果 |
| 高风险幻觉子集 | 问题涉及文字细节、语音引用、因果解释或功效判断 | 验证链式反思校验效果 |

这些子集可通过人工标注或规则初筛后人工复核获得。若样本规模有限，可从 AdsQA 测试集中抽取代表性样本进行分析。

## 5.3 评价指标

### 5.3.1 问答准确性指标

本文采用严格准确率作为主要评价指标。对于每个样本，若模型生成答案与标准答案语义一致，且不包含与视频事实冲突的信息，则判定为正确，否则判定为错误。准确率定义为：

```text
Accuracy = 正确样本数 / 总样本数
```

对于生成式答案，可辅以人工评分或大模型裁判评分，但需要在抽样子集上验证裁判与人工标注的一致性。

### 5.3.2 证据一致性指标

证据一致性衡量答案中的核心声明是否能够被视频证据支撑。设模型答案拆分为 `R` 条声明，其中有 `R_s` 条声明能够被关键帧、局部视图、ASR、OCR 或知识条目支撑，则：

```text
Evidence Consistency = R_s / R
```

该指标用于评估答案是否存在无依据解释或事实性幻觉。

### 5.3.3 知识一致性指标

知识一致性衡量模型是否正确使用广告营销概念。若答案中使用的营销策略与视频证据和知识库定义一致，则记为正确；若将普通促销误判为复杂策略，或将无关知识强行套入答案，则记为错误。

```text
Knowledge Consistency = 正确使用营销概念的样本数 / 涉及营销知识的样本数
```

### 5.3.4 幻觉率

幻觉率衡量答案中出现视频证据不支持内容的比例。本文重点关注以下幻觉类型：

- 虚构未出现的品牌、价格或功效；
- 错误引用旁白或字幕；
- 错误识别 Logo 或产品；
- 无依据套用营销策略；
- 将广告暗示解释为确定性事实。

定义为：

```text
Hallucination Rate = 出现幻觉的样本数 / 总样本数
```

### 5.3.5 效率指标

为验证视觉特征压缩的实际价值，本文报告以下效率指标：

| 指标 | 含义 |
|---|---|
| 平均候选帧数 | 高频过采样得到的帧数 |
| 平均关键帧数 | 语义优选后输入模型的帧数 |
| 平均视觉 Token 数 | 图像/视频视觉输入产生的 Token 数 |
| 平均文本 Token 数 | 问题、ASR、OCR、知识、Prompt 等文本 Token 数 |
| 总输入 Token 数 | 视觉 Token 与文本 Token 总和 |
| 平均推理时延 | 单样本端到端推理耗时 |
| RAG 检索耗时 | 知识检索与重排序耗时 |
| 链式反思耗时 | 反思校验额外耗时 |
| 峰值显存占用 | 单样本推理过程中的峰值 GPU 显存 |

## 5.4 实验设置与对比方法

### 5.4.1 基础模型

本文以多模态大语言模型作为基础推理模型。根据现有实验材料，阶段性实验采用 Qwen3-VL 作为核心推理模型，并使用 CLIP 或视觉—语言预训练模型进行关键帧筛选和响应图构建。后续实验可根据硬件条件选择 Qwen2-VL、Qwen2.5-VL、Qwen3-VL、MiniCPM-V、LLaVA-OV 等模型进行对比。

### 5.4.2 对比方法

对比方法包括：

| 方法 | 说明 |
|---|---|
| Qwen3-Base | 不使用本文方法的基座模型 |
| Qwen2.5-ReAd | 面向广告视频理解的相关基线 |
| Qwen2.5-VL | 通用多模态视觉语言模型 |
| MiniCPM-V | 轻量多模态模型 |
| Qwen2-VL | 通用多模态基线 |
| LLaVA-OV | 开源多模态模型 |
| Uniform Sampling + MLLM | 均匀采样后直接输入模型 |
| CLIP Top-K + MLLM | 使用 CLIP 语义筛帧后输入模型 |
| ASR Prompt + MLLM | 直接将 ASR 拼接到 Prompt |
| CoT-only | 仅使用结构化思维链 |
| RAG-only | 仅加入广告知识检索 |
| Reflection-only | 仅加入反思校验 |
| Ours | 完整方法 |

### 5.4.3 实现细节

建议在最终论文中明确以下设置：

- 过采样帧数：如 32 帧；
- 关键帧数量 K：如 8/16；
- 时序窗口半径 r：如 1s/2s/4s；
- 锚框尺度集合：如 0.4/0.6/0.8/1.0；
- RAG Top-K：如 3/5；
- 知识检索阈值：如 0.05；
- 链式反思触发条件：关键词触发或证据风险触发；
- 推理硬件：GPU 型号、显存、运行环境；
- 自动裁判模型和裁判 Prompt。

## 5.5 主实验结果

### 5.5.1 总体结果表

根据已有阶段性结果，可得到如下主实验表。后续若重新运行实验，应以最终实验结果为准。

| 类别 | Ours | Qwen3-Base | Qwen2.5-ReAd | Qwen2.5-VL | MiniCPM-V | Qwen2-VL | LLaVA-OV |
|---|---:|---:|---:|---:|---:|---:|---:|
| 视觉感知 | 0.362 | 0.362 | 0.315 | 0.265 | 0.212 | 0.185 | 0.144 |
| 情感分析 | 0.459 | 0.396 | 0.393 | 0.324 | 0.265 | 0.214 | 0.157 |
| 主题提取 | 0.455 | 0.412 | 0.365 | 0.308 | 0.252 | 0.225 | 0.165 |
| 营销策略 | 0.398 | 0.354 | 0.322 | 0.259 | 0.212 | 0.197 | 0.132 |
| 受众分析 | 0.384 | 0.369 | 0.325 | 0.276 | 0.234 | 0.210 | 0.133 |
| 整体平均 | 0.416 | 0.379 | 0.345 | 0.286 | 0.233 | 0.210 | 0.149 |

### 5.5.2 主实验分析模板

从总体结果可以看出，本文方法在 AdsQA 数据集上的整体准确率达到 0.416，高于 Qwen3-Base 的 0.379，提升 0.037，即 3.7 个百分点，相对提升约 9.8%；相比 Qwen2.5-ReAd 的 0.345，提升 0.071，即 7.1 个百分点，相对提升约 20.6%。这说明仅依赖通用多模态大模型或简单广告增强方法，仍难以充分处理广告视频中高信息密度、声画异步和营销语义隐含等问题。

从分任务结果看，本文方法在情感分析、主题提取、营销策略和受众分析任务上提升更明显，而在视觉感知任务上与 Qwen3-Base 持平。这一现象说明本文方法的主要收益并不完全来自基础视觉识别能力的提升，而更多来自对多模态证据的组织、广告知识解释和答案可靠性控制。对于视觉感知类问题，基座模型已经具备较强的对象和场景识别能力，因此提升空间相对有限；而对于营销策略和受众分析等高阶语义任务，本文的证据驱动知识推理和链式反思机制能够发挥更大作用。

## 5.6 视觉证据定位与压缩消融实验

### 5.6.1 实验目的

本实验用于验证第 3 章各模块对问答性能和效率的贡献。重点考察：

- 语义关键帧优选是否优于均匀采样；
- 问题响应图、ASR 响应图和 OCR/Logo 响应图是否分别有效；
- 时序滑动窗口是否有助于处理声画异步；
- 响应密度局部锚定是否提升细粒度证据捕获；

## 5.10 广告知识增强 RAG 消融实验

## 5.16 本章小结

本章围绕本文提出的广告视频问答方法设计了系统实验方案。主实验用于验证本文方法相较于多模态基线模型的整体性能；视觉证据定位与压缩消融实验用于验证第 3 章中关键帧优选、视听-文字响应图、局部锚定和全局—局部双流输入的贡献；声画异步实验和 OCR/Logo 细节实验用于验证方法对广告视频特有难点的适应能力；RAG 消融实验用于检验证据驱动广告知识检索是否真正提升营销语义理解；链式反思实验用于评估证据回溯式校验对幻觉抑制和错误修正的作用；效率与参数敏感性实验则用于分析方法在准确性、可靠性和推理成本之间的权衡。

通过上述实验，本文能够从“有效性—效率—鲁棒性—可靠性”四个层面论证所提出方法的合理性。尤其需要强调的是，本章实验不是对若干模块进行孤立评估，而是围绕“证据定位—证据压缩—证据解释—证据校验”的主线展开，旨在证明本文方法并非简单拼接 RAG、CoT 和反思机制，而是面向广告视频问答构建的一套证据流闭环框架。
