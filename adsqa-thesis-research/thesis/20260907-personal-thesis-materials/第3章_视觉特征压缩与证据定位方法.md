# 第3章 基于视觉特征压缩的广告视频证据定位方法

> 论文题目：基于视觉特征压缩与链式反思的广告视频问答方法  
> 本章定位：围绕“视觉特征压缩”展开，但将压缩定义为**证据保留型视觉输入重构**，核心目标是在降低广告视频冗余视觉输入的同时保留与问题回答相关的关键证据。

---

## 3.1 本章引言

广告视频是一类高度压缩的多模态传播内容，通常在较短时长内通过画面、字幕、品牌标识、产品包装、人物动作、旁白、音乐和场景切换共同传达产品卖点和营销意图。与普通生活视频或影视片段相比，广告视频具有三方面显著特点：第一，视觉信息密度高，Logo、价格、字幕和促销条款等关键线索可能只在局部区域短暂出现；第二，画面与旁白并不总是严格同步，广告常通过画外音提前铺垫或延后解释画面内容；第三，许多问题需要从局部视觉证据上升到广告意图和营销策略理解，单纯依赖全局视觉表征容易产生表层化回答。

现有多模态视频问答方法通常采用均匀采样、全局缩放或直接拼接 ASR 文本的方式处理视频。均匀采样虽然实现简单，但在广告视频中容易遗漏短时出现的关键帧；全局缩放虽然保留整体场景，但会模糊局部文字、Logo 和产品细节；直接拼接 ASR 文本虽然补充了语音信息，却无法说明语音内容对应哪一帧、哪一个局部区域，因而难以解决声画异步带来的跨模态错配问题。

针对上述问题，本章提出一种基于视觉特征压缩的广告视频证据定位方法。需要说明的是，本文中的“视觉特征压缩”并非单纯追求输入帧数或视觉 Token 数的最小化，而是强调在有限视觉输入预算下保留对问答最有价值的证据。具体而言，本章方法首先通过高频过采样与语义关键帧优选降低短时关键线索遗漏风险；随后构建由用户问题、ASR 语音文本和 OCR/Logo 文字显著性共同驱动的视听-文字时空响应图，用于定位问题相关的视觉区域；最后基于响应密度自适应选择局部高分辨率证据区域，并与全局视图共同构成证据保留型全局—局部双流视觉输入。

本章输出的并不是简单的裁剪图像，而是可被后续知识推理与链式反思共同使用的多模态证据包。该证据包包含关键帧编号、时间戳、局部裁剪坐标、全局视图、局部视图、ASR 片段、OCR 文本、视觉标签和响应分数等信息，为第 4 章中的广告知识检索和答案证据回溯校验提供基础。

## 3.2 问题定义与总体框架

### 3.2.1 任务输入与输出

设广告视频为：

```text
V = {I_1, I_2, ..., I_T}
```

其中，`I_t` 表示视频在时间步 `t` 的视觉帧，`T` 表示视频总帧数。用户输入的自然语言问题记为：

```text
q = {w_1, w_2, ..., w_N}
```

视频中的语音经 ASR 模型转写后得到带时间戳的语音片段序列：

```text
A = {(a_1, τ_1^s, τ_1^e), (a_2, τ_2^s, τ_2^e), ..., (a_M, τ_M^s, τ_M^e)}
```

其中，`a_i` 表示第 `i` 个语音片段文本，`τ_i^s` 和 `τ_i^e` 分别表示该片段的开始和结束时间。视频帧中的文字、Logo 或品牌相关线索经 OCR 或视觉文字检测得到：

```text
O = {(o_1, b_1, c_1), (o_2, b_2, c_2), ..., (o_L, b_L, c_L)}
```

其中，`o_l` 表示识别出的文字或 Logo 线索，`b_l` 表示其空间位置，`c_l` 表示识别置信度。

本章的目标是从原始广告视频 `V` 中构建与问题 `q` 相关的证据包：

```text
E = {E_1, E_2, ..., E_K}
```

每个证据单元 `E_k` 包含全局视图、局部视图、时间戳、裁剪坐标、关联 ASR 片段、OCR 文本和响应分数等信息。后续问答模型不再直接处理完整视频，而是基于证据包完成广告知识检索、结构化推理和链式反思校验。

### 3.2.2 总体流程

本章方法包括四个主要阶段：

1. **多模态预处理与语义关键帧优选**：对广告视频进行高频过采样，并利用用户问题和 ASR 语义筛选 Top-K 关键帧；
2. **视听-文字时空响应图构建**：分别计算视觉特征对用户问题、邻域 ASR 语义和 OCR/Logo 文字显著性的响应；
3. **基于响应密度的局部证据锚定**：根据综合响应图计算语义重心，生成多尺度候选锚框，并选择响应密度最高的局部区域；
4. **全局—局部双流视觉输入与证据包构建**：保留全局视图和局部高分辨率视图，并记录时间戳、坐标和模态来源信息。

流程可概括为：

```text
广告视频 + 问题
        ↓
高频过采样 + 语义关键帧优选
        ↓
问题响应图 + ASR 邻域响应图 + OCR/Logo 响应图
        ↓
视听-文字时空响应图
        ↓
响应密度锚定局部证据
        ↓
全局视图 + 局部视图 + 多模态证据包
```

## 3.3 多模态预处理与语义关键帧优选

### 3.3.1 ASR 语音转写与清洗

广告视频中的旁白、口播和人物对白常常直接承载产品卖点、促销信息和情感诉求。例如，“仅剩最后一天”“官方认证”“第二件半价”等语音内容对回答营销策略、优惠信息和广告意图类问题具有重要作用。因此，本文首先对视频音频轨道进行自动语音识别，得到带时间戳的 ASR 片段序列。

ASR 清洗包括：

- 去除空白片段和无语义停顿词；
- 合并时间上连续且语义相关的短片段；
- 保留语音片段的开始和结束时间；
- 对重复口播或背景歌词进行基础过滤；
- 标记 ASR 置信度较低的片段，供后续链式反思校验使用。

清洗后的 ASR 片段不仅作为文本上下文输入模型，更重要的是作为视觉证据定位的语义引导信号。

### 3.3.2 高频过采样

广告视频的关键视觉线索可能只持续极短时间。例如，产品包装上的小字、屏幕角落的 Logo、价格信息或促销条款可能在一两个镜头中快速出现。如果采用低频均匀采样，关键帧可能被遗漏。为降低这一风险，本文先对视频进行高频过采样，得到候选帧集合：

```text
F = {f_1, f_2, ..., f_S}
```

其中，`S` 表示过采样后得到的候选帧数量。高频过采样的目的不是直接将所有候选帧输入模型，而是为后续语义筛选提供更完整的候选空间。

### 3.3.3 语义关键帧优选

在获得候选帧集合后，本文利用视觉—语言预训练模型分别编码候选帧、用户问题和 ASR 文本。设候选帧 `f_s` 的视觉表示为 `v_s`，用户问题表示为 `u_q`，全局 ASR 表示为 `u_a`，则候选帧相关性得分可表示为：

```text
Score_frame(f_s) = λ_q · sim(v_s, u_q) + λ_a · sim(v_s, u_a) + λ_o · OCRBonus(f_s)
```

其中，`sim(·)` 表示跨模态相似度函数，`OCRBonus(f_s)` 表示该帧是否包含文字、Logo 或品牌相关线索的加分项，`λ_q`、`λ_a` 和 `λ_o` 分别表示问题、语音和文字线索的权重。

根据 `Score_frame` 从高到低选取 Top-K 帧作为关键帧序列：

```text
F_K = TopK({Score_frame(f_s) | f_s ∈ F})
```

该策略体现了“先密集保留、再语义筛选”的思想：过采样降低关键信息遗漏风险，语义筛选控制后续处理成本。

## 3.4 视听-文字时空响应图构建

### 3.4.1 响应图的基本思想

关键帧筛选解决的是“选择哪些帧”的问题，但广告视频问答还需要进一步判断“帧中的哪些区域与问题相关”。例如，当用户询问“画面中的优惠信息是什么”时，模型应关注字幕和价格区域；当用户询问“该广告如何体现快速配送”时，模型可能需要关注骑手动作、包裹、交通工具以及旁白中关于速度的描述。

因此，本文在关键帧内部构建视听-文字时空响应图。该响应图融合三类信号：

1. **问题响应**：视觉区域与用户问题之间的语义相关性；
2. **ASR 响应**：视觉区域与邻域语音语义之间的相关性；
3. **OCR/Logo 响应**：视觉区域中文字、Logo、品牌标识或促销信息的显著性。

### 3.4.2 问题—视觉响应图

设关键帧 `f_t` 的空间视觉特征图为：

```text
X_t ∈ R^{H × W × d}
```

其中，`H` 和 `W` 为空间尺寸，`d` 为特征维度。位置 `(i,j)` 处的视觉特征为 `x_{t,i,j}`。将视觉特征和问题向量映射到公共语义空间：

```text
\tilde{x}_{t,i,j} = W_v x_{t,i,j}
\tilde{q} = W_q u_q
```

则问题—视觉响应图可定义为：

```text
H_Q(t,i,j) = softmax_{i,j}( <\tilde{x}_{t,i,j}, \tilde{q}> / sqrt(d) )
```

该响应图用于衡量当前帧中不同区域对用户问题的语义响应强度。

### 3.4.3 ASR 邻域响应图

广告视频中旁白与画面经常存在时间错位。若仅使用当前帧时间戳对应的 ASR 片段，可能遗漏与当前画面相关但略早或略晚出现的语音内容。为此，本文为每个关键帧构建以其时间戳 `t` 为中心的语音邻域窗口：

```text
Ω(t) = {a_m | |center(a_m) - t| ≤ r}
```

其中，`r` 为窗口半径，`center(a_m)` 表示语音片段中心时间。对窗口内语音片段按照时间距离赋予权重：

```text
g(t,m) = exp( - (center(a_m) - t)^2 / (2σ^2) )
```

窗口聚合后的语音表示为：

```text
u_A(t) = Σ_{a_m ∈ Ω(t)} g(t,m) · Enc(a_m) / Σ_{a_m ∈ Ω(t)} g(t,m)
```

进一步计算 ASR—视觉响应图：

```text
H_A(t,i,j) = softmax_{i,j}( <W_v x_{t,i,j}, W_a u_A(t)> / sqrt(d) )
```

该设计使语音不再只是全局文本上下文，而是用于引导当前帧的视觉区域定位。

### 3.4.4 OCR/Logo 文字响应图

广告视频中的屏幕文字和品牌标识对问答具有重要价值。本文通过 OCR 结果、Logo 检测结果或预设文字显著性关键词构建文字响应图。设文字线索集合为：

```text
C = {text, logo, brand, price, discount, slogan, number}
```

将每个文字线索编码为语义向量，并与视觉空间特征计算响应。OCR/Logo 响应可表示为：

```text
H_O(t,i,j) = max_{c ∈ C} softmax_{i,j}( <W_v x_{t,i,j}, W_c Enc(c)> / τ )
```

其中，`τ` 为温度系数，用于调节文字响应图的分布锐度。若已存在 OCR 检测框，则可将 OCR 框区域的响应分数提高，以增强文本细节区域的显著性。

### 3.4.5 综合视听-文字时空响应图

最终综合响应图由三类响应融合得到：

```text
H(t,i,j) = α · H_Q(t,i,j) + β · H_A(t,i,j) + γ · H_O(t,i,j)
```

其中，`α`、`β` 和 `γ` 分别表示问题、语音和文字响应的权重。对于不同类型问题，权重可进行任务自适应调整。例如，价格、字幕和 Logo 类问题可提高 `γ`；旁白内容类问题可提高 `β`；普通视觉识别类问题可提高 `α`。

综合响应图 `H(t)` 表示当前关键帧中与用户问题最相关的视觉证据分布，是后续局部锚定和视觉特征压缩的基础。

## 3.5 基于响应密度的局部证据锚定

### 3.5.1 语义重心定位

得到综合响应图后，本文首先计算其空间语义重心：

```text
c_x = Σ_i Σ_j j · H(t,i,j) / Σ_i Σ_j H(t,i,j)
c_y = Σ_i Σ_j i · H(t,i,j) / Σ_i Σ_j H(t,i,j)
```

其中，`(c_x, c_y)` 表示响应图能量分布的中心位置。该位置可被视为当前帧中与问题最相关的视觉区域中心。

### 3.5.2 多尺度候选锚框生成

广告视频中的关键证据大小差异较大：Logo 或价格可能很小，人物动作或场景线索则可能覆盖较大区域。因此，本文围绕语义重心生成多尺度候选锚框。设尺度集合为：

```text
S = {s_1, s_2, ..., s_n}
```

例如可取 `{0.4, 0.6, 0.8, 1.0}`。对于尺度 `s`，候选框宽高为：

```text
w_s = s · W_img
h_s = s · H_img
```

候选框坐标为：

```text
B_s = [c_x - w_s/2, c_y - h_s/2, c_x + w_s/2, c_y + h_s/2]
```

并通过边界截断函数确保候选框不超出图像范围。

### 3.5.3 归一化响应密度筛选

若直接选择响应能量总和最大的区域，大尺度候选框往往更占优势。为避免面积偏置，本文引入归一化响应密度：

```text
D(B_s) = Σ_{(i,j) ∈ B_s} H(t,i,j) / Area(B_s)^ρ
```

其中，`ρ` 为面积惩罚系数。当 `ρ=1` 时表示平均响应密度；当 `ρ<1` 时允许较大区域保留一定优势。最终选择响应密度最高的候选框：

```text
B* = argmax_{B_s} D(B_s)
```

`B*` 所对应的区域被裁剪并上采样为局部高分辨率证据视图。

### 3.5.4 多峰响应的扩展处理

在部分广告视频中，关键证据可能分散在多个区域，例如左侧人物动作和右下角价格信息同时重要。若仅使用单一语义重心，可能忽略次要但关键的证据区域。为此，本文可扩展采用局部峰值检测和非极大值抑制，选取多个候选局部区域：

```text
{B_1*, B_2*, ..., B_m*}
```

在实际实验中，可根据输入预算选择 Top-1 或 Top-m 局部区域。若模型输入预算有限，默认采用 Top-1 局部区域；若问题涉及文字、价格或多对象关系，可采用 Top-m 证据区域。

## 3.6 全局—局部双流视觉输入构建

### 3.6.1 全局视图

全局视图由原始关键帧缩放得到，用于保留广告的整体场景信息，包括人物关系、场景类型、情绪氛围、构图和动作上下文。全局视图记为：

```text
G_t = Resize(f_t)
```

全局视图适合回答场景意图、情绪氛围和整体主题类问题，但对小文字、Logo 和价格信息的保留能力有限。

### 3.6.2 局部视图

局部视图由最佳锚框 `B*` 裁剪并上采样得到：

```text
L_t = Upsample(Crop(f_t, B*))
```

局部视图用于保留高分辨率细节，例如产品包装、促销字幕、品牌标识、价格数字和小尺寸图标。局部视图的作用不是替代全局视图，而是补充全局缩放后可能丢失的细粒度证据。

### 3.6.3 双流输入

最终视觉输入由全局视图和局部视图组成：

```text
Z_t = [G_t ; L_t]
```

其中，`;` 表示在输入序列维度或图像组维度上的拼接。对于每个关键帧，模型同时看到整体语境和局部证据，从而降低全局缩放造成的信息损失。

### 3.6.4 压缩率定义

为避免“视觉特征压缩”概念模糊，本文从三个层面定义压缩率。

**帧级压缩率：**

```text
CR_frame = 1 - K / S
```

其中，`S` 为过采样候选帧数量，`K` 为最终保留关键帧数量。

**空间输入压缩率：**

```text
CR_area = 1 - Area(B*) / Area(f_t)
```

该指标衡量局部证据区域相对于整帧图像的面积压缩程度。

**Token/计算压缩率：**

若模型可统计视觉 Token 数或输入 Token 数，则定义：

```text
CR_token = 1 - Token_compressed / Token_original
```

在实验中，应同时报告帧数、视觉 Token、总输入 Token、推理时延和显存占用，避免仅凭概念声称压缩有效。

## 3.7 多模态证据包构建

### 3.7.1 证据包的必要性

本章方法不仅要为问答模型提供压缩后的视觉输入，还要为后续的广告知识检索和链式反思校验提供可追溯证据。如果只输出全局图和局部图，后续模型虽然可以生成答案，但难以解释答案依据，也难以在反思阶段回查具体证据。因此，本文将每个关键帧的视觉、语音和文字信息组织为证据包。

### 3.7.2 证据包结构

每个证据包 `E_t` 可表示为：

```text
E_t = {
  frame_id: t,
  timestamp: τ_t,
  global_view: G_t,
  local_view: L_t,
  crop_bbox: B*,
  response_score: D(B*),
  question_response: H_Q,
  asr_response: H_A,
  ocr_response: H_O,
  asr_segment: Ω(t),
  ocr_text: O_t,
  visual_tags: Tags_t
}
```

其中，`Tags_t` 表示通过视觉识别或模型描述得到的视觉标签，如“商品展示”“倒计时”“人物微笑”“品牌 Logo”等。

### 3.7.3 证据包的后续用途

证据包将在第 4 章中发挥三方面作用：

1. **知识检索查询构建**：利用 ASR、OCR、视觉标签和用户问题构造广告知识检索查询；
2. **结构化推理证据引用**：在“观察—知识匹配—分析—答案”过程中显式引用证据；
3. **链式反思回溯校验**：对答案中的视觉、文字、语音和营销推理声明进行逐项核查。

因此，证据包是连接视觉压缩、广告知识推理和链式反思的核心桥梁。

## 3.8 算法描述

### 算法 3-1：视听-文字协同证据定位与视觉压缩

```text
输入：广告视频 V，用户问题 q，关键帧数量 K，窗口半径 r，尺度集合 S
输出：证据包集合 E

1. 使用 ASR 对视频音频进行转写，得到语音片段序列 A；
2. 使用 OCR/Logo 检测提取画面文字与品牌线索 O；
3. 对视频进行高频过采样，得到候选帧集合 F；
4. 对每个候选帧 f_s：
   4.1 编码帧视觉特征 v_s、问题语义 u_q 和 ASR 语义 u_a；
   4.2 计算帧级相关性 Score_frame(f_s)；
5. 选取得分最高的 Top-K 帧，得到关键帧集合 F_K；
6. 对每个关键帧 f_t：
   6.1 提取空间视觉特征图 X_t；
   6.2 计算问题—视觉响应图 H_Q；
   6.3 根据时间窗口 Ω(t) 聚合邻域 ASR 表示，计算 ASR—视觉响应图 H_A；
   6.4 计算 OCR/Logo—视觉响应图 H_O；
   6.5 融合得到综合响应图 H；
   6.6 根据 H 计算语义重心；
   6.7 生成多尺度候选锚框；
   6.8 计算各候选框响应密度 D(B_s)；
   6.9 选择最佳锚框 B* 并裁剪局部视图 L_t；
   6.10 保留全局视图 G_t；
   6.11 构建证据包 E_t；
7. 返回证据包集合 E。
```

## 3.9 本章小结

本章围绕论文题目中的“视觉特征压缩”展开，提出了一种面向广告视频问答的证据保留型视觉压缩方法。该方法首先通过高频过采样与语义关键帧优选降低关键帧遗漏风险；随后利用用户问题、邻域 ASR 语义和 OCR/Logo 文字显著性构建视听-文字时空响应图；进一步基于响应密度自适应锚定局部高分辨率证据区域，并结合全局视图形成双流视觉输入；最后，将视觉、语音和文字信息组织为可追溯的多模态证据包。

与传统均匀采样或全局缩放方法相比，本章方法更强调对广告视频中关键证据的定位与保留，能够在降低冗余视觉输入的同时提升 Logo、字幕、价格和产品细节等细粒度信息的可见性。该证据包不仅作为问答模型的输入，也为后续广告知识检索和链式反思校验提供基础。下一章将在此基础上进一步研究如何利用证据包进行广告知识增强推理，并通过证据回溯式链式反思提升答案可靠性。
