# 基于视觉特征压缩与链式反思的广告视频问答方法

## 摘要

随着短视频平台、流媒体服务和数字营销产业的快速发展，广告视频已成为品牌传播和产品推广的重要内容形态。广告视频通常在较短时间内综合利用画面、旁白、字幕、音乐、品牌标识和场景变化传达产品卖点与营销意图，具有信息密度高、声画非严格同步、文字与 Logo 线索短时出现、语义表达隐含等特点。现有多模态大语言模型在通用视频问答任务中取得了较好效果，但在广告视频问答场景中仍面临关键视觉证据易丢失、视听语义难以对齐、广告领域知识不足以及生成答案缺乏证据约束等问题。

针对上述问题，本文提出一种基于视觉特征压缩与链式反思的广告视频问答方法。该方法围绕“证据定位—证据压缩—证据解释—证据校验”的主线展开。首先，针对广告视频中 Logo、字幕、价格和产品细节短时出现的问题，采用高频过采样与语义关键帧优选相结合的策略，减少关键帧遗漏风险；其次，构建由用户问题、ASR 语音文本和 OCR/Logo 文字显著性共同驱动的视听-文字时空响应图，并通过时序滑动窗口缓解广告旁白与画面之间的声画异步问题；在此基础上，基于响应密度自适应锚定局部高分辨率证据区域，同时保留全局视图以维持场景上下文，形成证据保留型全局—局部双流视觉输入。进一步地，本文构建广告营销知识库，将视觉、语音与文字证据转化为检索线索，获取与当前视频语境匹配的营销概念和策略解释，辅助模型完成从视觉感知到广告意图理解的推理。最后，设计证据回溯式链式反思机制，将初始答案中的核心声明回查至对应的视觉帧、局部区域、ASR 片段、OCR 文本和知识条目，从而降低无依据营销解释和事实性幻觉。

在 AdsQA 广告视频问答数据集上的阶段性实验表明，本文方法在整体准确率上优于多个多模态基线模型，并在情感分析、主题提取、营销策略和受众分析等高阶语义任务上取得更明显收益。进一步的消融实验将从视听-文字响应图、双流视觉压缩、广告知识检索和链式反思校验等方面验证各模块贡献，并通过压缩率、推理时延、幻觉率和证据一致性等指标评估方法的效率与可靠性。

**关键词：** 广告视频问答；视觉特征压缩；视听协同；证据定位；检索增强生成；链式反思；多模态大语言模型

# 第1章 绪论

## 1.1 研究背景

随着短视频平台、流媒体服务和数字营销产业的发展，广告视频已经成为品牌传播、产品推广和用户转化的重要载体。与一般视频相比，广告视频通常在较短时长内集中呈现商品、品牌、人物、场景、字幕、旁白、音乐和情绪节奏等多模态信息，并借助视觉隐喻、夸张对比、情绪共鸣和行动召唤等方式传达营销意图。广告视频问答任务要求模型根据给定视频和自然语言问题生成准确答案，不仅需要识别画面中出现的对象和动作，还需要理解广告背后的产品卖点、情绪诉求、说服策略和目标受众。

近年来，多模态大语言模型在图像问答、视频问答和开放式视觉理解任务中取得了显著进展。然而，面对广告视频这类高信息密度、强语义压缩和多模态非同步的内容，通用模型仍然容易出现关键证据遗漏、声画语义错配、营销知识不足和生成幻觉等问题。例如，广告中的 Logo、价格、字幕或促销条款可能只在局部区域短暂出现，低频均匀采样容易错过这些证据；旁白内容可能先于或滞后于相关画面出现，简单拼接 ASR 文本难以建立语音与视觉区域之间的对应关系；营销策略和受众判断又依赖广告学、消费者心理学等领域知识，通用模型容易停留在表层描述或无依据套用概念。

因此，广告视频问答需要一套围绕证据展开的多模态推理框架：首先从冗余视频输入中定位并保留关键视觉证据，再基于证据检索广告知识并进行结构化推理，最后对答案中的核心声明进行证据回溯式校验。本文即围绕“证据定位—证据压缩—证据解释—证据校验”的主线，研究基于视觉特征压缩与链式反思的广告视频问答方法。

## 1.2 研究意义

从理论意义上看，本文将广告视频问答中的“视觉特征压缩”重新定义为面向问题的证据保留型视觉输入重构，强调在有限上下文预算下保留与答案生成相关的关键视觉线索，而不是单纯减少帧数或图像 Token。通过引入用户问题、ASR 语音文本和 OCR/Logo 文字显著性共同构建视听-文字时空响应图，本文尝试解决广告视频中声画异步和局部细节易丢失的问题，为高信息密度视频理解中的证据定位提供一种新的研究思路。

从应用意义上看，广告视频问答可服务于广告创意分析、素材审核、投放效果评估、用户反馈理解和智能营销决策等场景。相比只输出表层视觉描述的模型，具备证据定位、广告知识解释和链式反思校验能力的问答系统能够提供更可靠、更可解释的分析结果，有助于提升广告内容理解和智能营销工具的实际可用性。

## 1.3 研究问题

本文围绕以下四个研究问题展开：

**RQ1：如何在高信息密度广告视频中定位与用户问题相关的关键视觉证据？** 广告视频中大量关键线索可能短暂出现在局部区域，本文通过高频过采样、语义关键帧优选、问题响应图、ASR 邻域响应图和 OCR/Logo 响应图定位关键证据。

**RQ2：如何在压缩视觉输入的同时保留全局语境和局部细节？** 本文基于响应密度选择局部高分辨率证据区域，同时保留全局视图，构建全局—局部双流视觉输入。

**RQ3：如何将广告营销知识用于解释视频证据，而不是引入无关幻觉？** 本文构建广告营销知识库，并基于视觉标签、ASR 文本、OCR 文本和用户问题进行证据驱动检索与重排序。

**RQ4：如何通过链式反思降低无依据回答和事实性幻觉？** 本文将初始答案拆分为视觉、文字、语音和营销推理声明，并回溯至多模态证据包进行校验。

# 第2章 相关理论与技术基础

## 2.1 广告视频问答与证据定位需求

视频问答任务要求模型根据给定视频和自然语言问题生成答案，是衡量多模态理解能力的重要任务。与图像问答相比，视频问答还需要理解跨帧事件、时序关系、语音信息和动态场景。广告视频问答进一步引入广告意图、情绪表达、受众定位和营销策略等高层语义，对模型的证据定位和推理能力提出了更高要求。

广告视频通常具有高信息密度和强语义压缩的特点。大量关键信息可能以字幕、Logo、价格、产品包装或旁白的形式短时出现，并且这些信息未必与画面严格同步。因此，广告视频问答的关键不仅是识别画面中有什么，还包括定位哪些视觉、语音和文字证据与当前问题相关。

## 2.2 多模态大语言模型与视频理解

多模态大语言模型通过视觉编码器、跨模态投影层和语言模型主体实现图像、视频、文本和语音信息的联合理解。该类模型具备较强的开放词汇识别、指令跟随和自然语言生成能力，能够完成视频描述、视觉问答、因果解释和开放式推理等任务。

然而，在广告视频问答场景中，通用多模态大语言模型仍存在不足。首先，视频帧输入带来大量视觉 Token，增加上下文和计算压力；其次，广告视频中的短时文字、Logo 和细节可能在全局缩放中丢失；再次，广告营销语义依赖领域知识，模型容易泛化解释或误用概念；最后，生成式答案可能缺少证据约束，产生多模态幻觉。

## 2.3 视觉特征压缩与视觉证据选择

视觉特征压缩旨在降低图像或视频输入的冗余度，常见方法包括均匀采样、关键帧选择、Token 剪枝、区域裁剪、特征聚合和问题引导的视觉选择。对于广告视频问答而言，压缩不能只追求输入规模最小，还需要保留 Logo、字幕、价格、产品细节和场景语境等关键证据。

本文将视觉特征压缩理解为证据保留型视觉输入重构：先通过过采样降低关键帧遗漏风险，再通过语义关键帧优选和局部响应图定位与问题相关的证据区域，最终通过全局—局部双流输入兼顾整体语境和局部细节。

## 2.4 视听协同融合与声画异步建模

广告视频通常同时包含画面、旁白、字幕、音效和音乐等多源信息。语音旁白常用于说明产品卖点、促销信息或品牌主张，视觉画面则提供商品、人物、场景和情绪线索。然而，在广告创作中，旁白与画面并不总是严格同步，可能存在语音领先、语音滞后或语音与画面弱相关的情况。

因此，简单将 ASR 文本拼接到 Prompt 中无法充分利用语音信息。本文采用时序滑动窗口聚合邻域 ASR 语义，将语音从被动上下文转化为主动视觉定位信号，从而构建更鲁棒的视听-文字时空响应图。

## 2.5 检索增强生成与广告知识推理

检索增强生成通过从外部知识库检索相关内容并注入生成模型上下文，能够缓解大模型在专业领域中的知识不足和事实幻觉问题。在广告视频问答中，问题经常涉及稀缺效应、社会认同、权威背书、情绪共鸣、视觉隐喻和目标受众画像等营销概念，因此需要广告领域知识辅助解释。

但普通 RAG 如果仅根据问题检索知识，可能引入与视频无关的概念，导致无依据营销解释。本文采用证据驱动的广告知识检索，将视觉标签、ASR 文本、OCR 文本和用户问题共同作为检索线索，并通过证据感知重排序降低知识误注入风险。

## 2.6 链式推理、反思机制与幻觉校验

链式推理通过显式组织中间推理过程，提高复杂问题回答的可解释性。自我反思或自我校验机制进一步要求模型检查初始答案，发现并修正错误。然而，普通反思方法容易停留在让模型重新生成答案，缺乏对原始多模态证据的回溯。

本文将链式反思定义为证据回溯式声明校验：首先将初始答案拆解为视觉声明、文字声明、语音声明和营销推理声明，再分别回查关键帧、局部视图、ASR 片段、OCR 文本和知识条目。该机制有助于降低 OCR 误读、ASR 错配、营销策略误归因和无依据推断。

## 2.7 本章小结

本章介绍了广告视频问答、多模态大语言模型、视觉特征压缩、视听协同融合、检索增强生成和链式反思相关理论。现有方法为广告视频问答提供了基础，但仍难以同时解决关键证据定位、声画异步、广告知识解释和答案证据校验问题。后续章节将在此基础上提出面向广告视频问答的证据流闭环方法。

# 第3章 基于视觉特征压缩的广告视频证据定位方法



## 3.1 本章引言

广告视频是一类高度压缩的多模态传播内容，通常在较短时长内通过画面、字幕、品牌标识、产品包装、人物动作、旁白、音乐和场景切换共同传达产品卖点和营销意图。与普通生活视频或影视片段相比，广告视频具有三方面显著特点：第一，视觉信息密度高，Logo、价格、字幕和促销条款等关键线索可能只在局部区域短暂出现；第二，画面与旁白并不总是严格同步，广告常通过画外音提前铺垫或延后解释画面内容；第三，许多问题需要从局部视觉证据上升到广告意图和营销策略理解，单纯依赖全局视觉表征容易产生表层化回答。

现有多模态视频问答方法通常采用均匀采样、全局缩放或直接拼接 ASR 文本的方式处理视频。均匀采样虽然实现简单，但在广告视频中容易遗漏短时出现的关键帧；全局缩放虽然保留整体场景，但会模糊局部文字、Logo 和产品细节；直接拼接 ASR 文本虽然补充了语音信息，却无法说明语音内容对应哪一帧、哪一个局部区域，因而难以解决声画异步带来的跨模态错配问题。

针对上述问题，本章提出一种基于视觉特征压缩的广告视频证据定位方法。需要说明的是，本文中的“视觉特征压缩”并非单纯追求输入帧数或视觉 Token 数的最小化，而是强调在有限视觉输入预算下保留对问答最有价值的证据。具体而言，本章方法首先通过高频过采样与语义关键帧优选降低短时关键线索遗漏风险；随后构建由用户问题、ASR 语音文本和 OCR/Logo 文字显著性共同驱动的视听-文字时空响应图，用于定位问题相关的视觉区域；最后基于响应密度自适应选择局部高分辨率证据区域，并与全局视图共同构成证据保留型全局—局部双流视觉输入。

本章输出的并不是简单的裁剪图像，而是可被后续知识推理与链式反思共同使用的多模态证据包。该证据包包含关键帧编号、时间戳、局部裁剪坐标、全局视图、局部视图、ASR 片段、OCR 文本、视觉标签和响应分数等信息，为第 4 章中的广告知识检索和答案证据回溯校验提供基础。


## 3.2 问题定义与总体框架

### 3.2.1 任务输入与输出

设广告视频为：

```text
V = {I_1, I_2, ..., I_T}
```

其中，`I_t` 表示视频在时间步 `t` 的视觉帧，`T` 表示视频总帧数。用户输入的自然语言问题记为：

```text
q = {w_1, w_2, ..., w_N}
```

视频中的语音经 ASR 模型转写后得到带时间戳的语音片段序列：

```text
A = {(a_1, τ_1^s, τ_1^e), (a_2, τ_2^s, τ_2^e), ..., (a_M, τ_M^s, τ_M^e)}
```

其中，`a_i` 表示第 `i` 个语音片段文本，`τ_i^s` 和 `τ_i^e` 分别表示该片段的开始和结束时间。视频帧中的文字、Logo 或品牌相关线索经 OCR 或视觉文字检测得到：

```text
O = {(o_1, b_1, c_1), (o_2, b_2, c_2), ..., (o_L, b_L, c_L)}
```

其中，`o_l` 表示识别出的文字或 Logo 线索，`b_l` 表示其空间位置，`c_l` 表示识别置信度。

本章的目标是从原始广告视频 `V` 中构建与问题 `q` 相关的证据包：

```text
E = {E_1, E_2, ..., E_K}
```

每个证据单元 `E_k` 包含全局视图、局部视图、时间戳、裁剪坐标、关联 ASR 片段、OCR 文本和响应分数等信息。后续问答模型不再直接处理完整视频，而是基于证据包完成广告知识检索、结构化推理和链式反思校验。

### 3.2.2 总体流程

本章方法包括四个主要阶段：

1. **多模态预处理与语义关键帧优选**：对广告视频进行高频过采样，并利用用户问题和 ASR 语义筛选 Top-K 关键帧；
2. **视听-文字时空响应图构建**：分别计算视觉特征对用户问题、邻域 ASR 语义和 OCR/Logo 文字显著性的响应；
3. **基于响应密度的局部证据锚定**：根据综合响应图计算语义重心，生成多尺度候选锚框，并选择响应密度最高的局部区域；
4. **全局—局部双流视觉输入与证据包构建**：保留全局视图和局部高分辨率视图，并记录时间戳、坐标和模态来源信息。

流程可概括为：

```text
广告视频 + 问题
        ↓
高频过采样 + 语义关键帧优选
        ↓
问题响应图 + ASR 邻域响应图 + OCR/Logo 响应图
        ↓
视听-文字时空响应图
        ↓
响应密度锚定局部证据
        ↓
全局视图 + 局部视图 + 多模态证据包
```


## 3.3 多模态预处理与语义关键帧优选

### 3.3.1 ASR 语音转写与清洗

广告视频中的旁白、口播和人物对白常常直接承载产品卖点、促销信息和情感诉求。例如，“仅剩最后一天”“官方认证”“第二件半价”等语音内容对回答营销策略、优惠信息和广告意图类问题具有重要作用。因此，本文首先对视频音频轨道进行自动语音识别，得到带时间戳的 ASR 片段序列。

ASR 清洗包括：

- 去除空白片段和无语义停顿词；
- 合并时间上连续且语义相关的短片段；
- 保留语音片段的开始和结束时间；
- 对重复口播或背景歌词进行基础过滤；
- 标记 ASR 置信度较低的片段，供后续链式反思校验使用。

清洗后的 ASR 片段不仅作为文本上下文输入模型，更重要的是作为视觉证据定位的语义引导信号。

### 3.3.2 高频过采样

广告视频的关键视觉线索可能只持续极短时间。例如，产品包装上的小字、屏幕角落的 Logo、价格信息或促销条款可能在一两个镜头中快速出现。如果采用低频均匀采样，关键帧可能被遗漏。为降低这一风险，本文先对视频进行高频过采样，得到候选帧集合：

```text
F = {f_1, f_2, ..., f_S}
```

其中，`S` 表示过采样后得到的候选帧数量。高频过采样的目的不是直接将所有候选帧输入模型，而是为后续语义筛选提供更完整的候选空间。

### 3.3.3 语义关键帧优选

在获得候选帧集合后，本文利用视觉—语言预训练模型分别编码候选帧、用户问题和 ASR 文本。设候选帧 `f_s` 的视觉表示为 `v_s`，用户问题表示为 `u_q`，全局 ASR 表示为 `u_a`，则候选帧相关性得分可表示为：

```text
Score_frame(f_s) = λ_q · sim(v_s, u_q) + λ_a · sim(v_s, u_a) + λ_o · OCRBonus(f_s)
```

其中，`sim(·)` 表示跨模态相似度函数，`OCRBonus(f_s)` 表示该帧是否包含文字、Logo 或品牌相关线索的加分项，`λ_q`、`λ_a` 和 `λ_o` 分别表示问题、语音和文字线索的权重。

根据 `Score_frame` 从高到低选取 Top-K 帧作为关键帧序列：

```text
F_K = TopK({Score_frame(f_s) | f_s ∈ F})
```

该策略体现了“先密集保留、再语义筛选”的思想：过采样降低关键信息遗漏风险，语义筛选控制后续处理成本。


## 3.4 视听-文字时空响应图构建

### 3.4.1 响应图的基本思想

关键帧筛选解决的是“选择哪些帧”的问题，但广告视频问答还需要进一步判断“帧中的哪些区域与问题相关”。例如，当用户询问“画面中的优惠信息是什么”时，模型应关注字幕和价格区域；当用户询问“该广告如何体现快速配送”时，模型可能需要关注骑手动作、包裹、交通工具以及旁白中关于速度的描述。

因此，本文在关键帧内部构建视听-文字时空响应图。该响应图融合三类信号：

1. **问题响应**：视觉区域与用户问题之间的语义相关性；
2. **ASR 响应**：视觉区域与邻域语音语义之间的相关性；
3. **OCR/Logo 响应**：视觉区域中文字、Logo、品牌标识或促销信息的显著性。

### 3.4.2 问题—视觉响应图

设关键帧 `f_t` 的空间视觉特征图为：

```text
X_t ∈ R^{H × W × d}
```

其中，`H` 和 `W` 为空间尺寸，`d` 为特征维度。位置 `(i,j)` 处的视觉特征为 `x_{t,i,j}`。将视觉特征和问题向量映射到公共语义空间：

```text
\tilde{x}_{t,i,j} = W_v x_{t,i,j}
\tilde{q} = W_q u_q
```

则问题—视觉响应图可定义为：

```text
H_Q(t,i,j) = softmax_{i,j}( <\tilde{x}_{t,i,j}, \tilde{q}> / sqrt(d) )
```

该响应图用于衡量当前帧中不同区域对用户问题的语义响应强度。

### 3.4.3 ASR 邻域响应图

广告视频中旁白与画面经常存在时间错位。若仅使用当前帧时间戳对应的 ASR 片段，可能遗漏与当前画面相关但略早或略晚出现的语音内容。为此，本文为每个关键帧构建以其时间戳 `t` 为中心的语音邻域窗口：

```text
Ω(t) = {a_m | |center(a_m) - t| ≤ r}
```

其中，`r` 为窗口半径，`center(a_m)` 表示语音片段中心时间。对窗口内语音片段按照时间距离赋予权重：

```text
g(t,m) = exp( - (center(a_m) - t)^2 / (2σ^2) )
```

窗口聚合后的语音表示为：

```text
u_A(t) = Σ_{a_m ∈ Ω(t)} g(t,m) · Enc(a_m) / Σ_{a_m ∈ Ω(t)} g(t,m)
```

进一步计算 ASR—视觉响应图：

```text
H_A(t,i,j) = softmax_{i,j}( <W_v x_{t,i,j}, W_a u_A(t)> / sqrt(d) )
```

该设计使语音不再只是全局文本上下文，而是用于引导当前帧的视觉区域定位。

### 3.4.4 OCR/Logo 文字响应图

广告视频中的屏幕文字和品牌标识对问答具有重要价值。本文通过 OCR 结果、Logo 检测结果或预设文字显著性关键词构建文字响应图。设文字线索集合为：

```text
C = {text, logo, brand, price, discount, slogan, number}
```

将每个文字线索编码为语义向量，并与视觉空间特征计算响应。OCR/Logo 响应可表示为：

```text
H_O(t,i,j) = max_{c ∈ C} softmax_{i,j}( <W_v x_{t,i,j}, W_c Enc(c)> / τ )
```

其中，`τ` 为温度系数，用于调节文字响应图的分布锐度。若已存在 OCR 检测框，则可将 OCR 框区域的响应分数提高，以增强文本细节区域的显著性。

### 3.4.5 综合视听-文字时空响应图

最终综合响应图由三类响应融合得到：

```text
H(t,i,j) = α · H_Q(t,i,j) + β · H_A(t,i,j) + γ · H_O(t,i,j)
```

其中，`α`、`β` 和 `γ` 分别表示问题、语音和文字响应的权重。对于不同类型问题，权重可进行任务自适应调整。例如，价格、字幕和 Logo 类问题可提高 `γ`；旁白内容类问题可提高 `β`；普通视觉识别类问题可提高 `α`。

综合响应图 `H(t)` 表示当前关键帧中与用户问题最相关的视觉证据分布，是后续局部锚定和视觉特征压缩的基础。


## 3.5 基于响应密度的局部证据锚定

### 3.5.1 语义重心定位

得到综合响应图后，本文首先计算其空间语义重心：

```text
c_x = Σ_i Σ_j j · H(t,i,j) / Σ_i Σ_j H(t,i,j)
c_y = Σ_i Σ_j i · H(t,i,j) / Σ_i Σ_j H(t,i,j)
```

其中，`(c_x, c_y)` 表示响应图能量分布的中心位置。该位置可被视为当前帧中与问题最相关的视觉区域中心。

### 3.5.2 多尺度候选锚框生成

广告视频中的关键证据大小差异较大：Logo 或价格可能很小，人物动作或场景线索则可能覆盖较大区域。因此，本文围绕语义重心生成多尺度候选锚框。设尺度集合为：

```text
S = {s_1, s_2, ..., s_n}
```

例如可取 `{0.4, 0.6, 0.8, 1.0}`。对于尺度 `s`，候选框宽高为：

```text
w_s = s · W_img
h_s = s · H_img
```

候选框坐标为：

```text
B_s = [c_x - w_s/2, c_y - h_s/2, c_x + w_s/2, c_y + h_s/2]
```

并通过边界截断函数确保候选框不超出图像范围。

### 3.5.3 归一化响应密度筛选

若直接选择响应能量总和最大的区域，大尺度候选框往往更占优势。为避免面积偏置，本文引入归一化响应密度：

```text
D(B_s) = Σ_{(i,j) ∈ B_s} H(t,i,j) / Area(B_s)^ρ
```

其中，`ρ` 为面积惩罚系数。当 `ρ=1` 时表示平均响应密度；当 `ρ<1` 时允许较大区域保留一定优势。最终选择响应密度最高的候选框：

```text
B* = argmax_{B_s} D(B_s)
```

`B*` 所对应的区域被裁剪并上采样为局部高分辨率证据视图。

### 3.5.4 多峰响应的扩展处理

在部分广告视频中，关键证据可能分散在多个区域，例如左侧人物动作和右下角价格信息同时重要。若仅使用单一语义重心，可能忽略次要但关键的证据区域。为此，本文可扩展采用局部峰值检测和非极大值抑制，选取多个候选局部区域：

```text
{B_1*, B_2*, ..., B_m*}
```

在实际实验中，可根据输入预算选择 Top-1 或 Top-m 局部区域。若模型输入预算有限，默认采用 Top-1 局部区域；若问题涉及文字、价格或多对象关系，可采用 Top-m 证据区域。


## 3.6 全局—局部双流视觉输入构建

### 3.6.1 全局视图

全局视图由原始关键帧缩放得到，用于保留广告的整体场景信息，包括人物关系、场景类型、情绪氛围、构图和动作上下文。全局视图记为：

```text
G_t = Resize(f_t)
```

全局视图适合回答场景意图、情绪氛围和整体主题类问题，但对小文字、Logo 和价格信息的保留能力有限。

### 3.6.2 局部视图

局部视图由最佳锚框 `B*` 裁剪并上采样得到：

```text
L_t = Upsample(Crop(f_t, B*))
```

局部视图用于保留高分辨率细节，例如产品包装、促销字幕、品牌标识、价格数字和小尺寸图标。局部视图的作用不是替代全局视图，而是补充全局缩放后可能丢失的细粒度证据。

### 3.6.3 双流输入

最终视觉输入由全局视图和局部视图组成：

```text
Z_t = [G_t ; L_t]
```

其中，`;` 表示在输入序列维度或图像组维度上的拼接。对于每个关键帧，模型同时看到整体语境和局部证据，从而降低全局缩放造成的信息损失。

### 3.6.4 压缩率定义

为避免“视觉特征压缩”概念模糊，本文从三个层面定义压缩率。

**帧级压缩率：**

```text
CR_frame = 1 - K / S
```

其中，`S` 为过采样候选帧数量，`K` 为最终保留关键帧数量。

**空间输入压缩率：**

```text
CR_area = 1 - Area(B*) / Area(f_t)
```

该指标衡量局部证据区域相对于整帧图像的面积压缩程度。

**Token/计算压缩率：**

若模型可统计视觉 Token 数或输入 Token 数，则定义：

```text
CR_token = 1 - Token_compressed / Token_original
```

在实验中，应同时报告帧数、视觉 Token、总输入 Token、推理时延和显存占用，避免仅凭概念声称压缩有效。


## 3.7 多模态证据包构建

### 3.7.1 证据包的必要性

本章方法不仅要为问答模型提供压缩后的视觉输入，还要为后续的广告知识检索和链式反思校验提供可追溯证据。如果只输出全局图和局部图，后续模型虽然可以生成答案，但难以解释答案依据，也难以在反思阶段回查具体证据。因此，本文将每个关键帧的视觉、语音和文字信息组织为证据包。

### 3.7.2 证据包结构

每个证据包 `E_t` 可表示为：

```text
E_t = {
  frame_id: t,
  timestamp: τ_t,
  global_view: G_t,
  local_view: L_t,
  crop_bbox: B*,
  response_score: D(B*),
  question_response: H_Q,
  asr_response: H_A,
  ocr_response: H_O,
  asr_segment: Ω(t),
  ocr_text: O_t,
  visual_tags: Tags_t
}
```

其中，`Tags_t` 表示通过视觉识别或模型描述得到的视觉标签，如“商品展示”“倒计时”“人物微笑”“品牌 Logo”等。

### 3.7.3 证据包的后续用途

证据包将在第 4 章中发挥三方面作用：

1. **知识检索查询构建**：利用 ASR、OCR、视觉标签和用户问题构造广告知识检索查询；
2. **结构化推理证据引用**：在“观察—知识匹配—分析—答案”过程中显式引用证据；
3. **链式反思回溯校验**：对答案中的视觉、文字、语音和营销推理声明进行逐项核查。

因此，证据包是连接视觉压缩、广告知识推理和链式反思的核心桥梁。


## 3.8 算法描述

### 算法 3-1：视听-文字协同证据定位与视觉压缩

```text
输入：广告视频 V，用户问题 q，关键帧数量 K，窗口半径 r，尺度集合 S
输出：证据包集合 E

1. 使用 ASR 对视频音频进行转写，得到语音片段序列 A；
2. 使用 OCR/Logo 检测提取画面文字与品牌线索 O；
3. 对视频进行高频过采样，得到候选帧集合 F；
4. 对每个候选帧 f_s：
   4.1 编码帧视觉特征 v_s、问题语义 u_q 和 ASR 语义 u_a；
   4.2 计算帧级相关性 Score_frame(f_s)；
5. 选取得分最高的 Top-K 帧，得到关键帧集合 F_K；
6. 对每个关键帧 f_t：
   6.1 提取空间视觉特征图 X_t；
   6.2 计算问题—视觉响应图 H_Q；
   6.3 根据时间窗口 Ω(t) 聚合邻域 ASR 表示，计算 ASR—视觉响应图 H_A；
   6.4 计算 OCR/Logo—视觉响应图 H_O；
   6.5 融合得到综合响应图 H；
   6.6 根据 H 计算语义重心；
   6.7 生成多尺度候选锚框；
   6.8 计算各候选框响应密度 D(B_s)；
   6.9 选择最佳锚框 B* 并裁剪局部视图 L_t；
   6.10 保留全局视图 G_t；
   6.11 构建证据包 E_t；
7. 返回证据包集合 E。
```


## 3.9 本章小结

本章围绕论文题目中的“视觉特征压缩”展开，提出了一种面向广告视频问答的证据保留型视觉压缩方法。该方法首先通过高频过采样与语义关键帧优选降低关键帧遗漏风险；随后利用用户问题、邻域 ASR 语义和 OCR/Logo 文字显著性构建视听-文字时空响应图；进一步基于响应密度自适应锚定局部高分辨率证据区域，并结合全局视图形成双流视觉输入；最后，将视觉、语音和文字信息组织为可追溯的多模态证据包。

与传统均匀采样或全局缩放方法相比，本章方法更强调对广告视频中关键证据的定位与保留，能够在降低冗余视觉输入的同时提升 Logo、字幕、价格和产品细节等细粒度信息的可见性。该证据包不仅作为问答模型的输入，也为后续广告知识检索和链式反思校验提供基础。下一章将在此基础上进一步研究如何利用证据包进行广告知识增强推理，并通过证据回溯式链式反思提升答案可靠性。

# 第4章 知识增强链式反思推理方法



## 4.1 本章引言

第 3 章围绕广告视频问答中的视觉证据定位与视觉特征压缩问题，构建了由全局视图、局部视图、ASR 片段、OCR 文本、视觉标签和响应分数组成的多模态证据包。证据包解决了“模型应当看哪里、听哪里、读哪里”的问题，但广告视频问答还需要进一步解决“这些证据意味着什么”和“生成答案是否被证据支撑”的问题。

广告视频不同于一般视频，它不仅包含对象、动作和场景，还包含品牌传播、产品卖点、情绪诉求、说服策略和目标受众等营销语义。例如，当视频中出现“限时抢购”“仅剩最后一天”和倒计时画面时，模型需要理解这不仅是促销信息，也可能体现了稀缺效应和损失规避；当广告展示普通用户的使用体验和好评时，模型需要理解其可能对应社会认同或 UGC 用户证言广告；当画面通过夸张对比或象征物表达产品价值时，模型需要进一步识别视觉隐喻。通用多模态大语言模型虽然具备一定常识和语言推理能力，但在广告营销语义理解中容易出现两类问题：一是停留在表层视觉描述，无法形成专业解释；二是过度套用营销概念，生成视频证据不支持的泛化回答。

因此，本章提出知识增强链式反思推理方法。与普通 RAG 或普通 CoT 不同，本章方法强调“证据驱动”和“证据回溯”：广告知识检索不是仅根据用户问题进行，而是同时参考视觉标签、ASR 文本、OCR 文本和局部证据区域；结构化推理不是自由生成，而是按照“观察—知识匹配—分析—答案”的路径组织多模态证据；链式反思不是简单让模型再次生成答案，而是将初始答案拆解为不同类型的声明，并回溯至关键帧、局部裁剪区域、ASR 片段、OCR 文本和知识条目进行核查。

本章目标是将第 3 章的证据包转化为可靠的广告视频问答答案。具体包括：构建广告营销知识库；设计基于证据包的知识检索与重排序；构建结构化推理生成协议；设计答案声明拆解方法；提出证据回溯式链式反思校验机制；并通过触发策略和早停机制控制额外推理成本。


## 4.2 广告营销知识库构建

### 4.2.1 知识库构建动机

广告视频问答中的许多问题无法仅依靠视觉识别直接回答。例如：

- “这个广告使用了什么营销策略？”
- “广告如何制造紧迫感？”
- “该广告主要面向哪类人群？”
- “这个画面中的夸张对比有什么作用？”
- “广告如何体现情绪共鸣？”

这些问题要求模型理解广告学、消费者心理学和传播学中的相关概念。通用多模态模型可能知道部分概念名称，但在具体视频中容易泛化使用，甚至把视频中没有出现的策略强行套入答案。因此，本文构建结构化广告营销知识库，为模型提供可控、可追溯的专家上下文。

### 4.2.2 知识库类别

知识库围绕 AdsQA 广告视频问答任务和广告分析需求构建，主要包括以下几类：

| 类别 | 代表知识 | 用途 |
|---|---|---|
| 营销理论 | AIDA、FAB、营销漏斗 | 分析广告转化路径和卖点表达 |
| 消费者心理 | 稀缺效应、社会认同、损失规避、权威背书 | 分析广告如何影响用户决策 |
| 广告创意 | 场景化广告、视觉隐喻、情绪共鸣、反差冲突 | 分析创意表达和主题呈现 |
| 多模态证据 | 旁白卖点、字幕承诺、产品特写、品牌资产一致性 | 连接视频证据和广告解释 |
| 合规与可靠性 | 绝对化用语风险、功效宣称风险、证据一致性、知识一致性 | 支持答案校验和错误归因 |

### 4.2.3 知识条目结构

每个知识条目采用结构化 JSON 表示，字段包括：

```text
K_i = {
  id: 知识编号,
  category: 知识类别路径,
  title: 知识名称,
  type: 知识类型,
  keywords: 检索关键词,
  aliases: 同义表达,
  content: 概念解释,
  applicable_scenarios: 适用场景,
  risk_notes: 使用风险,
  retrieval_text: 检索文本,
  source: 来源,
  version: 版本
}
```

其中，`risk_notes` 用于提醒模型不要过度推断。例如，对于稀缺效应，风险提示可以是“不得虚构库存或活动截止时间”；对于功效宣称，风险提示可以是“避免将普通宣传语扩展为确定性效果”。

### 4.2.4 知识库构建原则

为避免 RAG 引入新的幻觉，知识库构建遵循以下原则：

1. **来源可解释**：知识条目应来自通用营销理论、广告分析常识或公开教材资料，不应直接从测试集答案中抽取；
2. **概念边界清晰**：每个营销概念应包含适用场景和风险说明，避免模型混淆相似策略；
3. **证据优先**：知识条目只用于解释视频中已有证据，不能替代视频事实；
4. **支持消融**：知识库应支持 no-RAG、random-RAG、irrelevant-RAG、generic-RAG 和 marketing-RAG 等实验设置，验证知识贡献。


## 4.3 基于证据包的广告知识检索

### 4.3.1 普通 RAG 的局限

普通 RAG 往往仅根据用户问题检索外部知识。例如，当用户问“这个广告用了什么策略”时，系统可能检索出稀缺效应、社会认同、情绪共鸣等多个概念。但如果视频中并没有“限时、限量、倒计时、销量、好评”等线索，直接注入这些知识会诱导模型产生无依据解释。

因此，本文不采用单纯问题驱动的检索，而采用证据驱动的检索。检索查询不仅包含用户问题，还包含第 3 章证据包中的 ASR 片段、OCR 文本、视觉标签和局部证据描述。

### 4.3.2 复合查询构建

设用户问题为 `q`，证据包集合为 `E = {E_1, ..., E_K}`。从证据包中提取：

- ASR 文本：`A_E`；
- OCR 文本：`O_E`；
- 视觉标签：`T_E`；
- 局部证据描述：`L_E`；
- 全局场景描述：`G_E`。

构造复合查询：

```text
Q_R = concat(q, A_E, O_E, T_E, L_E, G_E)
```

为提升召回率，可根据广告语义规则进行轻量查询扩展。例如：

| 触发线索 | 扩展关键词 |
|---|---|
| 限时、限量、倒计时、库存 | 稀缺效应、紧迫感、损失规避 |
| 大家都在用、销量、好评、推荐 | 社会认同、UGC、用户证言 |
| 原价、现价、折扣、优惠 | 价格锚定、利益点前置 |
| 专家、认证、官方、获奖 | 权威背书、可信度 |
| logo、品牌色、口号、包装 | 品牌资产一致性、品牌记忆 |
| 故事、人物、冲突、转折 | 故事化叙事、反差冲突 |

### 4.3.3 检索打分

对每个知识条目 `K_i`，计算其与复合查询的相关性。检索得分由语义相似度、关键词命中、证据匹配和类别先验组成：

```text
Score(K_i) = μ_1 · Sem(Q_R, K_i) + μ_2 · Key(Q_R, K_i) + μ_3 · Ev(E, K_i) + μ_4 · Prior(K_i)
```

其中：

- `Sem(Q_R, K_i)` 表示查询与知识条目的语义相似度；
- `Key(Q_R, K_i)` 表示关键词命中比例；
- `Ev(E, K_i)` 表示知识条目与实际视频证据的匹配程度；
- `Prior(K_i)` 表示类别先验；
- `μ_1`、`μ_2`、`μ_3`、`μ_4` 为权重。

与普通 RAG 不同，本文特别引入证据匹配项 `Ev(E, K_i)`。例如，若知识条目为“稀缺效应”，则只有当证据包中出现“限时、限量、倒计时、库存、最后一天”等线索时，该条目才应获得较高分数。

### 4.3.4 证据感知重排序与过滤

检索得到候选知识集合后，系统进行证据感知重排序。若某条知识仅与问题文本相关，但无法在 ASR、OCR 或视觉标签中找到支撑线索，则降低其分数或过滤掉。最终保留 Top-M 个高置信知识条目：

```text
K_E = TopM({K_i | Score(K_i) ≥ θ})
```

其中，`θ` 为知识注入阈值。若无知识条目超过阈值，则系统不强行注入外部知识，而提示模型仅基于视频证据谨慎回答。


## 4.4 结构化广告视频问答推理

### 4.4.1 推理协议设计

为了避免模型自由生成导致的泛化解释，本文采用结构化推理协议。模型生成答案时必须按以下路径组织：

```text
观察 → 知识匹配 → 分析 → 答案
```

与传统“观察—分析—推理—答案”相比，本章显式加入“知识匹配”步骤，用于区分视频事实证据和广告理论解释。

### 4.4.2 观察阶段

观察阶段只允许模型描述证据包中可见、可听、可读的事实，包括：

- 全局视图中的场景、人物、产品和动作；
- 局部视图中的 Logo、字幕、价格、包装和促销文字；
- ASR 片段中的旁白、口播和语音信息；
- OCR 文本中的明确文字内容；
- 视觉标签中出现的对象或场景线索。

观察阶段不得直接推断营销策略。例如，模型可以说“画面文字出现‘限时抢购’”，但不应直接说“这是稀缺效应”，后者应放在知识匹配或分析阶段。

### 4.4.3 知识匹配阶段

知识匹配阶段需要判断检索到的知识条目是否与视频证据匹配。模型应明确说明：

- 哪些知识条目适用；
- 适用的证据是什么；
- 哪些知识条目不适用或证据不足；
- 是否存在合规或过度推断风险。

例如：

```text
知识“稀缺效应”适用，因为 ASR 中出现“仅剩最后一天”，OCR 中出现“限时抢购”，视觉标签中包含“倒计时”。
```

若只检索到“稀缺效应”，但视频证据中没有时间、库存或限量线索，则模型应说明证据不足，而不是强行使用该知识。

### 4.4.4 分析阶段

分析阶段将观察证据和知识条目结合起来，解释其与用户问题之间的关系。例如：

- 将“限时抢购”和“倒计时”解释为制造紧迫感；
- 将“用户好评”和“多人使用场景”解释为社会认同；
- 将“专家认证”和“官方背书”解释为权威背书；
- 将“家庭场景”和“温暖音乐”解释为情绪共鸣。

分析阶段应避免过度推断，尤其在品牌、功效、价格和受众判断上，应使用“可能”“倾向于”“根据现有证据”等限定表达。

### 4.4.5 答案阶段

答案阶段给出简洁结论。答案应满足：

1. 与用户问题直接相关；
2. 核心判断由观察证据支撑；
3. 营销概念使用准确；
4. 不编造视频中不存在的品牌、价格、功效或数据；
5. 证据不足时明确说明不确定性。

### 4.4.6 Prompt 模板

结构化推理 Prompt 可表示为：

```text
你是广告视频问答助手。请优先依据视频证据回答，外部广告知识仅用于解释视频中已经出现的线索，不得编造视频中不存在的事实。

【用户问题】
{question}

【多模态证据包】
- 全局场景：{global_summary}
- 局部证据：{local_evidence}
- ASR 片段：{asr_segments}
- OCR 文本：{ocr_text}
- 视觉标签：{visual_tags}

【检索到的广告知识】
{retrieved_knowledge}

请按以下结构回答：
1. 观察：列出可见、可听、可读证据；
2. 知识匹配：说明哪些知识适用，哪些不适用；
3. 分析：解释证据与广告意图、策略或受众之间的关系；
4. 答案：给出简洁结论。

要求：
- 不确定时使用“可能”“倾向于”；
- 不得虚构品牌、价格、功效或数据；
- 每个营销判断必须有视频证据或知识条目支撑。
```


## 4.5 初始答案声明拆解

### 4.5.1 为什么需要声明拆解

若直接对完整答案进行整体反思，模型可能只给出“答案正确”或“答案需要修改”的模糊判断，难以定位具体错误。广告视频问答中的错误往往具有不同来源：

- 视觉对象识别错误；
- OCR 文字或价格误读；
- ASR 内容错配；
- 声画异步导致时间关联错误；
- 广告知识误用；
- 营销策略过度推断。

因此，本文在链式反思前先对初始答案进行声明拆解。

### 4.5.2 声明类型

初始答案中的声明可分为四类：

| 声明类型 | 示例 | 所需证据 |
|---|---|---|
| 视觉声明 | “画面中出现了饮料瓶和品牌 Logo” | 关键帧、局部 crop、视觉标签 |
| 文字声明 | “字幕写着第二件半价” | OCR 文本、局部 crop |
| 语音声明 | “旁白提到仅剩最后一天” | ASR 片段、时间窗口 |
| 营销推理声明 | “广告使用稀缺效应制造紧迫感” | 视频证据 + 知识条目 |

声明拆解结果可表示为：

```text
C = {c_1, c_2, ..., c_R}
```

每个声明包含：

```text
c_r = {
  claim_id: 声明编号,
  claim_text: 声明文本,
  claim_type: 声明类型,
  required_evidence: 所需证据类型
}
```

### 4.5.3 声明拆解示例

对于初始答案：

```text
该广告通过限时抢购和倒计时制造紧迫感，使用了稀缺效应来促进用户尽快购买。
```

可拆解为：

| 声明编号 | 声明文本 | 类型 | 所需证据 |
|---|---|---|---|
| C1 | 广告中出现限时抢购 | 文字声明 | OCR/局部 crop |
| C2 | 广告中出现倒计时 | 视觉声明 | 关键帧/视觉标签 |
| C3 | 广告制造紧迫感 | 营销推理声明 | C1/C2 + 稀缺效应知识 |
| C4 | 广告促进用户尽快购买 | 营销推理声明 | CTA/促销证据 + 知识条目 |


## 4.6 证据回溯式链式反思校验

### 4.6.1 校验目标

链式反思的目标不是让模型自由重写答案，而是对每条声明进行证据核查。校验结果包括：

- `CONFIRM`：声明有证据支撑，可保留；
- `REVISE`：声明部分错误，需要修正；
- `REJECT`：声明无证据支撑，应删除或拒答；
- `LOW_CONFIDENCE`：证据不足，应降低确定性表达。

### 4.6.2 各类声明的校验规则

#### 视觉声明校验

视觉声明必须回查全局视图、局部视图和视觉标签。若声明涉及 Logo、产品、人物或场景，应检查对应区域是否可见。

校验规则：

```text
如果视觉声明中的对象或动作能在关键帧/局部 crop 中找到，则确认；
如果对象不可见或与视觉标签冲突，则修正或拒绝；
如果对象模糊不可辨，则降低置信度。
```

#### 文字声明校验

文字声明必须回查 OCR 文本和局部 crop。涉及价格、数字、优惠、品牌口号等内容时，应优先以 OCR 和局部图为依据。

校验规则：

```text
如果答案中的文字与 OCR 文本一致，则确认；
如果答案中的数字、价格或优惠与 OCR 冲突，则修正；
如果 OCR 置信度低或局部图不可辨，则降低置信度或说明无法确定。
```

#### 语音声明校验

语音声明必须回查 ASR 时间窗口。若答案引用旁白内容，应检查 ASR 中是否存在对应片段。

校验规则：

```text
如果 ASR 片段中存在对应语义，则确认；
如果答案引用的语音内容不存在，则拒绝；
如果 ASR 可能识别错误，则降低置信度。
```

#### 营销推理声明校验

营销推理声明必须同时满足两个条件：

1. 视频证据中存在相应线索；
2. 检索知识条目与该线索匹配。

例如，判断“稀缺效应”时，应至少有“限时、限量、倒计时、库存、最后一天”等证据之一。若只有知识条目但没有视频证据，则不能确认该声明。

校验规则：

```text
如果营销声明有视频证据和知识条目共同支撑，则确认；
如果只有知识条目但视频证据不足，则降低置信度或删除；
如果使用了错误营销概念，则修正为更合适的概念；
如果无法判断，则说明证据不足。
```

### 4.6.3 校验 Prompt 模板

```text
你是广告视频问答的证据核查员。请不要自由发挥，只根据给定证据检查初始答案中的声明是否成立。

【用户问题】
{question}

【初始答案】
{initial_answer}

【声明列表】
{claims}

【多模态证据包】
{evidence_package}

【广告知识条目】
{retrieved_knowledge}

请对每条声明输出：
- claim_id
- verdict: CONFIRM / REVISE / REJECT / LOW_CONFIDENCE
- evidence_ids: 支撑或冲突的证据编号
- error_type: 无 / 视觉误读 / OCR误读 / ASR错配 / 时间错位 / 知识误用 / 过度推断
- revised_text: 如需修改，给出修正文本

要求：
1. 不得引入证据包中没有的信息；
2. 营销策略判断必须同时有视频证据和知识条目支撑；
3. 证据不足时不要强行确认，应输出 LOW_CONFIDENCE 或 REJECT。
```

### 4.6.4 最终答案生成

根据校验结果，系统更新初始答案：

- 所有核心声明为 `CONFIRM`：保留初始答案；
- 部分声明为 `REVISE`：用修正文本替换对应部分；
- 存在关键声明为 `REJECT`：删除无证据内容或输出无法确定；
- 多个声明为 `LOW_CONFIDENCE`：降低答案确定性表达。

最终答案应同时满足准确性和谨慎性。


## 4.7 触发策略、早停与成本控制

### 4.7.1 为什么需要触发策略

链式反思会带来额外 Token 和推理时延。若对所有样本都进行反思，虽然可能提升可靠性，但会显著增加计算成本。广告视频问答中并非所有问题都具有同等风险，因此本文采用触发式链式反思。

### 4.7.2 基于问题关键词的触发

当用户问题包含以下类型关键词时，触发链式反思：

| 触发类型 | 示例关键词 | 风险 |
|---|---|---|
| 文字细节 | 字幕、文字、价格、数字、Logo、标语 | OCR 误读 |
| 语音内容 | 旁白、说了什么、提到、声音 | ASR 错配 |
| 逻辑因果 | 为什么、如何体现、原因、作用 | 过度推断 |
| 营销策略 | 策略、受众、情绪、隐喻、说服 | 知识误用 |
| 高风险事实 | 功效、保证、第一、唯一、永久 | 合规风险 |

### 4.7.3 基于证据风险的触发

仅依赖关键词可能漏掉部分高风险样本。因此，可进一步引入证据风险分数：

```text
Risk = η_1 · OCR_uncertainty + η_2 · ASR_uncertainty + η_3 · RAG_conflict + η_4 · Response_entropy
```

其中：

- `OCR_uncertainty` 表示 OCR 置信度低或文字区域模糊；
- `ASR_uncertainty` 表示 ASR 置信度低或语音片段与画面时间差较大；
- `RAG_conflict` 表示多个知识条目得分接近或存在语义冲突；
- `Response_entropy` 表示响应图分布过于分散，说明视觉证据定位不确定。

当 `Risk` 超过阈值时触发链式反思。

### 4.7.4 早停策略

若初始答案的核心声明均能被高置信证据支撑，且风险分数较低，则直接输出答案，避免不必要的反思。早停条件可表示为：

```text
if Confidence(answer) ≥ δ and Risk ≤ ε:
    output initial_answer
else:
    run evidence-grounded reflection
```

该策略用于平衡答案可靠性和推理成本。


## 4.8 错误类型归因

链式反思不仅用于修正答案，也用于分析模型错误来源。本文将广告视频问答错误归纳为以下类型：

| 错误类型 | 表现 | 可能原因 | 修正方向 |
|---|---|---|---|
| 视觉误读 | 将物体、人物、场景识别错误 | 全局图模糊，局部区域未命中 | 改进视觉锚定 |
| OCR误读 | 价格、字幕、Logo 识别错误 | 文字过小、运动模糊、遮挡 | 提高局部分辨率或 OCR 置信校验 |
| ASR错配 | 错误引用旁白内容 | 声画异步，ASR 错误 | 调整时间窗口或降低置信度 |
| 时间错位 | 将语音内容对应到错误画面 | 严格时间对齐失效 | 引入邻域语音响应 |
| 知识误用 | 将普通促销误判为复杂策略 | RAG 噪声，概念边界不清 | 证据感知重排序 |
| 过度推断 | 生成视频中没有的信息 | 模型根据常识补全 | 证据回溯校验 |
| 合规风险 | 使用绝对化或功效确定表达 | 未识别风险词 | 合规知识约束 |

错误归因结果可用于第 5 章案例分析和失败样本分析。


## 4.9 算法描述

### 算法 4-1：证据驱动广告知识推理与链式反思

```text
输入：用户问题 q，第3章输出的证据包集合 E，广告知识库 K
输出：最终答案 y

1. 从证据包 E 中提取 ASR 文本、OCR 文本、视觉标签、局部证据描述和全局场景描述；
2. 构造复合检索查询 Q_R；
3. 对知识库中每个知识条目 K_i：
   3.1 计算语义相似度 Sem(Q_R, K_i)；
   3.2 计算关键词命中 Key(Q_R, K_i)；
   3.3 计算证据匹配得分 Ev(E, K_i)；
   3.4 计算最终检索得分 Score(K_i)；
4. 根据阈值 θ 和 Top-M 策略选择高置信知识条目 K_E；
5. 构造结构化推理 Prompt，输入 q、E 和 K_E；
6. 按“观察—知识匹配—分析—答案”生成初始答案 y_0；
7. 判断是否触发链式反思：
   7.1 若问题关键词或证据风险分数满足触发条件，进入步骤 8；
   7.2 否则输出 y_0；
8. 将 y_0 拆解为声明集合 C；
9. 对每个声明 c_r：
   9.1 根据声明类型确定所需证据；
   9.2 回查证据包 E 和知识条目 K_E；
   9.3 输出 CONFIRM / REVISE / REJECT / LOW_CONFIDENCE；
10. 根据校验结果修正或确认答案；
11. 输出最终答案 y。
```


## 4.10 本章小结

本章围绕论文题目中的“链式反思”展开，提出了一种证据驱动的广告知识增强推理与证据回溯式链式反思方法。首先，针对广告视频问答中营销语义理解需要专业知识支撑的问题，构建结构化广告营销知识库；其次，基于第 3 章输出的证据包构造复合查询，并通过证据感知重排序过滤与视频语境不匹配的知识条目；随后，设计“观察—知识匹配—分析—答案”的结构化推理协议，使模型区分视频事实证据和广告理论解释；最后，将初始答案拆解为视觉、文字、语音和营销推理声明，并分别回溯至关键帧、局部视图、ASR 片段、OCR 文本和知识条目进行核查。

与普通 RAG 或普通自我反思方法相比，本章方法强调证据驱动和证据回溯。外部知识只用于解释视频中已有证据，不能替代视频事实；链式反思也不是自由重写，而是对答案声明进行证据约束校验。该机制能够降低无依据营销解释、OCR 细节误读、ASR 错配和营销策略误归因等问题，为第 5 章中的可靠性实验、错误归因和案例分析提供方法基础。

## 5.3 评价指标

### 5.3.1 问答准确性指标

本文采用严格准确率作为主要评价指标。对于每个样本，若模型生成答案与标准答案语义一致，且不包含与视频事实冲突的信息，则判定为正确，否则判定为错误。准确率定义为：

```text
Accuracy = 正确样本数 / 总样本数
```

对于生成式答案，可辅以人工评分或大模型裁判评分，但需要在抽样子集上验证裁判与人工标注的一致性。

### 5.3.2 证据一致性指标

证据一致性衡量答案中的核心声明是否能够被视频证据支撑。设模型答案拆分为 `R` 条声明，其中有 `R_s` 条声明能够被关键帧、局部视图、ASR、OCR 或知识条目支撑，则：

```text
Evidence Consistency = R_s / R
```

该指标用于评估答案是否存在无依据解释或事实性幻觉。

### 5.3.3 知识一致性指标

知识一致性衡量模型是否正确使用广告营销概念。若答案中使用的营销策略与视频证据和知识库定义一致，则记为正确；若将普通促销误判为复杂策略，或将无关知识强行套入答案，则记为错误。

```text
Knowledge Consistency = 正确使用营销概念的样本数 / 涉及营销知识的样本数
```

### 5.3.4 幻觉率

幻觉率衡量答案中出现视频证据不支持内容的比例。本文重点关注以下幻觉类型：

- 虚构未出现的品牌、价格或功效；
- 错误引用旁白或字幕；
- 错误识别 Logo 或产品；
- 无依据套用营销策略；
- 将广告暗示解释为确定性事实。

定义为：

```text
Hallucination Rate = 出现幻觉的样本数 / 总样本数
```

### 5.3.5 效率指标

为验证视觉特征压缩的实际价值，本文报告以下效率指标：

| 指标 | 含义 |
|---|---|
| 平均候选帧数 | 高频过采样得到的帧数 |
| 平均关键帧数 | 语义优选后输入模型的帧数 |
| 平均视觉 Token 数 | 图像/视频视觉输入产生的 Token 数 |
| 平均文本 Token 数 | 问题、ASR、OCR、知识、Prompt 等文本 Token 数 |
| 总输入 Token 数 | 视觉 Token 与文本 Token 总和 |
| 平均推理时延 | 单样本端到端推理耗时 |
| RAG 检索耗时 | 知识检索与重排序耗时 |
| 链式反思耗时 | 反思校验额外耗时 |
| 峰值显存占用 | 单样本推理过程中的峰值 GPU 显存 |

| 整体平均 | 0.416 | 0.379 | 0.345 | 0.286 | 0.233 | 0.210 | 0.149 |

### 5.5.2 主实验分析模板

从总体结果可以看出，本文方法在 AdsQA 数据集上的整体准确率达到 0.416，高于 Qwen3-Base 的 0.379，提升 0.037，即 3.7 个百分点，相对提升约 9.8%；相比 Qwen2.5-ReAd 的 0.345，提升 0.071，即 7.1 个百分点，相对提升约 20.6%。这说明仅依赖通用多模态大模型或简单广告增强方法，仍难以充分处理广告视频中高信息密度、声画异步和营销语义隐含等问题。

从分任务结果看，本文方法在情感分析、主题提取、营销策略和受众分析任务上提升更明显，而在视觉感知任务上与 Qwen3-Base 持平。这一现象说明本文方法的主要收益并不完全来自基础视觉识别能力的提升，而更多来自对多模态证据的组织、广告知识解释和答案可靠性控制。对于视觉感知类问题，基座模型已经具备较强的对象和场景识别能力，因此提升空间相对有限；而对于营销策略和受众分析等高阶语义任务，本文的证据驱动知识推理和链式反思机制能够发挥更大作用。

本章围绕本文提出的广告视频问答方法设计了系统实验方案。主实验用于验证本文方法相较于多模态基线模型的整体性能；视觉证据定位与压缩消融实验用于验证第 3 章中关键帧优选、视听-文字响应图、局部锚定和全局—局部双流输入的贡献；声画异步实验和 OCR/Logo 细节实验用于验证方法对广告视频特有难点的适应能力；RAG 消融实验用于检验证据驱动广告知识检索是否真正提升营销语义理解；链式反思实验用于评估证据回溯式校验对幻觉抑制和错误修正的作用；效率与参数敏感性实验则用于分析方法在准确性、可靠性和推理成本之间的权衡。

通过上述实验，本文能够从“有效性—效率—鲁棒性—可靠性”四个层面论证所提出方法的合理性。尤其需要强调的是，本章实验不是对若干模块进行孤立评估，而是围绕“证据定位—证据压缩—证据解释—证据校验”的主线展开，旨在证明本文方法并非简单拼接 RAG、CoT 和反思机制，而是面向广告视频问答构建的一套证据流闭环框架。

# 第6章 总结与展望

## 6.1 工作总结

本文围绕广告视频问答中的高信息密度、声画异步、领域知识不足和生成答案缺乏证据约束等问题，提出一种基于视觉特征压缩与链式反思的广告视频问答方法。不同于将视觉压缩、RAG 和反思机制简单并列组合，本文围绕“证据定位—证据压缩—证据解释—证据校验”的主线构建方法框架。

在视觉特征压缩方面，本文提出视听-文字协同证据定位方法，通过高频过采样、语义关键帧优选、问题响应图、ASR 邻域响应图和 OCR/Logo 响应图构建时空响应图，并基于响应密度自适应选择局部高分辨率证据区域，同时保留全局视图形成双流输入。在知识推理方面，本文构建广告营销知识库，并基于证据包进行广告知识检索和证据感知重排序。在链式反思方面，本文将初始答案拆解为不同类型的声明，并回溯至视觉、文字、语音和知识证据进行核查，从而提升答案可靠性。

## 6.2 主要创新点总结

本文主要创新点包括：第一，提出面向声画异步广告视频的视听-文字协同证据定位方法；第二，提出基于响应密度的证据保留型全局—局部双流视觉压缩机制；第三，提出证据驱动的广告知识增强推理与证据回溯式链式反思校验机制。

## 6.3 不足与未来工作

本文仍存在以下不足。首先，广告营销知识库规模仍有限，后续可结合更系统的营销理论、行业知识和品牌知识进行扩充。其次，当前局部锚定主要基于响应图和候选框，对于多个分散关键区域的处理仍有提升空间。再次，OCR 和 ASR 错误会影响证据包质量，后续可引入更强的多帧文字融合和语音置信度建模。最后，链式反思会带来额外 Token 和推理延迟，未来可进一步研究轻量化校验器、动态触发策略和多模型协同验证机制。

## 6.4 展望

未来工作可从三个方向继续推进：一是构建更大规模、更细粒度的广告视频问答数据集，特别是标注声画异步、OCR/Logo 细节和营销策略证据；二是探索可训练的证据定位模块，使视听-文字响应图与最终问答目标更紧密结合；三是将证据回溯式链式反思扩展到广告审核、营销素材评估和多模态内容安全等应用场景。
