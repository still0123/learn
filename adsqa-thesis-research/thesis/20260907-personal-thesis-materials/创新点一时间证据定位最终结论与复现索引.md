# 创新点一时间证据定位最终结论与复现索引

**日期：** 2026-07-12  
**结论性质：** 按预注册门禁完成的阶段最终结论

## 1. 最终结论

固定视觉 Token 预算下的问题条件化时间证据定位具有证据筛选价值，但没有在独立集上证明稳定 QA 增益。自研轻量选择器在 Pilot50 正向，在全新 Confirm-300C 仍微正，但效应很小且置信区间跨 0；VideoITG 官方强基线无增益；唯一覆盖约束修正又损失人工证据召回。

因此停止时间准确率路线，不接回空间裁剪，不运行统一时空 QA 或 balanced-3000。论文保留以下成立贡献：公平 Token 协议、问题条件化时间选择器、公开强基线、独立集验证、时间覆盖与证据精度权衡，以及证据定位改善不保证生成式 QA 提升的系统性实证。

## 2. 公平协议

- 回答模型：Qwen3-VL-8B，`/data1/qky/Model/Qwen3Vl-8B`；
- 每题 32 个实际提交/表示视图；
- 每题 11,664 个视觉 Token；
- processor 二次采样关闭；
- 同一 Answer Prompt、ASR、数据文件与 Qwen checkpoint；
- 无 RAG、反思和 Agent；
- DeepSeek 使用历史 Answer-only 口径，实际响应模型 `deepseek-v4-flash`；
- 配对 Bootstrap 10,000 次，seed 42。

## 3. 关键结果

| 方法 | 数据 | Strict/Relaxed | 配对候选减 Raw | 结论 |
|---|---|---:|---:|---|
| Raw Uniform | Pilot50 | 44% / 61% | - | 对照 |
| 自研 MMR32 | Pilot50 | 52% / 66% | `+0.05`，CI `[-0.04,+0.14]` | 小样本正向 |
| Raw Uniform | Confirm-300C | 54.00% / 69.00% | - | 独立对照 |
| 自研 MMR32 | Confirm-300C | 55.00% / 69.83% | `+0.00833`，CI `[-0.02667,+0.04333]` | 微正但不稳定 |
| VideoITG-8B | Pilot50 | 44% / 60% | `-0.01`，CI `[-0.08,+0.05]` | 强基线无增益 |

Confirm-300C 中自研方法 44 胜、215 平、41 负；Type2 平均下降 `0.04167`，Type3/4 分别提高 `0.04167/0.03333`，存在 6 个 `0→1` 和 4 个 `1→0`，说明边界异质且不是稳定整体改善。

## 4. 时间证据权衡

| 方法 | Evidence Recall | 帧精度 | 平均最大归一化空洞 |
|---|---:|---:|---:|
| Raw32 | 30/30 | 47.42% | 3.28% |
| 自研 MMR32 | 30/30 | **53.26%** | 12.51% |
| VideoITG | 30/30 | 52.17% | 17.51% |
| 保守 24+8 | 29/30 | 48.10% | 7.17% |

MMR32 与 VideoITG 提高证据帧精度，但扩大时间空洞；24+8 缩小空洞却损失一个证据单元。这解释了为何相关性更高并未稳定转化为 QA 增益。

## 5. 停止规则执行

1. 自研轻量版通过 Pilot50 后冻结配置，并在与此前 650 个问题/视频零重合的 Confirm-300C 验证；
2. Confirm-C 不用于权重、候选数或阈值扫描；
3. VideoITG 作为外部强基线单独评测，不冒充自研创新；
4. 唯一修正固定为每个时间箱 `3 Raw + 1 evidence`，没有派生第二组比例；
5. 修正因人工 Evidence Recall 下降而在 Qwen 前停止；
6. 因时间门禁未稳定通过，统一时空和 balanced-3000 按规则不运行。

## 5.1 组件消融结论

在 23 条人工问题、30 个视觉证据单元上，去问题或去 ASR 都使 Recall 从 30/30 降至 29/30；去覆盖把帧精度从 53.26% 提高到 54.35%，但平均覆盖从 7.96 降至 7.48 bins、最大空洞从 12.51% 增至 16.02%。去场景变化和去重复惩罚未造成退化。

因此论文只强调三项有证据支撑的技术对象：问题条件化相关性、ASR支持和时间覆盖约束。场景变化与重复抑制作为辅助项并如实报告弱消融，不包装成主要贡献。

## 6. 当前最优版本

- **QA 主版本：** Raw Uniform 32 + ASR + Qwen3-VL-8B；
- **时间证据解释分支：** 自研 MMR32，Evidence Recall 30/30、帧精度 53.26%；
- **空间证据解释分支：** 16+16 frame-cap + 查询条件化 OCR，Evidence Recall 29/30、Region Recall 10/10；
- **论文表述：** 固定 Token 预算下的问题条件化视听证据定位与失效分析，不宣称稳定提高总体 QA。
