# 方案 B：512 多中心低成本 A2 预注册（2026-07-31）

## 1. 动机

当前主方法 A2 为 12 视图/3,104 视觉 Token（8×512 + 2×(512+896)），相对 Uniform8（1,024 Token）约 2.9×。本方案验证：**若把 A2 降级为全 512 多中心（1,536 Token，约 1.5×），在完全同 token 的普通帧对照下，多中心裁剪是否能保持/提升精度**。

## 2. 两臂设计（唯一差异：裁剪 vs 普通帧）

| 视图 | `multicenter_512`（方法臂） | `uniform_extra4`（对照臂） |
|---|---|---|
| V1-V8 | MMR8 8 帧 512（1,024 token） | 相同 |
| V9 | 锚点1 中心1（响应中心）512 裁剪 | 锚点1 时刻的 512 普通帧 |
| V10 | 锚点1 中心2（deterministic_random_center）512 裁剪 | 锚点1 时刻的另一 512 普通帧 |
| V11 | 锚点2 中心1 512 裁剪 | 锚点2 时刻的 512 普通帧 |
| V12 | 锚点2 中心2 512 裁剪 | 锚点2 时刻的另一 512 普通帧 |
| **Token** | **约 1,536** | **约 1,536（同）** |

对照臂的"4 个普通帧"来自锚点时刻的 32 帧候选（同一 source_global_rank 的相邻帧或确定性选择），与 `deterministic_random_center` 完全对称。

## 3. 冻结的组件（全部复用，不新发明）

- 证据锚点：现有 `evidence_anchors`（fusion_score / visual / ASR / OCR rank score 融合选择，2 个/题）
- 响应中心：现有锚点 `bbox_norm` 中心
- 第 2 中心：**`deterministic_random_center`**（`build_avfunnel8_manifest_v1.py` 已冻结：question_id+anchor_index 的 SHA256 哈希，与证据中心保持距离）
- 裁剪：`crop_frame`（512×512）
- 回答器：clean Qwen3-VL-8B，同 Prompt（A2 verify/revise），`max_new_tokens=192`
- 裁判：DeepSeek answer-only（deepseek-v4-flash），同 Prompt SHA，10,000 次视频聚类 Bootstrap

## 4. 验证协议（预注册，不碰 Full 标签）

- **数据**：Confirm-600 同构的独立题集（与 OOF-500、Train-500、Pilot-300 视频不重叠）——先用 600 题验证方向
- **对照**：三臂同题——`Uniform8`（A0 基线）、`multicenter_512`、`uniform_extra4`
- **停止规则（预注册，先定死）**：
  - **方向门禁**：`multicenter_512` 相对 `uniform_extra4` 的 Strict/Relaxed 差 > 0（点估计为正）且 10,000 次 Bootstrap 的 Relaxed CI 下界 > -0.5pp，才进入下一步
  - **显著门禁**：若 600 题上 CI 完全为正 → 视为显著，考虑 Full 扩展
  - **止损**：若 600 题上点估计 ≤ 0 或 CI 下界 < -0.5pp → 停止，方案 B 不进入主方法，作为效率工作点记录
- **裁判**：三臂同题，DeepSeek answer-only，`not_human_gold=true`
- **Token 核算**：两臂均需精确记录实际视觉 Token（理论上 1,536，实测为准）

## 5. 预期结论的三种可能

| 结果 | 意义 | 论文处理 |
|---|---|---|
| 显著（CI 完全为正） | 多中心在低成本下仍优于普通帧 | 方案 B 作为效率工作点进入主表，与 896 高清版并置 |
| 方向正但不显著 | 低成本有微弱优势 | 作为"低成本工作点 + 方向证据"报告，不单独宣称 |
| 方向负/无 | 裁剪在低分辨率下失效 | 诚实报告：证明"高分辨率裁剪"是增益的必要条件，支持现有 896 主方法 |

## 6. 成本

- 600 题 × 2 臂 A2 推理：约 1-2 小时 GPU（512 分辨率，token 减半）
- 裁判：约 1,200 次调用（DeepSeek），约 5-10 元
- 总成本低，止损风险可控

## 7. 与现有实验的关系

- 不改变已冻结的 Qwen3 主方法（896 高清版仍为主结果）
- 方案 B 是**独立的效率工作点验证**，不触碰 Full 标签
- 若显著，作为"低成本部署选项"进入论文效率小节
