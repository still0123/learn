> 状态：有效。  
> 本文件是当前唯一有效的多 Agent 编排规范。  
> 旧版 `Agent编排执行方案.md` 和临时编排说明均视为历史参考，不再作为执行依据。  
> 唯一题目与术语真源：`docs/术语与题目真源.md`

---

## 1. 系统目标

本系统用于辅助完成硕士论文：

```text
基于视觉特征压缩与链式反思的广告视频问答方法
```

系统目标不是一次性生成文本，而是通过闭环多 Agent 机制持续打磨论文：

```text
查资料 → 写作 → 技术审查 → 创新性审查 → 语言结构审查 → 修改 → 主编定稿
```

核心质量目标：

1. 题目不变；
2. 主线统一；
3. 引用真实；
4. 不编数据；
5. 可复跑；
6. 有审查记录；
7. 每轮有通过门槛。

---

## 2. 唯一主线

所有 Agent 必须遵循：

```text
证据定位 → 证据压缩 → 证据解释 → 证据校验
```

禁止把论文主线写成：

```text
视觉压缩 + RAG + CoT + Self-Reflection
```

---

## 3. 固定 Agent 编号

以下编号固定，不再变更。

| 编号 | 名称 | 职责 |
|---|---|---|
| A0 | 主编 Agent | 总控、最终裁决、定稿 |
| A1 | 资料检索 Agent | 查资料、查引用、查风险 |
| A2 | 章节写作 Agent | 根据资料写初稿 |
| A3 | 技术审查 Agent | 审方法、公式、流程、实验接口 |
| A4 | 创新性审查 Agent | 防模块拼接、对比已有方法 |
| A5 | 语言结构审查 Agent | 审语言、结构、术语、衔接 |
| A6 | 修改 Agent | 根据审查意见修订 |
| A7 | 实验执行 Agent | 跑实验、填真实数据 |
| A8 | 答辩防守 Agent | 准备答辩 Q&A 和风险回应 |
| A9 | 格式排版 Agent | 套学校模板、图表、目录、参考文献格式 |

任何后续文档不得改变上述编号含义。

## 6. 通过门槛 Gates

每轮定稿前必须检查以下门槛。

## Gate 1：题目一致性

必须完全等于：

```text
基于视觉特征压缩与链式反思的广告视频问答方法
```

## Gate 2：术语一致性

必须遵循：

```text
术语与题目真源.md
```

## Gate 3：未核查引用检查

正文中不得出现未经核查却被当成真实引用的论文。

未核查必须标注：

```text
待核查
```

## Gate 4：虚构实验数据检查

不得编造：

- Accuracy；
- Token；
- Latency；
- Memory；
- Kappa；
- 人工评估结果；
- 消融实验数值。

没有数据写：

```text
待补
```

## Gate 5：待补残留检查

允许草稿中存在“待补”，但主编必须在 `gates.md` 中列出所有待补项。

## Gate 6：创新性风险检查

必须回答：

1. 是否像 AVAM + ASR？
2. 是否像普通 RAG？
3. 是否像 CoT Prompt？
4. 是否像 Self-Refine？
5. 是否像普通视频问答套广告场景？

若任一项风险为高，不能进入最终定稿，只能进入修订稿。

## 9. 夜间自动执行计划

用户睡觉期间可执行以下任务：

1. deep-research 核查真实参考文献；
2. 固化编排规范；
3. 根据闭环版第3/4章和已核查参考文献整合全文；
4. 生成新版完整论文 Markdown；
5. 生成新版完整论文 Word；
6. 生成参考文献清单；
7. 生成待补实验清单；
8. 生成明早检查摘要。

禁止事项：

- 不编实验数据；
- 不改题目；
- 不写入 efs-mgr；
- 不把未核查文献当真实引用。
