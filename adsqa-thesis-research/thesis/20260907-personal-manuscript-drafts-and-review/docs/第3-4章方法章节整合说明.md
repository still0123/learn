## 2. 章节定位

### 第 3 章定位

第 3 章对应题目中的“视觉特征压缩”。

但本章没有把视觉特征压缩写成简单减少 Token，而是写成：

```text
证据保留型视觉输入重构
```

核心是：

```text
高频过采样
→ 语义关键帧优选
→ 问题/ASR/OCR 三流响应图
→ 时序滑动窗口处理声画异步
→ 响应密度锚定局部证据
→ 全局—局部双流视觉输入
→ 多模态证据包
```

### 第 4 章定位

第 4 章对应题目中的“链式反思”。

但本章没有把链式反思写成普通 Self-Reflection，而是写成：

```text
证据回溯式链式反思
```

核心是：

```text
证据包
→ 证据驱动广告知识检索
→ 观察—知识匹配—分析—答案
→ 初始答案声明拆解
→ 视觉/文字/语音/营销声明逐项校验
→ 修正、拒答、降置信度或确认
```
