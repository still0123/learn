# 创新点一阶段性负结果与论文降级方案

**更新时间：** 2026-07-12  
**适用项目：** AdsQA 毕业论文创新点一  
**结论性质：** 已通过两个独立 Confirm-300、统一视觉预算与同口径 DeepSeek 裁判支持的阶段性结论

## 1. 一句话结论

在固定 Qwen3-VL-8B、32 个实际表示视图、11,664 视觉 Token、关闭二次采样的公平协议下，当前所有空间裁剪增强都没有稳定超过 Raw Uniform。部分机制显著改善区域定位，focus-context 也在 pilot50 两次正向，但均未转化为独立集上的稳定 QA 增益。

因此目前不能把“自适应裁剪提高 AdsQA 准确率”写成已成立结论。可以保留的技术贡献是：**问题条件化的视听响应、严格 Token 预算下的时空证据分配，以及定位与问答收益不一致的系统性实证**。

## 2. 最关键结果

| 数据/方法 | Strict | Relaxed | 相对直接对照 | 结论 |
|---|---:|---:|---|---|
| Confirm-300 Raw Uniform | **50.00%** | **68.50%** | - | 首个独立集最优 |
| Confirm-300 16+16 frame-cap | 48.00% | 65.33% | 对 Raw -3.17，CI 跨 0 | 替换时间帧有代价 |
| Confirm-300 train-null OCR | 46.33% | 64.67% | 对 frame-cap -0.67 | OCR 校准停止 |
| Pilot50 24+8 | 40.00% | 60.00% | 对 Raw -1 | 固定折中无增益 |
| Pilot50 focus-context 首轮/复评 | 54/52% | 66/65% | 对 Raw +6/+4 | 小样本方向正向 |
| Confirm-300B Raw Uniform | 50.33% | **68.50%** | - | 第二独立集对照 |
| Confirm-300B focus-context | **51.33%** | 66.83% | 36胜/216平/48负，-1.67，CI `[-4.83,+1.33]` | pilot 未复现 |

Confirm-300B 上 focus-context 的 Strict 虽高 1 个百分点，但 Relaxed 配对均值为负。分数转移同时包含 29 个 `0.5->1`、20 个 `0.5->0` 和 28 个 `1->0.5`，说明它使回答更极化，不能只报告 Strict。

## 3. 已排除的解释

这些负结果不能归因于常见协议问题：

- 两个方法使用同一 Qwen3-VL checkpoint 和同一 Answer Prompt；
- 每题均为 32 个实际表示/提交视图和 11,664 Token；
- processor 二次采样关闭；
- Confirm-300B 中 Raw 与 focus-context 的 32 个源帧逐题 300/300 完全一致；
- DeepSeek 使用历史 Answer-only Prompt，当前实际模型为 `deepseek-v4-flash`；
- 600/600 评分可解析，配对 Bootstrap 为 10,000 次；
- Confirm-300B 与 pilot50、首个 Confirm-300 的问题和视频均零重合；
- GPU OOM 项均被重新推理补齐，没有把缺失结果计 0。

## 4. 四条路线分别证明了什么

### 4.1 OCR 可靠性校准

缓存 OCR 把人工证据单元从 26/30 提高到 29/30、Region Recall 从 7/10 提高到 10/10，但 pilot50 DeepSeek 与 frame-cap 完全持平，Confirm-300 的 train-null 版本反而低 0.67 个百分点。

它证明了“文字区域定位可改善”，没有证明“整体 AdsQA QA 可改善”。

### 4.2 固定全局/局部预算

`32+0 -> 24+8 -> 16+16` 的视觉时间召回为 `30/30 -> 30/30 -> 29/30`，Region Recall 为 `0/10 -> 4/10 -> 7/10`。24+8 的确形成指标折中，但 QA 没有提高。

它证明了固定比例存在可解释的时间/空间权衡，没有找到统一最优比例。

### 4.3 Focus-Context 保时序编码

该方法在同一个视觉槽位内编码完整帧和 ROI，保留全部 32 个时间点。pilot50 两轮都优于 Raw，但 Confirm-300B 的 Relaxed 配对均值为负。

它证明了“局部图挤占时间帧”不是唯一问题；错误或无关 ROI 本身也会干扰抽象问题。

### 4.4 Contrastive-Gradient 定位

全局图文匹配的 gradient x input 把响应 concentration 从 0.0125 提高到 0.1534，但 Region Recall 仍为 7/10，只产生 GBP340 与 Maisa Rojas 的一得一失。

它证明了显著图更尖锐不等于证据定位更正确，因此没有进入 QA。

## 5. 根本原因

AdsQA 大量问题询问受众、情绪、叙事策略、隐喻和品牌使命。这些答案通常依赖跨时间叙事、ASR 和整段广告语义，而不是一个可裁剪的单一空间对象。

当前 CLIP 空间响应使用抽象整句与 patch token 对齐，平均 concentration 约 0.01；OCR 和梯度能够改变局部图，但不能稳定判断“这个 ROI 是否足以回答问题”。84 个 Confirm-300B 变化样本中有 82 个没有显式文字意图，也支持这一判断。

## 6. 当前最优可用版本

### QA 主结果

使用 **Raw Uniform 32 帧 + ASR + Qwen3-VL-8B**。它在两个独立 Confirm-300 上的 Relaxed 都是 68.50%，是目前最稳定的问答配置。

### 证据定位/可解释性

使用 **16+16 frame-cap + 查询条件化缓存 OCR** 生成证据可视化。它的人工 Evidence Recall 为 29/30、Region Recall 为 10/10，但必须明确标注为解释性分支，不能宣称提高整体 QA。

### 不应进入主表的版本

- 统一 80% 大裁剪；
- 跨帧 OCR 归一化；
- train-null OCR QA 候选；
- 固定 24+8；
- 固定 8 帧 focus-context；
- contrastive-gradient QA。

## 7. 推荐论文降级方案

### 推荐方案：从“准确率创新”降为“预算约束证据定位与失效分析”

创新点一改为：

> 面向广告视频问答的 Token 预算约束视听证据定位框架。该框架统一问题、ASR 与 OCR 响应，在严格固定视觉 Token 下显式分配时间覆盖和空间细化预算，并揭示证据定位改善与生成式问答准确率之间的非单调关系。

论文中可以成立的技术与实验贡献：

1. 实际视觉 Token、表示帧和二次采样均可审计的公平协议；
2. 问题/ASR/OCR 响应、局部候选和预算分配器；
3. `32+0/24+8/16+16/focus-context` 的完整消融；
4. Answer、Evidence Unit、Temporal Recall、Region Recall 的联合评价；
5. 两个双重独立 Confirm-300 对 pilot 假阳性的验证。

必须删除或改写的主张：

- 删除“自适应裁剪稳定提高 AdsQA 总体准确率”；
- 不用定位指标替代 QA 指标；
- 不把 pilot50 的 focus-context 正向写成最终结果；
- 不把 Strict 单指标的 +1 写成独立集增益。

### 若必须保留准确率创新

停止空间裁剪主线，转向有公开视频源码的时间证据选择器，例如 VideoITG/GroundVTS，并先验证其相对 Raw Uniform 的独立集收益。该方向会成为新的技术方案，不应伪装成当前裁剪方法的小修改。

## 11. 创新点二衔接状态（2026-07-12，运行中）

本文件的创新点一负结论保持不变。为检验“证据已找到但模型未稳定利用”这一诊断，已在与所有 Confirm 集零重合的训练开发集启动反事实充分性 MVP：固定 Raw 或冻结 MMR32 初始证据，构造 E+/E-，并在低充分性时执行一次 24+8 固定预算局部补全。该工作尚未产生 QA 结果，不能作为撤销或弱化本文件降级结论的依据；只有其独立开发集和后续冻结 Confirm 验证均通过门槛，才会重新评估创新点一的论文定位。

## 12. 创新点二 Pilot 负结果（2026-07-13）

反事实充分性 MVP 已完成 100 条零泄漏开发集的四组对照。尽管 97/100（Raw）和 98/100（MMR）样本都呈现正确方向的 `s(E+) > s(E-)`，低充分性时的 24+8 补全并未转化为 QA 收益：Raw Relaxed `58.0%→55.0%`，MMR Relaxed `55.5%→54.0%`。MMR+二仅有一条 `0→1`，却有两条 `1→0`；品牌、价格等关键类别无稳定改善。

因此不扩展该策略到 300 条或 Confirm-300C，也不再调充分性阈值、破坏强度或补全比例。它只能作为“反事实敏感性与生成式答案纠错并不等价”的补充负结果，不能单列为已成立的第二准确率创新。创新点一的降级结论保持不变。

## 13. 后续轻量验证器与本文件结论的关系（2026-07-13）

已启动一个严格收缩的新阶段：不修改 Raw/MMR32 选帧、32 视图预算、24+8 补看候选、Qwen3-VL 或回答 Prompt，只把旧条件似然切换规则替换为反事实监督的轻量声明—证据验证器。该阶段使用 Train500 训练，并在调参前联合冻结新的 Dev300 与 Confirm-D300；只有 Dev 门禁通过才允许一次 Confirm-D。

## 15. 问题自适应路由最终门禁（2026-07-16）

Raw 与 MMR32 在 Evidence-300 上存在明显逐题互补，因此额外进行了一次回答前路由门禁。路由器使用冻结的 `200/50/50` 视频隔离划分，只读取问题、ASR 可靠性、MMR 响应分布、Raw/MMR 帧差异和时间覆盖统计；标准答案与裁判分数只作为监督，不进入特征。

固定 16 维单隐层 MLP 在内部验证中最佳 epoch 为 `1`，正例召回为 `0`。校准 50 条没有阈值满足预注册约束，fail-closed 阈值为 `0.7874`；开发 50 条最终切换 `0` 条，Strict/Relaxed 仍为 Raw 的 `62.00%/74.00%`，门禁失败。
