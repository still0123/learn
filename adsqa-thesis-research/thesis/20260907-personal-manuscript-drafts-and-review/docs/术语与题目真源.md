## 1. 唯一论文题目

```text
基于视觉特征压缩与链式反思的广告视频问答方法
```

硬规则：

1. 任何 Agent 不得修改该题目；
2. 若需要英文题目，必须另行标注为“英文译名”，不得替代中文题目；
3. 文中不得出现其他中文题目作为正式题目。

## 2. 唯一主线

本文唯一主线为：

```text
证据定位 → 证据压缩 → 证据解释 → 证据校验
```

展开解释：

1. **证据定位**：利用用户问题、ASR 邻域语义、OCR/Logo 显著性和视觉特征定位广告视频中的关键证据；
2. **证据压缩**：将视觉特征压缩解释为证据保留型视觉输入重构，不是单纯减少 Token；
3. **证据解释**：基于证据包进行广告知识检索和营销语义解释；
4. **证据校验**：对初始答案中的声明进行证据回溯式链式反思。

任何章节不得把本文主线写成：

```text
视觉压缩 + RAG + CoT + Self-Reflection
```

这种写法只可作为“容易被误解的旧表述”出现，不能作为本文方法主线。

## 3. 统一术语表

| 统一术语 | 可接受别称 | 禁止/慎用表达 | 说明 |
|---|---|---|---|
| 视觉特征压缩 | 证据保留型视觉输入重构 | 简单 Token pruning、普通裁剪 | 必须解释为保留关键证据并控制输入预算 |
| 视听-文字时空响应图 | 综合响应图、响应图 | 热力图乱用、注意力图乱用 | 首次出现应使用完整术语 |
| ASR 邻域响应 | 语音邻域响应 | ASR 直接拼接 | 强调 ASR 参与视觉定位，不只是 Prompt 文本 |
| OCR/Logo 文字显著性 | 文字响应、品牌线索响应 | OCR 文本简单输入 | 强调文字/Logo 参与局部区域定位 |
| 局部高分辨率证据视图 | 局部视图、局部证据视图 | ROI 裁剪图单独作为核心术语 | 强调局部视图是证据视图，不是普通 ROI |
| 全局语境视图 | 全局视图 | 原图缩放 | 强调保留场景、人物关系和情绪氛围 |
| 证据包 | 多模态证据包 | 简单特征集合 | 第3章输出，第4章输入，第5章评估对象 |
| 证据驱动广告知识检索 | 证据驱动 RAG | 普通 RAG、广告 RAG | 强调知识必须由 evidence_id 触发 |
| 证据感知重排序 | evidence-aware rerank | 普通 Top-K | 强调根据视频证据过滤知识 |
| 观察—知识匹配—分析—答案 | 结构化推理协议 | CoT Prompt | 强调中间步骤受证据和知识许可约束 |
| 声明级证据回溯式链式反思 | 声明级回溯校验、证据回溯式校验 | Self-Reflection、Self-Refine 直接等同 | 强调按声明类型回查证据 |
| 幻觉率 | 事实性幻觉率 | 绝对消除幻觉 | 只能说降低，不能说消除 |
| 证据一致性 | evidence consistency | 可解释性泛泛表达 | 衡量答案声明是否被证据支撑 |
| 知识一致性 | knowledge consistency | 专业性泛泛表达 | 衡量营销概念是否被正确使用 |

## 4. 禁用或慎用表达

### 4.1 禁止夸大

禁止写：

```text
完全解决幻觉问题
消除所有错误
显著降低 40% 推理时间（无数据时）
彻底突破现有方法
```

可替换为：

```text
降低事实性幻觉风险
缓解关键证据遗漏问题
在实验中验证其效率收益
在特定广告视频问答任务上提升可靠性
```

### 4.2 禁止编造数据

若没有真实实验结果，必须写：

```text
待补
待运行
阶段性结果
需复核
```

不得编造 Accuracy、Token、Latency、Memory、Kappa 等数值。

### 4.3 禁止把辅助模块写成主创新

RAG、CoT、Self-Reflection 不能作为单独主创新写成：

```text
本文创新性地引入 RAG
本文创新性地使用 CoT
本文创新性地使用自我反思
```

必须写成：

```text
本文基于证据包进行广告知识检索
本文将推理过程约束为观察—知识匹配—分析—答案
本文对答案声明进行证据回溯式链式反思
```

## 6. 第3章必须坚持的表达

第3章必须把视觉特征压缩解释为：

```text
证据保留型视觉输入重构
```

必须说明压缩包含：

1. 帧级压缩；
2. 区域级压缩；
3. Token 与计算开销压缩。

必须显式区别于：

- AVAM；
- 普通 ROI 裁剪；
- 普通 ASR Prompt；
- 普通均匀采样；
- 普通 CLIP Top-K。
