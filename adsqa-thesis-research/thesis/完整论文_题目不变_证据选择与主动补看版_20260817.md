# 基于视觉特征压缩与链式反思的广告视频问答方法

> 版本说明：本稿为论文全稿重写版（2026-08-17），主线为"问题驱动的视听证据选择（创新点一）+ 证据缺口驱动的主动补看与保守答案决策（创新点二）"。所有实验数字来自 2026-07-31 冻结结果与后续独立确认实验，均为大模型机器裁判口径（`not_human_gold=true`）。按写作决策，本稿不包含空间裁剪相对同预算完整帧的精度归因实验与同 Token 裁剪对照实验。

## 摘要

随着短视频平台与数字营销产业的发展，广告视频已成为品牌传播的核心载体。广告视频在短时间内密集呈现画面、旁白、字幕、品牌标识与价格信息，具有关键证据短时出现、声画非严格同步、语义高度压缩等特点。现有多模态大语言模型在处理此类视频时，通常依赖均匀采样构造视觉输入，容易遗漏决定答案的短时证据；而简单增加帧数与分辨率又会引入大量冗余信息并推高计算成本。在答案生成侧，让模型对初始答案进行无约束的反思重写，已被本文实验证明会稳定损害准确率。

针对上述问题，本文提出一种"问题驱动的证据选择—证据缺口驱动的主动补看"两阶段广告视频问答方法。第一阶段（创新点一）：以用户问题为查询，融合视觉相关性、视频内 OCR 文字与分段 ASR 语音的时间索引，在 64 帧候选上采用最大边际相关（MMR）同时优化问题相关性与帧间冗余，构造低预算、时间排序的初始证据；当初答证据支持不足时，进一步融合多模态响应定位时间分散的证据锚点，按需补充完整帧与响应密度锚定的自适应多尺度裁剪证据视图，并为每个证据输出帧号、时间戳、响应来源与视觉 Token 的可审计路径。第二阶段（创新点二）：将初答的不足归因为可定位的证据缺口，由缺口类型决定补看动作——证据已充分则直接保留初答（DIRECT），缺少事件、时序或语音证据则补看新的时间位置（LOOK_TIME），缺少文字、标识或局部属性证据则补看证据锚点区域（LOOK_REGION）；补看后独立生成候选答案，再由以真实正反声明构造监督、以最小破坏反事实证据对（E+/E−）进行对比校准的轻量声明—证据验证器，对初答与候选进行同口径充分性比较，仅当候选同时满足绝对支持阈值与相对提升裕量时才替换初答，否则保守回退，从而抑制无约束反思带来的错误修改。

在 AdsQA 数据集 7,844 题完整评测集上的实验表明：本文证据选择方法（MMR8）相对均匀采样基线提高 Strict/Relaxed 准确率 3.61/3.89 个百分点；完整两阶段方法相对 MMR8 进一步提高 7.00/10.12 个百分点（视频聚类 Bootstrap 95% 置信区间完全为正），相对均匀采样基线累计提高 10.61/14.00 个百分点。在官方 GRPO 训练模型 ReAd-R 共同基座上，方法迁移取得 0.83/0.67 个百分点的稳定小幅增益（置信区间完全为正，无错误修改）；在外部数据集 E-VAds 的 1,000 题独立确认集上，完整方法相对均匀采样与 MMR8 的五分制准确率增益分别为 2.60 与 1.70 个百分点，三项指标置信区间均为正。机制分析进一步表明：无门控的自由反思使准确率下降 8.87/6.66 个百分点，而本文充分性门控将其伤害完全抑制；补看增益主要来自证据缺口明确指向区域细节的问题子集。实验同时报告了触发率、平均视觉 Token、推理延迟与错误修改风险等成本指标，验证了方法在准确率优先工作点下的代价与风险特征。

# 第1章 绪论

## 1.1 研究背景

随着短视频平台、流媒体服务和数字营销产业的快速发展，广告视频已成为品牌传播、产品推广和用户转化的重要载体。与一般视频相比，广告视频通常在较短时长内集中呈现商品、品牌、人物、场景、字幕、旁白、音乐和情绪节奏等多模态信息，并借助视觉隐喻、夸张对比、情绪共鸣和行动召唤等方式传达营销意图。广告视频问答任务要求模型根据给定视频和自然语言问题生成准确答案，不仅需要识别画面中出现的对象和动作，还需要理解广告背后的产品卖点、情绪诉求、说服策略和目标受众。

近年来，多模态大语言模型在图像问答、视频问答和开放式视觉理解任务上取得了显著进展。然而，将该类模型直接应用于广告视频问答仍面临两方面突出困难。

第一，**关键证据短时出现且跨模态分散，均匀采样容易遗漏**。广告中的价格字幕、品牌标识、产品细节和促销信息往往只在少数几帧中出现；决定答案的语音内容与画面内容也常常非严格同步。以固定间隔均匀抽取少量帧作为视觉输入，是当前视频问答系统最常用的做法，但它在信息密度高度不均匀的广告视频上存在系统性的证据遗漏风险。而单纯按"与问题相似"挑选帧，又容易选出大量内容重复的画面，浪费有限的视觉 Token 预算。

第二，**初答缺乏证据支持时，模型缺少"回去补看什么"的机制**。一种常见做法是让模型对初始答案进行自由反思并重写。本文第5章的实验表明，这种无约束反思在广告视频问答上会稳定损害准确率（Strict 口径下降 8.87 个百分点），因为模型在没有新证据的情况下重写答案，主要是在重新组织已有信息甚至引入幻觉。真正需要的机制是：先判断初答缺少哪一类证据，再回到视频中定向获取该类证据（新的时间位置或局部区域细节），最后只有在补看后的新答案确实获得更强证据支持时才允许替换初答。

## 1.2 研究意义

从理论意义上看，本文将广告视频问答中的"看什么"与"是否再看"统一为证据组织问题：在固定视觉 Token 预算下，证据选择需要同时优化问题相关性与帧间冗余；在初答生成后，补看决策需要从答案风险出发，将"何时补看、补看哪里、是否改答"转化为可度量、可审计的显式决策过程。本文提出的证据缺口分类（时间缺口与区域缺口）与保守替换门控，为高信息密度视频理解中的选择性推理提供了一条可检验的技术路线。

从应用意义上看，广告视频问答可服务于广告创意分析、素材审核、投放效果评估和智能营销决策等场景。相比只输出表层视觉描述或无依据营销解释的模型，具备证据选择、定向补看和充分性校验能力的问答系统能够提供更可靠、可追溯的分析结果：每个答案都可以回溯到具体的帧号、时间戳、OCR 文本、ASR 片段与补看动作记录，有助于提升广告内容理解工具在实际业务中的可用性与可信度。

## 1.3 研究问题

本文围绕以下三个研究问题展开：

**RQ1：如何在固定视觉预算下选择与问题相关且不冗余的视听证据？** 广告视频关键线索短时出现且模态分散，本文以问题为查询，融合视觉相关性、OCR 与分段 ASR 时间索引，以最大边际相关准则构造初始证据，并在需要时定位时间分散的证据锚点（第3章）。

**RQ2：当初答证据支持不足时，系统应补看什么、以及是否采纳新答案？** 本文将初答不足归因为可定位的证据缺口，据此决定 DIRECT/LOOK_TIME/LOOK_REGION 三类补看动作；对补看后候选与初答进行同口径充分性比较，以绝对阈值加相对裕量的保守门控决定是否替换（第4章）。

**RQ3：两阶段联合方法能否在控制成本与错误修改风险的前提下稳定提高准确率？** 本文在 AdsQA 完整评测集、官方训练基座 ReAd-R、跨基座 Qwen2.5 与外部数据集 E-VAds 上验证联合有效性，并报告触发率、视觉 Token、延迟与错误修改风险（第5章）。

## 1.4 主要研究内容

本文主要研究内容包括：

1. 问题驱动的视听证据选择方法：64 帧候选构造、问题相关视觉评分、MMR 冗余受控选择、多模态响应融合的证据锚点定位与响应密度锚定的自适应多尺度裁剪视图生成；
2. 证据缺口驱动的主动补看方法：正反声明与反事实证据对（E+/E−）的验证器训练、声明—证据支持度验证、基于问题逻辑叶与模态状态的证据缺口诊断、DIRECT/LOOK_TIME/LOOK_REGION 动作决策与补看执行；
3. 保守答案决策方法：证据增强候选的独立生成协议、绝对支持阈值与相对提升裕量门控、回退机制；
4. 面向 AdsQA 与 E-VAds 的系统性实验评估：主实验、跨基座与外部数据集独立确认、组件消融、机制分析、成本与风险分析。

## 1.5 本文创新点

**（1）提出问题驱动的冗余受控视听证据选择与证据锚点定位方法。** 针对广告视频关键证据短时出现、均匀采样易遗漏、相似度选帧易冗余的问题，本文以问题为查询，在 64 帧候选上以最大边际相关准则同时优化问题相关性与帧间冗余，构造低预算、时间排序的初始证据；当初答支持度不足时，融合问题—视觉响应、OCR 文字峰与 ASR 时间段定位两个时间分散的证据锚点，按需补充完整帧与响应密度锚定的自适应多尺度裁剪视图——多尺度候选框中响应密度最高的局部区域经裁剪与上采样形成局部高分辨率证据视图，与完整帧全局语境并存——并输出帧号、时间戳、响应来源与视觉 Token 的可审计证据路径。该方法在 AdsQA 完整评测集上相对均匀采样提高 Strict/Relaxed 准确率 3.61/3.89 个百分点（置信区间完全为正）。

**（2）提出证据缺口驱动的主动补看与保守答案决策方法。** 针对无约束反思损害准确率、盲目补看浪费预算的问题，本文将初答不足归因为可定位的证据缺口，由缺口类型决定补看动作：证据已充分则直接保留初答（DIRECT），缺少事件、先后关系或语音证据则补看新的时间位置（LOOK_TIME），缺少文字、标识或局部属性证据则补看证据锚点区域（LOOK_REGION）；补看后基于增强证据独立生成候选答案，再由同一声明—证据验证器（以真实正反声明构造监督、以最小破坏的反事实证据对 E+/E− 进行对比校准与扰动诊断）对初答与候选进行充分性比较，仅当候选同时满足绝对支持阈值与相对提升裕量时才替换，否则回退初答。完整两阶段方法在 AdsQA 完整评测集上相对第一阶段证据选择进一步提高 7.00/10.12 个百分点（置信区间完全为正），且充分性门控将无约束反思造成的 8.87 个百分点准确率下降完全抑制。

## 1.6 术语界定

本文题目中的两个核心术语在正文中按如下方式界定和使用：

- **"视觉特征压缩"**：指固定视觉 Token 预算约束下的问题驱动证据组织与按需多尺度呈现：在有限视图数与视觉 Token 内选择与问题最相关、彼此最不冗余的证据帧，并在补看时以响应密度锚定的自适应多尺度裁剪提供局部高分辨率证据视图、同时保留完整帧全局语境。需要说明的是，本文不主张任何空间裁剪策略相对同预算完整帧的独立准确率优势，也不包含此类对照实验；自适应裁剪在本文中的角色是证据呈现与视觉 Token 的预算控制。
- **"链式反思"**：指证据缺口驱动的选择性补看与保守答案决策，即先诊断初答缺少哪类证据、再定向补看、最后以充分性门控决定是否替换答案；而不是指让模型在不引入新证据的情况下自由输出长思维链并重写答案。第5章将证明后者在广告视频问答上有害。

此外，"证据锚点"指由多模态响应融合确定的、带有帧号与时间戳的证据时刻及其空间响应中心；"补看"指在初答生成后从视频中额外获取证据的动作；"充分性"指答案声明所获证据支持的程度。

# 第2章 相关理论与技术基础

## 2.1 广告视频问答与广告视频理解

广告视频问答（Advertising Video Question Answering）要求模型在理解广告画面、语音、文字与营销意图的基础上回答自然语言问题。AdsQA 基准系统刻画了广告视频快节奏、高信息密度、高阶营销语义的特点，并指出通用模型在广告意图、情绪诉求与说服策略理解上的不足；其官方基座模型 ReAd-R 在 Qwen2.5-VL 上通过组相对策略优化（GRPO）强化学习训练，是本领域代表性强基线。VideoAds 等基准进一步表明，广告理解需要同时覆盖视觉查找类问题与营销推理类问题。

与通用视频问答相比，广告视频问答有三个与本文直接相关的特性：其一，价格、品牌标识、促销条款等决定性证据常以屏幕文字形式短时出现，对帧选择高度敏感；其二，旁白与画面非严格同步，语音证据需要与视觉证据在时间轴上对齐；其三，营销策略类问题容易诱发模型的无依据泛化解释，答案校验必须回到视频内证据。这些特性共同指向"以证据为中心"的方法设计。

## 2.2 多模态大语言模型与视频理解

多模态大语言模型（MLLM）将视觉编码器与大语言模型结合，在图像与视频理解任务上取得了广泛成功。Qwen2.5-VL 与 Qwen3-VL 系列支持动态分辨率与多图输入，是本文实验的主要基座：本文主实验使用 Qwen3-VL-8B，共同基座实验使用 AdsQA 官方 GRPO 训练的 Qwen2.5-7B-VL-ReAd-R，跨基座实验使用 Qwen2.5-VL-7B-Instruct。

视频输入受上下文长度与计算成本约束，通常需要将视频压缩为有限帧序列。模型对提交帧数的实际编码受二次采样机制影响：本文在实现中发现，提交的帧数并不必然等于实际编码的帧数，因此本文所有实验均显式关闭二次采样，并逐题记录实际视觉 Token 数，保证视觉预算可审计。GRPO 等强化学习方法（如 DeepSeekMath 所提出）被用于训练推理增强型多模态模型，ReAd-R 即属此类；本文与之互补，在推理阶段以证据组织与选择性补看提升固定基座的表现。

## 2.3 视觉证据选择与关键帧选择

视觉证据选择研究如何在有限帧预算内挑选与问题最相关的帧。现有方法大致分为三类：

1. **均匀采样**：以固定间隔抽取帧，实现简单且无查询依赖，是大多数视频问答系统的默认策略，但在信息密度不均匀的视频上存在系统性遗漏风险。
2. **查询相关排序**：以问题为查询计算帧相关性并取最高分帧，代表性做法基于 CLIP 等对比式视觉—语言模型。此类方法只优化相关性，不考虑所选帧之间的冗余，容易选出内容高度重复的画面。
3. **相关性与多样性联合优化**：最大边际相关（MMR）准则由 Carbonell 与 Goldstein 在文本检索中提出，迭代选择"与查询相关且与已选集合不相似"的条目，在查询摘要与搜索多样性中广泛使用。本文将其引入广告视频证据选择，以问题相关性与帧间冗余的联合排序构造初始证据。

在时间定位方向，VideoITG 等工作训练时间定位器为问题挑选关键帧；OneClip-RAG 提出问题引导的连续片段切分与检索，强调连续上下文；LeAdQA 先改写问题中的因果与时间约束，再进行细粒度时刻定位，提示时间关系类问题需要显式处理"先后、变化、动作结果"。这些工作共同表明：帧/片段选择的质量取决于是否显式建模问题所需的证据类型。本文的证据锚点定位进一步融合视频内 OCR 与分段 ASR 的时间索引，使证据时刻的选择同时覆盖视觉、文字与语音三类模态。

## 2.4 视听协同与声画异步建模

广告视频的语音旁白（经 ASR 转写）与屏幕文字（经 OCR 识别）是回答营销类问题的重要证据源。声画异步指旁白内容与画面内容在时间轴上不严格对齐：旁白可能在画面出现之前或之后描述产品特性。已有视听理解工作通常在特征层融合音频与视觉信号；本文则在不改动基座模型的前提下，将 ASR 段落与 OCR 事件的时间戳作为证据索引参与帧选择与锚点定位，例如在时间关系类问题上利用 ASR 段落边界确定补看位置，在文字细节类问题上利用跨帧稳定出现的 OCR 事件确定证据时刻。这种"索引级"视听协同不依赖模型内部结构，可迁移到任意视觉—语言模型。

## 2.5 反思机制、主动视觉获取与工具调用式推理

**反思机制。** 思维链提示让模型输出中间推理步骤；Reflexion 等工作进一步让模型对先前答案进行语言化反思并自我修正。在多模态领域，此类反思被用于降低幻觉。然而，反思的有效性依赖于反思过程中获得新信息；当模型只是在相同输入上重新生成时，反思更可能引入新的随机错误。本文第5章的对照实验（无门控自由反思相对初始答案 Strict 下降 8.87 个百分点）证实了这一风险，并将其作为本文设计保守门控的直接动机。

**主动视觉获取。** 近期一系列工作研究让模型在推理过程中主动决定获取哪些视觉内容：LFPC 以信息缺口驱动的精确聚焦为核心，先学习何时聚焦、再学习如何操作；AdaptVision 通过自适应视觉获取提升视觉—语言模型效率；VisionLeaf 采用熵引导的叶节点优先推理，优先补足最不确定且必需的证据；Active-Look 在多个定位信号不一致时触发主动再看；LENS 按问题自适应分配空间与时间预算；OmniReasoner 在推理过程中调用带时间锚点的工具并输出可审计的多模态工具轨迹。在区域细化方向，DeepEyes（arXiv:2505.14362）、ZoomEye 与 VLM-R3 探索了多轮放大、树搜索与交错区域细化等学习式策略。这些工作共同指向"按需获取证据"的范式，但大多依赖专门的策略训练。本文的差异化路线是：以规则化、可审计的证据缺口分类（DIRECT/LOOK_TIME/LOOK_REGION）作为第一轮实现，在冻结基座上验证"缺口驱动的补看 + 充分性门控替换"这一机制本身的有效性，学习式控制器留作未来工作。

**置信度校准与增量决策。** QANTA 等工作强调根据置信度决定何时继续接收证据、何时提交答案，与本文的支持度触发和保守替换在思想上一致；SEATS 的阶段自适应视听 Token 分配则为预算效率方向提供了参考。

## 2.6 检索增强、答案验证与大模型裁判

检索增强生成（RAG）通过检索外部知识辅助生成，Self-RAG 等工作进一步引入检索与自我反思的控制器。本文在早期阶段曾探索广告营销知识库检索，但实验表明其增益不稳定，因此最终方法将全部证据来源限定在视频内部（视觉帧、OCR、ASR），以避免外部知识引入幻觉。在答案验证方向，本文将答案拆解为可核查声明，训练轻量声明—证据验证器估计支持度，用于触发补看与门控替换，这与声明级事实验证（Fact Verification）的任务形式相近。

在评测侧，大模型裁判被广泛用于开放式问答评分。本文采用冻结提示词的 DeepSeek 裁判按答案等价性输出多级评分，并对全部结果标注 `not_human_gold=true`；同时设计人工一致性抽检方案（第5.11 节）以补充机器裁判的可信度证据。统计检验采用按视频聚类的配对 Bootstrap 置信区间，以适应同一视频多题的非独立性。

## 2.7 本章小结

本章综述了广告视频问答的任务特性、多模态大语言模型与视频输入预算约束、视觉证据选择的三类方法、视听协同的证据索引作用，以及反思机制与主动视觉获取的最新进展。现有工作或在策略训练上较重、或未将"补看什么"与"是否改答"联合建模，且普遍缺乏对反思伤害的显式控制。这为本文"问题驱动证据选择 + 证据缺口驱动主动补看与保守决策"的两阶段框架提供了直接的改进空间。

# 第3章 问题驱动的视听证据选择方法

## 3.1 本章引言

广告视频问答的第一道关卡是视觉输入构造。现有多模态大语言模型通常以均匀采样抽取固定数量的帧，这一策略在信息密度均匀的长视频上尚可接受，但在广告视频上面临两方面失衡：一方面，价格、品牌标识、产品细节等决定性证据可能只在极少数帧中出现，均匀采样存在系统性的遗漏概率；另一方面，广告中大量画面内容高度重复（如持续的产品展示、同一场景的多个角度），把预算花在冗余帧上挤占了真正关键证据的空间。

仅按"与问题相关"排序选帧也不能解决问题：相关性排序天然倾向于集中选择同一语义事件的多个相似帧，导致证据多样性不足。本章提出问题驱动的冗余受控视听证据选择方法，核心思想是：**把视觉预算的分配建模为"问题相关性最大化"与"帧间冗余最小化"的联合优化，并在初答证据不足时，将选择单位从"帧"升级为"融合多模态响应的证据锚点"。** 本章方法既是独立的初始证据构造模块，也为第4章的主动补看提供证据定位基础设施。

本章贡献包括：（1）64 帧候选与 OCR/ASR 时间索引的多模态证据召回；（2）问题相关视觉评分与 MMR 冗余受控的 8 帧初始证据选择；（3）融合问题—视觉、OCR 与 ASR 响应的证据锚点定位，含响应峰空间中心与响应熵不确定性；（4）基于响应密度锚定的自适应多尺度裁剪证据视图与可审计证据包。裁剪在本文中的定位是证据呈现与 Token 预算控制机制，本章不涉及裁剪相对同预算完整帧的准确率比较。

## 3.2 问题定义与总体框架

### 3.2.1 问题定义

给定广告视频 $V$、自然语言问题 $q$，以及从视频中离线提取的多模态索引：

- 候选帧集合 $F=\{f_1,\dots,f_{64}\}$，按时间顺序均匀覆盖全片，每帧带有帧号与时间戳；
- OCR 事件集合 $O=\{(t_k, b_k, c_k, s_k)\}$，其中 $t_k$ 为时间戳，$b_k$ 为文字区域，$c_k$ 为识别文本，$s_k$ 为识别置信度；
- ASR 段落集合 $A=\{(\tau_m, \text{text}_m)\}$，其中 $\tau_m=[t_m^{start}, t_m^{end}]$ 为语音时间段。

给定初始视觉预算 $B_0$（本文为 8 视图、1,024 视觉 Token）与补看预算 $B_2$（12 视图、不超过 4,096 视觉 Token），证据选择问题定义为两个子问题：

**初始证据选择**：从 $F$ 中选择规模为 $K=8$ 的帧子集 $S_0$，在预算 $B_0$ 内最大化问题覆盖与模态覆盖、最小化帧间冗余。

**证据锚点定位**（由第4章的低支持触发调用）：从 $F$ 及多模态索引中确定 $M=2$ 个证据锚点 $\{(t_j^{a}, \mathbf{x}_j^{a})\}_{j=1}^{M}$，其中 $t_j^{a}$ 为证据时刻，$\mathbf{x}_j^{a}$ 为该时刻的空间响应中心；两锚点应时间分散、来源互补，且不与初始证据 $S_0$ 已覆盖的时刻重复。

### 3.2.2 总体框架

本章方法的处理流程为：

```text
广告视频 + 问题
→ 离线多模态预处理（64 帧候选、OCR 事件、分段 ASR）
→ 问题相关视觉评分（第3.4 节）
→ MMR 冗余受控选择 8 帧（λ = 0.70）（第3.4 节）
→ 时间排序初始证据 S0 → 送入基座模型生成初始答案 A0（第4章）
【低支持触发时】
→ 多模态响应融合（问题—视觉 / OCR 峰 / ASR 时间段）（第3.5 节）
→ 两个时间分散证据锚点 + 响应峰空间中心 + 响应熵不确定性
→ 每锚点：完整帧 + 自适应多尺度裁剪视图（预算受控）（第3.6 节）
→ 证据包（帧号、时间戳、来源、Token、二次采样状态）（第3.7 节）
```

## 3.3 多模态预处理与候选证据召回

**候选帧构造。** 对视频按时间均匀网格抽取 64 帧作为候选池。64 的规模在本文数据集上覆盖了广告视频的典型时长与镜头切换频率，既保证短时证据至少落入若干候选帧，又控制了离线评分的计算量。所有候选帧按时间顺序编号，保留原始分辨率以支持后续高分辨率视图生成。

**OCR 事件提取。** 对候选帧运行视频 OCR，将同一文本在相邻帧的重复检测合并为跨帧事件，记录每次出现的置信度、区域与时间戳。跨帧出现次数与平均置信度构成 OCR 事件的可靠性度量：在后续锚点定位中，只有问题明确需要文字证据、且事件满足置信度与跨帧稳定性条件时，才作为文字证据锚点候选。

**ASR 分段。** 对音频转写文本按语音停顿切分为带时间戳的段落。ASR 段落承担两个职责：其一，作为语音证据参与问题—证据相关性计算（问题词项与段落文本的重合度）；其二，其段落边界（段首/段尾时间点）在后续 LOOK_TIME 补看中作为候选补看位置，使时间补看对齐语音事件的边界而非任意偏移。

预处理产物与问题文本共同构成证据召回的输入。需要强调的是，全部预处理均在读取问题后、生成答案前完成，不访问任何参考答案与评分信息，保证流程可复现与无泄漏。

## 3.4 问题相关视觉评分与 MMR 冗余受控选择

### 3.4.1 问题相关视觉评分

对每个候选帧 $f_i$ 计算问题相关视觉得分 $r(q, f_i)$，度量帧内容与问题所需视觉证据的匹配程度。评分采用冻结的视觉—语言对齐模型（本文使用 CLIP 类图像—文本编码器），以问题文本为查询、候选帧为键，得到归一化相关性分数。该得分反映"这一帧是否包含与问题同义的视觉内容"，是 MMR 选择中相关性项的基础。

对于时间关系类问题（先后、同时、变化），单纯的帧级相关性不足以刻画"覆盖多个事件状态"的需求；本文通过 MMR 的多样性项间接缓解——冗余惩罚使得所选帧在时间上自然分散，从而提高覆盖不同事件状态的概率。

### 3.4.2 MMR 冗余受控选择

初始证据选择采用最大边际相关准则，在相关性与冗余之间显式权衡：

$$
f^{(k)} = \arg\max_{f \in F \setminus S_{k-1}} \left[ \lambda \cdot r(q, f) - (1-\lambda) \cdot \max_{f' \in S_{k-1}} \text{sim}(f, f') \right]
$$

其中 $S_{k-1}$ 为已选集合，$\text{sim}(\cdot,\cdot)$ 为帧间视觉相似度（由同一对齐模型的图像嵌入余弦相似度给出），$\lambda$ 为相关性—冗余权衡系数，本文冻结为 $\lambda = 0.70$。从相关性最高的种子帧开始迭代，直至选满 $K=8$ 帧；所选帧最终按时间顺序排列送入基座模型，以保持时序信息的自然呈现。

与纯相关性 Top-K 相比，MMR 的冗余惩罚项使得第二个及之后的帧必须在"相关"与"和已选帧不相似"之间取得边际最优，从而把预算分散到语义不同的证据上。第5.8 节的实验表明：在同预算下，MMR8 相对 CLIP TopK8 在 AdsQA 补充分区上提高 4.24/4.38 个百分点，验证了冗余控制的必要性。

### 3.4.3 与 ASR 证据的联合组织

语音证据不占用视觉预算：与问题相关的 ASR 段落文本作为上下文与 8 帧视觉输入一同提供给基座模型。问题与 ASR 段落的词项重合度决定相关段落的选取；这一设计使初始证据包在 1,024 视觉 Token 的预算内同时覆盖视觉与语音两个模态。

## 3.5 证据锚点定位

当初答被第4章的验证器判定为低支持时，需要从视频中定位新的证据时刻。本节描述锚点定位的三个步骤：多模态响应融合、时间分散约束与空间响应中心。

### 3.5.1 多模态响应融合

对每个候选帧位置 $i$ 构造三路响应：

1. **问题—视觉响应** $v_i$：第3.4.1 节的问题相关视觉得分；
2. **OCR 响应** $o_i$：位置 $i$ 附近 OCR 事件的问题相关性与可靠性（置信度、跨帧出现次数）加权和；
3. **ASR 响应** $a_i$：位置 $i$ 所处 ASR 段落与问题的词项重合度，以及该段落是否覆盖问题中的时间关系约束。

总响应取三路的融合分 $e_i = g(v_i, o_i, a_i)$。融合的关键约束是**模态条件化**：并非三路响应简单求和，而是根据问题逻辑（由第4章的问题逻辑树给出）确定该问题必需的模态——文字细节类问题的锚点主要由 OCR 响应驱动，语音/时序类问题主要由 ASR 响应驱动，视觉对象/动作类问题主要由视觉响应驱动。这一条件化避免了无关模态的高响应侵占证据槽位（本文在开发预检中发现，无条件融合会使无关 OCR/ASR 事件挤占锚点，该预检已作为失败案例记录并修正）。

### 3.5.2 时间分散与去重约束

两个锚点从响应峰中选择时施加以下冻结约束：

- **不与初始证据重复**：锚点对应帧不得复用 $S_0$ 中已选帧的位置，保证补看提供的是新证据；
- **时间分散**：两锚点之间保持最小时间间隔（本文以候选网格上的秩间隔刻画），避免两个锚点落在同一事件附近；
- **来源互补**：优先选择响应来源不同的锚点组合（例如一个视觉驱动、一个 OCR/ASR 驱动），提高证据覆盖的模态多样性。

### 3.5.3 空间响应中心与不确定性

对每个锚点时刻，响应图在空间维度上的峰值位置给出证据的**空间响应中心**，即该时刻问题相关内容最可能集中的图像区域；响应图的空间熵作为**不确定性代理**：熵高意味着问题相关证据在整帧内弥散（如场景级问题），熵低意味着证据集中在局部（如标识、文字、局部属性问题）。响应中心与不确定性共同决定锚点证据视图的组织方式（第3.6 节）：不确定性高时保留更多全局语境，不确定性低时提供更聚焦的高分辨率证据视图。

本文在开发集上的三臂归因实验（第5.8 节）表明，相对固定中心与固定尺度，响应中心定位与不确定性自适应尺度具有可分解的正向作用（Relaxed 口径 +0.50 个百分点，置信区间完全为正，500 题无一处错误修改）。

## 3.6 基于响应密度锚定的自适应多尺度裁剪视图生成

对每个证据锚点，本章生成"完整帧 + 局部高分辨率裁剪"并存的双流证据视图：

1. **完整帧视图（全局语境流 $G_t$）**：锚点时刻的完整画面，保留场景、人物与布局等全局语境，是每个锚点的固定组成；
2. **自适应多尺度裁剪视图（局部细节流 $L_t$）**：以空间响应中心为参考，在相对尺度 {0.4, 0.6, 0.8, 1.0} 的多尺度候选框中，按响应密度评分

$$D(B) = \sum_{p \in B} H(p) \,/\, \text{Area}(B)^{\rho}$$

选择响应密度最高的锚框 $B^{*}$，经裁剪与上采样生成局部高分辨率视图，用于呈现文字、标识、价格、产品细节等需要更高有效分辨率的证据内容。指数 $\rho$ 控制面积惩罚强度；响应熵作为不确定性代理调节尺度选择——熵高（证据弥散）时偏向较大尺度乃至完整帧，熵低（证据集中）时偏向聚焦尺度。

三点设计说明：其一，完整帧与裁剪视图**同时**提供（$Z_t=[G_t;L_t]$），局部细节的获取不以丢失语境为代价；其二，全部视图的视觉 Token 计入统一预算（本文补看阶段 12 视图、3,104 视觉 Token，上限 4,096），并在生成前执行预算审计——超预算的输入组合在生成前即被拦截，而不是事后降级；其三，本文对自适应裁剪的定位是**证据呈现与 Token 预算控制机制**：在不同问题所需证据粒度不同的前提下按需分配视图的有效分辨率，使有限视觉 Token 覆盖更完整的证据信息，本文不主张裁剪相对同预算完整帧的独立准确率优势。

## 3.7 证据包构建与可审计输出

证据选择的全部产物组织为结构化证据包，随答案一起输出：

```json
{
```

证据包的可审计性体现在三个层面：**证据级**（每个视图可回溯到帧号、时间戳与响应来源）；**模态级**（OCR/ASR 引用以文本与时间段形式回指）；**预算级**（视图数、实际视觉 Token 与二次采样状态逐题记录）。这使后续的第4章补看动作可以显式引用"已有证据"与"缺失证据"，也让全部实验的视觉输入协议可复核。

## 3.8 算法流程

```text
算法 3-1：问题驱动的视听证据选择
输入：视频 V，问题 q，预算 (K=8, B0, B2)，OCR 索引 O，ASR 索引 A
输出：初始证据 S0；条件触发的锚点证据包 E

1  F ← UniformGrid(V, 64)                       # 候选帧
2  for f in F: r(q,f) ← VisualRelevance(q, f)    # 问题相关评分
3  S0 ← MMRSelect(F, r, λ=0.70, K=8)             # 冗余受控选择
4  S0 ← SortByTime(S0)
5  return S0 → 基座模型生成初始答案 A0（转第4章）

# —— 低支持触发时执行 ——
6  T ← QuestionLogicTree(q)                      # 问题逻辑叶（第4章）
7  for i in 1..64:
8      e_i ← ModalityConditionedFusion(v_i, o_i, a_i; T)
9  (t1,x1),(t2,x2) ← SelectAnchors(e; 去重/分散/互补约束)
10 for each anchor (t, x):
11     views ← {FullFrame(t), AdaptiveCrop(t, x; 尺度{0.4,0.6,0.8,1.0}, D(B), entropy(t))}
12 E ← 预算审计(views, B2)                       # 超预算组合生成前拦截
13 return E（含帧号、时间戳、来源、Token、OCR/ASR 回指）
```

## 3.9 本章小结

本章提出了问题驱动的视听证据选择方法：以 64 帧候选与 OCR/ASR 时间索引为基础，用 MMR 准则同时优化问题相关性与帧间冗余，构造低预算初始证据；在初答低支持时，以模态条件化的响应融合定位时间分散、来源互补的证据锚点，并以响应中心、响应密度与响应熵组织完整帧与自适应多尺度裁剪视图，输出帧号、时间戳、来源与 Token 级可审计证据包。本章方法回答了 RQ1；其锚点定位与证据包机制是第4章主动补看的执行基础。

# 第4章 证据缺口驱动的主动补看与保守答案决策方法

## 4.1 本章引言

第3章构造的初始证据在多数问题上足以支撑初答，但当初答缺少关键证据时，系统面临两个连续的决策问题：**补看什么**与**是否采纳新答案**。

对第一个问题，现有反思式方法通常让模型在相同输入上重新生成答案。本文第5章的对照实验表明这一做法在广告视频问答上稳定有害：在 300 题开发集上，无门控自由反思使 Strict/Relaxed 准确率下降 8.87/6.66 个百分点，错误修改是正确修改的约一倍。其根因在于：反思没有引入新信息，模型的重写主要受生成随机性支配，而广告视频问答的答案对短时证据高度敏感，重写更容易丢失原本正确的证据指向。因此，有效的改进必须**回到视频中获取新证据**，且新证据的获取应当针对初答所缺的具体证据类型。

对第二个问题，即使补看产生了新证据与新候选答案，也不能无条件采纳：本文实验显示，无门控采纳补看候选虽在均值上提高准确率（+3.33/+5.00 个百分点），但同时将 5 个原本 Strict 正确的答案改为错误。答案替换必须以"新答案确实获得更强证据支持"为条件。

本章提出证据缺口驱动的主动补看与保守答案决策方法。核心思想是：**将初答的不足显式归因为可定位的证据缺口，由缺口类型决定补看动作；对补看后的候选与初答进行同口径充分性比较，仅在候选满足绝对阈值与相对裕量时替换，否则回退。** 该设计将"何时补看、补看哪里、是否改答"从隐式的端到端行为转化为可审计的显式决策链。

## 4.2 问题定义与总体框架

### 4.2.1 问题定义

给定初始答案 $A_0$（由第3章初始证据 $S_0$ 生成）、验证器支持度函数 $\phi$，主动补看与保守决策定义为四元组决策过程：

$$
(A_0, \phi) \;\xrightarrow{\text{缺口诊断}}\; \text{action} \in \{\text{DIRECT}, \text{LOOK\_TIME}, \text{LOOK\_REGION}\} \;\xrightarrow{\text{补看}}\; A_2 \;\xrightarrow{\text{充分性门控}}\; A^{*} \in \{A_0, A_2\}
$$

其中 DIRECT 表示现有证据已足够、直接保留初答；LOOK_TIME 表示缺少事件、先后关系或语音时间段证据，补看新的时间位置；LOOK_REGION 表示缺少文字、标识、价格或局部属性证据，补看证据锚点区域。最终答案 $A^{*}$ 由充分性门控决定：

$$
A^{*} = \begin{cases} A_2, & \phi(A_2) \ge \tau \;\wedge\; \phi(A_2) - \phi(A_0) \ge \text{margin} \\ A_0, & \text{否则} \end{cases}
$$

即候选必须同时满足**绝对支持阈值** $\tau$ 与**相对提升裕量** margin 才能替换；平票、格式失败或验证器不可用等情况一律回退 $A_0$。

### 4.2.2 总体框架

```text
初始证据 S0 → 基座模型 → 初始答案 A0
→ 声明—证据验证器：支持度 φ(A0)
→ φ(A0) ≥ τ_trigger ？ → 是：输出 A0（大多数题在此结束）
                      → 否：证据缺口诊断（第4.4 节）
   ┌─ 缺口为时间型（事件/时序/语音段缺失或时间峰分歧）→ LOOK_TIME
   ├─ 缺口为区域型（OCR/标识/局部属性缺失、低可信或定位分歧）→ LOOK_REGION
   └─ 低支持但无可定位缺口 → DIRECT（保留 A0，避免无目的补看）
→ 补看执行（第4.5 节，调用第3章锚点机制）→ 证据增强输入
→ 独立生成候选答案 A2（第4.6 节）
→ 同一验证器对 A0 与 A2 评分：φ(A0), φ(A2)
→ 充分性门控（τ, margin）→ 替换或回退 → 输出 A* 与完整决策轨迹
```

流程包含两道安全阀：触发端的 $\tau_{\text{trigger}}$ 控制补看计算只发生在低支持问题上；替换端的 $(\tau, \text{margin})$ 控制只有证据支持实质性增强的候选才能改答。

## 4.3 声明—证据支持度验证器

### 4.3.1 声明拆解与正反声明构造

验证器将答案转化为可核查声明集合 $C(A)=\{c_1,\dots,c_n\}$：每个声明是答案中一个可被证据证实或否定的事实单元（如"优惠截止日期为 8 月 31 日""广告中出现的产品是 X"）。给定证据包（视觉帧、OCR 文本、ASR 段落），验证器输出声明级支持度并聚合为答案级支持度 $\phi(A) \in [0,1]$。

验证器的监督数据采用真实正反声明库（RealClaim）：从真实模型回答中整理 985 条原子声明，按其与参考答案的关系自动推导弱监督标签，得到 642 条 supported（正声明）与 343 条 not-supported（反声明），覆盖 139 个训练视频，与全部校准、开发与评测视频保持视频级隔离。正反声明并存使验证器学习的是"证据是否支持该声明"的判别而非答案记忆；标签为自动推导的弱监督（`not_human_gold=true`），不使用人工金标准。

### 4.3.2 反事实证据对（E+/E−）构造

为提供证据级的对比监督，本文对声明构造反事实证据对：**E+ 为完整证据**（决定性证据与背景上下文均保留）；**E− 为最小破坏证据**——仅破坏决定性证据而保留背景，包含四种破坏算子：删除关键帧、模糊关键文字、语音段错移 ±2 秒、以同视频相邻的无关干扰帧替换关键片段。E+/E− 支持配对排序目标：

$$\text{score}(q, c, E^{+}) > \text{score}(q, c, E^{-}) + \text{margin}$$

即在同一问题与声明下，验证器对完整证据的评分应高于被破坏证据。最小破坏设计迫使模型依赖决定性证据本身，而不能依赖背景画面或文本先验。

### 4.3.3 LoRA 训练与支持度输出

验证器在基座模型上以 LoRA 微调得到：视觉编码器冻结，仅在语言侧 q_proj/v_proj 注入低秩适配器（约 252 万参数，占基座约 0.03%）；每条输入固定 8 个证据视图、问题、原子声明与 ASR 文本，不含参考答案与标签字段。训练路线按实验记录冻结为**真实正反声明直接训练**（声明级支持二分类）：受控反事实适配器（156 对 supported/contradicted 声明加排序目标）在校准集上 AUROC 为 0.575，未达预设 0.70 门禁；真实声明直接训练在相同校准集上取得更高判别力（第5.9.1 节），因此 E+/E− 反事实对在正式方法中保留为对比校准与证据扰动诊断用途。验证器输出声明级支持状态（支持/反驳/不足）并聚合为答案级支持度 $\phi(A)\in[0,1]$；对 $A_0$ 与 $A_2$ 使用同一模型、同一证据口径评分，保证比较的对称性。

### 4.3.4 支持度的两个用途

1. **触发**：$\phi(A_0) < \tau_{\text{trigger}}$ 判定初答为高风险，进入缺口诊断。触发阈值在视频级隔离的开发/校准集上确定，不接触评测集标签。
2. **门控**：$(\phi(A_2) \ge \tau) \wedge (\phi(A_2) - \phi(A_0) \ge \text{margin})$ 决定替换。

本文在三个基座上分别冻结了门控参数（第5.3 节），不复用跨基座阈值；第5.13 节的阈值扫描分析进一步表明，跨基座迁移阈值不可行，可分性瓶颈在候选质量而非阈值取值。

## 4.4 证据缺口诊断与动作决策

### 4.4.1 问题逻辑树

缺口诊断的第一步是确定"该问题需要哪些证据"。本文用纯文本接口的辅助大模型（Qwen3）将问题拆解为证据需求逻辑树：树叶标注证据类型，取值为

```text
OCR | ASR | VISUAL_ACTION | VISUAL_OBJECT | VISUAL_SCENE
```

并保留问题的时间关系约束（先后、同时、紧随其后）。逻辑树只读取问题文本生成，不接触答案、参考答案与评分；生成过程带重试与白名单校验，解析失败的题目按冻结规则回退到保守逻辑树。逻辑叶将问题的证据需求显式化，是缺口分类的"需求侧"。

### 4.4.2 证据缺口记录

"供给侧"是第3章证据包中实际覆盖的模态与时刻。两侧对齐后生成 answer-free 的缺口记录：

```json
{
  "question_id": "...",
  "missing_leaf": "OCR | ASR | VISUAL_ACTION | VISUAL_OBJECT | VISUAL_SCENE | null",
  "gap_reason": "missing | conflict | locator_disagreement | low_support | none",
  "action": "DIRECT | LOOK_TIME | LOOK_REGION",
  "tool_budget": 0,
  "not_human_gold": true
}
```

其中 `gap_reason` 区分四类缺口成因：**missing**（所需证据叶在初始证据中缺失）、**conflict**（证据间相互冲突）、**locator_disagreement**（视觉峰、OCR 峰与 ASR 时间段指向不一致的时间位置）、**low_support**（整体支持度低但无具体可定位缺口）。

### 4.4.3 动作决策规则

动作决策按以下冻结优先级执行：

1. **必需 OCR 叶缺失、低可信或与视觉定位分歧 → LOOK_REGION**。文字、标识、价格类证据需要更高的有效分辨率与区域聚焦，补看指向证据锚点区域。
2. **必需 ASR、动作叶缺失，或时序类（SEQ/紧随其后）叶缺失与时间峰分歧 → LOOK_TIME**。事件与语音证据需要新的时间位置，补看指向初始证据未覆盖的时刻。
3. **低支持但无可定位缺口 → DIRECT**。避免无目的补看：没有明确缺口指向时，盲目增加输入只会放大噪声。
4. **同题单轮最多执行一个补看动作**。首轮实现不做循环式多轮 Agent，以保证因果归因清晰、成本可控。

该规则体系的可审计性体现在：每个非 DIRECT 动作都输出帧号、时间戳、区域与调用原因，形成可回放的多模态工具轨迹；任何"未实际改变输入证据"的伪工具调用都会被协议审计判为失败。

## 4.5 补看执行与证据增强

### 4.5.1 LOOK_TIME：时间证据补看

LOOK_TIME 从初始证据未覆盖的时间位置获取新帧。候选位置来自两个来源：**ASR 段落边界**（问题相关段落的段首/段尾时间点，对齐语音事件的发生位置）与**锚点邻域**（第3章锚点时刻的固定偏移邻域）。所有补看帧与初始 8 帧及锚点帧均不相同，并计入统一视觉 Token 预算。时间补看同时附带给定时间段的 ASR 文本回指，使时间证据与语音证据在输入中共同呈现。

### 4.5.2 LOOK_REGION：区域证据补看

LOOK_REGION 调用第3章的锚点机制：以模态条件化响应融合确定证据时刻与空间响应中心，每个时刻同时提供完整帧与响应密度锚定的自适应裁剪视图，并附该时刻的 OCR 文本与所处 ASR 段落回指。区域补看的目标是让文字、标识、价格与局部属性类证据以更高的有效分辨率进入输入，同时保留完整帧以维持语境。

### 4.5.3 动作分层与设计依据

本文在冻结的 60 题内部确认集上对两类动作的增益做了分层分析（第5.9 节）：区域型缺口（37 题）贡献了主要增益（Strict 21.62→27.03%，Relaxed 48.65→56.76%），时间型缺口（13 题）净变化为零。这一分层结果与缺口分类的直觉一致——广告视频问答中"答案取决于短时出现的文字/标识细节"的问题比例更高，且这类证据最容易被均匀采样遗漏；而时间型缺口的补看收益则依赖更精确的事件定位，是未来工作的重点（第6章）。

## 4.6 证据增强候选生成

### 4.6.1 独立生成协议

补看证据就位后，候选答案 $A_2$ 采用**独立生成**协议：基于全部证据视图与 OCR/ASR 回指，独立生成一个简短候选答案，**不**以初答为改写对象、不要求模型在"保留/修改"之间表态。

### 4.6.2 为什么不是最小改写

本文曾实现"仅当引用证据直接否定初答决定性事实时做最小修改，否则原样保留"的最小改写协议。协议审计与差异性预检显示：该协议过度保守且格式脆弱——在 20 题时间补看预检中，60%–85% 的生成因格式契约失败被安全回退，补看帧虽与锚点不同，答案变化率却为 0/20；瓶颈不在取帧是否变化，而在改写协议压制了新证据的使用。相比之下，独立生成协议在同一预检中产生 60% 的候选差异率，通过候选差异性门禁。因此本文将**证据获取**与**答案采纳**彻底解耦：候选生成只负责在增强证据上给出最好答案，是否采纳完全交给下一节的充分性门控。这一解耦使补看证据真正参与答案生成，同时把改答风险收敛到单一可控的决策点。

## 4.7 充分性比较与保守替换

### 4.7.1 门控规则

最终答案由第4.2.1 节的规则决定。除阈值条件外，门控还包含以下保守条款：

- **验证器不可用或评分失败 → 回退 $A_0$**；
- **$A_2$ 生成格式非法 → 回退 $A_0$**；
- **$A_2$ 与 $A_0$ 相同 → 无操作**。

### 4.7.2 三基座冻结参数

本文在三个基座上分别校准并冻结门控参数，校准只使用视频级隔离的开发/校准集，评测集标签不参与选择：

| 基座 | 用途 | 冻结参数 | 校准来源 |
|---|---|---|---|
| Qwen3-VL-8B | 主方法 | $\tau$ = 0.9602926671504974 | OOF-500（视频级隔离） |
| ReAd-R（Qwen2.5-7B-VL） | 共同基座 | $\tau$ = 0.9241418242454529, margin = 0 | Pilot Calibration-100 |
| Qwen2.5-VL-7B-Instruct | 跨基座 | $\tau$ = 0.39243705570697784, margin = 0.25 | GroupCV-500（视频级隔离，五折） |

三个基座的阈值差异本身反映了支持度分布的基座依赖性，因此本文坚持"每个基座独立校准、冻结后不再调整"的原则；第5.13 节的离线扫描表明，在可分性不足的基座上扫描阈值无法产生稳定增益。

### 4.7.3 门控的风险控制作用

门控的价值由三组实验共同支撑（第5章）：其一，无门控自由反思造成 −8.87/−6.66 个百分点的稳定伤害，充分性门控将其完全抑制（差值回到 0 附近）；其二，无门控采纳补看候选带来 +3.33/+5.00 个百分点均值增益但引入 5 个错误修改，门控后的完整方法在主实验中实现 1,153 次正确修改对 604 次错误修改（纠正精度 65.62%），在 ReAd-R 共同基座上实现 5 次正确修改、0 次错误修改；其三，外部数据集独立确认中门控后方法相对 MMR8 为 28 胜 0 负。门控以少量均值增益的牺牲换取错误修改风险的显著收敛，这正是"保守"的含义。

## 4.8 算法流程

```text
算法 4-1：证据缺口驱动的主动补看与保守答案决策
输入：A0，证据包 E0，验证器 φ，冻结参数 (τ_trigger, τ, margin)
输出：最终答案 A* 与决策轨迹

1  φ0 ← φ(A0, E0)
2  if φ0 ≥ τ_trigger: return A0（DIRECT-by-support，结束）
3  T ← QuestionLogicTree(q)                  # 证据需求逻辑叶
4  gap ← DiagnoseGap(T, E0)                  # 缺口记录（answer-free）
5  if gap.missing_leaf ∈ {OCR, 局部属性} 或 locator_disagreement(OCR)：
6      E2 ← LOOK_REGION(锚点机制)             # 第3.5–3.6 节
7  elif gap.missing_leaf ∈ {ASR, 动作, SEQ} 或时间峰分歧：
8      E2 ← LOOK_TIME(ASR段界/锚点邻域新帧)
9  else: return A0（DIRECT，无可定位缺口）
10 A2 ← IndependentGenerate(E0 ∪ E2 ∪ OCR/ASR回指)
11 if 格式非法或 A2 = A0: return A0
12 φ2 ← φ(A2, E0 ∪ E2)
13 if φ2 ≥ τ and φ2 − φ0 ≥ margin: return A2
14 else: return A0
15 输出决策轨迹：{gap, action, 补看帧号/时间戳/区域, φ0, φ2, 决策}
```

## 4.9 本章小结

本章提出了证据缺口驱动的主动补看与保守答案决策方法：以声明—证据支持度验证器识别初答风险，以问题逻辑树与证据包对齐诊断证据缺口，按缺口类型执行 DIRECT/LOOK_TIME/LOOK_REGION 三类动作；补看后以独立生成协议产生候选，再由绝对阈值加相对裕量的充分性门控决定替换或回退。方法将"何时补看、补看哪里、是否改答"转化为可审计的显式决策链，回答了 RQ2；与第3章联合构成完整方法，其有效性在 第5章 验证（RQ3）。

## 5.4 评价指标

- **Strict**：完全正确的题目比例（Answer:1 / N）；

- **R5/R3/R2**：E-VAds 五分制下分别以 5、3、2 分为阈值的准确率；
- **胜/平/负（W/T/L）**：配对题级比较；
- **wrong→right / right→wrong（w2r/r2w）**：错误修改与正确修改计数，**纠正精度** = w2r / (w2r + r2w)；
- **置信区间**：按视频聚类的 10,000 次配对 Bootstrap 95% CI（同一视频多题作为簇，避免非独立性导致区间过窄）；
- **成本**：触发率、平均视觉 Token、推理延迟（秒/题）、显存峰值；
- **评分覆盖**：本文不填补缺失评分，缺失时同时报告最坏/最好边界。

### 5.8.1 选帧准则：相关性 vs 相关性+冗余

表 5-10 报告声明—证据验证器在视频级隔离的 Calibration-240 上的判别能力（声明级支持二分类）。

**表 5-10 验证器判别能力（Calibration-240）**

| 验证器 | AUROC | AUPRC | ECE | Brier |
|---|---:|---:|---:|---:|
| 冻结 Qwen3 基座（不训练） | 0.5409 | 0.6665 | 0.3780 | 0.3857 |
| 受控反事实 LoRA（E+/E− 排序，156 对） | 0.5752 | 0.6958 | — | — |
| Qwen2.5 真实正反声明 LoRA | 0.6345 | 0.7348 | — | — |
| Qwen3 真实正反声明 LoRA（本文） | **0.6599** | **0.7789** | **0.2120** | **0.2630** |

本文验证器相对冻结基座的 AUROC 点差 +0.1190，35 视频聚类 Bootstrap 均值差 +0.1202（95% CI `[+0.0456, +0.1988]`），支持"声明证据 LoRA 能学习到独立于冻结基座的支持判别能力"；相对 Qwen2.5 版本为点估计领先（CI 跨 0）。该表同时构成训练路线的选择依据：受控反事实（E+/E− 排序）适配器判别力不足，真实正反声明弱监督直接训练成为主线，E+/E− 保留为对比校准与证据扰动诊断。验证器校准（ECE 由 0.378 降至 0.212）也是后文触发阈值与门控参数可直接使用支持度分数的前提。

### 5.9.2 无门控反思的危害与门控的抑制

本节是创新点二的动机实验。在同一 300 题开发集（209 视频，严格视频不重叠子集 233 题）上，比较三个共享相同初始证据（LogicEvidence8）的版本：初始答案 A0、无门控自由反思（NoGate，模型对初答自由重写）、充分性门控反思（EvidenceGated，本文机制的文本侧前身）。

**表 5-9 反思机制对照（Dev-300）**

| 方法 | Strict | Relaxed | 相对 A0 | w2r/r2w |
|---|---:|---:|---:|---:|
| 初始答案 A0 | 31.53% | 48.81% | — | — |
| NoGate 自由反思 | 22.15% | 41.78% | **−8.87 / −6.66 pp** | — |
| EvidenceGated | 31.76% | 48.65% | 0 / −0.34 pp | 12/12 |

NoGate 的两项差值视频聚类 Bootstrap CI 均完全低于 0（严格子集上保守边界同样全负）：**无约束反思在广告视频问答上稳定有害**。NoGate 对全部 300 题都改写了答案，而其中绝大多数改写没有新证据支撑。EvidenceGated 接受并改答 131 题（43.67%），将伤害完全抑制（差值 CI 跨 0），w2r/r2w 恢复到 12/12 的均衡。该实验直接支撑第4章的设计原则：改答必须以新证据与充分性比较为条件。本文最终方法进一步将反思升级为"定向补看新证据"（而非同证据重写），从而把门控后的"无害"推进到主实验中的"+7.00/+10.12 pp 增益"。

### 5.9.3 无门控补看的风险与动作分层

本节为分离"补看动作"与"门控"的贡献，本文在冻结的 60 题内部确认集（12 视频；DIRECT=10、LOOK_TIME=13、LOOK_REGION=37）上报告**无门控采纳**补看候选的结果。

**表 5-11 无门控补看与动作分层（Confirm-60B，内部确认集）**

| 口径 | Strict | Relaxed | w2r/r2w |
|---|---:|---:|---:|
| A0 | 35.0% | 57.5% | — |
| 无门控采纳补看候选 | 38.33% | 62.5% | 1/5 |

无门控采纳带来 +3.33/+5.00 pp 的均值增益（CI 跨 0），纠正精度 63.16%，但将 5 个原本 Strict 正确的答案改为错误——这正是不允许无条件采纳的原因，也是 5.7.2 节 Fresh-500 中"补看候选直接 +10.60 pp 但最终方法只保留 +3.4 pp"的原因：门控牺牲部分均值以消除错误修改。

按补看动作分层：37 个 LOOK_REGION 题贡献了主要增益（Strict 21.62%→27.03%，Relaxed 48.65%→56.76%，10 胜/22 平/5 负）；13 个 LOOK_TIME 题净变化为零（2 胜/9 平/2 负）。该分层与缺口分类的设计预期一致：广告视频问答中，答案取决于短时文字/标识/局部细节的问题占比高、且最易被初始采样遗漏，区域型补看收益最大；时间型补看的收益依赖更精确的事件定位能力，当前规则版的收益有限，是本文明确界定的局限（第6章）。

### 5.9.4 门控工作点与触发行为

主实验（Full-7844）在准确率优先工作点下的触发率为 91.45%（7,173/7,844），门控后实际替换率约 89.86%；ReAd-R Confirm-600 触发率 25.33%、实际换答 21 题；Qwen2.5 触发 16 题、替换 4 题。三个基座的触发率差异来自支持度分布的基座依赖性。需要强调：91.45% 是准确率优先（而非成本优先）的工作点；Qwen2.5 上本文同时报告了成本优先点（触发 2.0%、替换 0.4%），说明工作点可在校准集上按需选择。

## 5.11 裁判可靠性与人工抽检设计

本文全部精度数字来自冻结提示词的 DeepSeek answer-only 机器裁判，统一标注 `not_human_gold=true`。为量化裁判可信度，本文设计了 88 题人工一致性抽检方案，按四类分层抽样：正确修改（w2r，40 题）、错误修改（r2w，25 题）、候选未替换（A0≠A2 但被门控拒绝，20 题）与方法间分歧（3 题）。抽检表已生成（`adsqa_human_review_sample_20260731.csv`）；若由大模型辅助复核，将标注 `LLM_substitute=true`。抽检结果将用于报告机器裁判与人工判断的一致率，作为全部自动评分的可信度补充。本文同时在第5.4 节的口径下避免两个已知偏差：裁判不读取模型推理过程（避免风格偏置）；缺失评分不填补并报告边界（避免选择性幸存）。

## 5.12 流程示例

以下为方法流程的示意性走查（用于说明机制，非实测个案）。设广告视频在 12–15 秒处出现"限时满减"价格字幕约 1.5 秒，问题为"广告中的优惠活动持续到什么时候？"

1. **初始证据选择**：MMR8 从 64 帧候选中选出 8 帧；价格字幕因出现时间短，未进入初始证据；模型基于画面与 ASR 生成初答 A0="优惠持续到月底"。
2. **验证与缺口诊断**：验证器支持度 φ(A0)=0.71 < τ_trigger；问题逻辑树的必需叶为 OCR（日期类文字证据），初始证据中 OCR 覆盖缺失 → `gap_reason=missing`，动作判定为 **LOOK_REGION**。
3. **补看**：模态条件化响应融合将 OCR 峰值时刻定位为证据锚点（第 22.8 秒附近），生成完整帧与自适应多尺度裁剪视图，附 OCR 文本回指"满减优惠 至8月31日"。
4. **候选生成**：模型基于增强证据独立生成 A2="优惠持续到 8 月 31 日"。
5. **充分性门控**：φ(A2)=0.97 ≥ τ 且 φ(A2)−φ(A0)=0.26 ≥ margin → 替换，输出 A2。
6. **输出证据包与决策轨迹**：帧号、时间戳、OCR 回指、两阶段支持度与替换决策全程可回溯。

若缺口诊断为时间型（如"主播先介绍了什么，随后演示了什么？"缺少时序证据），系统改走 LOOK_TIME，从 ASR 段落边界获取新帧；若低支持但无可定位缺口，系统保留 A0，不做无目的补看。

## 5.13 错误归因分析

本文对负向与弱结果做了系统归因，主要发现如下：

1. **候选质量是跨基座增益差异的主因**。Qwen2.5 上 500 题中补看候选文本与初答不同的有 461 题，但统一裁判仅判定 7 题更优、442 题持平、12 题更差；其中 456 题的支持度增量落在 [0, 0.03) 区间——大量"改写"没有形成可辨认的证据增益。离线阈值扫描进一步表明：从 3.2% 触发提高到 100% 触发，固定 margin 下最多新增 3 次实际换答并引入 1 次损失。**瓶颈是候选与初答的可分性，不是阈值取值**；这解释了 5.6.2 节弱正向结果的来源，也界定了本文方法的适用条件（基座的证据利用能力）。
2. **时间型补看的收益有限**（5.9.3 节）：LOOK_TIME 净变化为零，反映规则版时间定位尚未充分利用事件结构；本文未在此方向继续调参，而是将其列入未来工作。
3. **错误修改的残留风险**：主实验 w2r/r2w = 1,153/604（纠正精度 65.62%），即约 1/3 的替换是错误的。这类错误集中在支持度增量刚刚越过 margin 的边界区间，说明当前验证器对"小幅证据改善"的判别仍不充分；人工抽检中的 r2w 层（25 题）即为检验该风险的专门设计。
4. **触发率与成本的权衡**：91.45% 的触发率意味着准确率优先工作点几乎对所有题执行补看，成本接近"全部二次回答"；在成本敏感场景应采用低触发工作点（Qwen2.5 上按需执行补看的平均视觉 Token 相对仅执行初始证据提高约 8%，1,317.57→1,423.74；2% 触发的成本点将进一步降低该开销）。

## 5.14 本章小结

本章在 AdsQA 完整评测集、三个基座与外部数据集上验证了本文方法：证据选择相对均匀采样稳定增精（+3.61/+3.89 pp），完整方法在主实验中相对 MMR8 再增 +7.00/+10.12 pp（CI 完全为正），并经 ReAd-R 共同基座（+0.83/+0.67 pp、零错误修改）、Qwen2.5 跨基座（弱正向）、E-VAds 外部数据集（+1.70/+2.10/+1.60 pp、零错误修改）与 Fresh-500 全新视频（+3.4 pp R5、零错误修改）多角度确认。机制分析表明：无门控反思有害（−8.87 pp）而门控完全抑制伤害；补看增益主要来自区域型证据缺口；候选质量而非阈值是跨基座差异的主因。全部自动评分为机器裁判口径，配套 88 题人工抽检设计。

# 第6章 总结与展望

## 6.1 工作总结

本文针对广告视频问答中"均匀采样易遗漏短时关键证据、无约束反思损害准确率"两个核心问题，提出了"问题驱动的证据选择—证据缺口驱动的主动补看"两阶段方法，主要工作与结论如下：

**（1）问题驱动的冗余受控视听证据选择方法（第3章）。** 以问题为查询，在 64 帧候选上以最大边际相关准则（λ=0.70）同时优化问题相关性与帧间冗余，构造低预算、时间排序的初始证据；在初答低支持时，以模态条件化的响应融合定位时间分散、来源互补的证据锚点，以响应峰与响应熵组织完整帧与高分辨率证据视图，输出帧号、时间戳、来源与 Token 级可审计证据包。实验表明：MMR8 相对均匀采样提高 3.61/3.89 个百分点（CI 完全为正），相对 CLIP TopK8 提高约 4.2/4.4 个百分点，验证了冗余控制的必要性；锚点机制的组件归因显示响应中心与不确定性自适应具有可分解的正向作用且零伤害。

**（2）证据缺口驱动的主动补看与保守答案决策方法（第4章）。** 以真实正反声明（642 supported/343 not-supported）与最小破坏反事实证据对（E+/E−）训练的轻量 LoRA 声明—证据验证器度量初答支持度并触发补看（Calibration-240 AUROC 由冻结基座的 0.541 提高到 0.660，CI 全正）；将初答不足归因为可定位的证据缺口，按缺口类型执行 DIRECT/LOOK_TIME/LOOK_REGION 三类动作；补看后以独立生成协议产生候选，由绝对阈值加相对裕量的充分性门控决定替换或回退。机制分析确立了两个关键事实：无门控自由反思稳定有害（−8.87/−6.66 个百分点），充分性门控将其伤害完全抑制；无门控采纳补看候选虽均值正向但引入错误修改，门控以可控的均值牺牲换取错误修改风险的显著收敛（ReAd-R、E-VAds 与 Fresh-500 上均实现零错误修改）。

**（3）系统性实验验证（第5章）。** 完整方法在 AdsQA 7,844 题完整评测集上相对均匀采样累计提高 10.61/14.00 个百分点，相对证据选择阶段再提高 7.00/10.12 个百分点（CI 完全为正）；在同题配对下超过官方 GRPO 训练模型 ReAd-R（+10.57 pp Strict）；在 ReAd-R 共同基座（+0.83/+0.67 pp，5 胜 0 负）、Qwen2.5 跨基座（弱正向）、E-VAds 外部数据集（+1.70/+2.10/+1.60 pp，28 胜 0 负）与 Fresh-500 全新视频（+3.4 pp R5，29 胜 0 负）上完成多角度确认。全部实验遵循预注册、协议冻结、视频级隔离与 SHA256 审计的规范，成本与风险指标（触发率、视觉 Token、延迟、纠正精度）同步报告。

## 6.2 局限性

1. **评分为机器裁判口径**。全部精度数字来自冻结提示词的 DeepSeek answer-only 裁判（`not_human_gold=true`），88 题人工一致性抽检方案已生成但尚未执行；机器裁判与人工判断的一致率有待补充报告。
2. **触发率为准确率优先工作点**。主实验 91.45% 的触发率接近对全部题目执行二次回答，不是低成本部署点；低成本工作点（触发 2%）的增益幅度未在主基座上系统报告。
3. **时间型补看的收益有限**。LOOK_TIME 在动作分层分析中净变化为零，规则版时间定位尚未充分利用事件结构；本文将其界定为机制边界而非已验证组件。
4. **门控的判别能力受候选质量制约**。在 Qwen2.5 等基座上，补看候选与初答的支持度可分性不足，门控只能实现弱正向；错误修改的残留风险（主实验纠正精度 65.62%）集中在支持度增量刚越过裕量的边界区间。
5. **动作决策为规则版**。DIRECT/LOOK_TIME/LOOK_REGION 的缺口分类规则由冻结的人工规则实现，本文验证的是"缺口驱动补看 + 充分性门控"这一机制本身的有效性；学习式动作控制器的增量收益未在本文中评估。

## 6.3 未来工作

1. **轻量动作控制器**。在规则版机制验证的基础上，训练轻量三分类动作控制器替换冻结规则，学习"何类缺口、何种证据状态下补看收益最大"；控制器稳定超过规则版后，再考虑与策略优化方法结合。
2. **候选—初答配对收益门控**。将门控从"两个绝对支持度加裕量"升级为同证据、顺序对称的配对收益判别，直接建模"这次替换是否值得"，以压缩错误修改的边界区间。
3. **时间证据定位的强化**。引入显式的事件边界与状态转移建模（动作状态与结果状态的成对覆盖），提升 LOOK_TIME 在时序类问题上的有效性。
4. **人工评估与可信度闭环**。执行 88 题人工一致性抽检并扩展开放式答案的人工偏好评估，为机器裁判口径建立可量化的可信度证据。
5. **预算自适应部署**。在支持度校准曲线上按业务约束选择"准确率优先/成本优先"工作点，并探索多轮渐进补看（按剩余预算与剩余风险决定是否继续）。
