# 广告视频问答中期改题与创新点重构建议

> 用途：供中期答辩前快速查看，整理当前论文题目、创新点、答辩口径和后续实验建议。  
> 关联详细调研文档：`docs/2025-2026多模态与视频问答顶会论文调研及论文改题建议.md`

---

## 1. 总体判断

当前如果继续把论文概括为：

```text
热力图 + 思维链
```

创新性会偏弱，容易被认为是已有模块的简单组合。

尤其是“思维链”部分，不建议继续作为题目或核心创新点。原因是：

1. CoT / 思维链已经是通用大模型推理范式；
2. 只把 CoT 用到广告视频问答上，容易被认为是场景替换；
3. Prompt 型思维链很容易被评价为工程技巧；
4. “热力图 + 思维链 + RAG + 反思”会显得像模块堆叠。

但是，“热力图 / 响应图 / 证据定位”这条线仍然可以作为工作点保留。关键是不能写成事后可视化，而要写成：

> **问题条件化的视听-文字证据响应图，用于选择广告视频中的关键时间片段、关键帧和局部证据区域，并进一步约束答案生成与证据一致性评价。**

也就是说，热力图不是创新点本身，真正的创新点是：

```text
证据定位 → 证据保留型输入重构 → 证据约束生成 → 答案-证据一致性评价
```

---

## 2. 推荐修改后的论文题目

### 2.1 最推荐题目

> **基于视听证据定位与证据约束生成的广告视频问答方法**

推荐理由：

- 保留你现有的“热力图 / 响应图 / 证据定位”工作；
- 避免把“思维链”作为弱创新点；
- 不把 RAG 写进题目，因为当前实验表明 RAG 更适合作为辅助或消融；
- 与 2025-2026 年视频问答、多模态大模型和可信 VQA 的研究趋势一致；
- 题目不算太长，中期答辩时比较好解释。

---

### 2.2 学术性更强的备选题目

> **基于证据保留型视觉输入重构与证据一致性校验的广告视频问答方法**

这个题目更强调第3章的视觉输入重构和第4章的证据校验，适合如果你还想保留“视觉压缩”的方法味道。

---

### 2.3 偏可靠问答方向的备选题目

> **面向广告视频问答的证据引导多模态推理与验证方法**

这个题目更偏“可靠生成”和“可信问答”，适合后续如果把答案-证据一致性验证作为重点。

---

### 2.4 不建议继续使用的题目表述

| 题目 | 问题 |
|---|---|
| 基于热力图与思维链的广告视频问答方法 | 热力图和思维链都像已有模块，创新性弱 |
| 基于视觉特征压缩与链式反思的广告视频问答方法 | “视觉特征压缩”容易被误解为 token pruning；“链式反思”容易被理解为 Self-Refine |
| 基于 RAG 与思维链的广告视频问答方法 | RAG / CoT 均为通用范式，且当前实验结果不支持 RAG 作为主贡献 |
| 基于多模态大模型的广告视频问答系统 | 太泛，像应用系统，不像方法论文 |

---

## 3. 建议重构后的三条创新点

### 创新点一：问题条件化的广告视频证据定位机制

面向广告视频中短时字幕、Logo、价格、商品细节、口播和行动号召等关键证据，构建由用户问题、ASR、OCR/Logo 和广告证据类型共同驱动的视听-文字时空响应图，用于选择与问题相关的关键帧、时间片段和局部证据区域。

可以这样写：

> 针对广告视频中关键信息短时出现、声画不同步和局部文字细节易丢失的问题，本文提出问题条件化的视听-文字时空响应图，将问题语义、语音片段、屏幕文字和品牌标识共同映射为证据响应信号，实现对关键帧、证据时间段和局部区域的联合定位。

---

### 创新点二：证据保留型视觉输入重构方法

不是普通均匀采样，也不是普通 ROI 裁剪，而是在有限输入预算下保留全局语境视图和局部高分辨率证据视图，实现“降低冗余输入”和“保留细粒度广告证据”的平衡。

可以这样写：

> 本文将视觉特征压缩界定为推理输入侧的证据保留型视觉输入重构。该方法在有限输入预算下同时保留广告整体语境和局部高分辨率证据区域，避免均匀采样遗漏短时字幕、Logo、价格和商品细节等关键线索。

---

### 创新点三：答案-证据一致性约束与验证

将广告视频问答从“只生成答案”改为“答案必须由选中证据支持”。可以要求模型输出答案、证据时间段、证据区域或证据描述，并通过证据一致性、无依据知识注入率、幻觉率或人工复核验证答案可靠性。

可以这样写：

> 为降低广告视频问答中的无依据推断和营销概念误用，本文将生成答案拆解为可验证声明，并回溯至视觉、OCR、ASR 或广告知识证据，判断答案是否受到证据支持。对于证据不足或冲突的声明，系统执行降置信、修正或删除，从而提升答案与视频证据的一致性。

## 4. 论文主线建议

### 4.1 不建议的主线

```text
视觉压缩 + RAG + CoT + Reflection
```

这个主线的问题是：

- 每个模块都是已有通用技术；
- 放在一起容易被认为是工程堆叠；
- 难以说明为什么这些模块在广告视频问答中形成统一创新。

---

### 4.2 建议采用的主线

```text
证据定位 → 证据保留型输入重构 → 证据约束生成 → 答案-证据一致性验证
```

对应解释：

1. **证据定位**：通过问题条件化响应图找到广告视频中与问题相关的关键帧、时间段和区域；
2. **证据保留型输入重构**：保留全局语境和局部高分辨率证据视图，减少无关帧和冗余视觉输入；
3. **证据约束生成**：答案生成不能脱离证据包，避免无依据营销解释；
4. **答案-证据一致性验证**：答案不仅要正确，还要能说明依据来自哪些视频证据。

---

## 5. 中期答辩建议口径

### 5.1 如果老师问：“你是不是就是热力图 + 思维链？”

建议回答：

> 不是。本文没有把热力图作为事后可视化，也没有把思维链作为主要创新。本文关注的是广告视频问答中的证据稀疏和证据不一致问题：一方面通过问题条件化的视听-文字响应图选择与问题相关的时间片段和局部视觉证据；另一方面让最终答案回溯到这些证据，避免模型生成无依据的广告解释。因此，热力图只是证据定位的表达形式，核心是证据选择、证据保留型输入重构和答案-证据一致性约束。

---

### 5.2 如果老师问：“为什么不是模块堆叠？”

建议回答：

> 简单模块堆叠通常是先采样视频，再检索知识，再让模型用思维链回答；各模块之间没有统一约束。本文的区别在于，问题条件化响应图生成的证据包贯穿后续过程：知识必须由证据触发，答案必须引用证据，校验也基于同一证据进行。因此，本文不是把热力图、RAG 和思维链串联起来，而是围绕同一个证据接口完成证据定位、证据压缩、答案生成和证据验证。

---

### 5.3 如果老师问：“那实验怎么证明？”

建议回答：

> 除了常规问答准确率，后续实验会增加三个维度：第一，证据定位质量，例如证据时间段命中率、OCR/Logo 区域命中率；第二，效率指标，例如关键帧数、视觉 token、推理时延；第三，答案-证据一致性指标，例如无依据回答比例、幻觉率和声明级证据支持率。这样可以证明方法不是单纯提高答案分数，而是提高广告视频问答中的证据利用质量。

---

## 6. 第3章修改建议

### 6.1 方法名调整

不建议继续使用：

```text
热力图生成模块
视觉热力图方法
注意力热力图解释
```

建议统一为：

```text
视听-文字时空响应图
问题条件化证据响应图
广告视频证据定位响应图
证据保留型视觉输入重构
```

---

### 6.2 第3章应强调的内容

| 技术对象 | 应写成什么 | 不应写成什么 |
|---|---|---|
| 响应图 | 问题条件化证据选择函数 | 模型注意力可视化 |
| 局部图 | 局部高分辨率证据视图 | 普通 ROI 裁剪 |
| 关键帧 | 问题相关证据帧 | 均匀采样帧 |
| ASR | 参与时间证据定位的邻域线索 | 直接拼接到 Prompt |
| OCR/Logo | 局部区域定位和证据支持来源 | 额外文本提示 |
| 证据包 | 后续生成/验证接口 | 简单特征集合 |

---

### 6.3 可直接放入第3章的表述

> 广告视频中与问题相关的证据常以短时、局部、跨模态的形式出现。例如字幕、价格、Logo、包装文字和行动号召可能只在少数帧出现，旁白与画面也可能存在时间错位。因此，本文不采用均匀采样或事后热力图解释，而是构建问题条件化的视听-文字时空响应图，在候选帧、ASR 片段和 OCR/Logo 区域之间建立响应关系。该响应图用于生成全局语境视图和局部高分辨率证据视图，并输出包含 evidence_id、timestamp、bbox、source_type 和 confidence 的证据包，为后续答案生成和证据一致性验证提供可追溯输入。

## 7. 第4章修改建议

### 7.1 不建议继续主打“思维链”

不建议写：

```text
本文通过链式思维提升广告视频问答推理能力。
```

建议写：

```text
本文将答案生成约束为证据驱动的结构化输出过程，并将最终答案拆解为可验证声明，逐条回溯到视频证据、ASR、OCR 或广告知识条目进行一致性校验。
```

---

### 7.2 第4章更稳的结构

```text
4.1 证据包到答案生成的接口
4.2 广告知识条目与证据许可条件
4.3 证据约束的答案生成协议
4.4 答案声明拆解
4.5 声明-证据一致性校验
4.6 受控答案修正：CONFIRM / REVISE / REJECT / LOW_CONFIDENCE
4.7 与普通 CoT、RAG、Self-Refine、LLM Judge 的区别
```

## 8. 第5章实验建议

### 8.1 最小可交付实验组合

| 实验 | 目的 | 指标 |
|---|---|---|
| Qwen3 raw/uniform vs Qwen3 evidence no-RAG | 验证证据组织有效 | Accuracy / strict / relaxed |
| Uniform sampling vs question-aware frame selection | 验证问题条件化帧选择 | Accuracy、关键证据帧命中率 |
| Global only vs Local only vs Global+Local | 验证局部高分辨率证据视图 | OCR/Logo 子集准确率、Token |
| no-RAG vs evidence-aware RAG | 验证知识是否应由证据触发 | 知识一致性、无关知识注入率 |
| no verification vs evidence consistency check | 验证证据校验作用 | 幻觉率、误修正率 |

---

### 8.2 建议人工标注小集

不建议一开始做大规模像素级 mask 标注。更现实的是抽样 100-300 条 AdsQA 样本，标注时间段和证据类型。

建议标注格式：

```json
{
  "sample_id": "...",
  "question": "...",
  "answer": "...",
  "evidence_time": [start, end],
  "evidence_type": ["visual", "ocr", "asr", "logo", "product", "cta"],
  "ocr_or_logo_needed": true,
  "answer_supported_by_evidence": true
}
```

该小集可以支持以下指标：

- 时间证据命中率；
- OCR/Logo 证据召回；
- 答案-证据一致性；
- 幻觉/无依据推断比例。

## 10. 最终建议

1. 中期题目建议改为：

   > **基于视听证据定位与证据约束生成的广告视频问答方法**

2. 论文主线从：

   ```text
   视觉压缩 + RAG + CoT + Reflection
   ```

   改为：

   ```text
   证据定位 → 证据保留型输入重构 → 证据约束生成 → 答案-证据一致性验证
   ```

3. “热力图”最终定位为：

   > 证据响应图的可视化表达，而不是事后解释图。

4. “思维链”最终定位为：

   > 结构化输出形式，而不是论文创新点。

5. 第5章一定不要只报 Accuracy，还要补：

   - 证据定位质量；
   - Token / Latency；
   - 答案-证据一致性；
   - 幻觉率；
   - 误修正率或无依据推断比例。

## 11. 一句话版本

> 本文不应被概括为“热力图 + 思维链”，而应被概括为“面向广告视频问答的证据定位、证据保留型输入重构和证据约束生成方法”。热力图只是证据响应的表达形式，思维链只是结构化输出形式，真正的创新点应落在问题条件化证据选择和答案-证据一致性约束上。
