# Qwen3 声明证据验证器 OCR 补充校准实验预注册

## 1. 实验目的

Qwen3 RealClaim985 LoRA 在冻结 Calibration240 上相对冻结 Qwen3 基座取得了稳定的整体 AUROC 提升，但该校准集的 `ocr_present` 全为 `false`，因此无法检验 OCR 声明分层。

本实验只回答一个补充问题：

> 在视频中确有可见且跨帧稳定的 OCR 文字时，RealClaim985 LoRA 是否比冻结 Qwen3 基座更能区分“被画面文字支持”的声明与最小反事实声明？

本实验不重新训练模型、不选择阈值、不访问 Development244，也不测量最终 QA 准确率。

## 2. 数据来源与隔离

候选视频来自 AdsQA 测试视频及既有 64 帧 OCR 缓存，但必须排除：

- Pilot50；
- Confirm-A300、Confirm-B300、Confirm-C300；
- 冻结的 Confirm-D300；
- RealClaim985 训练视频；
- RealClaim Calibration240 和 Development244 视频。

构建过程禁止读取参考答案、历史预测、DeepSeek 分数或人工/LLM 标签。全部样本标记：

```text
answer_free=true
weak_ocr_labels=true
not_human_gold=true
```

目标为 80 个视频、80 个正负声明对，共 160 条；最低门禁为 50 个视频、50 对。

## 3. OCR 证据与声明构造

每个视频只选择一个 OCR 短语，必须满足：

- OCR 置信度不低于 0.90；
- 相同规范化文本至少出现在两个不同候选帧；
- 包含至少 4 个字母或数字；
- 归一化框面积在 `[0.001, 0.5]`；
- 排除疑似模型分数、时间戳、纯标点、明显乱码和极短噪声。

正声明 `E+`：

```text
The advertisement visibly displays the text "<OCR phrase>".
```

负声明 `E-` 使用另一候选视频中长度和字符类型相近的真实 OCR 短语替换，且该短语不得出现在当前视频的任一 OCR 检测中。正负声明共享同一视频、问题、ASR 和 8 个输入帧。

8 个帧必须包含代表性 OCR 帧，并按时间顺序补充上下文帧。不得进行二次帧采样。

## 4. 冻结比较

同一数据、同一提示、同一 8 视图和视觉 Token 上限比较：

1. 冻结 Qwen3-VL-8B；
2. 冻结 Qwen3-VL-8B + RealClaim985 LoRA。

另设 text-only 对照，删除全部图像但保持问题与声明文本不变，用于判断结果是否来自语言模式。

不得重新训练、扫描阈值、修改 Prompt、改变图片尺寸或只对某一方法增加视觉预算。

## 5. 指标与统计

报告：

- AUROC、AUPRC；
- 同视频配对准确率 `P(score(E+) > score(E-))`；
- 正负声明平均分差；
- 冻结 Qwen3 与 LoRA 的逐视频配对差；
- 10,000 次视频级 Bootstrap；
- text-only 对照；
- 实际视图数、视觉 Token 范围和二次采样审计。

## 6. 预注册门禁

OCR 补充能力门禁同时要求：

- 数据不少于 50 对且覆盖不少于 50 个视频；
- LoRA 视觉 AUROC 不低于 0.70；
- LoRA 视觉配对准确率不低于 0.70；
- LoRA 相对冻结 Qwen3 的 AUROC 点估计为正；
- 10,000 次视频级 Bootstrap 的相对 AUROC 差下界不低于 `-0.05`；
- LoRA 视觉配对准确率至少比其 text-only 对照高 `0.10`；
- 全部样本为 8 个视图、视觉 Token 不超预算、无二次采样；
- 无训练、Calibration240、Development244 或 Confirm-D 视频泄漏。

若门禁通过，只能说明 OCR 证据识别能力得到补充验证；不能据此宣称最终 QA 精度提高。若门禁失败，保留结果并把 OCR 分层记为未通过，不进行参数扫描。
