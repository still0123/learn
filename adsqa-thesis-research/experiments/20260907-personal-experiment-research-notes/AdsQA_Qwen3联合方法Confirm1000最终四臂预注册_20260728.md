# AdsQA Qwen3联合方法Confirm-1000最终四臂预注册

## 1. 目的

本实验只回答一个核心问题：在不修改既有阈值、触发率、Prompt、证据锚点和视觉 Token 协议的前提下，当前选择性视听证据补看方法能否在第二个 1,000 题方法级冻结确认集上继续提高 QA 正确率。

该集合已在任何本次推理开始前冻结。它包含 1,000 题、1,000 个唯一视频，Type 1–5 各 200 题，并与当前联合方法的训练、校准、开发和 Confirm-D300 视频隔离。

## 2. 固定模型

- 回答模型：干净的 `Qwen3-VL-8B`，不加载回答 LoRA；
- 支持度验证器：已冻结的 `Qwen3-VL-8B + RealClaim985 LoRA`；
- 回答模型、验证器权重、回答 Prompt、解码方式均不得根据 Confirm-1000 结果修改。

## 3. 四个实验臂

| 方法 | 输入与作用 |
|---|---|
| `Uniform8` | 8 个均匀时间帧，1,024 视觉 Token；主基线，同时作为 A0 初答 |
| `MMR8` | 64 帧候选上执行固定 `lambda=0.70` 的 CLIP-MMR，选 8 帧后按时间排序；强静态选帧基线 |
| `ExtraGlobalControl` | 与完整方法触发完全相同的 100 题、相同证据时刻、OCR/ASR、12 视图和 3,104 Token；把两个局部裁剪替换为 896 高分辨率完整帧 |
| `FullJointMethod` | 对支持度最低的 10% 题补看两个证据时刻，每个时刻输入 512 全帧和 896 中尺度裁剪，并加入 OCR 与分段 ASR |

`ExtraGlobalControl` 就是此前 `NoLocalCrop` 的严格计算量控制版本。它与完整方法唯一的核心视觉差异是高分辨率完整帧和局部裁剪，因此可以判断收益是否真的来自证据区域定位，而不是“多看四张图”。

## 4. 冻结触发与选择规则

1. 先为全部 1,000 题生成 `Uniform8` 初答；
2. 用冻结支持度验证器评估 A0；
3. 按 `P(A0)` 升序、再按 `question_id` 排序，选择最低 100 题；
4. 仅这 100 题运行完整补看和 ExtraGlobal 控制；
5. 两方法都使用同一答案切换规则：

```text
P(A2) >= 0.8933094143867493
and P(A0) < 0.8933094143867493
and P(A2) - P(A0) >= 0.25
```

不满足时必须回退 A0。不得把触发率从 10% 改为其他比例，也不得根据本确认集重新校准阈值。

## 5. 主要与次要比较

- 主要比较：`FullJointMethod - Uniform8`；
- 关键次要比较：`FullJointMethod - MMR8`；
- 机制比较：`FullJointMethod - ExtraGlobalControl`。

报告 Strict、Relaxed、胜平负、wrong→right、right→wrong、纠正精度、触发率、切换率、视觉 Token、延迟、Type 1–5 分层，以及按视频聚类的 10,000 次 Bootstrap 置信区间。

不能只报告点估计；不能在结果出现后从完整方法和 ExtraGlobal 中择优作为“最终方法”。
