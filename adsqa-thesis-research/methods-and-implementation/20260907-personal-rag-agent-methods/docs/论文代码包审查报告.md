## 4. 核心方法脚本 inference.py 审查

`inference.py` 是最接近你论文方法的脚本。

### 4.1 已实现内容

该脚本实现了：

1. 高频过采样：`oversample_count = 32`；
2. 语义关键帧优选：`top_k_frames = 16`；
3. CLIP 图文相似度筛帧；
4. Question + ASR 双流筛帧；
5. 视听 + OCR 融合响应图；
6. 动态锚框裁剪；
7. Global + Local 双流输入；
8. Rich factual prompt；
9. 基于关键词触发的反思；
10. 输出初始 reasoning、final prediction、ground truth、reflection_status。

### 4.2 关键类：S23VisualProcessor

该类对应论文第 3 章。

#### select_top_frames

实现：

```python
scores = question_score * 0.6 + audio_score * 0.4
```

对应论文：

```text
语义关键帧优选
问题响应 + ASR 响应
```

不足：

- 没有 OCR 加分；
- 没有 ASR 时间窗口，只用 asr_text[:100]；
- 没有输出 frame_id / timestamp。

#### smart_crop

实现：

```python
Question 50% + Audio 30% + OCR 20%
```

其中：

- 问题特征：question；
- 音频特征：audio_text；
- OCR 特征：固定文本 `text`, `logo`, `brand`, `words`；
- 响应图：patch-level CLIP similarity；
- 锚框：计算重心 + scales [0.6, 0.8, 1.0]；
- score：box_energy / scale^0.5。

这和你专利/论文第 3 章高度相关。

不足：

- OCR 不是实际 OCR 检测框，而是用固定 OCR prompt 近似；
- Logo 也不是实际 logo detection；
- 没有保存 bbox；
- 没有保存响应图；
- 没有证据包 JSON；
- `crop_ratio` 配置没有实际使用；
- `safe_audio` 和 `ocr_tokens` 的注释/代码格式有轻微混乱，但逻辑上仍可执行；
- 多尺度只有 0.6/0.8/1.0，论文中可以写为阶段性实现。

### 4.3 CoTReflectionPrompts

实现：

- initial_prompt：Observation / Reasoning / Answer；
- reflection_prompt：Fact-Checker，输出 `[KEEP]` 或 `[Final Answer]`。

对应论文第 4 章：

```text
结构化推理 + 触发式链式反思
```

不足：

- 还不是声明级证据回溯式反思；
- 没有 claim extraction；
- 没有 evidence_id；
- 没有 OCR/ASR/marketing claim 类型；
- 没有 CONFIRM / REVISE / REJECT / LOW_CONFIDENCE；
- 没有 RAG。
