> 论文题目：基于视觉特征压缩与链式反思的广告视频问答方法  
> 目的：给出可落地的代码结构、模块实现路线和实验设置，支撑第3章、第4章、第5章。

---

## 1. 总体实现思路

代码实现建议不要一开始就训练新模型，而是先实现一个**推理时增强框架**：

```text
数据读取
→ 视频采样 / ASR / OCR / 视觉标签
→ 证据包构建
→ 证据驱动 RAG
→ 多模态模型推理
→ 声明级证据回溯校验
→ 评测与消融
```

这样与论文当前方法一致，也更容易在有限时间内完成实验。

## 4.4 关键帧优选模块

文件：

```text
evidence/frame_selector.py
```

实现方式：

- 使用 CLIP / SigLIP / Chinese-CLIP 计算图文相似度；
- 文本查询为 `question + ASR summary + OCR text`；
- 选 Top-K。

建议简单实现：

```python
def select_keyframes(frames, question, asr_text, ocr_text, topk=8):
    query = question + " " + asr_text + " " + ocr_text
    scores = clip_similarity(frames, query)
    return topk_frames
```

消融：

```text
Uniform sampling
CLIP question only
CLIP question + ASR
CLIP question + ASR + OCR
```

## 4.5 响应图模块

文件：

```text
evidence/response_map.py
```

如果没有底层模型 attention，可以先用“近似实现”：

1. OCR bbox 区域直接加高响应；
2. Logo/brand/price 等关键词区域加权；
3. 若使用 CLIP patch 特征，可计算 patch-text similarity；
4. ASR 邻域根据时间窗口加权。

建议先实现工程可跑版本：

```python
def build_response_map(frame, question, asr_window, ocr_boxes):
    H_q = patch_text_similarity(frame, question)
    H_a = patch_text_similarity(frame, asr_window)
    H_o = ocr_box_heatmap(ocr_boxes)
    H = alpha * H_q + beta * H_a + gamma * H_o
    return H
```

如果 patch-level CLIP 实现困难，可先用 bbox-based heatmap + image-text global score 近似。

## 5.6 评价方式

优先级：

1. 如果 AdsQA 有标准答案，先用 exact/semantic judge；
2. 自动裁判用 DeepSeek-V3 / Qwen；
3. 抽样人工复核 200-500 条；
4. 记录 judge prompt。

不要只依赖一个 LLM judge。

## 6. 推荐实现顺序

### 第一步：只跑文本链路

先不做复杂图像响应图，只用：

```text
已有帧 + ASR + OCR + RAG + MLLM + judge
```

目标：跑通完整 pipeline。

### 第二步：加入关键帧选择

加入 CLIP Top-K。

### 第三步：加入 OCR bbox heatmap 和 local crop

先实现 OCR 区域局部裁剪。

### 第四步：加入 ASR window

比较 ASR prompt vs window evidence。

### 第五步：加入 reflection

实现声明抽取和证据核查。

### 第六步：补实验表

按第 5 章最小实验组合填数据。

## 7. 风险与替代方案

| 风险 | 替代方案 |
|---|---|
| 没有 AdsQA 原始视频 | 使用已有输出或抽样广告视频构造小规模验证集 |
| OCR 效果差 | 使用 MLLM 对局部图读取文字，或人工标注部分 OCR |
| Logo 检测难 | 先用 OCR/视觉标签替代 Logo 检测 |
| Patch-level CLIP 难实现 | 先用 OCR bbox heatmap + global CLIP score |
| MLLM 推理太慢 | 先小样本跑消融，报告子集实验 |
| LLM judge 不稳定 | 加人工抽样复核 |

---

## 8. 明确不能做的事

1. 不能编造实验结果；
2. 不能声称压缩 40% 除非有真实 latency/token 数据；
3. 不能把 AVAM 当已核查参考文献，除非找到真实链接；
4. 不能只报告 Accuracy，不报告 Token/Latency；
5. 不能只做 Full vs Base，必须至少做关键消融。
