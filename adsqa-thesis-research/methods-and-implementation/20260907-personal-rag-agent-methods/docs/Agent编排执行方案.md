## 1. 编排目标

围绕硕士论文后续完善任务，将工作拆成“主控 Agent + 专项写作 Agent + 实验 Agent + 质检 Agent”的结构，避免一个 Agent 同时处理所有章节导致逻辑不一致、术语混乱或实验支撑不足。

当前主线保持为：

> 广告视频信息密度高、声画异步、领域知识缺失且生成结果易幻觉，因此本文提出“视听协同特征压缩 + 广告知识增强 RAG + 链式校验优化”的广告视频问答框架。

- RAG MVP 扩展文件。

**输出：**
