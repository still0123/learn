# 广告视频内容检索分析系统V1.0 代码材料清单

这份清单用于配合软著代码材料整理。代码材料不从中间片段拼凑，而是按文件顺序读取完整源码文件；每个文件保持原始顺序，能够回到项目目录中直接运行或参与测试。

## 一、软件名称与版本

软件全称：广告视频内容检索分析系统

版本号：V1.0

代码页眉建议写作：广告视频内容检索分析系统V1.0

上述名称应与申请表、使用说明书标题、代码材料页眉保持一致。

## 二、代码材料范围

核心系统代码位于：

```text
ad_video_analysis_system/
```

该目录包含 Flask Web 服务、SQLite 数据存储、素材管理、内容预处理、语义检索、问答分析、历史记录和前端界面代码。为了和论文、专利及已有实验代码衔接，代码材料清单还纳入 `code_refactor/` 中的数据读取、证据包构建、知识检索、提示生成、声明校验和测试脚本。

固定清单由下面脚本维护：

```text
ad_video_analysis_system/scripts/source_audit.py
```

导出代码材料 PDF 使用：

```bash
cd ${PROJECT_DIR}/ad_video_analysis_system
PYTHONPATH=scripts python3 scripts/export_code_material.py
```

## 三、连续性说明

导出脚本按固定顺序读取完整文件，不抽取函数中间段，也不删除文件内部行。若总页数超过 60 页，脚本会生成前 30 页与后 30 页组成的 60 页代码材料；若总页数不足 60 页，则导出全部源码页。

代码材料所列源码的运行入口为：

```bash
cd ${PROJECT_DIR}/ad_video_analysis_system
python3 -m pip install -r requirements.txt
python3 run.py --host 127.0.0.1 --port 8765
```

核心烟测命令为：

```bash
cd ${PROJECT_DIR}/ad_video_analysis_system
PYTHONPATH=. python3 scripts/smoke_test.py
```

## 四、注释比例控制

代码材料脚本会统计总行数、非空行数、注释行数和注释占比。当前要求是注释不超过 10%，因此正式导出前应运行：

```bash
cd ${PROJECT_DIR}/ad_video_analysis_system
PYTHONPATH=scripts python3 scripts/source_audit.py
```

审计结果会写入：

```text
output/source_audit.json
output/source_audit.md
```

## 五、敏感信息检查

代码材料导出前需要检查绝对路径、服务器地址和凭证关键词。`source_audit.py` 会扫描常见风险词，例如个人本机目录、服务器数据目录、用户目录、内网 IP、密码、令牌和接口密钥等。若命中旧实验脚本中的路径，正式提交前应将其改成 `${PROJECT_DIR}`、`${DATA_DIR}`、`${MODEL_DIR}` 或 `${OUTPUT_DIR}` 一类占位符。

## 六、说明书写作备注

说明书应围绕当前系统真实页面和真实处理链路写，不把“多模态大模型”写成自研能力，也不宣称已实现没有代码支撑的功能。界面部分可引用总览、视频素材管理、内容预处理、语义检索、问答分析和历史记录管理六张截图。
