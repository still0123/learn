# 广告视频内容检索分析系统V1.0 软件说明书

## 1. 软件概述

### 1.1 软件名称

软件全称：**广告视频内容检索分析系统**

软件简称：**广告视频检索分析系统**

版本号：**V1.0**

### 1.2 软件用途

广告视频内容检索分析系统V1.0 是一款面向广告视频内容理解和智能问答场景的软件系统。系统支持读取广告视频问答样本、语音识别文本、视频元信息和广告营销知识库，并将问题文本、视频编号、ASR 文本、视觉帧路径、广告证据类型和检索知识统一组织为结构化数据，用于广告视频问答分析、营销语义解释、证据辅助推理和结果复核。

系统主要用于广告视频内容分析、广告素材理解、多模态问答实验、广告营销知识检索、模型推理辅助、答案声明拆解和结果统计等场景。系统 V1.0 重点实现广告视频问答流程中的数据读取、证据包构建、知识检索、结构化提示生成、声明校验计划生成和结果统计等功能。

### 1.3 适用对象

本软件适用于以下用户和场景：

1. 广告视频内容分析人员；
2. 多模态问答任务研究人员；
3. 广告营销语义分析人员；
4. 视频内容理解系统开发人员；
5. 广告素材审核和复核辅助场景；
6. 广告视频问答模型实验和评估场景。

### 1.4 软件特点

1. 支持广告视频问答数据读取与样本标准化；
2. 支持 ASR 语音文本与视频问答样本关联；
3. 支持构建面向广告视频问答的多源证据包；
4. 支持广告营销知识条目的结构化管理与检索；
5. 支持证据驱动的知识召回与重排序；
6. 支持生成结构化问答提示内容；
7. 支持对答案文本进行声明拆分和校验计划生成；
8. 支持推理结果保存、覆盖率统计和运行摘要导出；
9. 支持本地 dry-run 模式验证核心流程；
10. 支持后续接入多模态模型、OCR、Logo 检测、向量检索和更完整的证据回查模块。

## 2. 运行环境

### 2.1 硬件环境

本软件可根据运行模式部署在普通计算机或 GPU 服务器上。

轻量级本地验证模式建议配置：

1. CPU：普通多核处理器；
2. 内存：8GB 及以上；
3. 磁盘：具备存放数据、知识库、索引和输出结果的空间。

多模态模型推理模式建议配置：

1. CPU：多核处理器；
2. GPU：支持 CUDA 的 NVIDIA GPU；
3. 显存：根据所加载模型规模确定；
4. 内存：16GB 及以上；
5. 磁盘：具备存放模型文件、视频帧、数据集和推理结果的空间。

### 2.2 软件环境

1. 操作系统：Linux、macOS 或 Windows；
2. 编程语言：Python 3；
3. Web 服务框架：Flask；
4. 数据存储：SQLite；
5. 前端运行环境：Chrome、Edge、Safari 等现代浏览器；
6. 大模型问答扩展：支持接入 OpenAI-compatible Chat Completions 接口；
7. 多模态模型推理扩展：根据实际运行环境可接入 PyTorch、Transformers、CUDA 环境及相应模型工具包；
8. 视频处理扩展：根据实际运行环境可接入 decord、OpenCV、FFmpeg 等组件；
9. 检索扩展：可选接入 sentence-transformers、FlagEmbedding、Transformers 等嵌入模型后端。

### 2.3 部署方式

系统 V1.0 采用轻量 B/S 架构运行。用户在本地启动 Flask 服务后，通过浏览器进入系统界面，完成素材登记、内容预处理、语义检索、问答分析和历史记录查看。核心流程可在普通计算机上完成；如需使用大模型回答，可配置第三方大模型接口作为问答分析引擎。若接口未配置或调用失败，系统会回退到本地检索式问答，保证基本功能可继续使用。

## 3. 系统总体架构

本软件采用 Flask Web 服务、SQLite 数据库和原生前端页面组成的模块化分层架构，整体包括界面交互层、数据存储层、数据接入层、证据组织层、知识检索层、推理组织层、声明校验层和结果输出层。

### 3.1 界面交互层

界面交互层负责向用户提供浏览器操作页面。用户可在左侧导航中切换总览、视频素材管理、内容预处理、语义检索、问答分析和历史记录管理等功能页面，在右侧工作区完成素材录入、问题输入、结果查看和记录维护。界面通过 Flask 提供的接口读取或提交数据，页面刷新后可以重新加载数据库中的最新状态。

### 3.2 数据存储层

数据存储层使用 SQLite 数据库保存系统运行数据。数据库中保存广告视频素材、广告营销知识条目、问答分析历史和系统配置。素材登记、预处理状态更新、问答记录保存和历史清理等操作都会写入本地数据库，便于用户在多次运行系统时继续查看已有记录。

### 3.3 数据接入层

数据接入层负责读取广告视频问答相关输入文件，包括问题数据、标准答案数据、ASR 文本数据、视频编号、任务类型和样本元信息。系统将不同来源的数据合并为统一样本对象，为后续证据构建和检索推理提供输入。

### 3.4 证据组织层

证据组织层负责将问题文本、视频编号、ASR 文本、元信息、视觉帧路径、OCR 字段、Logo 字段和广告证据类型封装为统一证据包。证据包为后续知识检索、结构化提示生成和声明校验计划提供统一数据接口。

### 3.5 知识检索层

知识检索层负责读取广告营销知识库，并根据当前问题和证据包内容召回相关广告知识。系统支持基于词项匹配、TF 余弦相似度、证据匹配分数和混合检索接口的知识召回与排序。

### 3.6 推理组织层

推理组织层负责将问题、证据包和检索知识组织为结构化提示内容。提示内容按照观察信息、知识匹配、分析过程和答案输出的结构生成，用于辅助第三方大模型或本地检索式问答模块完成广告视频问答分析。系统记录回答来源、模型名称、调用状态和回退原因，便于后续复核。

### 3.7 声明校验层

声明校验层负责对答案文本进行声明拆分和类型识别，生成不同类型声明所需的证据校验计划。系统可识别视觉内容、OCR/Logo 文字、ASR 语音文本和营销推理等不同声明类型，为后续答案复核和证据回查提供依据。

### 3.8 输出与评估层

输出与评估层负责保存系统运行过程中的中间结果和最终结果，包括证据包、检索知识、结构化提示、声明校验计划、预测答案、运行摘要和覆盖率统计报告等。

## 4. 功能模块说明

### 4.1 广告视频问答数据适配模块

该模块负责读取广告视频问答数据文件，并将问题、答案、视频编号、任务类型和 ASR 文本进行合并。模块支持将原始任务类型字段映射为系统内部任务类别，并统计样本数量、视频数量、任务类型分布和重复问题编号等信息。

主要功能包括：

1. 读取问题文件；
2. 读取标准答案文件；
3. 读取 ASR 文本文件；
4. 合并样本字段；
5. 生成统一样本对象；
6. 统计样本和任务类型分布。

### 4.2 多模态证据包构建模块

该模块负责构建面向广告视频问答的证据包。证据包可包含问题文本、视频编号、ASR 文本、元信息、OCR 文本字段、Logo 文本字段、视觉标签、广告证据类型、全局视觉视图字段和局部证据视图字段。

系统 V1.0 已实现文本级和元信息级证据组织，并为后续接入真实 OCR、Logo 检测和局部视觉区域信息预留字段。

主要功能包括：

1. 生成证据包对象；
2. 封装问题、ASR 和元信息；
3. 维护 OCR、Logo 和视觉字段；
4. 标记广告证据类型；
5. 生成可用于检索和提示构造的证据文本。

### 4.3 广告证据类型识别模块

该模块根据问题、ASR 文本、元信息和相关证据字段，识别广告视频问答中可能涉及的广告证据类型。系统支持识别稀缺、行动号召、社会认同、权威背书、情绪诉求、受众定位、品牌信息、价格信息等广告线索。

主要功能包括：

1. 根据关键词识别广告证据类型；
2. 为知识检索提供检索标签；
3. 为结构化提示生成提供广告语义线索；
4. 为声明校验计划提供声明类型参考。

### 4.4 广告营销知识条目管理模块

该模块负责读取和管理广告营销知识库。系统将原始知识条目转换为统一的知识对象，并抽取知识标题、类别、关键词、营销逻辑、行业语境、风险提示和版本信息等字段。

主要功能包括：

1. 读取原始知识库；
2. 转换知识条目结构；
3. 抽取关键词；
4. 标记风险提示；
5. 生成统一知识对象；
6. 保存规范化知识库。

### 4.5 证据驱动知识检索模块

该模块根据用户问题和证据包内容构造检索查询，并从广告营销知识库中召回相关知识条目。系统默认支持轻量级词项匹配、TF 余弦相似度和证据匹配分数融合，并提供 embedding 和 hybrid 检索扩展接口。

主要功能包括：

1. 构造检索查询；
2. 计算词项匹配分数；
3. 计算文本相似度；
4. 计算证据匹配得分；
5. 融合排序得分；
6. 输出知识编号、匹配原因和支持证据编号。

### 4.6 向量化与混合检索扩展模块

该模块提供知识库向量化和混合检索能力的扩展接口。系统支持 hashing 嵌入后端，并可扩展接入 sentence-transformers、FlagEmbedding 和 Transformers mean pooling 等嵌入模型。

主要功能包括：

1. 构建知识库向量索引；
2. 保存和加载索引文件；
3. 支持 embedding 检索；
4. 支持 lexical 与 embedding 的混合检索；
5. 支持不同嵌入后端切换。

### 4.7 结构化问答提示生成模块

该模块负责将问题、证据包和检索知识组织为结构化提示内容。提示内容按照观察信息、知识匹配、分析说明和答案输出的结构生成，并要求模型尽量基于已有证据和允许知识进行回答。

主要功能包括：

1. 读取证据包；
2. 读取检索知识；
3. 构造观察信息；
4. 构造知识匹配信息；
5. 构造回答约束；
6. 生成完整提示文本。

### 4.8 多模态模型推理适配模块

该模块负责对接外部或开源多模态模型，用于广告视频问答推理。系统保留多个模型推理适配脚本，可根据不同实验环境调用不同模型进行问答生成。

主要功能包括：

1. 加载多模态模型；
2. 读取视频帧路径；
3. 拼接问题、ASR 和结构化提示；
4. 执行模型推理；
5. 保存预测答案；
6. 记录运行耗时和状态。

说明：本模块用于模型调用和流程编排，不主张对第三方基础模型本身享有著作权。

### 4.9 答案声明拆分与校验计划模块

该模块负责对答案文本进行声明拆分，并根据声明内容识别其所需证据类型。系统可识别视觉声明、OCR/Logo 声明、ASR 声明和营销推理声明，并生成对应的证据校验计划。

主要功能包括：

1. 拆分答案文本；
2. 生成声明编号；
3. 判断声明类型；
4. 匹配所需证据来源；
5. 输出声明校验计划；
6. 支持后续人工或自动证据回查。

### 4.10 推理结果保存与覆盖率统计模块

该模块负责保存推理结果和统计预测覆盖情况。系统可读取预测结果目录，与标准答案进行对齐，并统计整体样本覆盖率和不同任务类型下的覆盖情况。

主要功能包括：

1. 保存预测结果；
2. 保存运行摘要；
3. 读取预测目录；
4. 对齐标准答案；
5. 统计覆盖率；
6. 按任务类型生成统计报告。

### 4.11 实验配置与批量运行管理模块

该模块负责组织实验参数、运行路径和批量样本处理流程。系统支持设置起止样本编号、输出目录、模型路径、GPU 编号、知识检索数量和 dry-run 模式等参数。

主要功能包括：

1. 解析命令行参数；
2. 创建输出目录；
3. 批量处理样本；
4. 跳过异常样本；
5. 记录错误信息；
6. 输出运行摘要。

## 5. 业务流程

### 5.1 系统初始化流程

1. 用户准备广告视频问答问题文件、答案文件、ASR 文件和广告营销知识库；
2. 系统读取运行参数；
3. 系统检查输入路径和输出路径；
4. 系统加载问题、答案和 ASR 文本；
5. 系统加载广告营销知识库；
6. 系统初始化检索器和输出目录；
7. 系统进入样本处理流程。

### 5.2 单样本处理流程

1. 系统读取一个广告视频问答样本；
2. 获取问题文本、视频编号、参考答案、任务类型和 ASR 文本；
3. 构建统一样本对象；
4. 构建多模态证据包；
5. 根据问题和证据包构造检索查询；
6. 从广告营销知识库中检索相关知识；
7. 将问题、证据包和知识条目组织为结构化提示；
8. 生成答案声明校验计划；
9. 在 dry-run 模式下保存流水线 JSON；
10. 在正式推理模式下调用模型生成预测答案；
11. 保存预测结果和运行摘要。

### 5.3 检索增强流程

1. 系统读取广告营销知识库；
2. 将知识条目转换为统一结构；
3. 根据当前问题、ASR、元信息和广告证据类型构造查询文本；
4. 计算查询与知识条目的匹配得分；
5. 结合证据匹配情况进行重排序；
6. 返回 Top-K 知识条目；
7. 将知识条目写入结构化提示。

### 5.4 声明校验计划生成流程

1. 系统读取答案文本或候选答案；
2. 对答案进行句子或短语级拆分；
3. 为每条声明分配声明编号；
4. 判断声明属于视觉、OCR/Logo、ASR 或营销推理类型；
5. 生成该声明需要查验的证据类型；
6. 输出声明校验计划，供后续自动或人工复核。

### 5.5 结果统计流程

1. 系统读取预测结果目录；
2. 解析预测文件；
3. 读取标准答案文件；
4. 按问题编号对齐；
5. 统计已生成预测结果的样本数量；
6. 按任务类型统计覆盖情况；
7. 输出统计报告。

## 6. 输入输出说明

### 6.1 输入数据

系统主要输入包括：

4. 广告营销知识库文件；
5. 视频帧路径或视频文件路径；
6. 模型路径；
7. 运行参数配置。

### 6.2 中间数据

系统运行过程中可生成：

1. 统一样本对象；
2. 多模态证据包；
3. 检索查询文本；
4. 检索知识条目；
5. 结构化提示内容；
6. 声明校验计划；
7. 视频帧路径列表；
8. 运行日志。

### 6.3 输出数据

系统主要输出包括：

1. 单样本流水线 JSON；
2. 检索知识结果；
3. 结构化提示内容；
4. 声明校验计划；
5. 模型预测答案；
6. 运行摘要文件；
7. 覆盖率统计报告。

## 7. 异常处理

### 7.1 输入文件缺失

当问题文件、答案文件、ASR 文件或知识库文件不存在时，系统输出错误信息，并提示用户检查文件路径。

### 7.2 数据格式异常

当输入 JSON 文件格式错误或字段缺失时，系统记录异常样本信息。对于单条样本异常，可跳过该样本并继续处理后续样本。

### 7.3 视频帧路径异常

当视频帧路径不存在或为空时，系统可继续执行文本级证据构建、知识检索和提示生成流程，并在输出文件中记录帧路径为空。

### 7.4 模型加载异常

当模型路径不存在、GPU 不可用、依赖库缺失或模型加载失败时，系统停止正式模型推理流程，并提示用户检查模型环境。用户可切换 dry-run 模式验证非模型部分流程。

### 7.5 检索结果为空

当检索模块未召回相关知识时，系统仍可基于当前证据包生成提示内容，并在结果中记录无外部知识命中。

### 7.6 单样本推理失败

当单个样本推理失败时，系统记录问题编号、视频编号和错误原因，并继续处理后续样本。运行摘要中记录错误列表。

### 7.7 输出目录异常

当输出目录不存在时，系统自动创建；当输出目录无写入权限时，系统提示权限错误。

## 8. 系统特点

1. **面向广告视频问答场景**：系统围绕广告视频问答任务设计，能够处理问题、ASR、视频编号、任务类型和广告知识等多类输入。
2. **多源证据统一组织**：系统通过证据包结构统一管理不同来源的信息，为检索和推理提供统一接口。
3. **证据驱动知识检索**：系统根据问题和证据包内容召回广告营销知识，并记录知识得分和支持证据。
4. **结构化提示生成**：系统将证据和知识组织为结构化提示，辅助模型按统一格式进行回答。
5. **声明校验计划生成**：系统对答案声明进行拆分和分类，为后续证据回查提供基础。
6. **支持本地 dry-run 验证**：系统可在不加载大型模型的情况下验证主要数据流和模块连接。
7. **支持多模型实验适配**：系统保留多种多模态模型的推理入口，便于不同模型在广告视频问答任务上的实验。
8. **模块化结构便于扩展**：系统可继续扩展 OCR、Logo 检测、向量检索、视觉证据回查、自动评测等功能。

## 9. V1.0 功能边界说明

本软件 V1.0 已实现广告视频问答数据读取、文本级证据包构建、广告营销知识条目管理、证据驱动知识检索、结构化提示生成、声明校验计划生成、推理结果保存和覆盖率统计等功能。

V1.0 中部分能力作为扩展接口或原型能力存在，例如完整 OCR 检测、Logo 检测、精确局部边界框证据、自动事实判定和完整多模态证据回查等。相关内容在说明书中应表述为“支持接入”“预留字段”或“可扩展”，不宜表述为已经完整工程化实现。
